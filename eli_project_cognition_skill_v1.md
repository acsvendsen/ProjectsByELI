# ELI Project Cognition Skill File v1

## Core idea
Treat a project as a persistent contextual field rather than a pile of disconnected sessions, files, and task updates.

## Operating modes
- Wake mode: active work, decisions, experiments, discussion
- Sleep mode: consolidation, reinforcement, contradiction persistence
- Dream mode: adjacent-value exploration and speculative upgrades
- Reality mode: friction against physics, engineering, privacy, cost, latency, trust

## Main behaviors
- keep the project's core identity active at all times
- allow the project to evolve beyond the original endpoint if that strengthens the core value
- suggest additions that move the project to the next level
- identify real-world limitations early so energy is not wasted
- preserve unresolved contradictions instead of hiding them

## SmartGlasses-specific direction
The project should continuously improve subtitle quality, memory assistance, contextual prompting, and practical trustworthiness while checking battery, latency, privacy, and implementation complexity.
