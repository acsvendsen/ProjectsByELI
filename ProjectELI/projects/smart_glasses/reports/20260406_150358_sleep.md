# Consolidation for SmartGlasses V1 Direction

## Strengthening Signals
- **Subtitle Quality:** Subtitles must remain near-real-time to maintain trust, with emphasis on fast and accurate text placement.
- **Face/Name Recall:** Memory reinforcement over time is essential for building confidence in face/name recall accuracy.

## Weakening Signals
- **Feature Bloat:** Avoid adding unnecessary features or interactions until they directly support the core mission. 
- **Complex Interactions:** Stick to frame-touch interactions; avoid voice activation or complex multimodal UIs in V1.

## Contradictions That Must Stay Alive
- **Privacy vs Usefulness:** Balance the need for rich memory with clear privacy controls and user comfort.
- **Battery Constraints:** Always-on features must respect battery limits, ensuring subtitles remain usable without draining power too quickly.

## Dormant Ideas Worth Reactivating
- **Subtitle Placement:** Revisit subtitle placement to ensure it is both visible and non-distracting, based on real-world usage feedback.
- **Memory Cache Policy:** Consider a more detailed memory cache policy that balances offline usability with privacy concerns.

## Concrete Tensions Around Key Areas
1. **Subtitle Quality:**
   - **Tension:** Fast enough subtitles vs battery drain.
   - **Decision Area:** Optimize subtitle rendering for speed while minimizing thermal and power usage on the glasses.

2. **Confidence Trust:**
   - **Tension:** How to represent confidence clearly without overwhelming the user.
   - **Decision Area:** Use a label + short reason approach, possibly incorporating a numeric score for developers but not displaying it directly to the user.

3. **Automatic Memory Behavior vs Explicit Remember-Touch Behavior:**
   - **Tension:** How much should the system automatically remember versus relying on explicit touch input from the user.
   - **Decision Area:** Focus on automatic memory reinforcement over time, with explicit touch inputs used for rapid confirmation or correction.

4. **Fast Lookup Requirements:**
   - **Tension:** Balancing rich context with low-latency response times.
   - **Decision Area:** Implement a caching strategy that prioritizes frequently accessed information while minimizing latency.

5. **Privacy:**
   - **Tension:** Rich memory vs privacy perception.
   - **Decision Area:** Design memory storage and retrieval policies to ensure user data is handled transparently and securely, with options for users to manage their own data.

6. **Visual UX:**
   - **Tension:** Discreet UX vs enough visual clarity.
   - **Decision Area:** Ensure subtitles are clear but not overly intrusive, using a balanced approach between visibility and distraction.

7. **Battery & Thermals:**
   - **Tension:** Always-on sensing vs battery and thermal constraints.
   - **Decision Area:** Optimize local processing on the glasses for minimal impact while leveraging phone resources for heavier tasks when necessary.

## Open Questions
- **Subtitle Placement:** What subtitle placement is most usable without becoming distracting?
- **Confidence Display:** How should confidence be represented: numeric score, label, and short reason?

## Summary of Core Mission and Tensions

### Core Mission:
Create smart glasses that act as a discreet, context-aware personal assistant focusing on live subtitles, face/name recall, conversation memory, and one-line support to help the wearer understand and respond better in real-world interactions.

### Key Tensions:
- **Subtitle Quality vs Battery Drain:** Optimize subtitle rendering for speed while minimizing thermal and power usage.
- **Confidence Trust vs Privacy Perception:** Balance rich memory with clear privacy controls.
- **Automatic Memory Behavior vs Explicit Remember-Touch Behavior:** Focus on automatic memory reinforcement over time, but allow explicit user inputs for rapid confirmation or correction.
- **Fast Lookup Requirements vs Low-Latency Response Times:** Implement a caching strategy that prioritizes frequently accessed information while minimizing latency.
- **Discreet UX vs Visual Clarity:** Ensure subtitles are clear but not overly intrusive.

### V1 Guardrails
- Stick to frame-touch interactions only.
- Prefer phone-first architecture with cloud optional where clearly justified.
- Focus on real utility and avoid unnecessary feature sprawl or hardware complexity.
