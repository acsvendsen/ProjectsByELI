# Consolidation of Core Signals for SmartGlasses V1

## Strengthening Signals

### 1. **Subtitle Quality**
   - Subtitles must feel near-real-time to maintain trust.
   - Subtitle placement should be optimized for readability without distraction.

### 2. **Memory Trust and Lookup**
   - Face/name recall must clearly expose uncertainty, building confidence over time.
   - Memory storage and lookup should focus on high-value, relevant information.

### 3. **Low-Friction UX**
   - Interaction should remain minimal, using frame touches only to keep the experience discreet and non-intrusive.
   - One-line prompts should be concise and clear, enhancing rather than overwhelming the wearer.

## Weakening Signals

### 1. **Complex Interaction Patterns**
   - Avoid adding voice commands or spoken user controls in V1 to maintain focus on core functionalities.
   - Complex multimodal UIs are not prioritized in this version.

### 2. **Heavy On-Glasses Processing**
   - Early versions should rely heavily on the phone for processing, reducing thermal and battery load on glasses.
   - Full on-glasses inference is not a priority at this stage.

## Contradictions That Must Stay Alive

### 1. **Privacy vs Usefulness**
   - The system must balance providing useful assistance with respecting user privacy.
   - Memory storage should be optimized for high-value information while minimizing unnecessary data collection.

### 2. **Always-On Sensing vs Battery and Thermals**
   - Always-on sensing can introduce significant battery and thermal issues, so it is not a priority in V1.
   - Subtitle generation must remain fast to avoid draining the battery or overheating the glasses.

## Dormant Ideas Worth Reactivating

### 1. **Subtitle Placement Optimization**
   - Revisit subtitle placement options that balance readability with minimal distraction.
   - Consider user feedback on current placements and adjust accordingly.

### 2. **Confidence Display Formats**
   - Explore different formats for confidence display, such as labels, short reasons, or numeric scores, to find the best balance between trust and usability.

## Concrete Tensions Around Key Areas

### 1. **Subtitle Quality, Confidence Trust, Memory Lookup, Privacy, Latency, Battery, Visual UX**

   - **Subtitle Quality**: Subtitles must be accurate and timely to maintain user trust.
   - **Confidence Trust**: Face/name recall should provide clear indications of certainty or uncertainty.
   - **Memory Lookup**: The system should efficiently store and retrieve relevant memory without overwhelming the wearer.
   - **Privacy**: Memory storage must respect privacy, avoiding unnecessary data collection.
   - **Latency**: Subtitle generation and memory lookup should remain fast to ensure real-time responses.
   - **Battery**: On-glasses processing must be minimized to reduce battery drain.
   - **Visual UX**: The visual design of subtitles and prompts should be clear and unobtrusive.
