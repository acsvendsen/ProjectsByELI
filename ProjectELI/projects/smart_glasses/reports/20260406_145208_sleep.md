# Consolidation of Key Signals for SmartGlasses V1

## Strengthening Signals
- **Subtitle Quality**: The need for near-real-time subtitles is increasing as more users report difficulties understanding spoken content, especially in noisy environments. This reinforces the importance of minimizing latency and ensuring clear, legible text.
- **Memory Reinforcement**: Users are finding value in being reminded of previously encountered faces and names, particularly in multi-person conversations. Enhancing memory recall through explicit touch interactions is becoming a more critical feature.

## Weakening Signals
- **Complex Interactions**: There is less emphasis on introducing complex interaction methods such as voice commands or additional hardware features like eye tracking for V1. Frame-touch input remains the preferred method.
- **Feature Bloat**: Users are starting to see value in simpler, focused features rather than a wide array of options. The current focus on live subtitles, face/name recall, and conversation memory is gaining more traction.

## Contradictions That Must Stay Alive
- **Privacy vs Usefulness**: There is an ongoing tension between providing useful assistance through personal data (like name memories) and maintaining privacy to avoid social stigma or concerns.
- **Low Latency vs Battery Life**: The need for fast, responsive subtitles and memory recall is in conflict with the constraint of minimizing battery drain. This will require careful balancing.

## Dormant Ideas Worth Reactivating
- **One-Line Support**: Users are expressing interest in short, contextual prompts rather than long paragraphs. Reactivating this feature could enhance daily use value.
- **Subtitle Placement and Visual Hierarchy**: There is a need to revisit the placement of subtitles and how they integrate with the overall visual experience.

## Concrete Tensions Around Core Domains
1. **Subtitle Quality vs Battery Life**:
   - Subtitles must remain fast and clear but cannot significantly drain battery life.
2. **Memory Policy vs Privacy**:
   - Memory should be reinforced for useful recall, but privacy concerns dictate how much and when to cache personal data.
3. **Fast Lookup vs Always-On Sensing**:
   - Balancing the need for quick memory access with the constraints of always-on sensing is crucial.
4. **Discreet UX vs Visual Clarity**:
   - Ensuring subtitles and prompts are clear enough for understanding while not being distracting remains a key challenge.

## Open Questions
- **Subtitle Placement**: What is the best position for subtitles to be visible without causing distraction?
- **Confidence Display**: How should confidence in memory recall be represented (label only, label + short reason, or score + label)?
- **Memory/Cache Policy**: How much face/name memory should be cached locally on the phone versus requiring cloud support?

## Action Items
- **Subtitle Placement and Visual Hierarchy**: Conduct a usability test to determine the best subtitle placement.
- **Confidence Display**: Explore different formats for confidence labels to find the most effective one.
- **Memory/Cache Policy**: Define local caching strategies that balance memory reinforcement with privacy concerns.

## Reality Check
- The project should continuously surface real-world limitations early, including hardware, battery, thermals, latency, privacy, and usability constraints. This ensures resources are directed where they will have the greatest impact.
