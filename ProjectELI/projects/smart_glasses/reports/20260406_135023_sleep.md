# Consolidated Sleep Cycle for SmartGlasses V1

## Strengthening Signals
- **Subtitle Quality**: Subtitles must remain near-real-time to maintain trust.
- **Face/Name Recall**: Confidence objects should be prominently displayed to build user trust.
- **Memory Reinforcement**: Automatic memory behavior needs continuous improvement to ensure new faces and names are remembered with confidence over time.

## Weakening Signals
- **Complex Multimodal UI**: Avoid adding complex multimodal interactions in V1; focus on touch-first input.
- **Heavy Autonomous Behavior**: Limit autonomous actions without strong confidence signals until later iterations.
- **Social Acceptability Concerns**: Address social acceptability by keeping the glasses lightweight and discreet.

## Contradictions that Must Stay Alive
- **Always-on Sensing vs Battery Pressure**: Prioritize always-on sensing for critical features like subtitles, but be mindful of battery constraints.
- **Rich Context vs Low-latency Response**: Optimize for low-latency responses to maintain user trust while providing rich contextual support.

## Dormant Ideas Worth Reactivating
- **Subtitle Placement and Visual Hierarchy**: Revisit subtitle placement and visual hierarchy to ensure optimal readability without distraction.
- **Confidence Display Formats**: Explore different confidence display formats (label, label + short reason, score + label) to find the best balance between clarity and user trust.

## Concrete Tensions Around Core Areas
1. **Subtitle Quality**
   - **Latency vs Readability**: Strive for minimal latency without sacrificing readability.
   - **Visual Distraction**: Ensure subtitles do not distract the wearer but provide sufficient information.

2. **Confidence Display**
   - **Label Clarity vs Confidence Perception**: Find a balance between clear labels and building trust through additional context or scores.
   - **Placement and Visibility**: Optimize subtitle placement for easy reading while minimizing visual clutter.

3. **Memory System**
   - **Fast Lookup vs False Confidence**: Implement fast memory lookup without risking the perception of false confidence in recall accuracy.
   - **Privacy Perception**: Ensure that memory storage and use do not compromise user privacy, maintaining transparency about data handling practices.

4. **Hardware Stack**
   - **Battery Drain vs Local Compute**: Balance the need for always-on features with battery constraints by minimizing on-glasses compute requirements.
   - **Weight and Social Acceptability**: Keep hardware minimal to maintain social acceptability while ensuring functionality.

5. **Interaction Design**
   - **Frame Touch Interaction**: Ensure all interactions are touch-based in V1, avoiding voice commands or complex multimodal interfaces.
   - **User Control**: Prioritize simplicity in user control mechanisms, leveraging frame touches for interaction without complicating the interface.

6. **Privacy and Trust**
   - **Consent Clarity**: Clearly communicate to users how their data is being used and stored to build trust.
   - **Data Handling Practices**: Implement robust data handling practices that respect user privacy while providing necessary functionality.

## Open Questions
- What subtitle placement is most usable without becoming distracting?
- How should one-line prompts visually differ from subtitles?
- What confidence format builds trust best: label only, label + short reason, or score + label?
- How much face/name memory should be cached locally on the phone?
- Which interactions should work offline versus requiring cloud support?

## Core Tensions
- **Subtitle Quality vs Battery Drain**: Optimize for real-time subtitles while managing battery consumption.
- **Memory Trust vs Privacy Perception**: Ensure accurate and fast memory recall without compromising user privacy or trust in data handling.

By addressing these signals, contradictions, tensions, and open questions, the SmartGlasses project can continue to refine its core mission and enhance its real-world usefulness.
