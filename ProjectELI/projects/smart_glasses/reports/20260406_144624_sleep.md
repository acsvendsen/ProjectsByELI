# Consolidation of Core Signals for SmartGlasses V1

## Strengthening Signals
1. **Subtitle Quality**: Improving subtitle placement and visual hierarchy is critical for usability without distraction. The focus should remain on making subtitles easily readable while minimizing clutter.
2. **Memory Trust and Speed**: Enhancing the speed and accuracy of face/name recall, with clear confidence indicators, will build trust in the system's reliability.
3. **Phone/Cloud Balance**: Opting to use cloud processing only where necessary for heavy lifting ensures V1 remains lightweight and focused on essential functionality.

## Weakening Signals
1. **Complex Multimodal UI**: Reducing complexity in interactions and avoiding advanced multimodal features like voice commands in favor of frame-touch controls.
2. **Heavy Autonomous Behavior**: Minimizing autonomous actions without strong confidence signals to avoid overwhelming the user.

## Contradictions that Must Stay Alive
1. **Privacy vs Usefulness**: Balancing the need for detailed memory recall with privacy concerns, ensuring that the system does not infringe on personal boundaries while still being useful.
2. **Battery and Thermals**: Ensuring V1 remains lightweight to avoid overheating issues and excessive battery drain, especially for always-on features like live subtitles.

## Dormant Ideas Worth Reactivating
1. **Subtitle Placement and Visual Hierarchy**: Further exploration of subtitle placement and visual hierarchy design to find the best balance between clarity and non-distractiveness.
2. **Confidence Display Formats**: Investigating different confidence display formats (e.g., label only, label + short reason) to determine which builds trust most effectively.

## Concrete Tensions Around Core Areas
1. **Subtitle Quality vs Visual UX**:
   - Subtitle placement must be optimized for readability without causing distraction.
   - Visual hierarchy should support fast reading and low cognitive load.
2. **Confidence Trust vs Automatic Memory Behavior**:
   - Confidence objects need clear, understandable labels to build trust in the system's accuracy.
   - Fast lookup requirements for memory should be balanced with accurate automatic behavior.
3. **Battery and Thermals vs Always-On Sensing**:
   - The system must remain lightweight to avoid overheating issues and excessive battery drain.
   - Balancing always-on sensing with real-time subtitle quality is critical.

## Open Questions
1. **Subtitle Placement**: What is the best V1 split between glasses, phone, and cloud?
2. **Memory/Cache Policy**: How should face/name memory be stored and reinforced for fast lookup and trust?
3. **Confidence Display**: How should confidence be represented: numeric score, label, or short reason?

## Action Plan
- Focus on subtitle quality by optimizing placement and visual hierarchy.
- Enhance the speed and accuracy of face/name recall with clear confidence indicators.
- Ensure V1 uses cloud processing only where necessary to maintain a lightweight design.

By addressing these areas, the project can strengthen its core mission and provide a high-value, usable assistant for the wearer.
