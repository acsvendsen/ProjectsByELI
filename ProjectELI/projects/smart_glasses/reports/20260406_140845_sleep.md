# Consolidation of Key Signals for SmartGlasses V1

## Core Becoming More True
- **Subtitle Quality**: Subtitles must feel near-real-time or trust will break.
- **Memory Reinforcement**: New faces and names should be remembered with confidence objects over time, reinforcing memory through repeated interaction.
- **Fast Lookup Requirements**: One-line prompts should be fast and concise to avoid overwhelming the wearer.

## Core Becoming Less True
- **Complex Interactions**: The system should not become overly complex or rely on heavy voice activation in V1. Frame touches are the primary control method for now.
- **Feature Sprawl**: Focus on core features—live subtitles, face/name recall, conversation memory, and one-line support—without unnecessary additions.

## Core Contradictions That Must Stay Alive
- **Privacy vs Usefulness**: The system must balance providing useful assistance while respecting privacy concerns.
- **Always-On Sensing vs Battery and Thermals**: Early hardware should remain simple to avoid thermal issues and excessive battery drain.

## Dormant Ideas Worth Reactivating
- **Subtitle Placement and Visual Hierarchy**: Optimize subtitle placement for fast reading with minimal distraction, balancing visual clarity and user focus.
- **Confidence Display**: Experiment with different formats (label only, label + short reason, score + label) to find the best trust-building mechanism.

## Concrete Tensions Around Core Areas
### Subtitle Reasoning vs Memory Policy
- **Subtitle Quality vs Confidence Trust**: Strive for both. Subtitles should be clear and timely; confidence objects should provide context when recognition is uncertain.
- **Automatic New-Person Memory vs Explicit Remember-Touch Behavior**: Ensure automatic memory behavior works well while providing an option for explicit remember-touch to reinforce critical memories.

### Visual UX
- **Subtitle Placement**: Optimize placement for readability without being too distracting. Consider different scenarios (e.g., outdoor versus indoor use).
- **Visual Hierarchy**: Design a visual hierarchy that prioritizes subtitles and prompts in a way that enhances clarity without overwhelming the user.
  
### Phone/Cloud Boundary
- **Local Processing vs Cloud Intelligence**: Use the phone as the primary runtime but leverage cloud for heavy lifting where necessary, ensuring latency remains acceptable.
