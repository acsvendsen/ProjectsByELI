## Project Summary
The SmartGlasses project is focused on delivering real-time subtitles, reliable memory recall, and low-friction assistance while maintaining social acceptability and privacy. The current V1 version emphasizes frame-touch interaction, phone-first processing, and minimal hardware complexity to ensure a robust yet lightweight product.
