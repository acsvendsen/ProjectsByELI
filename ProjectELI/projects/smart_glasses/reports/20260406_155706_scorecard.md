## Project Summary
The project is focused on creating a discreet, context-aware personal assistant for live subtitles, face/name recall, conversation memory, and one-line support. The current V1 aims to keep the hardware lightweight and socially acceptable while ensuring minimal on-glasses compute. Key decisions include using frame touches as the primary interaction method and relying heavily on phone processing with optional cloud support.
