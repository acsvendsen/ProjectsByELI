### Idea 1: Subtitle Placement

1. **Why it benefits the core**
   - By defining a clear subtitle placement rule based on confidence level, the system can provide more useful information without overwhelming the wearer. This improves the balance between clarity and distraction, enhancing the real-time assistance provided in noisy environments.

2. **What small change unlocks it**
   - Define a simple subtitle placement policy that places subtitles at the bottom center of the frame when the confidence is high (e.g., over 0.9), and slightly above the lip area when the confidence is moderate (e.g., between 0.7 and 0.8).

3. **Likely payoff**
   - This rule will reduce visual distraction for confident matches, allowing the wearer to focus on the speaker more easily while still receiving critical information. It also prevents clutter in situations where the system is less certain about the text.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By defining a clear boundary for phone-first processing versus cloud fallbacks, we ensure that critical real-time operations remain local, reducing latency and enhancing trust. This focus on core functionality allows the glasses to provide immediate assistance without delays, maintaining the wearer's confidence in the system.

2. **What small change unlocks it**

   Define explicit rules for what operations run phone-local and which fall back to the cloud based on task-specific requirements. For example, live subtitle processing should always be local to ensure near-real-time performance, while memory archive syncs can use cloud resources when needed but stay off-device during critical interactions.

3. **Likely payoff**

   By keeping real-time operations local, we can significantly reduce latency and improve the reliability of the system. This enhances user trust and ensures that the glasses provide timely assistance without any perceptible lag, making the experience more seamless and useful for the wearer.

4. **Immediate next probe**

   Define one phone/cloud fallback boundary for live subtitle processing, ensuring all critical real-time operations remain local.
