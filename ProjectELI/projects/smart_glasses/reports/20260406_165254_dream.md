### Idea 1: Subtitle Placement

1. **Why it benefits the core**
   Improving subtitle placement rules can significantly enhance the wearer's understanding and reduce cognitive load during interactions. By defining specific placement modes for different confidence states, the glasses can ensure that subtitles remain stable, readable, and unobtrusive.

2. **What small change unlocks it**
   Define 2 to 3 subtitle placement rules for different confidence levels: a fixed position in the center, slightly offset from the center when the confidence is low but still relevant, and completely hidden when the confidence is too low to be useful.

3. **Likely payoff**
   By implementing these rules, the system will provide more consistent and reliable subtitles that do not distract the wearer during conversations with uncertain information. This improves trust in the glasses' assistance and enhances overall user experience.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

   Improving confidence display by using a label + short reason format helps build trust over time. This clarity ensures that the wearer understands when the system is certain about a piece of information versus when it has less certainty, thereby reducing social and cognitive friction.

3. **Likely payoff**

4. **Immediate next probe**

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**
   Improving local caching of face/name memories ensures that critical context is available quickly, reducing latency and enhancing trust by ensuring that recent interactions are easily recallable without relying on cloud connectivity.

2. **What small change unlocks it**
   Define a recency-first eviction policy for the local cache, where the most recently interacted with faces/names have higher priority in memory storage.

3. **Likely payoff**
   This change will ensure that frequently encountered people are always available locally, reducing the need for cloud requests and improving overall response time and trustworthiness of face/name recall.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

### 1. **Why it benefits the core**

Improving the phone-cloud boundary for live subtitle processing ensures that critical data and decisions are kept on the phone, reducing latency and ensuring real-time responsiveness. This strengthens trust by providing timely and accurate subtitles, which is essential for the wearer's understanding in noisy environments.

### 2. **What small change unlocks it**

Define a specific threshold for when to fallback from local subtitle processing to cloud processing based on network conditions and confidence score.

### 3. **Likely payoff**

By setting a clear boundary, the system can ensure that high-confidence subtitles are processed locally, reducing latency and maintaining trust. Lower-confidence or complex speech segments can then be sent to the cloud for more robust processing, balancing performance and accuracy.

### 4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.
