### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   By defining specific subtitle placement rules based on confidence levels, we can ensure that subtitles are always placed in a way that maximizes readability while minimizing distraction. This will help maintain the balance between providing clear assistance and not overwhelming the wearer.

2. **What small change unlocks it**

   Define 3 to 5 subtitle placement rules for different confidence states: high (90%+ confidence), medium (60-89%), and low (below 60%). Each rule should specify a fixed position or slight offset from the default frame edge, ensuring consistent readability without causing visual fatigue.

3. **Likely payoff**

   This change will lead to more stable and predictable subtitle placement, reducing the likelihood of subtitles moving around unexpectedly during conversations. It will also help in maintaining the wearer's focus on the conversation, as the subtitles will always appear in a familiar location, enhancing overall user experience and trust in the system.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By carefully defining what stays on the phone and what falls back to the cloud, we can ensure that critical real-time processing happens locally while still leveraging cloud resources for non-critical tasks. This balance reduces latency and conserves battery, maintaining high usability and reliability.

2. **What small change unlocks it**

   Define a clear boundary where face/name recall lookup should occur on-device. For example, basic face detection and initial name retrieval can be done locally, but detailed memory updates or long-term storage could fall back to the cloud.

3. **Likely payoff**

   This distinction ensures that real-time subtitle processing remains reliable and fast, while still benefiting from cloud storage for less critical tasks like updating memory archives. It enhances both performance and privacy by keeping sensitive data closer to the user.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.
