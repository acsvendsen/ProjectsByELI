## Project Summary
The SmartGlasses project is focused on creating a discreet, context-aware personal assistant with live subtitles, face/name recall, conversation memory, and one-line support. The current version (V1) uses frame-touch interaction exclusively and relies heavily on the phone for processing, with cloud services used only where justified.
