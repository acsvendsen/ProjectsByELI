```markdown
# Reality Check: SmartGlasses Core Field

## Feasible Now
- **Subtitle Assistance**: Implement real-time subtitles in noisy environments using phone processing. This can leverage existing text-to-speech technologies and display mechanisms on smartglasses.
- **Local vs Cloud Processing**: Bias towards phone-first processing for initial V1, allowing for heavy reliance on the cloud where needed (e.g., for advanced context or memory lookup).
- **Frame Touch Interaction**: Design simple user controls via frame touches. This can be straightforward to implement and test in a controlled environment.

## Feasible Later
- **Always-On Sensing**: Once early V1 is functioning, explore low-power always-on sensing technologies for real-time data collection.
- **On-Glasses Inference**: Develop minimal on-glasses inference capabilities that do not significantly drain battery or increase thermal load. This could include simple state tracking and UI updates.
- **Advanced AR Visuals**: Integrate more advanced augmented reality visuals as a future enhancement, starting with basic text display and gradually adding complexity.

## Likely Waste of Time
- **Voice Activation as Primary Method**: Voice activation for subtitle management, mode switching, or confirmations is likely to be too complex and resource-intensive in the early stages. Consider it a future exploration.
- **Complex Multimodal UI**: Designing a complex multimodal user interface with voice commands and advanced AR elements may not add significant value in V1.

## Assumptions Needing Evidence
- **Subtitle Placement**: Further research is needed to determine the optimal subtitle placement that maximizes usability without becoming distracting.
- **Confidence Format**: Testing different confidence formats (label only, label + short reason, or score + label) will help identify which builds trust best in real-world use cases.

## Key Considerations
- **Battery and Thermal Management**: Early V1 should focus on low-power solutions to avoid battery drain and overheating. This can be iterated upon as technology improves.
- **Privacy Concerns**: Ensure that any data collection or memory storage respects user privacy and does not raise concerns about tracking or surveillance.

## Summary
The current direction of focusing on real-time subtitle assistance using phone processing is feasible now, while always-on sensing and advanced AR visuals are more suitable for future iterations. Voice activation and complex UI elements should be deferred until V1 has proven its core value.
```

This markdown assessment categorizes the proposed directions based on their feasibility, potential waste of time, and assumptions needing evidence. It aligns with the current constraints and decisions while surfacing key considerations to ensure the project remains focused and realistic in its initial stages.
