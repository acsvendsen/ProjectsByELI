## Core Field Consolidation for SmartGlasses V1

### Strengthening Signals
1. **Subtitle Quality**: Subtitles must feel near-real-time to maintain trust, emphasizing the importance of minimizing latency.
2. **Face/Name Memory Trust**: The system should build strong confidence objects around face and name recognition, reinforcing memory over time through explicit remember-touch behavior.

### Weakening Signals
1. **Complex Interaction Patterns**: V1 interaction should remain frame touch-only; avoid introducing voice activation or spoken commands until explicitly justified.
2. **Heavy On-Glasses Processing**: Reduce reliance on on-glasses computation to minimize battery and thermal strain, focusing instead on phone-first architecture with cloud support where beneficial.

### Contradictions That Must Stay Alive
1. **Discreet vs Useful**: Balancing the need for a discreet experience with providing useful, context-aware assistance.
2. **Privacy vs Usability**: Ensuring that memory storage and recall respect privacy while maintaining the utility of personal memory features.
