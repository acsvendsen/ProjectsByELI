## Project Summary
The SmartGlasses project is focused on delivering a discreet, context-aware personal assistant that provides real-time subtitles, face/name recall, and one-line support. The V1 version emphasizes frame-touch interaction and phone-first architecture while managing core tensions like privacy vs. usefulness and latency vs. richness.
