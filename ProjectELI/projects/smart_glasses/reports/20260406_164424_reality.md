# Reality Check for SmartGlasses Project

## Core Mission
Create discreet, context-aware personal assistance through live subtitles, face/name recall, conversation memory, and one-line support.

### Decision Areas and Constraints

#### Subtitle Placement: More Prominent (Selected)
- **Feasible Now**: 
  - Display placement can be optimized in V1 to ensure readability without overwhelming the user. Given that glasses remain lightweight, this can be achieved through careful UI design.
  
- **Assumptions Needing Evidence**:
  - Confirm through user feedback if a more prominent subtitle display increases comprehension while maintaining usability.

#### Confidence Display: Label + Reason (Selected)
- **Feasible Now**: 
  - Implement a confidence label with a brief reason to inform the user about the reliability of the information provided. This can be done using simple, clear text that does not distract from the core functionality.
  
- **Assumptions Needing Evidence**:
  - Conduct usability tests to determine if users find the additional context helpful without feeling overwhelmed.

#### Memory/Cache Policy: Recency First (Selected)
- **Feasible Now**: 
  - Prioritize recent interactions and memories over older ones, which helps in maintaining a manageable cache while ensuring that relevant information is readily available.
  
- **Assumptions Needing Evidence**:
  - Validate through user testing if recency-first policy improves memory recall accuracy without causing confusion or unnecessary complexity.

#### Phone/Cloud Boundary: Phone First (Selected)
- **Feasible Now**: 
  - Rely on the phone for heavy processing tasks while keeping glasses as simple as possible. This approach reduces thermal and battery strain.
  
- **Assumptions Needing Evidence**:
  - Monitor battery usage to ensure that the current design does not lead to unexpected power draw.

#### Visual Hierarchy: Subtitles Dominate (Selected)
- **Feasible Now**: 
  - Ensure subtitles take precedence in visual hierarchy, making them the primary focus while still providing clear indicators for one-line prompts.
  
- **Assumptions Needing Evidence**:
  - Conduct A/B testing to determine if this hierarchy improves user comprehension and reduces cognitive load.

### Core Attractors
- **Real-time subtitle assistance**: Subtitles should be near-real-time to maintain trust and utility. V1 should focus on minimizing latency.
- **Personal memory support**: Memory recall for names and prior conversations should be fast and reliable, with automatic reinforcement based on context.
- **One-line contextual prompts**: Provide relevant, concise guidance without overwhelming the user.

### Core Tensions
- **Privacy vs Usefulness**: Ensure that face/name recognition is accurate but also respects privacy concerns. Automatic memory of new faces should come with clear user consent mechanisms.
  
  - **Feasible Now**:
    - Implement automatic memory with a default "remember" feature, supported by context clues and reinforced over time through explicit touches.

  - **Assumptions Needing Evidence**:
    - Test the balance between utility and privacy to ensure that users feel their data is being used responsibly.

### Drift Risks
- **Becoming a gimmick**: Focus on core features first before expanding.
  
  - **Feasible Now**:
    - Stick to real-world, high-value use cases such as noise-cancellation scenarios where subtitles can significantly enhance understanding.

  - **Assumptions Needing Evidence**:
    - Continuously gather user feedback and adapt the system based on real-world usage patterns.

### Feasibility Assessment
- **Subtitle Latency**: Ensure subtitles are displayed within 50ms of their corresponding sound for optimal comprehension.
- **Battery Draw**: Minimize power consumption by offloading heavy processing to the phone. Glasses should consume minimal battery in V1.
- **Thermal Pressure**: Avoid adding hardware that would significantly increase thermal load, keeping glasses lightweight and socially acceptable.
- **Privacy Perception**: Ensure clear communication about how data is handled, especially for automatic face/name recognition.

### Feasibility Ratings
- **Subtitle Latency & Display Quality**: **Feasible Now**
  - Given the focus on V1 interaction being frame-touch only, real-time subtitles can be achieved with minimal latency.
  
- **Memory Trust & Speed**: **Likely Waste of Time for V1**
  - While memory recall is crucial, focusing on recency and automatic reinforcement first is more practical in V1. Expanding to a broader cache could come later.

- **Visual Hierarchy & UX**: **Feasible Now**
  - Designing the visual hierarchy with subtitles as the primary focus can be achieved without complicating the system too much.
  
- **Cloud Dependency**: **Feasible Later**
  - Rely on the phone for V1, but consider integrating cloud services in future iterations to enhance capabilities.

### Summary
The current direction of focusing on core functionality such as real-time subtitles and personal memory support is feasible now. However, expanding into broader memory caching or heavy reliance on cloud processing should be deferred until these core features are well-established and validated through user feedback.
