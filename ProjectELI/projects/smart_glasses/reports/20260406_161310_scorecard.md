## Project Summary
The project is focused on delivering a lightweight, discreet smart glasses system that provides live subtitles, face/name recall, conversation memory support, and one-line prompts while adhering to V1 constraints such as frame-touch interaction and phone-first architecture. The current focus is on subtitle placement, confidence display, memory policy, phone/cloud boundary, and visual hierarchy to ensure the system remains useful, low-friction, and socially acceptable.
