# Core Field Consolidation for SmartGlasses V1

## Strengthening Signals
1. **Subtitle Quality**: The system should prioritize near-real-time subtitles that are clear and unobtrusive.
2. **Memory Reinforcement**: Automatic memory behavior, especially for new faces and names, is becoming increasingly important for building trust over time.

## Weakening Signals
1. **Explicit Remember-Touch Behavior**: Reducing the reliance on explicit user actions to enhance or correct memory entries can improve the system's autonomy.
2. **High-Frequency Interaction**: Minimizing the need for frequent frame touches by making interactions more efficient and less intrusive.

## Contradictions That Must Stay Alive
1. **Privacy vs. Usefulness**: Balancing the amount of personal data collected with the utility provided to the user remains a critical tension.
2. **Always-On Sensing vs. Battery Efficiency**: The need for always-on features that provide continuous assistance must be weighed against battery constraints.

## Dormant Ideas Worth Reactivating
1. **Improved Confidence Display**: Enhance the confidence display mechanism to better represent the reliability of memory and subtitles, addressing the current mixed signals.
2. **Contextual Prompt Placement**: Optimize where one-line prompts appear to ensure they are useful without overwhelming the user.

## Concrete Tensions Around Core Domains

### Subtitle Quality
- **Tension 1**: Ensuring high-quality real-time subtitles while minimizing battery drain and thermal issues.
- **Tension 2**: Balancing subtitle placement for clarity with avoiding distraction, ensuring subtitles do not overwhelm the wearer's visual field.

### Confidence Trust
- **Tension 1**: Determining the best format to display confidence (label only vs. label + short reason) without compromising user trust and privacy.
- **Tension 2**: Managing memory caching policies to balance between storing enough information for quick recall and respecting user privacy.

### Automatic Memory Behavior vs. Explicit Remember-Touch Behavior
- **Tension 1**: Developing a robust automatic memory behavior that can handle new people and situations effectively, while minimizing the need for explicit user actions.
- **Tension 2**: Ensuring that explicit remember-touch behaviors are used only when necessary to reinforce memory and build confidence.

### Fast Lookup vs. Memory Reinforcement
- **Tension 1**: Prioritizing fast lookup capabilities over memory reinforcement to ensure the system remains responsive.
- **Tension 2**: Striking a balance between storing detailed context (which may be valuable) and maintaining efficient memory policies that do not overwhelm the user.

### Visual UX
- **Tension 1**: Designing a visual hierarchy where subtitles dominate but are placed in a way that does not interfere with the user’s primary focus.
- **Tension 2**: Ensuring one-line prompts appear appropriately to provide useful information without overwhelming the wearer.

## Open Questions

- **Subtitle Placement and Visual Hierarchy**:
  - What is the optimal placement of subtitles for clarity while minimizing distraction?
  - How should one-line prompts visually differ from subtitles?

- **Confidence Display**:
  - Should confidence be displayed using a label only, a label with a short reason, or a numeric score plus a label?
  - When and how often should confidence objects be updated to provide accurate information?

- **Memory/Cache Policy**:
  - How much face/name memory should be cached locally on the phone for fast lookup?
  - What is the best strategy for storing and reinforcing memory entries over time?

## Reality Rules

- The system should remain discreet, context-aware, and assistive.
- Avoid feature sprawl or unnecessary hardware complexity in V1.
- Focus on core mission areas: live subtitles, face/name recall, conversation memory, and one-line support.

---

By addressing these signals, tensions, and open questions, the SmartGlasses project can continue to evolve while staying true to its core mission of providing discreet, context-aware personal assistance.
