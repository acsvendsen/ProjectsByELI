# Consolidated Insights for SmartGlasses V1 Direction

## Strengthening Signals
1. **Subtitle Quality**: Subtitles must feel near-real-time and provide clear, actionable information without overloading the user.
2. **Face/Name Recall**: Memory reinforcement is crucial; new faces and names should be remembered with confidence objects over time.
3. **Memory Policy**: The system should prioritize relevant memory and context for fast lookup and trust-building.

## Weakening Signals
1. **Complex Interactions**: Frame-touch-only interaction remains the primary control method in V1, avoiding voice activation or spoken command control.
2. **Heavy On-Glasses Compute**: Early versions should rely on phone processing with minimal local logic to keep hardware simple and battery-efficient.

## Contradictions that Must Stay Alive
1. **Privacy vs Usefulness**: Balancing the need for personal memory support with user privacy concerns.
2. **Battery Constraints**: Ensuring subtitle quality and real-time performance without excessive power consumption, which can impact wearability and usability.

## Dormant Ideas Worth Reactivating
1. **Subtitle Placement and Visual Hierarchy**: Optimizing subtitle placement to ensure clear reading while minimizing distractions.
2. **Confidence Display**: Deciding on the best format (label only, label + short reason, score + label) for confidence objects to build user trust without overwhelming them.

## Concrete Tensions Around Core Domains
1. **Subtitle Quality vs Battery Constraints**:
   - Subtitles must be clear and timely but cannot consume too much battery.
2. **Rich Memory vs Fast Lookup**:
   - The system should store relevant memory but prioritize fast, reliable lookups for high utility.
3. **Discreet UX vs Enough Visual Clarity**:
   - A balance between subtle assistive features and clear enough visual cues to ensure the user understands the context.

## Open Questions
1. **Subtitle Placement**: What subtitle placement is most usable without becoming distracting?
2. **Confidence Display Format**: How should confidence be represented (label only, label + short reason, score + label)?
3. **Face/Name Memory Caching**: How much face/name memory should be cached locally on the phone?

## Summary
The SmartGlasses project must focus on real-time subtitle quality and minimal on-glass computation to ensure a discreet and useful experience for the wearer. Face and name recall should be prioritized with confidence objects, while interactions remain frame-touch-only in V1. Subtitle placement, confidence display, and memory caching are key areas needing further exploration to balance usability and technical constraints.
