# Reality Check for SmartGlasses Core Mission

## Subtitle Placement: More Prominent
### Feasibility Now
- **Justification**: Given V1 interaction is frame-touch only, making subtitles more prominent can enhance readability without overwhelming the wearer. This approach respects the constraints of minimal on-glasses computation.
- **Constraints Met**: Avoids adding unnecessary complexity or battery drain.

## Confidence Display: Label + Reason
### Feasibility Now
- **Justification**: Using a label plus a brief reason for confidence in memory (e.g., "likely Joe Smith") can provide clear, concise information without overwhelming the wearer. This approach aligns with minimizing UI clutter and maintaining user trust.
- **Constraints Met**: Low computational demand, easy to implement on the phone.

## Memory/Cache Policy: Recency First
### Feasibility Now
- **Justification**: Implementing recency first ensures that recently seen or interacted-with entities are prioritized in memory recall. This approach respects the current hardware constraints and avoids unnecessary storage demands.
- **Constraints Met**: Reduces battery usage by minimizing long-term storage, aligns with V1 focus on real-time utility.

## Phone/Cloud Boundary: Phone First
### Feasibility Now
- **Justification**: Relying heavily on the phone for processing reduces thermal and battery strain. This approach ensures that V1 remains lightweight and usable in various environments.
- **Constraints Met**: Minimizes reliance on cloud infrastructure, ensuring real-time responsiveness.

## Visual Hierarchy: Subtitles Dominate
### Feasibility Now
- **Justification**: Prioritizing subtitles over other visual elements keeps the UI clear and focused. This approach ensures that core functionality (subtitles) remains central while still accommodating necessary interactions.
- **Constraints Met**: Simplifies user interface, reduces thermal strain on glasses.

## Interaction Through Frame Touches Only
### Feasibility Now
- **Justification**: Sticking to frame touches for all interactions maintains the simplicity and ease of use required in V1. This approach respects hardware limitations and avoids adding unnecessary complexity.
- **Constraints Met**: Ensures minimal battery drain, thermal pressure, and social acceptability.

## Real-time Subtitles vs Battery Drain
### Feasibility Now
- **Justification**: Given current constraints, real-time subtitles are feasible as long as they do not significantly increase battery consumption. The phone can handle this task efficiently.
