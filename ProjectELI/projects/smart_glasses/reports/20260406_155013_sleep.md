# Consolidation for SmartGlasses V1 Direction: Live Subtitles, Face/Name Recall, Conversation Memory, and One-Line Support

## Strengthening Signals
- **Subtitle Quality:** Emphasize real-time accuracy and clarity of subtitles to ensure the wearer understands the content fully without feeling overwhelmed.
- **Face/Name Memory:** Ensure that memory for new faces and names is reinforced over time with confidence objects to build trust in the system's recall ability.

## Weakening Signals
- **Complex Interactions:** Reduce complexity by limiting interactions to frame touches only. Avoid adding voice commands or spoken user controls in V1.
- **Heavy Cloud Dependence:** Favor phone-first processing for core functionalities, using cloud services only where they add clear value and do not introduce latency issues.

## Contradictions that Must Stay Alive
- **Social Acceptability vs. Functionality:** Balance the need to remain socially acceptable with providing necessary functionality such as subtitles in noisy environments.
- **Privacy Concerns:** Address privacy concerns by ensuring transparency and control over how personal information is stored and used, while still leveraging this data for useful interactions.

## Dormant Ideas Worth Reactivating
- **Visual Hierarchy Design:** Revisit the design of visual hierarchy to ensure that subtitles are easily readable without distracting from other activities or social contexts.
- **Memory Reinforcement Mechanisms:** Explore more effective ways to reinforce memory recall for new faces and names, such as quick touch interactions or contextual prompts.

## Concrete Tensions Around
1. **Subtitle Quality vs. Battery Drain:**
   - Ensure that subtitles are high-quality while minimizing battery usage through efficient processing and display strategies.
2. **Memory Depth vs. Fast Lookup:**
   - Decide how much memory should be cached locally versus fetched from the cloud to balance between fast lookup times and data privacy concerns.
3. **Discreet UX vs. Enough Visual Clarity:**
   - Find a balance where subtitles are clear enough for understanding but do not overwhelm or distract the user in social contexts.

## Open Questions
- **Subtitle Placement:** Determine the optimal placement of subtitles to enhance readability while minimizing distraction.
- **Confidence Display:** Decide on the best format for confidence display, such as label + short reason, to build trust without overwhelming the user.
- **Memory Policy:** Set a clear policy for caching face and name memory locally versus fetching from the cloud.

The core of SmartGlasses V1 remains focused on providing discreet, context-aware personal assistance through live subtitles, face/Name recall, conversation memory, and one-line support. The system should continuously surface real-world limitations early to ensure efficient and effective development. Specific decisions around subtitle quality, memory caching, confidence display, and visual hierarchy will drive the implementation of these core features while maintaining a balance between functionality and user experience.
