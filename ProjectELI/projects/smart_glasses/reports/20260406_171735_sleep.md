## Core Field Summary
### Mission
Create smart glasses that act as a discreet, context-aware personal assistant focused on live subtitles, face/name recall, conversation memory, and one-line support to help the wearer understand and respond better in real-world interactions.

### Non-negotiables
- Early hardware remains simple: display text, record audio/visual input; phone/cloud handles heavy processing.
- V1 interaction is frame-touch only; do not assume voice activation or spoken command control.
- Context must persist across sessions.
- New faces and names should be remembered with confidence objects and reinforcement over time.

### Core Attractors
- Real-time subtitle clarity: Keep subtitles clear, fast, and stable enough that the wearer can trust them in live conversation.
- Trustworthy memory support: Remember names, faces, and prior context without pretending certainty or creating corrupted recall.
- Low-friction assistance: Deliver one-line help and visible support without creating command overhead or social awkwardness.

### Core Tensions
- Privacy vs usefulness: Helpful assistive behavior should not quietly slide into invasive capture or retention.
- Latency vs richness: The system should provide timely help without overloading the runtime with richer but slower processing.
- Discreet UX vs visual clarity: Display behavior should remain socially acceptable while still being readable in motion and noise.

### Core Modes
- **Core Deepening**: Bias toward subtitle, memory, confidence, and architecture improvements that increase daily-use value.
- **Constraint Pressure**: Surface battery, latency, privacy, and usability limits early so weak directions are killed quickly.
- **Implementation Grounding**: Reason from actual repo files, app docs, and build truth instead of generic ideation.

## V1 Guardrails
- Mission: discreet, context-aware personal assistance through live subtitles, face/name recall, conversation memory, and one-line support.
- Interaction must use frame touches only; do not assume voice activation or spoken command control in V1.
- Prefer phone-first architecture; use cloud only when clearly justified.
- Favor improvements that deepen subtitle quality, memory trust, confidence display, and low-friction visual UX.
- Respect battery, thermals, latency, privacy, usability, and social acceptability constraints.
