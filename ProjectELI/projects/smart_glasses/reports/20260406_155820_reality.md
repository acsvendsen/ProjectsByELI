# Reality Check for SmartGlasses V1 Direction

## Summary
This reality check assesses proposed directions against real-world limits: hardware, battery, latency, privacy, manufacturability, software complexity, fast lookup reliability, and user trust. It adheres to the core mission of discreet assistive glasses focused on subtitles, memory trust, and one-line support.

## Core Mission Feasibility
- **Subtitle Placement**: 
  - **Feasible Now**: More prominent placement can be tested with frame-touch interaction to ensure it does not overwhelm the user but provides necessary visibility. Initial prototypes should focus on optimizing subtitle display without becoming too distracting.
  
- **Confidence Display**:
  - **Label + Reason**: This approach is **feasible now**. Labeling confidence with a brief reason (e.g., "high certainty" or "low certainty") can enhance trust and clarity, while keeping the interface simple and uncluttered.

- **Memory/Cache Policy**:
  - **Recency First**: Storing memory recency first is **feasible now**. This approach respects battery limits by reducing storage needs for older memories. Reinforcement learning over time will ensure that frequently recalled entities are prioritized, while less common ones are stored temporarily or in the cloud.

- **Phone/Cloud Boundary**:
  - **Phone First**: This architecture is **feasible now** and aligns with early V1 requirements. It minimizes battery drain and thermal pressure by offloading heavy processing to the phone, which can manage context and memory lookups efficiently.

- **Visual Hierarchy**:
  - **Subtitles Dominate**: Subtitles should dominate the visual hierarchy as they are the primary function. This approach is **feasible now** and helps in maintaining a clear focus on subtitles while ensuring that one-line prompts do not overwhelm the user.

## Core Tensions
- **Privacy vs Usefulness**:
  - Storing new faces and names with confidence objects and reinforcement is **feasible now**, as it respects privacy by only storing necessary information and reinforcing memories over time rather than immediately storing all data.
  
- **Always-on Sensing vs Battery and Thermals**:
  - Frame-touch interaction is a practical solution, ensuring minimal battery drain. This approach is **feasible now** and avoids the complexities of always-on sensing.

## Interactions
- **Frame Touches Only**: Frame-touch interactions are **feasible now** and maintain social acceptability while providing necessary control without overcomplicating the UI.
  
- **No Voice Activation in V1**: Avoiding voice activation in early V1 is a practical decision, as it simplifies hardware requirements and avoids potential privacy concerns.

## Real-world Constraints
- **Battery Draw**: Minimal local processing ensures low battery draw. The phone-first architecture will manage most of the workload, reducing strain on the glasses.
  
- **Thermal Pressure**: Frame-touch interaction minimizes thermal stress, making this approach **feasible now**.

- **Latency**: Subtitles must feel near-real-time to maintain trust. This can be achieved through efficient subtitle rendering and minimal processing delays, which are feasible with current technology.

## User Trust
- **Memory Integrity**: Ensuring that memory is stored accurately and reinforced over time builds user trust. This approach is **feasible now** by focusing on recency and confidence-based storage.
  
- **Subtitle Quality**: Near-real-time subtitles can be achieved through efficient subtitle rendering, making this aspect **feasible now**.

## Evolution Rule
The project should evolve to deepen the core mission rather than broaden it superficially. Core additions like improved memory recall and more sophisticated visual hierarchy are **feasible later** once V1 is well-established.

## Reality Guardrails
- **Interaction Constraint**: Frame-touch interaction is a **hard constraint**, ensuring social acceptability and minimizing hardware complexity.
  
- **UI Clarity**: UI should favor clarity over feature density, making this aspect **feasible now** and adhering to the core mission.

## Conclusions
The current V1 direction focuses on discreet assistive glasses with live subtitles, context-aware memory support, and one-line prompts. This approach is grounded in real-world constraints and aligns with the core mission of enhancing user understanding and confidence without overwhelming them.
