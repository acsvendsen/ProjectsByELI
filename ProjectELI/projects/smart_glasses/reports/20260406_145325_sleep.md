# Core Field Consolidation for SmartGlasses V1

## Strengthening Signals
1. **Subtitle Quality**: Enhance subtitle clarity and readability without becoming overly distracting.
2. **Memory Trust**: Build a robust system for remembering new faces and names with clear confidence indicators.
3. **Low-Friction UX**: Ensure interactions remain simple and unobtrusive, focusing on frame-touch controls only.

## Weakening Signals
1. **Voice Activation**: Avoid incorporating voice commands or spoken control in V1.
2. **Complex AR Features**: Limit the scope to minimal visual elements that support core functions like subtitles and memory recall.

## Contradictions That Must Stay Alive
1. **Battery vs Always-On Sensing**: Balance between real-time functionality and battery consumption, but prioritize usability over continuous always-on sensing.
2. **Privacy vs Utility**: Ensure data privacy without sacrificing the utility of the system for users in noisy environments or social interactions.

## Dormant Ideas Worth Reactivating
1. **Subtitle Placement Optimization**: Re-examine subtitle placement to find a balance between readability and non-intrusiveness.
2. **Memory Reinforcement Strategy**: Explore more effective methods for reinforcing memory recall, such as frequent reinforcement over time with confidence objects.

## Concrete Tensions Around Core Decisions

### Subtitle Quality
- **Tension**: Real-time vs. slightly delayed subtitles to balance on-device processing and battery life.
- **Current Decision**: Prioritize real-time subtitles to maintain user trust in the system’s reliability.

### Confidence Trust
- **Tension**: Numeric score vs. label with short reason for confidence display.
- **Current Decision**: Use labels with short reasons to provide clear but non-overwhelming feedback on memory recall accuracy.

### Automatic Memory Behavior vs Explicit Remember-Touch Behavior
- **Tension**: The system should remember new faces and names automatically over time, supplemented by explicit user touch inputs to reinforce these memories.
- **Current Decision**: Combine automatic memory capture with explicit user interactions through frame touches for reinforcement.

### Fast Lookup Requirements
- **Tension**: Balancing the need for fast lookup of frequently encountered information versus the risk of storing too much irrelevant data.
- **Current Decision**: Focus on prioritizing and caching key, relevant memories while minimizing storage of low-value or infrequently accessed information.

### Privacy vs. Social Acceptability
- **Tension**: Protect user privacy by limiting data collection and usage to essential functions without compromising the utility of memory recall in social settings.
- **Current Decision**: Design systems that respect user privacy through minimal data handling, but ensure they are useful in contexts where users may need name or face recognition.

### Visual UX
- **Tension**: Minimize visual intrusion while ensuring clear and effective display of information such as subtitles and confidence indicators.
- **Current Decision**: Use a clean, unobtrusive design for subtitle placement that allows rapid reading with minimal distraction.

## Open Questions

1. **Subtitle Placement**: What is the optimal placement for subtitles to maximize readability without causing distraction?
2. **Memory Policy**: How much memory should be cached locally on the phone versus relying on cloud storage for fast lookup and reinforcement?
3. **Visual Hierarchy**: How can we design a visual hierarchy that effectively communicates confidence levels in name or face recognition?

## Summary
The project is making strong progress towards its core mission of enhancing real-world interactions through live subtitles, face/name recall, conversation memory, and one-line support. Key tensions around subtitle quality, confidence trust, automatic vs explicit memory behavior, and fast lookup requirements are being addressed with a focus on maintaining usability and user trust. Continuous attention to these areas will help ensure the system remains effective while respecting real-world constraints such as battery life and privacy concerns.
