### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   By defining specific subtitle placement rules based on confidence states, the system can ensure that critical information is always visible while minimizing distraction. This helps the wearer stay informed without feeling overwhelmed, aligning with the mission of reducing social and cognitive friction.

2. **What small change unlocks it**

   Define three subtitle placement rules: one for high-confidence matches (always displayed prominently), one for medium-confidence matches (displayed when needed but not obstructing text), and one for low-confidence matches (only shown if explicitly requested).

3. **Likely payoff**

   This approach will enhance the subtlety and effectiveness of the subtitles, ensuring that important information is always visible while reducing unnecessary distractions. It will also provide a clear visual hierarchy that respects the wearer's attention and comprehension needs.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   By defining a clear and consistent confidence format that combines a numeric score with a label and short reason, we can enhance the trust and reliability of the system. This approach helps users understand the certainty behind each piece of information provided by the glasses.

2. **What small change unlocks it**

   Define a standardized confidence object format: `score XX + "Label" + "Short Reason"` where:
   - Score is a numeric value between 0 and 1.
   - Label is a simple descriptor like "High", "Medium", or "Low".
   - Short reason provides context for the score.

3. **Likely payoff**

   This change will provide users with clear, concise, and trustworthy information about the reliability of each piece of text displayed (subtitles, one-liners, etc.). Users can quickly assess whether to pay attention based on the confidence level, which in turn builds trust in the system's accuracy.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   By setting a recency-first cache eviction policy for face/name memory objects, the system ensures that recently encountered individuals are remembered with higher confidence over time, while older or less relevant memories are purged. This approach maintains a balance between rich memory and fast lookup, ensuring that the wearer can rely on recent interactions more accurately.

2. **What small change unlocks it**

   Define one local cache eviction rule based on recency, where older entries are evicted to make way for newer ones with higher confidence scores.

3. **Likely payoff**

   Implementing this policy will reduce the risk of cluttering memory space with outdated or less relevant information, thereby improving the accuracy and relevance of face/name recall over time. This ensures that the system's memory is more useful and reliable in real-world scenarios where interactions are frequent but memories can fade quickly.

4. **Immediate next probe**
   - Define a recency-first cache eviction rule for face/name memory objects.
