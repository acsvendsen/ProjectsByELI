# Consolidation for SmartGlasses V1 Direction

## Strengthening Signals
- **Subtitle Quality**: Subtitles must be near-real-time to maintain trust, with placement prioritized for readability without distraction.
- **Face/Name Recall**: Memory reinforcement through confidence objects and periodic touch interactions is essential for building trust in memory recall.
- **Memory Policy**: Recency-first caching on the phone helps manage battery while providing relevant context.

## Weakening Signals
- **Voice Activation**: Avoiding voice activation as a primary control method until further V1 iterations.
- **Complex UI**: Simplifying interactions to frame touches only, reducing complexity and potential social friction.

## Contradictions That Must Stay Alive
- **Battery Constraints**: Balancing subtitle quality with battery efficiency remains crucial. Subtitles must be fast enough but not at the cost of overheating or excessive drain.
- **Privacy vs Usefulness**: The system should provide useful assistance without compromising user privacy, especially in memory recall and face recognition.

## Dormant Ideas Worth Reactivating
- **Subtitle Placement and Visual Hierarchy**: Explore optimal subtitle placement that maximizes readability while minimizing distraction. This includes testing different visual hierarchies to ensure clear and unobtrusive subtitles.
- **Confidence Display**: Investigate various confidence display formats (e.g., label + reason) to understand which builds trust most effectively without overwhelming the user.

## Concrete Tensions Around Core Domains
### Subtitle Quality, Confidence Trust, Automatic New-Person Memory, Memory Reinforcement, Fast Lookup, Privacy, Latency, Battery, and Visual UX

1. **Subtitle Quality vs Battery Efficiency**: Ensure subtitles are clear and useful while maintaining battery efficiency to prevent overheating.
2. **Confidence Display**: Determine the best way to display confidence in memory recall without adding too much complexity or visual clutter.
3. **Automatic New-Person Memory**: Balance the need for rapid memory building with privacy concerns, ensuring new faces and names are remembered accurately but discreetly.
4. **Memory Reinforcement**: Implement periodic touch interactions to reinforce memory recall, balancing this against battery usage and social acceptability.
5. **Fast Lookup vs Privacy**: Ensure fast memory lookup while maintaining user privacy in how and when memories are accessed.
6. **Privacy vs Utility**: Strive for a balance between providing useful assistance and respecting user privacy, especially in sensitive contexts like face recognition.

## Open Questions
- **Subtitle Placement and Visual Hierarchy**: What is the optimal subtitle placement that maximizes readability without becoming distracting?
- **Confidence Display Format**: Which confidence display format (label only, label + reason, score + label) builds trust best?

## Reality Rules
- **Always Frame-Touch Interaction**: Stick to frame-touch interaction as primary control method in V1.
- **Phone-First Architecture**: Prioritize phone-first processing for speech and context management with cloud support where necessary.

## Current Unknowns
- **Subtitle Placement**: Determine the most usable subtitle placement that is also unobtrusive.
- **One-Line Prompts vs Subtitles**: Decide how to visually differentiate one-line prompts from subtitles in the UI.
- **Confidence Display Format**: Test different confidence display formats to see which builds trust best.

## Core Field Summary
The system should focus on providing near-real-time, context-aware support through live subtitles, face/name recall, and memory reinforcement. The V1 interaction is frame-touch only, with the glasses handling minimal local logic while relying heavily on phone processing for core functions. Balancing subtitle quality with battery efficiency, ensuring fast yet discrete memory recall, and maintaining a clear visual hierarchy are critical goals.

### Next Steps
- Conduct UI/UX tests to determine optimal subtitle placement.
- Explore different confidence display formats and select the best one.
- Implement periodic touch interactions for memory reinforcement while managing battery usage.
