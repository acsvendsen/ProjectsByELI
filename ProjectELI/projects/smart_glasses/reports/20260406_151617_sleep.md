# Consolidation of Core Signals and Trends for SmartGlasses V1

## Summary
Based on the recent project signals, here are the trends emerging:

### Strengthening Signals
- **Subtitle Quality:** Improving real-time subtitle latency and readability.
- **Memory Trust:** Enhancing confidence display to build trust in memory recall.
- **Local Processing:** Prioritizing local processing for critical functions like speech recognition.

### Weakening Signals
- **Voice Activation:** Reducing the emphasis on voice commands for V1 interaction.
- **Complexity:** Avoiding unnecessary complexity and overbuilding features that don't add immediate value.

### Contradictions That Must Stay Alive
- **Privacy vs. Usefulness:** Balancing the need for useful functionality with privacy concerns.
- **Battery vs. Always-On Sensing:** Managing battery constraints while ensuring always-on sensing is feasible.

### Dormant Ideas Worth Reactivating
- **Face/Name Memory Reinforcement:** Considering how to reinforce memory of new faces and names over time without overwhelming local storage.
- **Subtitle Placement and Visual Hierarchy:** Exploring optimal subtitle placement and visual hierarchy for clear yet unobtrusive readability.

### Concrete Tensions Around Core Domains

#### Subtitle Quality
- **Latency vs. Readability:** Ensuring subtitles feel near-real-time while remaining readable, especially in noisy environments.
  
#### Confidence Display
- **Label vs. Score:** Deciding whether to use a label or score format for confidence display.
  
#### Automatic Memory Behavior
- **Face/Name Memory Storage:** Determining how much face/name memory should be cached locally versus using cloud support.

#### Explicit Remember-Touch Behavior
- **User Touches for Confirmation:** How user touches can confirm memory entries without overcomplicating interactions.

#### Memory Policy
- **Weighted Relevant Memory vs. Rich Memory:** Balancing the need for rich memory with the practicality of fast lookup and low storage demands.

#### Phone/Cloud Boundaries
- **Optimal Use of Cloud:** Using cloud services only where they add clear value without compromising latency or battery efficiency.
  
#### Visual UX
- **Clarity vs. Feature Density:** Striking a balance between clear UI and avoiding overwhelming the user with too many features.

## Open Questions

### Subtitle Placement and Visual Hierarchy
1. What is the best subtitle placement for fast reading with minimal distraction?
2. How should subtitles coexist with one-line prompts to avoid visual overload?

### Confidence Display
3. Should confidence be represented as a label, score, or both with a short reason?

### Memory Policy
4. How much face/name memory should be cached locally versus using cloud support?

## Real-World Limitations

1. **Battery and Thermals:** Keep hardware simple in V1 to manage battery and thermal constraints.
2. **Privacy:** Ensure that any memory storage or usage respects user privacy.
3. **Latency:** Prioritize real-time responses over complex features that might introduce latency.

### Action Items
- Review and optimize subtitle placement and visual hierarchy.
- Define the best format for confidence display.
- Determine caching strategies for face/name memory.
- Ensure interactions remain frame-touch only in V1.

## Conclusion

The core mission of SmartGlasses remains focused on discreet, context-aware personal assistance through live subtitles, face/name recall, conversation memory, and one-line support. The recent signals highlight the importance of balancing functionality with usability and privacy, while avoiding unnecessary complexity that could detract from daily-use value.
