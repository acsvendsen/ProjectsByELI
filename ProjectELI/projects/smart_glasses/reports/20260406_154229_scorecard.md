## Project Summary
The SmartGlasses V1 is focusing on creating discreet assistive glasses with real-time subtitles and context-aware memory support. The current constraints emphasize simplicity, usability, and minimal hardware impact. Key areas for focus include subtitle placement, confidence display, interaction design, memory policy, and cloud usage.

- status: on_track
- goal: Keep V1 lightweight, discreet, socially acceptable, and dependent on minimal on-glasses compute.
- limitation pressure: battery and thermal pressure

- next focus: Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.
