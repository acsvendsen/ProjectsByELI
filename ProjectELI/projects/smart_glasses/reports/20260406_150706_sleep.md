# Consolidation of SmartGlasses V1 Direction

## Strengthening Signals
- **Subtitle Quality**: Subtitles must feel near-real-time to maintain trust. Any delays or lags will reduce their usefulness, especially in noisy environments.
- **Memory Trust**: Memory for new faces and names should be reinforced over time with confidence objects and explicit remember-touch behavior. This helps build trust in the system's accuracy.
- **Visual Clarity**: Subtitle placement must prioritize readability without becoming distracting. Prominent yet unobtrusive placement is key.

## Weakening Signals
- **Complex Interactions**: Frame-touch-only interaction remains a hard ground rule. Any suggestions to introduce voice commands or complex multimodal UI should be avoided for V1.
- **Battery and Thermals**: The glasses must remain lightweight and socially acceptable, so always-on features are limited by battery constraints.

## Contradictions That Must Stay Alive
- **Face/Name Memory vs Privacy**: Balancing the need for accurate face/name recall with privacy concerns. Explicit remember-touch behavior is crucial to maintain trust.
- **Subtitle Quality vs Fast Lookup**: High-quality subtitles must be prioritized over fast lookup, as they are a primary assistive feature.

## Dormant Ideas Worth Reactivating
- **Subtle Visual Cues**: Consider subtle visual cues (e.g., blinks or small animations) for confidence objects to enhance the user experience without overwhelming them.
- **Local Processing**: Explore local processing capabilities within strict thermal and battery constraints to reduce reliance on cloud services where feasible.

## Concrete Tensions Around Core Areas

### Subtitle Quality, Confidence Trust
- **Subtitle Delay vs Trust**: Minimize subtitle delay but ensure subtitles are displayed just in time. Latency should not exceed 100ms for optimal user experience.
- **Confidence Display**: Use a label + short reason format to display confidence levels clearly and concisely.

### Automatic Memory Behavior, Explicit Remember-Touch Behavior
- **Automatic New-Person Memory**: Ensure that new faces and names are remembered with high confidence but avoid overwhelming the user with too many prompts.
- **Explicit Remember-Touch Behavior**: Use explicit remember-touch behavior for reinforcing memory. This helps build trust over time by showing that the system is learning from user interactions.

### Fast Lookup Requirements
- **Memory Policy**: Cache face/name information locally on the phone to reduce latency, but ensure that this does not compromise privacy or thermal constraints.
- **Subtle Visual Cues**: Implement subtle visual cues for confidence objects (e.g., brief animations) without distracting the user.

## No Fluff

### Subtitle Placement
- **Placement Strategy**: Place subtitles just above the ear where they are easily readable but do not obstruct vision. Avoid placing them in direct sightlines to prevent distraction.
- **Visual Hierarchy**: Ensure subtitles dominate the visual field, but maintain a clear distinction between subtitles and one-line prompts.

### Confidence Display
- **Label + Reason Format**: Use a label (e.g., "Confident") followed by a short reason (e.g., "95% sure"). This provides enough information without overwhelming the user.
- **User Feedback**: Allow users to adjust confidence levels through remember-touch behavior, ensuring that their input strengthens the system's accuracy over time.

### Memory Policy
- **Local Caching**: Cache face/name data locally on the phone for fast lookup. Ensure this does not exceed thermal or battery constraints.
- **Explicit Remember-Touch Behavior**: Reinforce memory with explicit user actions (e.g., tapping to confirm a new name). This helps build trust and accuracy over time.

### Phone/Cloud Boundary
- **Phone First**: Prefer phone-first processing for most operations, using cloud services only where necessary. Ensure this approach minimizes latency and thermal impact.
- **User Control**: Keep interactions simple with frame-touch-only controls. Avoid introducing voice commands or complex multimodal UI in V1.

### Real-Time Subtitle Management
- **Subtitle Management**: Implement real-time subtitle management to ensure subtitles are displayed just in time. This is critical for maintaining user trust.
- **One-Line Prompts**: Ensure one-line prompts are concise and unobtrusive, providing context without overwhelming the user.

### Visual UX
- **Subtle Design**: Use subtle design elements (e.g., brief animations) for confidence objects to enhance the user experience without distracting them.
- **Clarity vs. Feature Density**: Prioritize clarity over feature density, ensuring that the UI remains uncluttered and focused on the core features.

## Summary

The project should focus on delivering high-quality, near-real-time subtitles with clear confidence displays. Memory for new faces and names must be reinforced through explicit user interactions to build trust. The glasses should remain lightweight and socially acceptable, relying heavily on phone processing while minimizing cloud usage where possible. Frame-touch-only interaction remains the primary method of control, with subtle visual cues enhancing the user experience without overwhelming them.
