# Consolidation of Core Signals for SmartGlasses V1 Direction

## Strengthening Signals

### Subtitle Quality and Placement
- **More Prominent Placement**: The operator has selected a more prominent subtitle placement, which is critical for ensuring that subtitles are easily readable without being too intrusive. This needs to balance clarity with the risk of becoming distracting.

### Confidence Display
- **Label + Reason**: The decision to use a label plus a short reason in confidence display will help build trust by providing clear feedback on the reliability of the information, thus reducing uncertainty and improving user acceptance.

### Memory Policy
- **Recency First**: The recency-first memory policy ensures that recent interactions are prioritized, which is crucial for maintaining relevance and usefulness. This aligns with the core mission to provide timely and accurate assistance.

### Interaction Design
- **Frame Touches Only**: Stick to frame-touch interaction as a primary mode of user control to avoid adding complexity. This ensures simplicity while still providing essential functionality.

## Weakening Signals

### Cloud Dependency
- The phone-first architecture is preferred, but there are no explicit signals indicating that cloud integration should be minimized or eliminated. This remains an open question and needs further exploration to determine where cloud processing can add the most value without compromising on real-world limits.

### Visual Hierarchy
- The preference for subtitles dominating the visual hierarchy suggests a focus on ensuring that subtitles remain the primary point of interaction, but this does not necessarily mean neglecting other important UI elements like face/name recall or one-line prompts. These elements should coexist in a balanced way to provide comprehensive support.

## Contradictions That Must Stay Alive

### Privacy vs Usefulness
- The tension between providing useful information and maintaining privacy must be managed carefully. Subtle memory reinforcement techniques need to be designed without compromising the user's comfort and privacy.

### Always-On Sensing vs Battery and Thermals
- The system needs to balance always-on functionality with battery and thermal constraints. This is particularly important for subtitle quality, as near-real-time processing is crucial but must not drain the battery excessively.

## Dormant Ideas Worth Reactivating

### Face/Name Recall Enhancement
- While the core decision on memory policy favors recency-first caching, there are still opportunities to enhance face/name recall through smarter reinforcement and user feedback mechanisms. This could involve more frequent updates or interactive elements that help solidify new memories.

## Concrete Tensions Around Core Areas

### Subtitle Quality vs Battery
- Ensuring subtitles remain clear and fast without draining the battery is a critical balance. The system must optimize subtitle delivery to be both effective and efficient.

### Confidence Trust vs Automatic New-Person Memory
- Providing enough confidence in the information displayed while not overwhelming the user with too many automatic memory updates is crucial. This requires careful design of the confidence indicators and how new faces are remembered.

### Fast Lookup vs Privacy
- Balancing the need for quick access to relevant memories without compromising privacy is essential. This involves thoughtful design around how and when memory data is stored and accessed.

### Discreet UX vs Visual Clarity
- The UI should be clear enough to provide useful information but discreet enough to avoid drawing too much attention, especially in social settings. This requires a careful balance between functionality and subtlety.

## Open Questions

1. **Subtitle Placement**: What is the optimal subtitle placement that balances readability with minimal distraction?
2. **One-Line Prompts vs Subtitles**: How should one-line prompts visually differ from subtitles to avoid overlap while ensuring both are useful in different contexts?

## Real-World Constraints

### Hardware and Battery
- The glasses must remain lightweight and socially acceptable, which limits the complexity of on-glasses processing.
- Battery management is a critical constraint for always-on functionality.

### Latency and Privacy
- Subtitles need to be near-real-time to maintain trust, but this must not compromise privacy or social acceptability.

### Social Acceptability
- The design should minimize social friction while still providing useful information.

## Decision Areas

1. **Subtitle Quality**: Ensure subtitles are clear and fast without draining the battery.
2. **Confidence Display**: Use a label plus reason format to build trust.
3. **Memory Policy**: Prioritize recency for memory caching.
4. **Interaction Design**: Stick to frame-touch interactions but consider how one-line prompts can coexist with subtitles.

By focusing on these areas, the project can continue to evolve in a way that strengthens its core mission and user experience while addressing key constraints and tensions.
