### Idea 1: Subtitle Placement

1. **Why it benefits the core**
   - Stable subtitle placement rules ensure that subtitles remain consistently readable and do not distract from the conversation, enhancing real-time clarity and trust.

2. **What small change unlocks it**
   - Define a fixed subtitle position rule for high-confidence states (e.g., "always bottom of screen, right-aligned").

3. **Likely payoff**
   - By defining clear placement rules, the system will reduce visual distractions during live conversations, making subtitles more reliable and less intrusive.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving the confidence display format will enhance the wearer's trust in the system by clearly indicating the reliability of the information provided. This clarity helps prevent misunderstandings and ensures that the wearer can rely on the subtitles, face/name recall, and one-line support when needed.

2. **What small change unlocks it**

   Define a simple numeric score + label + short reason confidence object format for V1. For example: "score 0.84 + 'High' + 'Seen recently'; score 0.42 + 'Low' + 'Weak match'; score 0.63 + 'Medium' + 'Name heard once in introduction'."

3. **Likely payoff**

   By implementing a clear and concise confidence display format, the system will provide more accurate and reliable information to the wearer, enhancing their trust and understanding of the subtitles and memory support provided by the glasses.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Improving local memory cache thresholds ensures that frequently encountered faces and names are stored efficiently, reducing latency and improving trust by providing quicker recall for common interactions.

2. **What small change unlocks it**

   Define a recency-based eviction policy where recently seen or interacted-with entities are kept in the local cache longer than those rarely accessed, ensuring that key memory objects like familiar faces and recent conversations are readily available.

3. **Likely payoff**

   By prioritizing frequently encountered entities in the local cache, the system will reduce the need for cloud lookups, enhancing response speed and user trust. This will also free up bandwidth and processing power on the phone, contributing to a more reliable and smoother overall experience.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By clearly defining what local processing stays on the phone versus what falls back to the cloud, we ensure that critical subtitle and memory tasks are handled efficiently without unnecessary latency or privacy risks. This focus helps maintain real-time responsiveness and reduces battery drain, ensuring the system remains useful and discreet.

2. **What small change unlocks it**

   Define one specific task boundary for live subtitle processing: decide whether transcript cleanup and finalization should run locally on the phone or be sent to the cloud first before presenting subtitles. This decision will help in setting local cache thresholds and confidence rules.

3. **Likely payoff**

   By keeping critical real-time tasks like subtitle generation and display local, we ensure that the glasses remain lightweight and responsive. This setup also allows for faster, more reliable memory recall and confidence handling without relying on potentially laggy cloud services. The result is a more seamless user experience with less latency and higher trust.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

1. **Why it benefits the core**
   Improving the visual hierarchy between subtitles and one-line support ensures that the wearer can easily distinguish between critical information (subtitles) and less critical information (one-line prompts), reducing cognitive load and maintaining focus during conversations.

2. **What small change unlocks it**
   Define a clear precedence rule where subtitles have higher visual prominence than one-line support, ensuring that subtitles are always visible and prioritized over other text overlays.

3. **Likely payoff**

This clarity also helps in maintaining a low-friction user experience by reducing distractions from less important prompts.

4. **Immediate next probe**
   - Define one visual priority rule between subtitles and one-line support in V1.
