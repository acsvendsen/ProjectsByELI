### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Improving subtitle placement rules ensures that subtitles are always clear, readable, and unobtrusive, which directly supports real-time subtitle clarity and low-friction assistance attractors.

2. **What small change unlocks it**

   Define a fixed subtitle placement rule that places subtitles at the bottom of the display, slightly offset to the left or right, ensuring they do not interfere with the wearer's natural gaze while remaining legible during motion.

3. **Likely payoff**

   By fixing the subtitle placement, we can ensure consistent and predictable subtitle visibility, reducing the likelihood of subtitle occlusion and improving overall user trust in the system’s assistive capabilities.

4. **Immediate next probe**
   - Define the fixed position rule for subtitles at the bottom of the display, slightly offset to the left or right.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving the confidence display format ensures that users can easily understand the reliability of the information provided by the system. A clear and consistent way to show certainty levels helps build trust in the subtitles and memory support, which is critical for the core mission of helping the wearer understand better.

2. **What small change unlocks it**

   Define a simple confidence display format using a score + label + short reason approach. For example, "score 0.95 + 'High' + 'Seen recently'; score 0.45 + 'Low' + 'Weak match'; score 0.68 + 'Medium' + 'Name heard once in introduction'."

3. **Likely payoff**

   By providing a clear and concise way to convey certainty, the system can avoid misleading the wearer about the accuracy of subtitles or memory support. This clarity will help build trust over time as users come to rely on the system for important interactions.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Improving the local memory cache threshold ensures that the system can quickly retrieve relevant person-memory objects without unnecessary cloud requests. This reduces latency and preserves battery life by keeping critical information locally, which is essential for trust and reliability in live conversations.

2. **What small change unlocks it**

   Define a fixed cache size limit of 50 entries for local face/name memory on the phone, with a recency-based eviction policy that prioritizes more recent encounters.

3. **Likely payoff**

   By limiting the number of cached entries to a manageable size and ensuring they are based on recent interactions, the system will remain fast and responsive, reducing the likelihood of lag or battery drain during critical conversations. This enhances trust by providing quick access to relevant memory without overwhelming local storage.

4. **Immediate next probe**
   - Define the cache size limit to 50 entries for local face/name memory on the phone.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   Improving subtitle placement for different confidence levels ensures that subtitles remain clear and stable enough to be trusted in live conversations. By defining specific rules for subtitle visibility based on confidence, we can enhance the reliability of real-time subtitles, making them more useful without overwhelming the wearer.

4. **Immediate next probe**

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   Ensuring a clear visual hierarchy between subtitles and one-line support helps the wearer focus on essential information without being overwhelmed by too many elements. This clarity improves overall understanding and reduces cognitive load, making the assistive features more useful in real-world interactions.

2. **What small change unlocks it**

   Define a visual priority rule that gives higher precedence to subtitles over one-line prompts when both are active. This can be achieved by routing one-line support text to less prominent areas or smaller font sizes compared to subtitles, ensuring subtitles remain the primary focus.

3. **Likely payoff**

   By prioritizing subtitles and making one-line support more subtle, users will find it easier to follow conversations without visual distractions. This reduces cognitive overload and enhances the wearer's ability to process spoken content effectively.

4. **Immediate next probe**
   - Define one visual priority rule between subtitles and one-line support in V1.
