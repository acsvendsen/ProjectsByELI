# Consolidation of Core Signals for SmartGlasses V1

## Strengthening Signals

### Subtitle Quality and Placement
- **Subtitle Placement**: More prominent placement is selected, indicating that subtitles should be visible but not overly distracting. This suggests placing subtitles slightly above the conversation level in a clear, readable font to minimize visual clutter.
- **Visual Hierarchy**: Subtitles dominate the interface, ensuring they are the primary focus for the wearer.

### Memory and Confidence
- **Face/Name Recall**: Memory policy is set to recency first, which means new faces and names will be remembered with higher confidence. This aligns with the need for real-time, context-aware assistance.
- **Confidence Display**: Label + reason format is selected, providing clear and concise feedback on the reliability of memory entries.

### Interaction and Privacy
- **Interaction Mode**: The system remains frame-touch only, which minimizes complexity and respects V1 constraints. This approach ensures that interactions are simple and do not introduce unnecessary voice or gesture controls.
- **Privacy Focus**: Early versions will rely heavily on phone processing to avoid privacy concerns associated with heavy on-glasses compute.

## Weakening Signals

### Complexity
- The system should avoid overcomplicating the interface. Rich context and complex multimodal UI are not currently part of V1, focusing instead on essential features.
- Full on-glasses inference is not a current priority, which means the system will rely more heavily on phone processing.

### Memory Storage
- Local memory storage is limited to recency first, meaning that newer interactions have higher confidence levels. This approach avoids storing low-value information and keeps the memory policy focused on relevant data.
- Face/name memory caching should be managed by the phone, reducing battery drain associated with heavy local computations.

## Contradictions That Must Stay Alive

### Interaction Mode
- Frame-touch interaction is the primary mode in V1, which means any voice or gesture-based interactions are not part of this release. This focus on simplicity and usability must be maintained to ensure a low-friction user experience.
- The system should avoid becoming overly complex by avoiding speculative additions like eye-tracking sensors.

### Memory Trust
- Confidence objects (labels + reasons) must clearly convey the reliability of memory entries, but should also remain uncluttered to maintain trust without overwhelming the wearer. This balance is critical for maintaining high levels of user confidence in the system.

## Dormant Ideas Worth Reactivating

### Context Persistence Across Sessions
- The project should continue exploring how context can persist across sessions while respecting V1 constraints on complexity and interaction mode.
- Investigating ways to improve subtitle quality through phone-based processing without introducing significant latency or battery drain.

## Concrete Tensions Around Core Areas

### Subtitle Quality, Confidence Trust, Automatic New-Person Memory, Memory Reinforcement
- **Subtitle Quality**: Balancing real-time subtitles with the need for minimal battery drain. This tension requires optimizing subtitle placement and text size to ensure they are readable yet unobtrusive.
- **Confidence Trust**: Ensuring that confidence objects provide clear feedback without being overwhelming. The label + reason format must be balanced to maintain trust while providing useful information.
- **Automatic New-Person Memory**: Implementing an effective memory policy for new faces and names while avoiding storing unnecessary data. This involves setting appropriate thresholds for memory caching.

### Fast Lookup, Privacy, Battery, Visual UX
- **Fast Lookup**: Ensuring that fast lookup requirements do not compromise battery life or introduce latency issues. This tension requires optimizing phone-based processing to provide quick responses.
- **Privacy**: Balancing the need for rich memory with privacy concerns associated with storing personal data on phones and in the cloud.
- **Battery**: Minimizing battery drain while providing real-time subtitles, which means carefully managing subtitle placement, text size, and update frequency.

### Discreet UX vs Enough Visual Clarity
- Ensuring that the system is discreet but still provides enough visual clarity for effective use. This involves optimizing subtitle placement and text size to be readable without becoming distracting.
