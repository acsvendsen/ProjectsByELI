# Core Field

## Mission
Create smart glasses that act as a discreet, context-aware personal assistant focused on live subtitles, face/name recall, conversation memory, and one-line support to help the wearer understand and respond better in real-world interactions.

## Non-negotiables
- The glasses help the wearer; they do not pretend knowledge the wearer does not have.
- Early hardware remains simple: display text, record audio/visual input; phone/cloud handles heavy processing.
- V1 interaction is frame-touch only; do not assume voice activation or spoken command control.
- Context must persist across sessions.
- New faces and names should be remembered with confidence objects and reinforcement over time.
- Real-world constraints must be surfaced early: latency, battery, privacy, social acceptability, on-device limits.

## Core Attractors
- Real-time subtitle assistance in noisy environments
- Personal memory support for names and prior conversations
- One-line contextual prompts rather than overwhelming paragraphs
- Low-friction human experience; assistive, not deceptive

## Core Tensions
1. **Subtitle Quality vs Confidence Trust**
   - Subtitles need to be accurate but also quick to display.
   - Too much latency or low confidence in subtitles can break trust.

2. **Automatic Memory Behavior vs Explicit Remember-Touch Behavior**
   - Automatic memory behavior (e.g., remembering new faces) should be reliable and unobtrusive.
   - Explicit remember-touch behavior should be used for critical moments where the wearer needs to confirm recall accuracy.

3. **Memory Policy vs Fast Lookup Requirements**
   - The system must balance remembering details over time with quick access to relevant information.
   - Memory reinforcement should prioritize frequently used or important information.

4. **Privacy vs Usefulness**
   - Strive for minimal data collection while ensuring the system remains useful and effective.

5. **Discreet UX vs Visual Clarity**
   - Subtitles and prompts must be readable but not distracting.
   - Confidence objects need to provide clear feedback without overwhelming the wearer.

## Strengthening Signals
- Enhance automatic memory behavior by focusing on confidence objects for new people and situations.
- Improve subtitle quality through better speech-to-text algorithms and real-time adjustments based on user feedback.

## Weakening Signals
- Reduce reliance on complex interactions that could distract from core functionality.
- Simplify the visual hierarchy to ensure subtitles are easily readable without causing visual overload.

## Contradictions That Must Stay Alive
- Ensure a balance between automatic memory and explicit remember-touch behavior to avoid over-reliance on one or the other.

## Dormant Ideas Worth Reactivating
