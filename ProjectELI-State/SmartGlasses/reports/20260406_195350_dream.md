### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Improving subtitle placement rules will enhance the overall usability of subtitles, ensuring they remain clear and stable enough for the wearer to trust in live conversation. This stability is crucial for maintaining the core attractor of "Real-time subtitle clarity."

2. **What small change unlocks it**

   Define 3 specific subtitle placement rules based on confidence levels: 
   - High-confidence speech: always display subtitles directly below the speaker's face.
   - Medium-confidence speech: show subtitles slightly to the side, but not obstructing other speakers or key visuals.
   - Low-confidence speech: use a temporary placeholder until more context is gathered.

3. **Likely payoff**

   By implementing these rules, subtitles will be less likely to distract during high-confident speech and better positioned for clarity during lower confidence scenarios. This refinement will significantly improve the wearer's trust in the subtitles, enhancing the core mission of real-time subtitle clarity.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Improving the local cache size for face/name memory ensures that frequently encountered individuals are remembered more reliably and quickly, reducing the need to rely on cloud services or heavy processing. This leads to faster lookups during conversations, enhancing the trust in the system’s ability to recall people correctly.

2. **What small change unlocks it**

   Define a local cache size limit for face/name memory objects that is set based on the number of recent encounters and the confidence scores associated with each person. For example, keep a local cache of up to 10 high-confidence faces and names seen in the last hour.

3. **Likely payoff**

   By limiting the local cache to a fixed size and prioritizing recent and highly confident memories, the system can provide faster, more reliable name recall during conversations. This reduces latency and ensures that the wearer’s memory of frequently encountered individuals is accurate and timely, thereby increasing trust in the system.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.
