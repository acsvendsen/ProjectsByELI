# Reality Check for SmartGlasses V1 Direction

## Subtitle Clarity

### Feasibility Now: **Feasible Now**
- **Current State**: The `TranscriptLab` app provides a live microphone capture and basic transcript behavior, which can be refined to meet real-time subtitle clarity.
- **Constraints**: Given the current focus on phone-first architecture, early prototypes should work within hardware limitations and ensure subtitles remain clear and stable during live conversations.

### Action Inbox
- **Subtitle Placement**: Ensure subtitle placement does not cause distraction. Initial tests should prioritize central but non-obtrusive placements to maintain readability.
- **Visual Hierarchy**: Define a simple visual hierarchy that supports quick reading without overwhelming the wearer. Consider high contrast, large text size, and minimal font choices.

## Memory Trust

### Feasibility Now: **Feasible Later**
- **Current State**: The memory system relies on phone-first architecture with cloud optional support.
- **Constraints**: Real-time context and face/name recall are dependent on the current transcript behavior, which is still in development. Memory trust involves reliable confidence scores and clear indications of uncertainty.

### Action Inbox
- **Memory Policy**: Implement a caching strategy for locally stored face and name data to ensure quick lookups without overloading the phone's resources.
- **Confidence Display**: Develop a confidence display format that helps users understand the reliability of memory recall, such as a label with a short reason or score.
