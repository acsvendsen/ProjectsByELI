### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   By refining subtitle placement rules, we can ensure that subtitles remain readable and do not distract from the conversation. Stable subtitle placement will help in maintaining trust and reducing cognitive load on the wearer.

2. **What small change unlocks it**

   Define 2 to 3 subtitle placement rules based on different confidence states: one for high-confidence speech (e.g., clear speaker, familiar topic), another for moderate-confidence speech (e.g., unfamiliar topic, background noise), and a third for low-confidence speech (e.g., weak match, ambiguous context).

3. **Likely payoff**

   Implementing these placement rules will make subtitles more reliable and less distracting. This improvement will contribute to the core mission of real-time subtitle clarity and low-friction assistance.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   By refining the confidence display, we can ensure that the wearer has a clear understanding of the reliability of the information being presented. This improves trust in the subtitle and memory support systems, which are critical for maintaining the wearer's confidence during interactions.

2. **What small change unlocks it**

   Define a consistent confidence format that includes a numeric score, label, and short reason. For example: "score 0.84 (High) - Seen recently."

3. **Likely payoff**

   A well-defined confidence format will help the wearer understand when to trust the subtitles or memory support more confidently. This clarity can reduce cognitive load and increase overall trust in the system.

4. **Immediate next probe**
   - Define a numeric score format for the confidence display.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

By refining the local memory cache thresholds, we can ensure that frequently encountered faces and names are remembered with high confidence and stored in a way that allows for fast retrieval. This improves the trustworthiness of face/name recall by reducing the chance of presenting uncertain or incorrect information to the wearer.

2. **What small change unlocks it**

Define a local memory cache size limit that prioritizes recently seen people over older ones, using a recency-based eviction policy. For instance, keep a cache of up to 50 most recent faces and names with their associated confidence scores and reinforcement history.

3. **Likely payoff**

This approach will reduce the likelihood of presenting weakly linked or outdated information to the wearer, thereby enhancing the trustworthiness of memory support. By focusing on recency, the system can ensure that the most relevant and reliable memories are readily available for fast lookup, improving both subtitle quality and overall user experience.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

By defining a clear boundary for what runs phone-locally versus falling back to cloud, we ensure that critical subtitle and memory functions are always available with minimal latency. This focus on local processing preserves the real-time responsiveness of subtitles and ensures that memory support is fast and reliable, aligning closely with the attractors of real-time subtitle clarity and memory trust.

2. **What small change unlocks it**

To achieve this, we can define a specific task boundary for live subtitle processing. For example, we can route all subtitle generation and display logic to run phone-locally while allowing cloud fallbacks only under certain conditions, such as when the local device is low on battery or when higher-quality transcriptions are needed.

3. **Likely payoff**

This change will ensure that subtitles remain clear and stable in real-time conversations, maintaining high trust among users. Additionally, it will enable faster memory recall and more reliable face/name recognition, enhancing overall memory support without sacrificing performance. The immediate benefits include reduced latency and improved user experience, aligning with the core attractors of subtitle clarity and memory trust.

4. **Immediate next probe**

Define one live subtitle processing task boundary where all subtitle generation and display logic runs phone-locally unless the device is low on battery or high-quality transcriptions are required.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   By defining a clear visual hierarchy between subtitles and one-line support, the system can ensure that the wearer remains focused on essential information without overwhelming them with excessive text. This will help in maintaining the core attractors of real-time subtitle clarity and low-friction assistance while ensuring the wearer can trust the information provided.

2. **What small change unlocks it**

   Define a visual hierarchy rule that prioritizes subtitles over one-line prompts, but ensures both are visible enough to be useful without distraction. For example, prioritize subtitles in a large, easily readable font while using a smaller, less prominent font for one-line support.

3. **Likely payoff**

   This change will enhance the wearer's ability to follow conversations by ensuring that critical information (subtitles) is prioritized and presented clearly. It also supports low-friction assistance by keeping non-critical prompts minimal and unobtrusive, thus reducing cognitive load without sacrificing essential support.

4. **Immediate next probe**
   - Define a visual hierarchy rule that prioritizes subtitles over one-line prompts in display order and prominence.
