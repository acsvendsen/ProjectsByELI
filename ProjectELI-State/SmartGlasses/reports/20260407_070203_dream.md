### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Improving subtitle placement rules can enhance the overall user experience by ensuring that subtitles remain stable and visible, reducing cognitive load during live conversations. This stability is crucial for maintaining trust in the system's reliability and effectiveness.

2. **What small change unlocks it**

   Define a fixed position rule for subtitles where they are always placed at the bottom of the frame, slightly above the text input area but not obstructing the main view. This simple change ensures consistent placement without requiring complex adaptive rules that could drain battery or introduce latency issues.

3. **Likely payoff**

   By maintaining a stable subtitle position, users will have a predictable and unobtrusive experience, reducing cognitive load during interactions. This can lead to higher trust in the system's ability to provide accurate and reliable subtitles, enhancing the overall user satisfaction and daily-use value of the glasses.

4. **Immediate next probe**
   - Define a fixed position rule for subtitles where they are always placed at the bottom of the frame, slightly above the text input area but not obstructing the main view.

4. **Immediate next probe**

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By defining a clear boundary between what runs on the phone and what falls back to the cloud for live subtitle processing, we ensure that the primary subtitle rendering is always fast and stable. This reduces latency and ensures real-time clarity, which is crucial for the core attractor of "Real-time subtitle clarity."

2. **What small change unlocks it**

   Define a specific task boundary where live subtitles are processed entirely on the phone, with no fallback to the cloud under any circumstances. This means that all face detection, name recognition, and confidence calculation related to subtitle rendering should run locally.

3. **Likely payoff**

   By keeping subtitle processing local, we can ensure sub-second response times for real-time subtitled conversations. This will significantly enhance the user's trust in the system during critical interactions, aligning with the core attractor of "Real-time subtitle clarity."

4. **Immediate next probe**
   - Define the specific task boundary where live subtitle processing, including face detection and name recognition, runs entirely on the phone with no fallback to the cloud.
