# Reality Check for SmartGlasses Core Field

## Subtitle Clarity: Real-time subtitle clarity (Subtitle Placement)
**Feasible Now**
- **Current Status**: The `TranscriptLab` app provides a test bed to validate real-time transcript behavior. Early tests should focus on ensuring subtitles are clear, fast, and stable enough for live conversation.
- **Constraints**: Glasses remain lightweight and socially acceptable; early versions do not depend on heavy on-glasses compute; subtitles must feel near-real-time or trust breaks.

## Memory Trust: Trustworthy memory support (Memory/Cache Policy)
**Feasible Now**
- **Current Status**: The system should remember names, faces, and prior context without creating corrupted recall. This can be achieved through local caching with periodic cloud updates.
- **Constraints**: Early versions rely heavily on phone processing; only use cloud where it adds clear value and latency remains acceptable.

## Low Friction Assistance: Low-friction assistance (Confidence Display)
**Feasible Now**
- **Current Status**: One-line prompts should be delivered in a way that minimizes command overhead or social awkwardness. This can be achieved by using simple, non-intrusive visual cues.
- **Constraints**: The system should remain discreet and low-friction; early versions do not depend on voice activation or spoken commands.

## Core Deepening Over Sprawl
**Feasible Now**
- **Current Status**: Focus on subtitle quality, memory trust, and visual UX improvements rather than broad feature expansion. This aligns with the core deepening mode.
- **Constraints**: The project should bias toward making the SmartGlasses core loop stronger.

## Constraint Pressure: Surface battery, latency, privacy, and usability limits early
**Feasible Now**
- **Current Status**: Early tests in `TranscriptLab` can surface battery and latency issues. Privacy concerns can be managed through clear user communication about memory behavior.
- **Constraints**: Glasses should remain lightweight; heavy on-glasses compute is not optimized yet.
