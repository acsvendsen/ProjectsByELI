### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   By defining specific subtitle placement rules for different confidence states, we can ensure that subtitles are always visible but not overly intrusive. This helps maintain high trust in the system by keeping the wearer informed without causing distraction.

2. **What small change unlocks it**

   Define a simple rule where subtitles appear at the bottom of the screen with lower opacity when confidence is low, and increase opacity as confidence increases until they become fully visible at high confidence levels.

3. **Likely payoff**

   This approach will reduce visual clutter while still ensuring that critical information is easily accessible. It respects the wearer's context awareness and prevents the system from becoming a distraction in social situations.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   By refining the confidence display to use a simple numeric score with a clear label and short reason, we can enhance the trustworthiness of our system. This approach aligns with the core attractor of "Trustworthy memory support" by ensuring that the wearer understands the reliability of the information provided.

2. **What small change unlocks it**

   The small change is to define a confidence format: `score 0.85 + "High" + "Seen recently"` for well-established entities and `score 0.33 + "Low" + "Weak match"` for less certain ones. This format uses a numeric score, a clear label, and a short reason to convey the level of confidence.

3. **Likely payoff**

   Implementing this change will provide the wearer with a clearer understanding of the system's reliability, thereby increasing trust in the memory support feature. Users will be more confident that they are receiving accurate information, which is crucial for the core attractor "Trustworthy memory support."

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Improving memory cache thresholds helps ensure that frequently encountered names and faces are stored locally with high confidence, reducing latency and ensuring reliable recall during live conversations. This improves the trustworthiness of face/name recall, aligning with the memory_trust attractor.

2. **What small change unlocks it**

   Define a local memory threshold for people based on recent encounters and frequent context. For example, set a rule to keep names seen more than five times in the last week cached locally for quick lookup.

3. **Likely payoff**

   By caching frequently encountered names and faces with high confidence, the system will provide faster and more reliable face/name recall during live conversations. This reduces latency and ensures that the wearer can trust the memory support provided by the glasses.

4. **Immediate next probe**

   Define a local cache eviction policy that keeps names seen more than five times in the last week cached locally for quick lookup.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By clearly defining which subtitle processing tasks are handled locally on the phone versus which fall back to the cloud, we can ensure that critical real-time performance and privacy requirements are met while leveraging cloud resources only when necessary. This balance optimizes battery life and latency, ensuring subtitles remain clear and stable enough for live conversations.

2. **What small change unlocks it**

   Define a specific task boundary for live subtitle processing that stays local on the phone to handle real-time stability and privacy concerns. For example, this could be "processing of transcribed audio for initial subtitle generation."

3. **Likely payoff**

   By keeping critical real-time subtitle processing local, we can ensure subtitles remain stable and clear enough for live conversations, maintaining trust and usability without overloading the battery or introducing latency issues that might degrade the user experience.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   Ensuring that subtitles are coherently prioritized with one-line prompts enhances the wearer's ability to focus on key information without visual overload. This improves understanding and retention of critical details in real-time conversations, aligning with the core attractors of subtitle clarity and low-friction assistance.

2. **What small change unlocks it**

   Define a single display precedence rule that prioritizes subtitles over one-line prompts when confidence is high but suppresses subtitles entirely if the context suggests they might be distracting or unnecessary. This rule would balance the need for clear, real-time information with the desire to avoid visual clutter.

3. **Likely payoff**

   By carefully controlling when and how subtitles are displayed relative to one-line prompts, the system can maintain a clear focus on essential details while minimizing distractions. This enhances overall usability and trust in the assistive capabilities of the glasses.

4. **Immediate next probe**
   - Define one visual priority rule between subtitles and one-line support in V1.
