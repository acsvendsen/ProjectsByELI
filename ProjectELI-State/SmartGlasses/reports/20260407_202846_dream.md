### Idea 1: Subtitle Placement

1. **Why it benefits the core**
   Improving subtitle placement rules ensures that subtitles remain readable, stable, and unobtrusive, which is crucial for maintaining trust in live conversations.

2. **What small change unlocks it**
   Define a fixed subtitle position at the bottom center of the frame with slight adjustments based on confidence levels: higher confidence can allow for smaller text size or less frequent updates, while lower confidence requires larger text size or more frequent updates to ensure clarity.

3. **Likely payoff**
   A consistent and reliable subtitle placement will enhance the wearer's trust in the system, making real-time subtitles more effective without causing visual distraction. This improvement aligns with the core attractor of "Real-time subtitle clarity."

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving the confidence display format enhances trust in both subtitle accuracy and memory support. Clear, concise, and reliable confidence indicators help the wearer understand when they can rely on the system's outputs without overloading them with unnecessary details.

2. **What small change unlocks it**

   Define a simple but effective confidence label format for V1 that combines a numeric score with a short reason. For example: "score 0.85 + 'High' + 'Seen recently'". This format allows the system to communicate its certainty level and source of information in a straightforward manner.

3. **Likely payoff**

   By clearly communicating the confidence levels, the system can help reduce cognitive load on the wearer by ensuring they focus only on highly reliable outputs. This will enhance trust and understanding without overwhelming them with too many details, making the assistance more useful and intuitive.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   By optimizing the local cache size for face/name memory on the phone, we can ensure that key entities are retained longer without consuming excessive battery or storage resources. This balance improves the trustworthiness of name recall and conversation memory while staying within real-world constraints.

2. **What small change unlocks it**

   Define a local cache eviction rule that retains recent face and name encounters for at least 7 days, with a maximum capacity limit of 50 entries to prevent excessive storage usage.

3. **Likely payoff**

   This rule will help the system maintain a reasonable number of remembered entities without draining battery or storage resources. It ensures that frequent faces and names are reliably recalled, enhancing the wearer's trust in memory support.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   Ensuring that subtitle processing remains local to the phone helps maintain real-time performance and reduces battery drain. By keeping live subtitle processing on the phone, we avoid cloud latency which can break trust in critical conversation moments.

2. **What small change unlocks it**

   Define a specific subtitle placement rule that keeps subtitles at the bottom of the screen but slightly above the user's line of sight when reading. This ensures clear visibility without causing distraction.

3. **Likely payoff**

   By keeping subtitle processing local, we can achieve faster and more reliable real-time transcription. This improves trust in noisy environments where timely assistance is crucial.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   By defining a clear visual hierarchy between subtitles and one-line support, we can ensure that the wearer remains focused on critical information while reducing potential distraction. This helps in maintaining clarity and reducing cognitive load during conversations.

2. **What small change unlocks it**

   Define a priority rule where subtitles are always displayed prominently unless their confidence is below a certain threshold, at which point they are hidden or simplified, and one-line support takes precedence to avoid overwhelming the wearer.

3. **Likely payoff**

   This approach will help in maintaining the core mission of providing real-time, trusted subtitle assistance while ensuring that additional contextual prompts do not interfere with the primary task of understanding spoken conversation. It also aligns with the low-friction assistance attractor by minimizing visual noise and social awkwardness.

4. **Immediate next probe**
