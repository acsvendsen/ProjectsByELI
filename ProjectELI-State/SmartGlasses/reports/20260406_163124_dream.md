### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   By defining a consistent subtitle placement rule that prioritizes visibility while minimizing distraction, we enhance the wearer's ability to follow conversations without feeling overwhelmed. This improves the overall user experience by ensuring subtitles are always easily readable but not too intrusive.

2. **What small change unlocks it**

   Define two subtitle placement rules: one for high-confidence matches (e.g., known people) and another for low-confidence matches (e.g., likely new faces or names). The high-confidence rule could place subtitles slightly lower in the visual hierarchy, while the low-confidence rule would position them higher to ensure they are noticed.

3. **Likely payoff**

   This change helps maintain a balance between visibility and non-intrusiveness. High-confidence matches can be given priority without overwhelming the wearer, while new or less certain matches get more attention. This enhances the trust in the system by showing respect for the user’s visual field and mental focus.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

2. **What small change unlocks it**

   Change the default confidence display from a numeric score (e.g., 0.84) to include both a label (e.g., "High") and a short reason (e.g., "Seen recently"). This provides more context without overwhelming the user.

3. **Likely payoff**

   This change will make it easier for users to quickly understand when they can trust the system's information, leading to better engagement with the subtitles and memory features. It also enhances transparency, which is crucial for maintaining trust over time.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 4: Phone/Cloud Boundary

   By defining a clear boundary for what runs locally on the phone versus what falls back to the cloud, we can ensure that real-time subtitle processing remains fast, which is crucial for maintaining user trust and ensuring that subtitles are always near-real-time.

   Define a specific task boundary where live subtitle processing must be handled on-device (phone) until cloud fallbacks are explicitly needed due to lack of local memory or context.

3. **Likely payoff**
