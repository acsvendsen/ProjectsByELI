# Reality-Checked Directions

## Subtitle Placement: Feasible Now

### Reasoning
The core goal is to ensure subtitles are clear, readable, and stable enough for the wearer to trust them in live conversation. The current focus on frame touches suggests a need for minimal distraction while ensuring legibility.

### Concrete Constraints
1. **Battery and Thermals**: Keeping the display simple reduces thermal load.
2. **Latency**: Subtitles must be fast to appear, maintaining real-time clarity.
3. **Privacy Perception**: Display should remain discreet and non-intrusive.

**Feasible Now**
- Position subtitles just below the wearer’s line of sight, ensuring they are easily readable without obstructing vision or drawing undue attention.
- Use a consistent font size and style that balances readability with minimal distraction (e.g., sans-serif fonts in medium to large sizes).

## Confidence Display: Feasible Later

### Reasoning
Confidence display is critical for building trust but should be carefully designed. Given the current focus on subtitle clarity and memory support, confidence indicators can be introduced as a subsequent improvement.

### Concrete Constraints
1. **Battery**: Additional processing required for dynamic confidence indicators.
2. **Usability**: Confidence must not become overwhelming or distracting.

**Feasible Later**
- Introduce a simple confidence indicator (e.g., a label like "Low," "Medium," or "High") alongside the subtitle.
- Initially, provide short explanations when necessary to avoid clutter.

## Memory/Cache Policy: Feasible Now

### Reasoning
Memory and cache policies are crucial for maintaining trust in name and face recall. The current emphasis on phone-first processing means heavy local memory storage should be avoided initially.

### Concrete Constraints
1. **Battery**: Heavy caching consumes power.
2. **Latency**: Local storage could introduce latency issues.

**Feasible Now**
- Store minimal, weighted relevant memories locally to ensure quick lookup and low battery impact.
- Use the phone for more complex lookups or when offline.
- Implement a reinforcement learning mechanism where new faces are remembered but older ones fade over time.

## Phone/Cloud Boundary: Feasible Now

### Reasoning
Given the current architecture direction, heavy processing should primarily happen on the phone. Cloud usage should be minimized to reduce battery drain and latency.

### Concrete Constraints
1. **Battery**: Heavy cloud dependency increases power consumption.
2. **Latency**: Real-time responses require minimal delay.

**Feasible Now**
- Keep all real-time transcription and memory lookup on the phone, with cloud support for less critical tasks or background processing.
- Design the system to offload only non-critical heavy lifting to the cloud when necessary.

## Visual Hierarchy: Feasible Now

### Reasoning
Visual hierarchy should focus on clarity and minimal distraction while ensuring subtitles remain legible. This aligns well with the current subtitle placement goals.

### Concrete Constraints
1. **Battery**: Simplified UI reduces thermal load.
2. **Usability**: Clear, readable layout enhances user experience.

**Feasible Now**
- Prioritize a clean, uncluttered display that minimizes distractions while ensuring subtitles are easily readable and prominent enough to be noticed but not overwhelming.
- Use dynamic adjustments in brightness or color contrast based on environmental lighting conditions to maintain readability without causing strain.

## Summary

- **Subtitle Placement**: Feasible now. Focus on minimal distraction with clear, legible subtitles.
- **Confidence Display**: Feasible later. Introduce confidence indicators as a subsequent improvement while maintaining simplicity.
- **Memory/Cache Policy**: Feasible now. Implement lightweight local storage and phone-first processing for memory management.
- **Phone/Cloud Boundary**: Feasible now. Keep heavy processing on the phone to minimize battery drain and latency.
- **Visual Hierarchy**: Feasible now. Design a clean, uncluttered display that enhances readability without causing distraction.

These directions align with the current core-deepening focus and respect the real-world constraints of hardware, battery, privacy, and usability.
