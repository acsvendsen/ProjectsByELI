# Consolidation of SmartGlasses Core Field and Recent Project Signals

## Strengthening Signals
1. **Subtitle Quality**: The importance of near-real-time subtitles is increasing, as they are essential for helping wearers understand their environment in noisy or hearing-challenged situations.
2. **Face/Name Recall**: Memory reinforcement and fast lookup of new faces and names should be prioritized to enhance the system's utility and user trust.

## Weakening Signals
1. **Voice Activation**: The current V1 design does not support voice activation, which may reduce interaction friction in future iterations but is not a priority for now.
2. **Complex Multimodal UI**: Early versions should focus on simplicity rather than adding complex multimodal interactions like AR visuals or full speech recognition.

## Contradictions That Must Stay Alive
1. **Always-on Sensing vs Battery and Thermals**: The system must balance always-on features with battery and thermal constraints, ensuring that real-time subtitles remain feasible without causing significant drain.
2. **Privacy vs Usefulness**: The system should prioritize user privacy by being discreet but still provide sufficient memory and context to be useful.

## Dormant Ideas Worth Reactivating
1. **One-Line Prompts**: While not a priority in V1, this feature could be revisited for future iterations as it can provide quick contextual support without overwhelming the wearer.
2. **Local Processing vs Cloud Intelligence**: Investigating local processing capabilities might become more feasible as hardware improves but should only be considered if it significantly enhances battery efficiency and performance.

## Concrete Tensions Around Core Aspects
1. **Subtitle Quality, Confidence Trust, Automatic New-Person Memory, Memory Reinforcement, Fast Lookup, Privacy, Latency, Battery, Visual UX**
   - Subtitle quality must remain high to prevent trust issues.
   - Ensuring fast lookup and confidence in face/name memory is crucial for maintaining user trust without overwhelming the system with complex processing demands.
   - Balancing privacy concerns with useful memory functionality remains a key tension.

## Open Questions
1. **Subtitle Placement**: What subtitle placement ensures readability without becoming too distracting?
2. **Confidence Display**: How should confidence be represented to build trust effectively (label only, label + short reason, or score + label)?
3. **Memory/Cache Policy**: How much face/name memory should be cached locally on the phone versus using cloud services?

## Action Items
- **Subtitle Placement and Visual Hierarchy**: Focus on a balanced approach that ensures subtitles are visible but not distracting.
- **Confidence Display**: Evaluate different confidence formats to determine which builds trust best without overwhelming the user.
- **Memory Policy**: Determine an optimal caching strategy for face/name memory that balances local processing with cloud support.

## Summary
The core mission of SmartGlasses remains focused on providing real-time subtitles, enhancing face/name recall, and supporting conversation memory. Key tensions include ensuring subtitle quality and confidence trust while managing hardware constraints like battery and thermals. The system should prioritize a simple, touch-first interaction model to keep the user experience low-friction and useful. Open questions around subtitle placement, confidence display, and memory caching will be addressed through concrete design probes and UX testing in future iterations.
