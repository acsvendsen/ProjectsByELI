# Reality Check for SmartGlasses Core Field

## Subtitle Placement: Feasible Now
- **Current Direction**: No specific subtitle placement decisions have been made yet.
- **Constraints**: Glasses should remain lightweight and socially acceptable; subtitles must feel near-real-time or trust breaks. 
- **Feasibility**: The glasses should focus on placing subtitles where they are most readable without being too distracting. Given the current simplicity of hardware, a bottom-center placement might be ideal for quick reading while minimizing distraction. This would need to be validated with prototypes and user feedback.

## Confidence Display: Feasible Now
- **Current Direction**: No specific confidence format decisions have been made yet.
- **Constraints**: The system should help the wearer understand better without faking understanding; face/name recall must expose uncertainty clearly.
- **Feasibility**: A simple confidence format, such as a label with a short reason (e.g., "Maybe" or "Likely"), could be effective. This would provide enough transparency to build trust while avoiding overwhelming the user. More complex formats can be explored later.

## Memory/Cache Policy: Feasible Now
- **Current Direction**: No specific cache policy has been defined.
- **Constraints**: V1 should rely heavily on phone processing; face/name recall must expose uncertainty clearly.
- **Feasibility**: Implement a caching strategy that keeps frequently used names and faces in memory but also allows for clear indications of uncertain recalls. This could involve storing data locally on the phone while ensuring that any retrieved information is marked with confidence levels.

## Phone/Cloud Boundary: Feasible Now
- **Current Direction**: V1 should primarily rely on phone processing.
- **Constraints**: V1 interaction must use frame touches only; do not assume voice activation or spoken command control in V1. Cloud usage should be optional where clearly justified.
- **Feasibility**: Design the architecture to minimize cloud dependency, focusing on local processing for subtitle generation and memory recall. Use the phone's capabilities fully before considering cloud services.

## Visual Hierarchy: Feasible Now
- **Current Direction**: No specific visual hierarchy decisions have been made yet.
- **Constraints**: UI should favor clarity over feature density; user control through frame touches only.
- **Feasibility**: Prioritize simplicity in the design. Ensure that subtitles are readable and not overwhelming. Use color coding or subtle animations to indicate new information or updates, but avoid cluttering the interface.
