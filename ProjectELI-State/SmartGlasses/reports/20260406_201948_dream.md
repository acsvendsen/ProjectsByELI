### Idea 1: Subtitle Placement

1. **Why it benefits the core**
   - Stable subtitle placement rules enhance user trust by ensuring that subtitles are always in a predictable and unobtrusive position, reducing cognitive load and visual distraction during live conversations.

2. **What small change unlocks it**
   - Define three fixed subtitle placement modes: one for high-confidence speakers (always visible), one for medium-confidence speakers (visible with user touch), and one for low-confidence speakers (only shown on user touch).

3. **Likely payoff**
   - By providing a clear, predictable layout for subtitles based on speaker confidence, the system will reduce user confusion and improve overall trust in the assistant's accuracy. This can lead to more consistent and reliable use of the product.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Ensuring clear, stable confidence labels helps build trust in the system's reliability. By providing concise and accurate confidence indicators, the wearer can better understand when to rely on the displayed information, thereby enhancing overall user confidence.

2. **What small change unlocks it**

   Define a simple numeric score range (0-1) for confidence levels that maps to clear labels like "Low", "Medium", and "High". For example:
   
   - 0.00-0.30: Low
   - 0.31-0.69: Medium
   - 0.70-1.00: High

3. **Likely payoff**

   By implementing a clear numeric score and label system, the system will provide more granular feedback to the wearer, which can help in making better decisions during interactions. This transparency reduces uncertainty and increases trust in the accuracy of the displayed information.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Ensuring a consistent memory cache size for face/name recall helps maintain reliable and fast lookup behavior, reducing latency and ensuring that the wearer can trust the system's memory support in critical interactions.

2. **What small change unlocks it**

   Define a local cache threshold of 5 recently interacted faces/names for each session to limit memory storage while maintaining frequent access speed.

3. **Likely payoff**

   By setting a clear and limited cache size, the system can provide fast and reliable name recall without overwhelming the phone's memory or introducing delays in lookup times. This ensures that memory support remains robust and useful during critical interactions.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By defining a clear boundary for what runs locally on the phone versus what falls back to the cloud, we ensure that critical real-time processing happens close to the glasses without unnecessary latency or data transfer. This improves subtitle clarity and trust while keeping the system lightweight and socially acceptable.

2. **What small change unlocks it**

   Define one specific task-boundary rule for live subtitle processing where the phone handles local audio transcription and sends only high-confidence transcripts to the cloud for final correction, if needed.

3. **Likely payoff**

   This boundary will ensure that subtitles are always delivered in near-real-time, reducing latency and maintaining trust with the wearer. The cloud will handle occasional corrections, improving accuracy without compromising real-time performance.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   Ensuring that subtitles are displayed in a clear, stable, and unobtrusive manner enhances the wearer's ability to follow conversations without feeling overwhelmed or distracted. This improves overall understanding and engagement in social situations, aligning with the project’s goal of reducing cognitive and social friction.

2. **What small change unlocks it**

   Define 2 to 3 subtitle placement rules for different confidence states:
   
   - For high-confidence matches (e.g., known names or repeated words), place subtitles at a fixed position slightly below the center.
   - For medium-confidence matches (e.g., new faces with seen names), place subtitles in a semi-transparent, slightly larger box that fades out over time as confidence increases.
   - For low-confidence matches (e.g., unfamiliar terms or sounds), suppress subtitles entirely and rely on one-line support to guide attention.

3. **Likely payoff**

   By defining clear placement rules for subtitles based on their confidence levels, the system can reduce visual clutter while ensuring that important information is always visible when needed. This balance improves the wearer’s trust in the subtitle accuracy and enhances the overall user experience.

4. **Immediate next probe**
   - Define one visual priority rule between subtitles and one-line support in V1.
