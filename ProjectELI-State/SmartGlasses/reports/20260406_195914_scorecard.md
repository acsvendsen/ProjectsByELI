## Project Summary
The SmartGlasses project is focused on delivering real-time subtitles, memory support for names and faces, and one-line contextual assistance while maintaining a discreet design. The V1 version will adhere to frame-touch interaction and rely primarily on the phone for processing heavy tasks. Current efforts are centered around subtitle clarity, memory trustworthiness, and low-friction assistive behavior.

## Hardware Stack
- status: on_track
- goal: Keep V1 lightweight, discreet, socially acceptable, and dependent on minimal on-glasses compute.
- limitation pressure: battery, thermal pressure, weight, social acceptability
- progress: The project is focusing on keeping the hardware stack simple by relying primarily on phone processing for heavy tasks. Current signals indicate that subtitle placement and visual clarity are being optimized to ensure readability without becoming overly distracting.
- next focus: Define a fixed subtitle position rule for V1, ensuring subtitles remain readable in noisy environments while minimizing social awkwardness.
- confidence: 0.9

## Software Stack
- status: on_track
- goal: Keep the cognition stack practical, maintainable, and centered on subtitle quality, memory trust, and low-friction assistive behavior.
- limitation pressure: complexity drift, latency, trust
- progress: The software stack is focused on delivering clear and reliable subtitles with robust memory support. The confidence display design is being refined to ensure it builds trust without overwhelming the user.
- next focus: Define a simple yet informative confidence object format that balances clarity and detail in V1.
- confidence: 0.8

## Wireless Interface
- status: on_track
- goal: Keep the glasses-phone link reliable enough for phone-first processing without making V1 fragile.
- limitation pressure: connection stability, latency, battery cost
- progress: The wireless interface is designed to ensure a stable and reliable connection between glasses and phone. The current implementation of the `TranscriptLab` app on the phone is providing practical testing for real-time transcript behavior.
- next focus: Define one phone/cloud fallback boundary for live subtitle processing where cloud fallback triggers at 500ms latency or higher, ensuring subtitles remain real-time.
- confidence: 0.8

## Firmware
- status: on_track
- goal: Keep firmware simple, robust, and aligned with touch-first input and lightweight display behavior.
- limitation pressure: embedded complexity, power draw, debugging overhead
- progress: The firmware is being designed to be minimalistic while ensuring the glasses can handle frame-touch interactions efficiently. The current focus on keeping hardware simple aligns well with early-stage requirements.
- next focus: Define one visual priority rule between subtitles and one-line support: prioritize subtitles over prompts when both are active, with prompts only displayed in the margin or as brief overlay notes during pauses in speech.
- confidence: 0.8

## Subtitle System
- status: on_track
- goal: Deliver near-real-time, readable subtitles with trust-preserving visual behavior.
- limitation pressure: latency, readability, visual distraction
- progress: The subtitle system is focusing on real-time generation and placement of subtitles. Initial testing suggests that subtitles are being displayed quickly enough to be useful in live conversations.
- next focus: Refine subtitle algorithms to ensure they remain clear and stable even when the wearer is moving or speaking loudly.
- confidence: 0.8

## Memory System
- status: on_track
- goal: Support fast, trustworthy face/name recall and conversation memory without storing too much low-value information.
- limitation pressure: privacy perception, lookup speed, false confidence
- progress: The memory system is being designed to remember names and faces based on recent interactions with clear indications of confidence. Initial tests indicate that the caching strategy is working well.
- next focus: Define a maximum cache size for local face/name memory objects, limiting them to the top N most recently interacted individuals (e.g., 5-10), ensuring efficient use of resources while maintaining useful recall.
- confidence: 0.8

## Privacy And Trust
- status: on_track
- goal: Help the wearer understand better without faking understanding, while keeping privacy and consent pressure visible.
- limitation pressure: consent, data handling, confidence clarity
- progress: The system is designed to be transparent about its capabilities and limitations. Initial tests suggest that users are comfortable with the level of memory support provided.
- next focus: Implement clear privacy policies and ensure all memory is handled with the utmost care to maintain user trust, particularly in terms of how confidence objects are represented.
- confidence: 0.8
