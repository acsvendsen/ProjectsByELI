# Reality Check Summary for SmartGlasses Project

## Subtitle Placement
**Feasible Now**: Ensure subtitles are placed where they do not distract from visual flow but remain easily readable, especially during motion. Given the constraints of frame-touch-only V1 interaction, subtitles should be positioned in a way that does not require frequent user attention or adjustment.

## Confidence Display
**Feasible Now**: Use a simple label and short reason format to indicate confidence levels. For example, "High" for high certainty and "Low" with a brief reason like "Uncertain" or "Possibly [name]." This keeps the UI uncluttered yet informative, aligning with the low-friction assistance attractor.

## Memory/Cache Policy
**Feasible Now**: Cache face and name data on the phone for quick lookup. Implement a reinforcement learning system where frequent interactions (e.g., tapping to confirm or deny a name) update memory confidence levels. This approach respects privacy while providing useful context, aligning with the privacy vs usefulness tension.

## Phone/Cloud Boundary
**Feasible Now**: Leverage cloud services only when they significantly enhance functionality without sacrificing real-time responsiveness. For example, cloud-based model updates and background processing can be used to improve accuracy over time, but local processing should remain the primary focus in V1.

## Visual Hierarchy
**Feasible Now**: Design a visual hierarchy where subtitles are prominent yet unobtrusive. Ensure one-line prompts visually differ from subtitles to avoid overwhelming the wearer. Use consistent and minimal UI elements that align with the discreet UX attractor.

### Justifications

- **Subtitle Placement**: The current constraint of frame-touch-only V1 interaction means subtitles must be placed in a way that does not require frequent user adjustment, minimizing distraction.
- **Confidence Display**: A simple label and short reason format respects the low-friction assistance principle while providing necessary feedback to the wearer.
- **Memory/Cache Policy**: Caching face and name data locally allows for quick lookup and updates based on interaction history, addressing the privacy vs usefulness tension effectively.
- **Phone/Cloud Boundary**: Using cloud services selectively (e.g., for model updates) respects real-time constraints and avoids unnecessary battery drain.
- **Visual Hierarchy**: A well-designed visual hierarchy ensures subtitles are clear without overwhelming the wearer, supporting the discreet UX attractor.

### Next Steps
1. **Subtitle Placement**: Design and test various subtitle placements to ensure they remain readable during motion.
2. **Confidence Display**: Implement a simple confidence display system with initial labels and reasons.
3. **Memory/Cache Policy**: Develop caching mechanisms for face and name data, integrating reinforcement learning.
4. **Phone/Cloud Boundary**: Test cloud services in non-critical background processing to ensure real-time responsiveness is maintained.
5. **Visual Hierarchy**: Create a prototype visual hierarchy and gather feedback from early testers.

By focusing on these concrete tasks, the project can continue to deepen its core mission without straying into speculative or low-value directions.
