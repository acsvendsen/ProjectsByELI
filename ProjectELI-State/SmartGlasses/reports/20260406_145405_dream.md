### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Ensuring that new faces and names are automatically remembered with a stable confidence object enhances the wearer's trust in the system. By reinforcing these memories over time, the glasses can provide more accurate and reliable face/name recall, which is crucial for maintaining social acceptability and reducing cognitive load.

2. **What small change unlocks it**

   Introduce an automatic memory reinforcement rule that assigns a high initial confidence score to new faces and names when they are encountered once. This score should decrease over time based on the lack of repeated interactions but remain strong enough to ensure accurate recall in subsequent sessions.

3. **Likely payoff**

   By automatically remembering likely new people, the glasses can significantly reduce the need for explicit frame-touch reinforcement while still providing reliable memory support. This approach maintains a low-friction user experience and ensures that the system is ready to assist with familiar faces as well as new ones without requiring constant re-engagement.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By clearly defining what stays on the phone versus what falls back to the cloud for live subtitle processing, we ensure real-time responsiveness while managing battery and thermal constraints effectively. This helps maintain a seamless user experience without compromising on the quality of subtitles.

2. **What small change unlocks it**

   Define a single task boundary for live subtitle processing that prioritizes local computation over network latency. For example, set the subtitle rendering and initial confidence calculation to run locally on the phone before any cloud fallbacks occur.

3. **Likely payoff**

   By keeping subtitle processing local, we can achieve faster response times, which are crucial for maintaining real-time subtitles in noisy environments. This will reduce battery drain from frequent network requests and ensure that the system is responsive even when connectivity is poor or intermittent.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.
