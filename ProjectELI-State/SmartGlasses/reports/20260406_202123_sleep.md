# Consolidation of Recent Signals

## Core Mission & Non-negotiables
- The glasses act as a discreet, context-aware personal assistant for live subtitles, face/name recall, conversation memory, and one-line support.
- V1 interaction is frame-touch only; no voice activation or spoken command control.
- Phone-first architecture with cloud optional where clearly justified.

## Strengthening Signals
- **Subtitle Clarity (subtitle_clarity)**: Increase focus on real-time subtitle quality to ensure clear, fast, and stable subtitles for live conversation. This will enhance the wearer's trust in the system during interactions.
- **Memory Trust (memory_trust)**: Improve memory support by ensuring names, faces, and prior context are remembered with honesty and clarity, without creating false certainty or corrupted recall.

## Weakening Signals
- **Low-friction Assistance (low_friction_assistance)**: Reduce emphasis on overcomplicating the interaction design. The system should provide simple one-line assistance to avoid creating command overhead or social awkwardness.
  
## Contradictions That Must Stay Alive
- **Privacy vs Usefulness**: Ensure that helpful assistive behavior does not slide into invasive capture or retention without clear justification.
- **Latency vs Richness**: Prioritize timely help over richer but slower processing. The system must provide real-time support to maintain trust.

## Dormant Ideas Worth Reactivating
- **Subtitle Placement and Visual Hierarchy (subtitle_placement)**: Revisit how subtitles are placed to ensure they remain readable in motion and noise without becoming distracting.
- **Confidence Display**: Evaluate different confidence formats, such as labels with short reasons or numeric scores, to build trust best.

## Concrete Tensions Around Core Features
1. **Subtitle Quality**:
   - **Subtle vs Clear (subtitle_clarity)**: Balance between clear and subtle subtitle placement to ensure readability without distraction.
   
2. **Memory Trust**:
   - **Automatic Memory Support vs Confidence and Correction Safety**: Ensure memory support is reliable but avoid overconfidence in automatic recall to maintain trust.

3. **Visual UX**:
   - **Discreet UX vs Visual Clarity (subtitle_placement, confidence_display)**: Strive for a balance between a subtle UI that remains socially acceptable while ensuring subtitles are readable in motion and noise.

4. **Battery and Latency**:
   - **Always-on Sensing vs Battery Drain**: Optimize subtitle clarity and memory support to minimize battery usage without compromising real-time responsiveness.
   
5. **Privacy Concerns**:
   - **Data Retention and User Consent**: Ensure that any data retention or processing respects user privacy and consent, avoiding invasive behaviors.

6. **Real-world Limits**:
   - **Phone-first vs Cloud Dependency**: Continue to favor phone-first architecture while exploring cloud capabilities when they add clear value without compromising battery and latency constraints.

## Open Questions
- **Subtitle Placement (subtitle_placement)**: Determine the best placement strategy for subtitles to ensure readability in motion and noise.
- **Confidence Display**: Decide on the best format for confidence display, such as a label with a short reason or a numeric score, to build trust effectively.
- **Memory/Cache Policy**: Define how much face/name memory should be cached locally versus stored remotely.

## Recent Project Signals
- Focus on real-time subtitle clarity and memory support.
- Prioritize low-friction assistance without overcomplicating the interaction design.
- Surface battery, latency, privacy, and usability limits early to avoid optimizing impossible directions.
- Revisit subtitle placement and confidence display for better visual UX.
- Evaluate local vs. cloud processing trade-offs.

By addressing these areas, we can deepen the core mission of SmartGlasses while ensuring real-world utility and user trust.
