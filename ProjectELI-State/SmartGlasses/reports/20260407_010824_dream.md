### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   By refining subtitle placement rules based on confidence levels, we can ensure that subtitles are always clear and readable while minimizing distraction. This will help maintain trust in the system's real-time capabilities, which is crucial for V1.

2. **What small change unlocks it**

   Introduce a simple rule where high-confidence subtitles appear at the top center of the field of view, while low-confidence subtitles move to the bottom right corner. 

3. **Likely payoff**

   This change will enhance subtitle clarity and stability, ensuring that the wearer can always trust the displayed text in live conversations. It will also reduce visual clutter and distraction, making the system more discreet and usable.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**
   
   Improving the confidence display format helps ensure that the wearer can trust the system's memory and subtitle suggestions. A clear and consistent confidence format builds user trust, which is critical for the product’s success.

2. **What small change unlocks it**

   Define a simple numeric score + label + short reason confidence object format. For example: "score 0.85 + 'High' + 'Seen recently'; score 0.45 + 'Low' + 'Weak match'; score 0.60 + 'Medium' + 'Name heard once in introduction'. 

3. **Likely payoff**

   A clear confidence format will help the wearer understand the reliability of memory and subtitle suggestions, leading to better user trust and more effective use of the product.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   By setting a local cache threshold for face/name memory, we ensure that likely new-person memories are automatically captured while maintaining trust through clear confidence indicators. This helps in reinforcing correct memory associations over time and reduces the risk of unnecessary privacy invasions.

2. **What small change unlocks it**

   Define one reinforcement rule that sets a recency threshold for capturing new person memories on the phone, such as "If a face or name is seen within 30 seconds, add a confidence object to the local cache."

3. **Likely payoff**

   This small change will help in automatically capturing likely new-person memories without constantly prompting the user, thus reinforcing correct memory associations and reducing the workload for explicit reinforcement. It also ensures that trust is maintained by providing clear confidence indicators.

4. **Immediate next probe**

   Define one reinforcement rule for repeated face/name encounters with a 30-second recency threshold.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By defining a clear boundary for what stays phone-local versus what falls back to cloud for live subtitle processing, we ensure that subtitles remain fast and reliable in real-time interactions. This enhances trust and usability by keeping processing close to the edge where latency is critical.

2. **What small change unlocks it**

   Define one specific task-boundary rule: live subtitle processing should be done entirely on the phone until the transcript cleanup task can be handled locally with minimal latency impact.

3. **Likely payoff**

   By keeping subtitle processing local, we reduce the risk of lag and maintain high trust in the subtitles during critical real-time interactions. This improves overall user satisfaction and reliability, aligning well with our core attractors for real-time clarity and low-friction assistance.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   By defining a clear visual hierarchy that prioritizes subtitles over one-line support, the system ensures that the wearer can focus on essential information without being overwhelmed by additional prompts. This helps maintain the core mission of providing clear and unobtrusive real-time assistance.

2. **What small change unlocks it**

   Define a subtitle-vs-one-line priority rule: When confidence is high for subtitles, prioritize showing them prominently; when one-line support is needed, show it in a less intrusive manner that does not compete with the subtitles.

3. **Likely payoff**

   This change will improve the wearer's ability to follow conversations by ensuring they can easily read and process critical information while minimizing distractions from less essential prompts. It also aligns with the core attractors of real-time subtitle clarity and low-friction assistance, enhancing overall usability without overwhelming the user.

4. **Immediate next probe**
   - Define one visual priority rule between subtitles and one-line support in V1.
