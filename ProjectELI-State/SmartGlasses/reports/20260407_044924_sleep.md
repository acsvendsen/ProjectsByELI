# Recent Consolidation for SmartGlasses Project

## Strengthened Signals
- **Subtitle Clarity**: Ensure subtitles remain clear, fast, and stable to maintain trust in live conversations.
- **Memory Trust**: Enhance the reliability of name and face recall without overconfidence or misattribution.

## Weakened Signals
- **Low-Friction Assistance**: Reduce emphasis on low-friction interaction modes that could introduce unnecessary complexity early in V1 development.

## Contradictions That Must Stay Alive
- **Privacy vs Usefulness**: The system must not trade privacy for functionality, ensuring user trust and data security remain paramount.
- **Latency vs Richness**: Optimize for timely responses without adding features that might significantly increase latency.

## Dormant Ideas Worth Reactivating
- **Subtitle Placement**: Revisit the current subtitle placement to ensure it remains non-distracting yet usable. This is particularly important given recent build summaries indicating successful updates in `TranscriptLab`.

## Concrete Tensions Around
1. **Subtitle Quality, Confidence Trust**:
   - Focus on continuous improvement of subtitle clarity and confidence display without overloading the user interface.
2. **Automatic Memory Behavior vs Explicit Remember-Touch Behavior**:
   - Ensure automatic memory reinforcement is subtle yet effective, avoiding explicit remember-touch behavior unless explicitly required by the project constraints.

## Open Questions
- **Subtitle Placement**: Determine an optimal placement that balances usability with distraction in motion and noise.
- **Confidence Display**: Evaluate different confidence formats to find a balance between clarity and non-intrusiveness.
- **Memory/Cache Policy**: Decide on the amount of face/name memory to cache locally versus relying on phone/cloud processing.
