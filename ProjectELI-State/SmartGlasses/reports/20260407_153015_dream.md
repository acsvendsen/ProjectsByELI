### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   By defining a clear subtitle placement rule based on confidence state, we can ensure that subtitles are placed in positions where they remain most readable and least distracting to the wearer. This improves the overall user experience by reducing cognitive load during critical moments of interaction.

2. **What small change unlocks it**

   Define two subtitle placement rules: one for high-confidence states (e.g., when the system is highly certain about the speaker) and another for lower-confidence states (e.g., when there are ambiguities or multiple speakers).

3. **Likely payoff**

   Implementing these rules will help maintain a consistent, unobtrusive display of subtitles, which can enhance the wearer's understanding without causing distraction. This balance is crucial for trust and usability in noisy environments.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

4. **Immediate next probe**

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**
   - By setting a clear threshold for local memory retention on the phone, we can ensure that the system prioritizes frequently encountered names and faces while managing battery usage effectively. This helps in maintaining trust through consistent and relevant memory support without overloading the device's resources.

2. **What small change unlocks it**
   - Define a recency-based eviction policy where memory objects older than X days are removed from the local cache, with a lower threshold for frequently encountered people.

3. **Likely payoff**
   - This approach will help in maintaining a balanced memory system that is both useful and efficient. It will ensure that the system does not consume unnecessary battery while still providing reliable support for names and faces that the wearer encounters frequently. Additionally, it will prevent the storage of low-value information, which can otherwise lead to privacy concerns or clutter.

4. **Immediate next probe**
   - Define one recency-based eviction rule for local face/name memory objects, setting a threshold such as "remove memory entries older than 30 days but retain those encountered more than once per week."

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   Ensuring that memory recall for new faces and names operates primarily on-device can improve trust by reducing reliance on potentially intrusive cloud services. This helps maintain privacy while still providing useful context to the wearer.

2. **What small change unlocks it**

   Define a local cache eviction policy that limits the number of person-memory objects stored on the phone before they are considered "old" and removed from active memory.

3. **Likely payoff**

   By keeping new faces and names in local memory, the system can quickly recall them during interactions without needing to query the cloud, thus reducing latency and preserving privacy. This also ensures that memory is reinforced over time through frequent interaction, improving long-term trust.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   Improving subtitle-vs-one-line priority rules ensures that critical real-time subtitles remain clear and unobtrusive while one-line support is appropriately prioritized for quick, low-friction assistance without overwhelming the wearer.

2. **What small change unlocks it**

   Define a visual hierarchy rule that prioritizes subtitles based on their confidence score, ensuring high-confidence subtitles are always visible, while lower-confidence subtitles or one-liners are suppressed when necessary to maintain clarity.

3. **Likely payoff**

   By defining clear subtitle priority rules, the system can better manage visual clutter and ensure that the wearer focuses on critical information without distraction, leading to a more usable and trusted assistive experience.

4. **Immediate next probe**
   - Define one visual priority rule between subtitles and one-line support in V1.
