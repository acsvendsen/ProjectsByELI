## Strengthening Signals
- **Subtitle Quality**: Users are increasingly recognizing the value of accurate and timely subtitles in noisy environments, highlighting the need for higher quality real-time processing.
- **Memory Lookups**: There is a growing expectation that the system should provide quick and reliable face/name recall, making memory lookup speed and accuracy more important.

## Weakening Signals
- **Complex Interaction Patterns**: The necessity for complex voice commands or multi-modal interactions is weakening as users appreciate the simplicity of frame-touch controls.
- **Heavy On-Glasses Processing**: Early concerns about on-glasses processing are fading due to advancements in phone capabilities, reducing the immediate pressure to offload tasks onto the glasses.

## Contradictions that Must Stay Alive
- **Privacy vs. Usefulness**: The tension between providing useful information and respecting privacy remains crucial. The system must be transparent about data usage while offering effective assistance.
- **Battery vs. Always-On Sensing**: The need for always-on sensing to improve context awareness is in constant conflict with battery life constraints, requiring careful balance.

## Dormant Ideas Worth Reactivating
- **Visual Hierarchy and UX**: Exploring new subtitle placements that enhance readability without increasing visual clutter could be valuable.
- **Confidence Display**: Investigating different ways to display confidence levels for subtitles and memory lookups might improve user trust and reliability of the system.

## Concrete Tensions Around Core Domains

### Subtitle Quality, Confidence Trust
- **Subtitle Reasoning vs. Memory Lookup**: The quality of real-time subtitle reasoning must be balanced with the accuracy and speed of face/name recall.
- **Confidence Display**: Should confidence levels be displayed numerically or as labels? How can this information be presented without overwhelming the user?

### Memory Lookup, Privacy
- **Local vs Cloud Storage**: Deciding how much memory should be cached locally versus stored in the cloud is critical. This impacts both battery usage and privacy concerns.
- **Memory Reinforcement**: How often should new faces/names be reinforced to ensure reliable recall? What are the best practices for updating memory without compromising privacy?

### Visual UX, Interaction
- **Subtitle Placement**: The ideal placement of subtitles on the glasses must balance readability with minimal distraction. Experimenting with different positions can provide insights.
