## Project Summary
The SmartGlasses project is focused on delivering core assistive features like real-time subtitles, face/name recall, and low-friction assistance while managing constraints related to privacy, battery life, and social acceptability. The current iteration is V1, with frame-touch interactions as the primary input method and phone-first processing for heavy computation.

## Hardware Stack
- status: on_track
- goal: Keep V1 lightweight, discreet, socially acceptable, and dependent on minimal on-glasses compute.
- limitation pressure: battery
- progress: The project remains focused on keeping the glasses hardware simple with minimal local processing. The subtitle placement is more prominent as requested, which should help readability in noisy environments.
- next focus: Optimize subtitle display to ensure stability and readability without overwhelming the wearer.
- confidence: 1.0
