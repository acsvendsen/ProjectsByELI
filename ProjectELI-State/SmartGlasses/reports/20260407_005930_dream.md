### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Ensuring stable subtitle placement rules for different confidence states helps maintain a consistent user experience, reducing cognitive load by making subtitles predictable and reliable. This stability is crucial for trust and daily-use value.

2. **What small change unlocks it**

   Define fixed position rules based on confidence levels: low-confidence subtitles should appear at the bottom of the screen with minimal intrusion; medium-confidence subtitles can take a central but smaller area; high-confidence subtitles can occupy a more prominent space while still being readable.

3. **Likely payoff**

   By implementing stable subtitle placement, the system will reduce visual clutter and improve readability. This stability enhances user trust in the subtitles' accuracy and reliability, making them a dependable tool for real-time communication support.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Ensuring that confidence objects are clearly formatted with a numeric score, label, and short reason helps maintain trust by providing transparency about the system's certainty level. This clarity ensures that the wearer understands when the system is highly confident versus when there is uncertainty, which is crucial for effective real-time assistance.

2. **What small change unlocks it**

   Define one confidence format candidate for V1, where each confidence object includes a numeric score, a label (like "High", "Medium", or "Low"), and a short reason (e.g., "Seen recently", "Weak match").

3. **Likely payoff**

   By providing clear and concise confidence information, the system can help the wearer trust its outputs more, leading to better engagement and utilization of the subtitle and memory assistance features. This clarity will also make it easier for users to understand when they should pay extra attention or when the system's suggestions are reliable.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   By optimizing the local cache size for face/name memory, we can ensure that critical entities are always quickly accessible without unnecessary data usage or latency. This improves the trust and reliability of memory support by reducing the time it takes to recall important names and faces.

2. **What small change unlocks it**

   Define a local cache size limit for frequently encountered individuals, ensuring that the most recently seen people are cached locally while older entries are evicted based on recency or frequency of use.

3. **Likely payoff**

   This change will enhance the speed and reliability of face/name recall, making memory support more trustworthy and responsive. It will help in maintaining a balance between local storage limitations and the need for fast lookup.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By defining a clear phone-cloud boundary for live subtitle processing, we ensure that critical real-time performance is maintained on the local device while less urgent tasks can leverage cloud resources. This balance enhances the reliability and trust of subtitles in noisy environments by reducing latency and ensuring consistent behavior.

2. **What small change unlocks it**

   Define one specific task as a phone-local fallback boundary for live subtitle processing, such as switching to cloud for transcript cleanup or memory archive sync but keeping real-time subtitle processing on-device.

3. **Likely payoff**

   By focusing the glasses' primary runtime on critical tasks like real-time subtitles, we maintain high trust and reliability in noisy environments where timely responses are crucial. This also allows the phone to handle less time-sensitive tasks more efficiently, extending battery life and reducing thermal stress on the glasses.

4. **Immediate next probe**
