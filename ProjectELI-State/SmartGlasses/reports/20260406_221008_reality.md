## Reality Check Summary

### Feasible Now
- **Subtitle Placement**: The glasses should prioritize a design that keeps subtitles clear, stable, and unobtrusive. Given the current lack of hardware constraints, this can be iterated upon with best effort (e.g., top-center placement for readability).
  
- **Confidence Display**: Implementing confidence as a label-only system is feasible now. A simple "Low", "Medium", or "High" indicator can provide early trust signals without overwhelming the wearer.

- **Memory Policy**: Caching face/name memory on the phone in a way that respects privacy (e.g., storing hashes of names and faces) is feasible now. This can be implemented with minimal storage impact while ensuring fast lookup speeds.

### Feasible Later
- **Subtitle Clarity**: Refine subtitle placement to minimize distraction and ensure readability. This could involve iterative design tweaks based on user feedback or further testing in noisy environments.
  
- **Memory Support**: Develop a more sophisticated memory support system that can handle richer contexts and faster lookups as the project evolves. This might include more complex reinforcement learning techniques.

### Likely Waste of Time
- **Voice Activation**: Assuming voice activation for V1 interaction is likely to be a waste of time since it conflicts with the current frame-touch-only constraint.
  
- **Fancy AR Visuals**: Introducing full AR features like 3D overlays or complex visualizations might be premature given the early hardware constraints and focus on core functionality.

### Assumptions Needing Evidence
- **Phone/Cloud Boundary**: Deciding when to use cloud processing for memory lookups versus phone-side processing needs more evidence. This should be grounded in real-world latency and battery impact tests.
  
- **Visual Hierarchy**: Defining the visual hierarchy that balances subtlety with clarity, especially for one-line prompts, requires concrete examples or prototypes.

### Core Deepening Over Sprawl
- The current V1 architecture direction is sound, focusing on core functionality (subtitle quality, memory support) before expanding into broader features. This approach should be maintained to ensure the project remains focused and impactful.
