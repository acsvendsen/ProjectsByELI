### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   By establishing consistent subtitle placement rules based on confidence levels, we can ensure that subtitles remain readable and unobtrusive while still providing necessary support. This helps maintain trust and clarity in real-time interactions.

2. **What small change unlocks it**

   Define three subtitle placement rules:
   - Fixed position at the bottom of the screen for high-confidence text.
   - Sliding up from the bottom with decreasing confidence to avoid obscuring critical information.
   - Hidden by default for low-confidence text and shown on user touch.

3. **Likely payoff**

   Implementing these rules will reduce visual clutter, maintain readability, and prevent distracting the wearer during conversations. This approach ensures that only necessary subtitles are visible, enhancing both clarity and trust in the system's behavior.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving the confidence display format enhances trust by clearly indicating the reliability of the displayed information to the wearer. This helps in maintaining the wearer's confidence in the system, which is crucial for real-time subtitle clarity and memory support.

2. **What small change unlocks it**

   Define a clear and concise confidence format that includes a numeric score with a label and a short reason. For example: "score 0.84 + 'High' + 'Seen recently';" this format provides immediate feedback on the reliability of the information without overwhelming the wearer.

3. **Likely payoff**

   A well-defined confidence format will help in building trust by making it clear when the system is highly confident versus less certain. This clarity can reduce cognitive load for the wearer, allowing them to focus more on understanding the conversation rather than questioning the accuracy of the subtitles or memory support.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**
   - Improving memory cache policy helps ensure that frequently encountered people and names are remembered with high confidence over time, reducing the likelihood of errors or forgotten context.

2. **What small change unlocks it**
   - Define a local cache eviction rule that prioritizes recent and frequent encounters for both face and name recognition, ensuring these entities remain strongly cached on the phone.

3. **Likely payoff**
   - This improvement will enhance the reliability and trustworthiness of memory support, making the system more useful in dense multi-person contexts where quick recall is essential.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By defining a clear phone-cloud boundary for live subtitle processing, we ensure that subtitles are delivered in near-real-time, maintaining trust and clarity. This approach helps the wearer stay present and informed during conversations without the risk of delayed or laggy text.

2. **What small change unlocks it**

   Define one local cache eviction rule for face/name memory to keep frequently used names and faces cached on-device, reducing latency and improving recall speed when needed.

3. **Likely payoff**

   Implementing a local cache for commonly encountered faces and names will reduce the need for cloud requests during live interactions, leading to faster response times and more reliable memory support. This enhances the core mission of providing timely and accurate subtitle and memory assistance without compromising on real-time performance.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.
