# Reality Check for SmartGlasses V1 Direction

## Subtitle Clarity (Subtitle Placement, Visual Hierarchy)

### Feasible Now:
- **Subtitle Placement:** The primary candidate of "More Prominent" is feasible now. This ensures subtitles remain visible in noisy environments without overwhelming the wearer.
  - Justification: The current implementation uses a prominent placement strategy which balances visibility and distraction.

### Feasible Later:
- **Visual Hierarchy:** Considering a subtler but more readable option might be beneficial as we evolve beyond V1, especially if it allows for more seamless integration with other UI elements without sacrificing clarity.
  - Justification: As the glasses gain additional features (e.g., one-line prompts), a refined visual hierarchy could optimize screen real estate.

### Likely Waste of Time:
- **Subtle Overlay:** Implementing extremely subtle subtitle placement might reduce distraction but could make subtitles less readable, especially in noisy environments.
  - Justification: Current tests suggest that moderately prominent placements are optimal for quick reading and minimal disruption.

## Memory Trust (Confidence Display)

### Feasible Now:
- **Label + Reason:** The operator has selected "Label + Reason" as the confidence display method. This is feasible now and aligns with real-world limitations.
  - Justification: It provides a clear indication of how confident the system is in its responses, helping to build trust without overwhelming the wearer.

### Feasible Later:
- **Numeric Score:** Introducing a numeric score might be considered later if it significantly enhances user trust and doesn’t add excessive complexity or visual clutter.
  - Justification: A numeric score could provide an immediate indication of confidence but may require careful design to ensure readability and ease of interpretation.

### Likely Waste of Time:
- **Complex UI Elements:** Adding multiple complex UI elements (e.g., progress bars, detailed explanations) might be overly complicated for V1.
  - Justification: The primary goal is to maintain a simple and usable interface that doesn’t detract from the core mission.
