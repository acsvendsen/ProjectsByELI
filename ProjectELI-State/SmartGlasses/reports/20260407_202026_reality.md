## Reality Check for SmartGlasses Project

### Subtitle Placement Feasibility: Likely Waste of Time
**Current Status:** Subtitle placement is a critical decision area, but early efforts should focus on ensuring subtitles are clear, stable, and not distracting. Given the current V1 interaction constraints (frame-touch only), the primary effort should be on optimizing text clarity and stability through transcript testing rather than placing subtitles.

- **Reasoning:** The `TranscriptLab` app is designed to test core subtitle behavior in a phone-first environment. Early efforts should focus on improving live transcription quality and confidence display, which are essential for V1 functionality. Subtitle placement can be addressed after the basic functionality is validated through this testing framework.
