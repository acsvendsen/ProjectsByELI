### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Improving subtitle placement rules can significantly enhance the wearer's understanding by making subtitles more readable and less distracting. Stable and predictable subtitle placement ensures that critical information is always visible, reducing cognitive load during conversations.

2. **What small change unlocks it**

   Define a simple, static subtitle placement rule for V1 that prioritizes readability without becoming distracting. For example, place subtitles at the bottom of the frame, slightly offset from the center, and ensure they remain within view regardless of head movement or object occlusion.

3. **Likely payoff**

   By setting a clear and consistent subtitle placement rule, we can reduce eye strain and increase comprehension during live interactions. This will help the wearer stay more focused on the conversation itself rather than trying to track subtitles that move unpredictably.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

Improving the confidence display format ensures that the wearer can trust the system's output more effectively. A well-defined confidence label with a short reason will help the wearer understand when to rely on the subtitles and when they might need to pay extra attention due to uncertainty.

2. **What small change unlocks it**

Define one specific confidence format, such as: score 0.84 + "High" + "Seen recently"; score 0.42 + "Low" + "Weak match"; score 0.63 + "Medium" + "Name heard once in introduction".

3. **Likely payoff**

This change will enhance the trustworthiness of the subtitles, helping the wearer better understand when to rely on the system's output and when additional attention is needed. It will also provide a clear indication of the reliability of memory support and one-line prompts.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   By setting a local cache threshold for name recall, we ensure that the glasses can quickly provide relevant context without excessive cloud traffic or latency, enhancing real-time subtitle clarity and memory support. This helps in maintaining trust by providing timely assistance.

2. **What small change unlocks it**

   Define a local cache size limit of 50 entries for names and faces, with a recency threshold of the last week's interactions. This ensures that frequent and relevant memories are prioritized while keeping the memory footprint manageable.

3. **Likely payoff**

   By implementing this cache policy, we can significantly reduce latency in name recall and face recognition, improving the overall user experience without overloading the phone or cloud. This will help in maintaining high confidence in memory support and ensuring that the glasses remain a reliable tool for understanding social interactions.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By defining clear boundaries for what runs on the phone versus the cloud, we can ensure that critical subtitle processing happens locally to maintain real-time performance and trust. This local processing also helps with battery management and privacy by keeping sensitive data closer to the wearer.

2. **What small change unlocks it**

   Define a single task boundary for live subtitle processing where only the glasses and phone handle local processing, while cloud fallback is limited to specific tasks like transcript cleanup or memory archive sync.

3. **Likely payoff**

   This approach will ensure that subtitles remain reliable and fast, maintaining trust in real-time interaction support. It also reduces battery drain and respects user privacy by minimizing data sent to the cloud.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.
