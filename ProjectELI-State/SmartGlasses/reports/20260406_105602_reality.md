# Reality Check for SmartGlasses V1 Direction

## Core Mission: Discreet Context-Aware Personal Assistance
- **Subtitle Quality:** Real-time, clear, and discreet subtitles are crucial.
- **Memory Trust:** Face/name recognition must be reliable yet non-intrusive.
- **One-Line Support:** Provide quick, context-aware guidance without overwhelming the wearer.

## V1 Interaction: Frame Touches Only
- No voice activation or spoken commands in V1. Focus on minimal touch interactions for subtitle management and mode switching.

## Core Constraints
### Hardware Limits
- **Display Text:** Clear and readable text with minimal distraction.
- **Audio/Visual Input:** Minimal sensor usage to avoid battery drain.

### Battery and Thermal Management
- **Limited On-Glasses Compute:** Heavy processing should remain on the phone or cloud.
- **Low Latency Subtitles:** Real-time subtitle generation is essential. Delayed subtitles can break trust.

### Privacy Considerations
- **Contextual Memory:** Store minimal, contextually relevant data to respect user privacy.
- **Face/Name Recall:** Implement clear uncertainty indicators for recognition confidence.

### Interaction Design
- **Frame Touches Only:** Ensure all interactions are intuitive with simple touch commands.
- **UI Simplicity:** Clear visual hierarchy and low-friction UX.

## Core Features: Feasibility Assessment

### Real-Time Subtitles (Feasible Now)
- **Current Signals:** No change in signals, confirming V1 should focus on real-time subtitle assistance.
- **Implementation:** Use phone to process audio input and generate subtitles for display. Optimize text clarity and placement to minimize distraction.

### Face/Name Recall (Likely Waste of Time)
- **Current Signals:** No recent changes suggest face/name recognition without cloud processing is not feasible now due to latency constraints.
- **Assumptions Needing Evidence:** Explicitly require evidence that local face recognition can meet the speed and accuracy requirements before considering this feature.

### One-Line Support (Feasible Now)
- **Current Signals:** V1 should focus on providing context-aware one-line prompts. Ensure these are concise, helpful, and do not overwhelm.
- **Implementation:** Utilize phone for processing user context to generate appropriate one-liners.

### Confidence Indicators (Feasible Later)
- **Current Signals:** While useful, full confidence indicators might be too complex in V1. Start with simple labels or minimal confidence cues.
- **Assumptions Needing Evidence:** Gather evidence on how simplified confidence indicators impact trust before implementing more complex systems.

## Likely Waste of Time
- **Complex AR Visuals and Multimodal UI:** These features are not justified for V1 given the current constraints. Focus on core functionality first.

## Real Implementation Constraints
- **Battery Drain:** Avoid heavy local processing to minimize battery draw.
- **Thermal Pressure:** Keep glasses lightweight and socially acceptable.
- **Privacy Perception:** Implement clear uncertainty indicators to manage user trust in memory features.

## Core Tensions
- **Always-On Sensing vs. Battery/Thermals:** Optimize for minimal always-on features that do not significantly impact battery life or heat generation.
- **Local Processing vs. Cloud Intelligence:** Prioritize cloud processing where it adds value and does not compromise real-time performance.

## Evolution Rule: Core Deepening
- **Subtitle Quality Improvement:** Focus on refining subtitle quality, placement, and clarity.
- **Memory Trust Enhancement:** Improve face/name memory accuracy and trust through clear uncertainty indicators.
- **Low-Friction UX:** Ensure all interactions are simple and intuitive to maintain user engagement.

## Next Steps
1. **Subtitle Placement:** Conduct a usability test to determine the most effective subtitle display location.
2. **Confidence Format:** Gather feedback on different confidence formats (labels, labels + short reasons) for better trust-building.
3. **One-Line Prompts:** Define specific use cases and examples of helpful one-liners for V1.

By focusing on these core aspects, the project can ensure it remains grounded in real-world constraints while continuously improving its core mission.
