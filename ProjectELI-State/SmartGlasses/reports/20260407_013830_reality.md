# Reality Check for SmartGlasses

## Subtitle Clarity (Real-time subtitle clarity)
- **Feasible now:** Ensure that the real-time subtitles are clear, fast, and stable enough to maintain trust in live conversations. Given the current focus on core deepening, this can be achieved by continuously refining the text display algorithm and optimizing the subtitle placement within the constraints of frame-touch interactions.

## Memory Trust (Trustworthy memory support)
- **Feasible now:** Implement face/name recall with confidence objects that clearly indicate uncertainty to prevent misleading the wearer. This can be done through the existing phone-first processing architecture, ensuring that new memories are reinforced over time without creating false certainty.
  
## Low-friction Assistance (Low-friction assistance)
- **Feasible now:** Deliver one-line contextual prompts without creating command overhead or social awkwardness. This involves carefully balancing the display of subtitles and prompts to ensure they do not overwhelm the wearer, focusing on the essential information needed for effective communication.

## Privacy vs Usefulness
- **Constraint Pressure:** Ensure that memory support respects privacy while providing useful assistance. For example, storing face/name memories with clear confidence levels can maintain trust by acknowledging uncertainty when there is no strong evidence.
  
## Latency vs Richness
- **Constraint Pressure:** Prioritize real-time subtitle clarity over rich context to avoid latency issues. Given the current phase of core deepening, focus on delivering clear and timely subtitles rather than overly complex memory recall that might introduce significant latency.

## Discreet UX vs Visual Clarity
- **Discreet UX:** The UI should remain socially acceptable while still being readable in motion and noise. This can be achieved by using subtle visual cues for the one-line prompts and ensuring subtitle placement does not interfere with the wearer's view of their surroundings.
  
### Actions:
1. **Subtitle Placement:** Focus on optimizing subtitle display within the field of vision, ensuring they do not become distracting but remain visible enough to aid in understanding. Use the `TranscriptLab` app to test different placements and ensure they are clear and stable.

2. **Confidence Display:** Implement confidence labels with short reasons where necessary to build trust without overloading the wearer. Ensure that these labels are easily understandable and clearly indicate when the system is uncertain.

3. **Face/Name Memory:** Use face/name memories reinforced through interactions on the phone, ensuring they do not create a false sense of certainty. Store new entries with appropriate confidence levels based on the available evidence.

4. **Low-friction Interaction:** Ensure that all interactions are controlled through frame touches only to maintain simplicity and avoid adding unnecessary complexity. The `TranscriptLab` app can be used to validate these interactions in real-time scenarios.

5. **Privacy Considerations:** Continuously evaluate memory storage practices to ensure they respect privacy while providing useful support. Use the current constraints and guidelines to guide decisions on how and when to store face/name memories.

6. **Latency Management:** Prioritize delivering clear, real-time subtitles over more complex contextual information that might introduce latency issues. The `TranscriptLab` app can help in refining this balance by testing different levels of context with varying latencies.

By focusing on these specific areas and using the `TranscriptLab` app for validation, we can ensure that the SmartGlasses remain focused on delivering core value without unnecessary complexity or trade-offs.
