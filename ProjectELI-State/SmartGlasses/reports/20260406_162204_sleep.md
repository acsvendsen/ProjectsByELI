# SmartGlasses Consolidation

## Strengthening Signals

### Subtitle Quality and Placement
- **Subtitle Placement**: The system should prioritize more prominent subtitle placement to ensure they are easily readable without becoming distracting. This means adjusting the visual hierarchy so subtitles dominate the wearer’s field of view.

### Memory Trust and Reinforcement
- **Memory Policy**: Implement recency-first caching on the phone for face/name recall, ensuring that recently seen faces are prioritized over older memories. This will help in maintaining a high level of trust in memory accuracy.
  
## Weakening Signals

### Interaction Complexity
- **Frame Touch Only**: V1 should strictly adhere to frame-touch interaction, avoiding any assumptions about voice activation or spoken command control.

### Cloud Usage
- **Phone First**: Rely heavily on the phone for processing, using cloud services only where necessary and justified. This helps in reducing battery drain and maintaining real-time response times.

## Contradictions That Must Stay Alive

### Privacy vs Usefulness
- The system must balance providing useful contextual information with respecting privacy concerns. This means carefully managing how and when to store and display memory data.

### Memory Reinforcement
- **Memory Cache Policy**: While the recency-first policy is good, there should be a mechanism for reinforcing memories that are crucial or frequently encountered. This can help in building stronger confidence over time without overwhelming the system with too much data.

## Dormant Ideas Worth Reactivating

### Confidence Display
- The current decision on using `Label + Reason` for confidence display is still relevant but could benefit from further refinement. Consider exploring different formats to see which one builds trust most effectively.
  
### Visual Hierarchy
- **Subtitle vs Prompt Placement**: There should be a clear distinction in visual hierarchy between subtitles and one-line prompts to ensure the wearer can easily distinguish between them.

## Concrete Tensions Around Core Areas

### Subtitle Quality, Confidence Trust, Automatic New-Person Memory, Memory Reinforcement, Fast Lookup, Privacy, Battery, Visual UX
- **Subtitle Quality**: Ensure subtitles are clear and readable without causing distraction.
- **Confidence Display**: Find the right balance in displaying confidence to avoid overloading the wearer with too much information.
- **Automatic New-Person Memory**: Implement a robust automatic memory behavior for new faces and names while respecting privacy boundaries.
- **Memory Reinforcement**: Balance between reinforcing important memories and maintaining user trust.
- **Fast Lookup**: Optimize fast lookup requirements without compromising on battery or thermal constraints.
- **Privacy**: Ensure that all interactions respect privacy, especially in the context of face/name recall.
- **Battery**: Minimize battery drain while ensuring real-time responsiveness.
- **Visual UX**: Design a visual hierarchy that is both functional and unobtrusive.
