### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   By defining clear subtitle placement rules based on confidence levels, we can ensure that subtitles are always visible and readable without becoming distracting. This improves the wearer's ability to understand real-time conversations while maintaining a low-friction UX.

2. **What small change unlocks it**

   Define a rule that places subtitles in a fixed position near the center of the screen for high-confidence matches and slightly lower on the right side for medium-confidence matches, with no placement for low-confidence matches.

3. **Likely payoff**

   This approach will reduce subtitle distraction while ensuring critical information is always visible. It also aligns with the core attractors by maintaining real-time clarity and reducing social friction.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving confidence display by using a clear, concise format helps maintain trust and reliability in memory support. A well-designed confidence indicator ensures that the wearer can quickly understand the certainty of name or face recognition without confusion.

2. **What small change unlocks it**

   Define a simple numeric score + label + short reason confidence object for V1. This involves setting a few basic rules on how to format and present confidence levels in real-time, such as showing "High" when the score is 0.8 or higher, "Medium" for scores between 0.5 and 0.79, and "Low" for scores below 0.5.

3. **Likely payoff**

   By defining a clear and concise confidence format, V1 can provide more reliable memory support that the wearer trusts. This will help in building confidence in the system’s ability to remember names and faces accurately, thereby enhancing overall user trust and satisfaction.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   By optimizing local memory thresholds, we can ensure that the system remembers names and faces with high confidence while minimizing battery drain and thermal load. This improves trust in name recall by ensuring accurate and timely responses without overloading the device.

2. **What small change unlocks it**

   Define a cache eviction rule based on recency and confidence score. For example, if a person is mentioned frequently but less recently, their memory should be retained longer than someone who was seen only once with low confidence.

3. **Likely payoff**

   This refined cache policy will allow the system to provide more accurate name recall over time without excessive battery usage. The wearer can trust that the glasses remember important names and faces reliably, enhancing the overall assistive experience.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   Ensuring that live subtitle processing stays on-device (phone) improves real-time responsiveness and reduces latency, which is crucial for maintaining trust in the wearer's ability to follow conversations effectively.

2. **What small change unlocks it**

   Define a boundary rule that specifies live subtitle processing must run phone-side unless explicitly overridden by a high-confidence threshold or a specific task requiring cloud resources.

3. **Likely payoff**

   By keeping subtitle processing local, we ensure subtitling quality is near-real-time, reducing the risk of delay and maintaining the wearer's trust in the system’s accuracy and timeliness.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   Ensuring a clear visual hierarchy between subtitles and one-line support helps maintain the wearer's focus on critical information while minimizing distraction. This balance is crucial for trust, as overly complex displays can overwhelm the user, leading to confusion or disengagement.

2. **What small change unlocks it**

   Define a subtitle-vs-one-line priority rule that keeps subtitles always visible with high prominence, while one-line support appears only when relevant and minimally intrusive. This ensures that critical information is never missed but also that any added context does not overwhelm the wearer.

3. **Likely payoff**

   By clearly prioritizing subtitles over one-line support, the system can maintain a high level of trust through unambiguous visual cues. This clarity will help in noisy environments and dense conversation contexts where accurate real-time information is paramount.

4. **Immediate next probe**
   - Define one visual priority rule between subtitles and one-line support in V1.
