### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Subtitle placement rules that are consistent and predictable will help users trust the subtitles more, ensuring they remain focused on live conversation without distractions. This stability reduces cognitive load and enhances overall user experience.

2. **What small change unlocks it**

   Define 3 to 5 fixed subtitle placement rules based on confidence levels: low (static bottom), medium (dynamic top-left), high (fixed top center).

3. **Likely payoff**

   By establishing stable, non-reactive subtitle placement rules, users will be more likely to trust the subtitles and focus on the conversation. This reduces cognitive load and enhances the overall user experience by minimizing visual distractions.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving confidence display ensures that the wearer can trust the system's outputs, which is crucial for real-time subtitle clarity and memory support. A clear and consistent confidence format helps the wearer understand when to rely on the system more or less, enhancing overall reliability and user trust.

2. **What small change unlocks it**

   Define a simple confidence format that combines a numeric score with a label and a short reason. This format will provide enough detail for the wearer to understand the certainty level of the information provided by the system.

3. **Likely payoff**

   By clearly displaying the confidence level, the system can reduce uncertainty and increase trust among users. This clarity will help in situations where the wearer needs to rely on the system more heavily, such as in noisy environments or when dealing with unfamiliar names and faces.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Improving memory cache size and eviction rules ensures that the system retains relevant information while managing battery usage effectively. This will help in providing more accurate and timely assistance to the wearer, thus enhancing trust and reliability.

2. **What small change unlocks it**

   Define a simple local-memory threshold rule where new face/name memories are cached only if they have been encountered multiple times within a short timeframe (e.g., 15 minutes). This will allow for robust memory reinforcement while minimizing cache bloat.

3. **Likely payoff**

   By setting a clear and conservative memory eviction policy, the system can maintain a balance between providing useful context without overwhelming the local cache. This will lead to faster lookups and more reliable memory support over time, improving overall user trust in the system's ability to recall relevant information when needed.

4. **Immediate next probe**
   - Define the eviction rule for memory objects, where any object is evicted if it has been encountered less than 10 times within a 24-hour period.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   Ensuring that live subtitle processing remains phone-local can maintain high real-time responsiveness and reduce battery drain, which are critical for preserving the wearer's trust in the system. By keeping subtitle processing on the phone, we avoid latency issues that could occur due to cloud delays, ensuring subtitles remain accurate and timely.

2. **What small change unlocks it**

   Define a strict boundary where live subtitle processing must be done on-device. This means that any audio input for subtitles should first go through speech-to-text conversion locally before being sent to the cloud if necessary for additional context or transcription refinement.

3. **Likely payoff**

   By keeping subtitle processing phone-local, we can ensure real-time clarity and stability of subtitles. This will help maintain high user trust and reduce battery drain on the glasses, making the system more reliable in noisy environments where clear and timely subtitles are essential.

4. **Immediate next probe**
   - Define the boundary for live subtitle processing to remain phone-local, even when additional context from the cloud is needed.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   By defining a clear visual hierarchy between subtitles and one-line support, we ensure that the wearer can focus on essential information without feeling overwhelmed by too much text. This clarity helps maintain a low-friction user experience, which is crucial for daily-use value.

2. **What small change unlocks it**

   Define two subtitle placement modes: high-priority mode (e.g., always visible) and low-priority mode (e.g., temporarily hidden when one-line support is needed).

3. **Likely payoff**

   This visual hierarchy will help the wearer prioritize information, reducing cognitive overload and increasing overall usability. It ensures that critical subtitles remain prominent while less essential prompts are suppressed or displayed in a secondary format.

4. **Immediate next probe**
   - Define one visual priority rule between subtitles and one-line support in V1.
