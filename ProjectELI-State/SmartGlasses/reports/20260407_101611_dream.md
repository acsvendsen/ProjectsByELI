### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   By defining specific subtitle placement rules based on confidence levels, we can ensure that subtitles remain clear and unobtrusive while still providing timely assistance. This approach helps maintain trust by keeping the display stable and relevant.

2. **What small change unlocks it**

   Define 3 to 5 subtitle placement rules for different confidence states: high-confidence (e.g., seen recently), medium-confidence (e.g., heard once in a conversation), and low-confidence (e.g., first-time mention).

3. **Likely payoff**

   This setup will enhance the stability and trust of subtitles, ensuring that they are always visible when needed but not so prominent as to be distracting. It will also provide a clear hierarchy for the wearer, improving their ability to focus on the conversation.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

1. **Why it benefits the core**

   By defining a clear boundary for what stays phone-local versus what falls back to cloud, we ensure that V1 can focus on delivering real-time, reliable subtitle assistance and memory support without overloading the glasses with complex processing tasks. This helps maintain low latency, which is crucial for maintaining trust and usability.

2. **What small change unlocks it**

   Define one task-specific phone/cloud fallback boundary for live subtitle processing, ensuring that basic subtitle generation happens locally on the phone while more intensive operations like memory lookup fall back to cloud only if necessary.

3. **Likely payoff**

   By keeping subtitle processing local, we can ensure faster and more reliable subtitle delivery in real-time interactions, which is essential for trust and effectiveness. Additionally, this setup allows us to use cloud resources more strategically, such as for complex memory lookups or background processing tasks that do not require immediate response.
