# Consolidation of Core Signals for SmartGlasses V1

## Strengthening Signals

### Subtitle Clarity
- **Subtitle Quality**: The system should maintain real-time subtitle clarity that is readable, stable, and trustworthy in live conversations.
- **Visual Hierarchy**: Ensure subtitles are placed and displayed to minimize distraction while remaining easily readable.

### Memory Trust
- **Face/Name Recall**: Enhance the ability to remember names and faces accurately without overconfidence or underconfidence. This includes ensuring memory recall is consistent and reliable.
- **Prior Context**: Support the wearer's recall of prior conversations with relevant context, ensuring that this information is accurate and useful without creating unnecessary cognitive load.

### Low-Friction Assistance
- **One-Line Prompts**: Provide concise, one-line prompts to support understanding in real-world interactions. Avoid overwhelming the user with excessive information.
- **Contextual Support**: Ensure that support provided through one-line prompts is contextual and relevant, enhancing the wearer's comprehension without adding unnecessary complexity.

## Weakening Signals

### Privacy vs Usefulness
- **User Experience Over Invasive Features**: Prioritize features that enhance user experience over those that could be invasive. This includes managing data collection and storage carefully to avoid creating privacy concerns.
- **Discreet Interaction**: Avoid designing interactions that may be perceived as intrusive or disruptive, maintaining a low-friction interaction model.

### Latency vs Richness
- **Timely Responses**: Focus on providing timely responses rather than overly rich but slower processing. This ensures the system remains responsive and useful in real-time scenarios.
- **Streamlined Processing**: Optimize local processing to ensure that even with limited computational resources, the system can still provide meaningful and timely assistance.

### Discreet UX vs Visual Clarity
- **Social Acceptability**: Ensure that all visual elements of the system remain discreet and socially acceptable. Avoid designs that may draw undue attention or create social awkwardness.
- **Low Distraction**: Minimize distractions while maintaining clarity, ensuring that subtitles and other visual aids do not overwhelm the wearer.

## Contradictions That Must Stay Alive

### Real-Time Subtitle Clarity vs Battery Drain
- **Balancing Readability and Efficiency**: The system must maintain real-time subtitle clarity without causing significant battery drain. This requires careful optimization to balance readability with energy efficiency.
- **User Trust and Reliability**: Ensure that the subtitles remain reliable and trustworthy, even under conditions of limited computational resources.

### Memory Support vs Privacy Perception
- **Balancing Utility and Privacy**: Provide strong memory support for names, faces, and context without compromising user privacy. This involves carefully managing data collection and storage to ensure transparency and trust.
- **Clear Uncertainty**: Ensure that memory recall is accompanied by clear indications of certainty or uncertainty, avoiding the creation of corrupted or unreliable recall.

## Dormant Ideas Worth Reactivating

### Confidence Display
- **Label + Short Reason**: Consider using a confidence display format that includes both a label (e.g., "High", "Medium") and a short reason for the level of confidence. This can help build trust by providing clear, contextual feedback.
- **Dynamic Adjustment**: Develop mechanisms to dynamically adjust confidence levels based on user interactions and context.

### Memory/Cache Policy
- **Local vs Cloud Storage**: Explore the trade-offs between storing memory data locally on the phone versus leveraging cloud storage for richer but slower processing. This includes evaluating the impact on battery life, privacy, and performance.
- **Reinforcement Learning**: Implement reinforcement learning to improve memory recall over time based on user interactions and feedback.

## Concrete Tensions Around Core Features

### Subtitle Quality
- **Subtitle Placement**: Optimize subtitle placement to ensure that subtitles are easily readable while minimizing distraction. This includes experimenting with different placements such as bottom center, side margins, or dynamic adjustments.
- **Visual Hierarchy**: Design the visual hierarchy of subtitles and other UI elements to minimize cognitive load and maintain clarity.

### Confidence Trust
- **Confidence Display**: Evaluate different confidence display formats (e.g., numeric score, label + short reason) to determine which best builds trust without overwhelming the user.
- **Dynamic Adjustment**: Develop mechanisms to dynamically adjust confidence levels based on context and user feedback.

### Automatic Memory Behavior vs Explicit Remember-Touch Behavior
- **Automatic Memory Support**: Strengthen automatic memory behavior by ensuring that new faces and names are remembered with high accuracy. This includes implementing reinforcement learning and periodic updates.
- **Explicit Remember-Touch Behavior**: Maintain the ability for users to explicitly touch or confirm memories, providing an additional layer of trust and control.

### Fast Lookup
- **Memory Cache Policy**: Implement caching policies to ensure fast lookup of frequently accessed information without compromising privacy or battery life.
- **Real-Time Updates**: Ensure that memory data is updated in real-time to reflect the most recent interactions and context.
