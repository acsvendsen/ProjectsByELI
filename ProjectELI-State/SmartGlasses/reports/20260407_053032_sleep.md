# Recent Signals Consolidation

## Strengthening Signals

1. **Subtitle Clarity**:
   - The core emphasis on maintaining clear, fast, and stable subtitles that can be trusted during live conversations remains strong.
   - This ensures the primary assistive feature of real-time subtitles is reliable and user-friendly.

2. **Trustworthy Memory Support**:
   - Face/name recall and prior context memory must remain credible without creating false certainty or corrupted recall.
   - Trust in memory support is critical for the system's effectiveness and wearer confidence.

3. **Core Deepening Focus**:
   - The project should continue to focus on improving subtitle quality, memory trust, and visual UX rather than expanding into broad feature areas.
   - This core-deepening approach ensures that the most impactful improvements are prioritized.

## Weakening Signals

1. **Low-Friction Assistance**:
   - While still important, this aspect has been downgraded from medium to low priority in recent discussions.
   - The focus should be on ensuring subtitles and memory support remain primary and reliable before expanding into more complex assistive behaviors.

2. **Discreet UX vs Visual Clarity**:
   - The pressure for a discreet user experience versus sufficient visual clarity remains high but has seen some weakening.
   - This tension will continue to guide design decisions, ensuring the glasses are functional yet unobtrusive.

## Contradictions That Must Stay Alive

1. **Privacy vs Usefulness**:
   - Balancing the need for helpful assistive behavior with the risk of privacy invasion remains a critical contradiction.
   - The system must provide value without compromising user privacy or creating an invasive experience.

2. **Latency vs Richness**:
   - Ensuring timely responses while maintaining rich, contextual support is essential but challenging.
   - The project should continue to find the right balance between quick responses and providing sufficient context for effective assistance.

## Dormant Ideas Worth Reactivating

1. **Automatic Memory Behavior vs Explicit Remember-Touch Behavior**:
   - Although not immediately in focus, these two memory behaviors remain important considerations.
   - They should be revisited as the project evolves to ensure a robust memory support system that complements explicit user actions.

2. **Subtitle Placement and Visual Hierarchy**:
   - These areas have been on hold but are worth reactivating for optimal subtitle presentation and user experience.
   - Ensuring subtitles are placed and displayed in a way that enhances readability without causing distraction is crucial.

## Concrete Tensions Around Key Areas

1. **Subtitle Quality, Memory Trust, Fast Lookup, Privacy, Battery, Latency, Visual UX**:
   - These core tensions remain relevant and should continue to guide decision-making.
   - Ensuring that subtitle quality does not compromise battery life or privacy while maintaining trust is essential.

2. **Real-World Constraints**:
   - Early surfacing of real-world constraints such as hardware limitations, battery management, latency, and social acceptability remains a guiding principle.
   - The project should continually address these constraints to ensure the system is practical and useful in real-life scenarios.

## Open Questions

1. **Subtitle Placement**:
   - What is the best V1 subtitle placement that balances readability with low distraction?

2. **Confidence Display**:
   - How should confidence be represented to build trust without creating false certainty or confusion?

3. **Memory/Cache Policy**:
   - How much face/name memory should be cached locally on the phone, and how should it be reinforced for fast lookup and trust?

4. **Phone/Cloud Boundary**:
   - Which interactions should work offline versus requiring cloud support to balance practicality with performance?

5. **Visual Hierarchy**:
   - How can subtitles and one-line prompts coexist without overloading the wearer? What is the best visual hierarchy for this interaction?

## Summary

The project continues to focus on core improvements in subtitle clarity, memory trust, and low-friction assistance while managing key tensions around privacy, usability, and real-world constraints. The open questions related to subtitle placement, confidence display, and memory policy need immediate attention to ensure the system delivers optimal value without compromising user experience or privacy.
