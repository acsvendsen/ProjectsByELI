### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Improving subtitle placement rules will enhance the real-time subtitle clarity attractor by ensuring that subtitles remain stable and unobtrusive during live conversations. This improves trust in the subtitles, which is crucial for the wearer to rely on them effectively.

2. **What small change unlocks it**

   Define two different subtitle placement modes: one fixed position mode for high-confidence speech and another dynamic fallback mode for low-confidence or background noise scenarios.

3. **Likely payoff**

   By implementing these subtitle placement rules, we can ensure that subtitles remain readable and unobtrusive even in challenging acoustic environments. This will increase the trustworthiness of the subtitles, contributing to a better overall user experience.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving the confidence display format enhances the trustworthiness of subtitles and memory support by providing clear and consistent feedback to the wearer. A well-designed confidence object can help the user understand when they should pay more attention, thus reducing social friction and increasing reliability.

2. **What small change unlocks it**

   Define a standardized confidence format that includes a numeric score (e.g., 0-1), a label (e.g., High, Medium, Low), and a short reason (e.g., "Seen recently", "Weak match"). This simple change will allow the system to convey certainty levels more effectively.

3. **Likely payoff**

   By implementing a clear confidence format, the system can better manage the wearer's trust in real-time subtitles and memory support. This will lead to more effective interactions where the wearer knows when to rely on the system and when additional context might be needed.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   By defining a clear local memory threshold for face/name recall, the system can prioritize which memories to keep in phone-local cache, reducing the load on cloud processing while ensuring that critical names and faces are always available offline.

2. **What small change unlocks it**

   Define a recency-based eviction policy where less frequently accessed entities are removed from the local cache when space is needed for more recently encountered or crucial ones.

3. **Likely payoff**

   This change will reduce the burden on cloud storage, making the system more efficient and responsive in offline scenarios while maintaining high recall accuracy for key individuals and interactions.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**
   Improving subtitle placement rules under different confidence states ensures that subtitles are always clear and readable, enhancing trust in live conversations without becoming distracting.

2. **What small change unlocks it**
   Define two to three subtitle placement rules for different confidence levels: one for high-confidence matches where subtitles can be more prominent, another for medium-confidence matches with slight adjustments, and a third for low-confidence matches that are less intrusive but still visible.

3. **Likely payoff**
   By defining clear subtitle placement rules, the system will maintain high trust in live interactions while minimizing distraction, ensuring that the wearer can focus on conversations without constant glances at the glasses.

4. **Immediate next probe**

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   Improving the visual hierarchy between subtitles and one-line support ensures that the wearer can easily distinguish and prioritize information without feeling overwhelmed or distracted. This clarity supports the wearer's focus on the conversation, enhances trust in the system by reducing cognitive overload, and aligns with the mission of creating a low-friction assistive tool.

2. **What small change unlocks it**

   Define a visual priority rule that ensures subtitles remain prominent but allow one-line support to be shown when appropriate without causing distraction. For example, set a policy where subtitles are always visible but can be temporarily dimmed or hidden if one-line prompts are necessary and relevant.

3. **Likely payoff**

   By defining such a rule, the system will maintain the essential functionality of real-time subtitles while ensuring that contextual one-line support does not detract from the main task of understanding the conversation. This balance enhances the daily-use value by making both forms of assistance equally accessible and useful.

4. **Immediate next probe**

   Define one visual priority rule between subtitles and one-line support, prioritizing subtitles for readability but allowing temporary dimming or hiding to show relevant one-line prompts without distraction.
