## Project Summary
The SmartGlasses project is focusing on improving subtitle clarity and memory support while maintaining a phone-first architecture to avoid heavy on-glasses computation. The current mode, core deepening, emphasizes improvements in subtitle quality, memory trust, and visual UX without broad feature expansion. However, there are ongoing tensions such as privacy vs usefulness and discreet UX vs visual clarity that need balanced attention.
