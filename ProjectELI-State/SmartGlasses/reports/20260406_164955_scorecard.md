## Project Summary
The SmartGlasses V1 project is focusing on delivering discreet, context-aware personal assistance through live subtitles, face/name recall, conversation memory, and one-line support. The current iteration prioritizes lightweight hardware, phone-first processing, minimal on-glasses computation, and user-friendly interactions controlled via frame touches only.
