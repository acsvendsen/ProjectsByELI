### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Ensuring stable subtitle placement rules for different confidence states will help maintain trust in real-time subtitles. By providing a consistent visual layout, users can rely on the subtitles without distraction or confusion, which is crucial for their understanding and comfort during conversations.

2. **What small change unlocks it**

   Define two subtitle placement rules: one for high-confidence matches (e.g., names and faces seen recently) to be prominently displayed at the top of the frame, and another for lower-confidence matches (e.g., new people or context) placed slightly below with reduced prominence but still visible.

3. **Likely payoff**

   By setting clear placement rules, V1 can provide a more stable and predictable user experience. This will help maintain trust in the subtitles and ensure that critical information is always easily accessible without causing visual clutter. Users can focus on the conversation while feeling confident about understanding the context accurately.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving the confidence display format in V1 will help establish trust between the wearer and the system. Clear and consistent confidence indicators ensure that the wearer understands the reliability of the subtitles and memory support provided by the glasses, which is crucial for maintaining a low-friction user experience.

2. **What small change unlocks it**

   Define a simple confidence display format using a numeric score with a label and short reason. For example: "score 0.84 + 'High' + 'Seen recently'".

3. **Likely payoff**

   By implementing this simple but effective confidence format, the system can provide clear feedback to the wearer about the reliability of the information being displayed. This will help in building trust and ensuring that the wearer knows when they can rely on the glasses for accurate subtitles or memory support.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   By defining a clear local memory threshold for face/name recall, we ensure that the system efficiently manages memory usage while maintaining high trust in fast lookups. This balance helps preserve battery and thermal resources, crucial for an always-on product, without compromising on the core mission of providing reliable and timely assistance.

2. **What small change unlocks it**

   Define a local cache size limit for face/name memory objects that triggers automatic evictions when the threshold is reached. For example, set a rule that the system will automatically remove less frequently accessed faces/names after 10 touches or 3 days of inactivity to maintain a manageable cache size.

3. **Likely payoff**

   This change will reduce memory usage on the phone, decreasing the risk of battery drain and thermal issues while ensuring fast and reliable lookups for common interactions. It will also improve user trust by avoiding cluttered and unresponsive interfaces.

4. **Immediate next probe**

   Define one local cache eviction rule for face/name memory objects based on touch count or inactivity duration to manage the size of the local cache efficiently.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   Ensuring that live subtitle processing remains phone-local can significantly reduce latency and improve real-time responsiveness, which is crucial for maintaining trust in subtitles during live conversations. By keeping this process on the phone, we avoid network delays that could otherwise degrade the user experience.

2. **What small change unlocks it**

   Define a specific task boundary where live subtitle processing must remain phone-local: live subtitle generation and initial display.

3. **Likely payoff**

   This ensures that subtitles are generated and displayed with minimal latency, enhancing the wearer's trust in the system during critical moments of conversation.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   Improving the visual hierarchy between subtitles and one-line support ensures that the wearer can focus on critical information without feeling overwhelmed or distracted. This enhances overall understanding and reduces cognitive load, aligning with the core attractors of real-time subtitle clarity and low-friction assistance.

2. **What small change unlocks it**

   Define a clear precedence rule where subtitles have higher visual prominence than one-line support, but both are visible. For example, always show subtitles in full text while allowing one-line prompts to briefly display over them if necessary.

3. **Likely payoff**

   By ensuring that subtitles remain the primary focus, the system can maintain trust and clarity during live interactions. This improves the core mission of helping the wearer understand better without creating social awkwardness or cognitive overload.

4. **Immediate next probe**

   Define one visual priority rule between subtitles and one-line support where subtitles always have higher precedence but both are visible.
