### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   By defining specific subtitle placement rules based on confidence states, we can ensure that subtitles are always clear and readable while minimizing distraction. This improves the wearer's trust in the system and enhances their ability to follow conversations.

2. **What small change unlocks it**

   Define three distinct subtitle placement modes: 
   - High-confidence state (always visible, stable position)
   - Medium-confidence state (visible but slightly less prominent)
   - Low-confidence state (visible only when triggered by frame touch)

3. **Likely payoff**

   This approach will provide a clear and consistent visual cue for the wearer, ensuring that high-importance information is always easily readable while maintaining minimal distraction from lower-importance information. It will also make it easier to adjust subtitle visibility based on real-time confidence levels.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

   By optimizing the local memory cache size for face/name recall, we can ensure that critical personal memories are retained with high confidence while minimizing battery and thermal load. This improves real-time subtitle clarity and trustworthiness by providing timely support without overloading the system.

2. **What small change unlocks it**

   Define a specific local cache size limit for face/name memory objects that balances retention duration, refresh intervals, and cloud fallback boundaries. For example, limiting the local cache to store only the most recent 10 encounters with each person or object.

3. **Likely payoff**

   By setting a clear threshold for local caching, we can reduce the risk of overloading the phone's memory and battery while ensuring that critical face/name memories are readily available. This will enhance subtitle clarity by providing more accurate real-time support without unnecessary cloud queries.

4. **Immediate next probe**
   - Define a local cache size limit of 10 entries for face/name memory objects.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   By defining a clear visual hierarchy rule between subtitles and one-line support, we can ensure that the wearer gets the most essential information first without overwhelming them. This improves trust by making the interface more predictable and user-friendly, aligning with our mission to help the wearer stay present and informed.
