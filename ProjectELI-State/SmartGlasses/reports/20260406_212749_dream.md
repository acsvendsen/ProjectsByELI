### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Improved subtitle placement rules can enhance readability and reduce distraction, ensuring that subtitles remain clear and stable enough for the wearer to trust them during live conversations. This directly supports the primary attractor of real-time subtitle clarity.

2. **What small change unlocks it**

   Define two subtitle placement modes: one for high-confidence content (like names) in a fixed position at the bottom center, and another for lower-confidence content (like background noise or less critical words) that adjusts slightly to avoid overlap but remains visible.

3. **Likely payoff**

   By defining these placement rules, V1 can provide more reliable and unobtrusive subtitle support, reducing cognitive load and ensuring that important information is always easily readable. This will enhance the overall trust in the subtitles and improve the wearer's ability to follow conversations accurately.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving the confidence display format will enhance trust in the system by clearly communicating certainty levels to the wearer. This clarity ensures that the wearer can understand when they are being provided with a high-confidence piece of information versus something that is more uncertain, thus reinforcing the system's reliability.

2. **What small change unlocks it**

   Define a simple confidence format that combines a numeric score, label, and short reason for each memory or subtitle event. For example: `score 0.85 + "High" + "Seen recently"; score 0.43 + "Low" + "Weak match"`.

3. **Likely payoff**

   By implementing this confidence format, the system will provide clearer feedback to the wearer, reducing ambiguity and enhancing overall trust. This will lead to more accurate memory recall and better understanding of real-time subtitles, ultimately improving daily-use value without overloading the UI with too much complexity.

4. **Immediate next probe**

   Define one confidence format candidate for V1: `score [0-1] + "Low/Medium/High" + "Reason"`.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   By setting a local cache threshold for name recall, we ensure that the glasses can quickly provide relevant information without requiring cloud access, which is critical for maintaining low-latency response times and preserving privacy.

2. **What small change unlocks it**

   Define a local cache size limit for frequently encountered names, ensuring that common names are stored on-device with a high probability of recall.

3. **Likely payoff**

   This will enable faster name recall during live interactions, reducing the latency between when the wearer sees someone and when their name is shown in subtitles or one-line prompts. It also reduces reliance on cloud resources, improving privacy and battery efficiency.

4. **Immediate next probe**

   Define a local cache size limit of 20 names for frequent encounters to balance memory usage with recall speed during live interactions.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**
   - By defining a clear boundary for live subtitle processing that stays on the phone, we ensure real-time responsiveness without relying on cloud latency. This improves trust and reliability in noisy environments where timely subtitles are crucial.

2. **What small change unlocks it**
   - Define a rule stating that all live subtitle processing must be done locally on the phone within 100 milliseconds of receiving audio input.

3. **Likely payoff**
   - Faster, more reliable subtitles that can be trusted in real-time conversations, reducing the risk of dropped or delayed text during critical moments.

4. **Immediate next probe**
   - Define rules for when live subtitle processing falls back to the cloud if local processing fails within 100 milliseconds of receiving audio input.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   Ensuring that subtitles are coexisting with one-line support in a way that respects visual hierarchy helps maintain clarity and reduce cognitive load for the wearer. By carefully managing which elements gain prominence, we can prevent visual overwhelm while ensuring key information is easily accessible.

2. **What small change unlocks it**

   Define a clear visual priority rule between subtitles and one-line prompts that ensures subtitles remain the primary focus but allow one-line support to appear when necessary without becoming intrusive.

3. **Likely payoff**

   By establishing a well-defined visual hierarchy, we can enhance the overall user experience by ensuring that critical information (subtitles) is prioritized while still providing useful contextual cues (one-line prompts). This will help in maintaining readability and reducing cognitive strain during conversations.

4. **Immediate next probe**

   Define one visual priority rule between subtitles and one-line support such that subtitles retain primary focus but allow for necessary one-line assistance to be displayed clearly when needed.
