1. **Subtitle Clarity**: The importance of clear, fast, and stable subtitles that can be trusted in live conversations remains high.
2. **Memory Trust**: The need for trustworthy memory support without creating corrupted recall or pretending certainty is crucial.

## Weakening Signals
1. **Low-Friction Assistance**: The medium strength of this signal suggests a slight weakening in the emphasis on delivering one-line help and visible support that does not create command overhead or social awkwardness.
   
## Contradictions That Must Stay Alive
- **Privacy vs Usefulness**: Balancing the system's ability to be helpful without infringing on privacy concerns remains a persistent tension.
- **Latency vs Richness**: The need for timely responses without overloading the runtime with richer but slower processing continues to pose challenges.

## Dormant Ideas Worth Reactivating
- **Subtitle Placement and Visual Hierarchy**: These ideas should remain alive as they are key to ensuring usability and low visual distraction. They were previously considered dormant but now warrant reactivation due to their impact on user experience.
  
## Concrete Tensions Around Subtitle Quality, Confidence Trust, Automatic New-Person Memory, Memory Reinforcement, Fast Lookup, Privacy, Latency, Battery, Visual UX
- **Subtitle Quality vs. Speed**: Ensuring subtitles are clear and fast while maintaining battery efficiency is critical.
- **Memory Trust vs. Privacy**: Balancing the need for trust in memory support with privacy concerns must be carefully managed.
- **Automatic Memory Behavior vs. Explicit Remember-Touch Behavior**: Determining how automatic memory works versus user-initiated recall remains a tension point.
- **Confidence Display**: Deciding on the best format (label only, label + reason, score + label) for confidence to build trust.

## Open Questions
1. **Subtitle Placement and Visual Hierarchy**:

   - How should one-line prompts visually differ from subtitles?

2. **Confidence Display**:
   - Should confidence be displayed as a label only, label + short reason, or score + label?
   - How much face/name memory should be cached locally on the phone for fast lookup and reinforcement?

3. **Interaction Mode**:
   - What interactions should work offline versus requiring cloud support? 

4. **Battery and Thermal Constraints**:
   - How can always-on features like subtitles be optimized without causing significant battery drain or overheating issues?
