### Idea 1: Subtitle Placement

1. **Why it benefits the core**
   - By establishing stable subtitle placement rules, we ensure that subtitles are consistently placed in a predictable location on the wearer's field of view. This reduces cognitive load and improves trust by providing a reliable visual cue for the wearer.

2. **What small change unlocks it**
   - Define three fixed subtitle placement modes based on confidence levels: 
     1. High-confidence subtitles always appear at the bottom center.
     2. Medium-confidence subtitles are placed slightly above and to one side of high-confidence ones, but still remain visible without distraction.
     3. Low-confidence subtitles are displayed in a less prominent area or with a reduced size.

3. **Likely payoff**
   - This change will make subtitle placement more predictable and stable, reducing the wearer's cognitive load and improving overall trust in the system. Users will be able to focus on the conversation without constantly adjusting their gaze to locate subtitles.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   By refining the confidence display format, we can enhance the wearer's trust in the system by providing clear and unambiguous feedback about the reliability of the information being presented. This will help maintain the balance between useful assistance and privacy concerns, ensuring that the wearer is never overconfident or misled.

2. **What small change unlocks it**

   Define a confidence format that uses a numeric score, label, and short reason to describe certainty. For example, "score 0.84 + 'High' + 'Seen recently'; score 0.42 + 'Low' + 'Weak match'; score 0.63 + 'Medium' + 'Name heard once in introduction'."

3. **Likely payoff**

   Implementing this confidence format will allow the system to provide more granular and precise feedback, which can help users trust the system more effectively without compromising privacy. It also simplifies user understanding of the reliability of information, reducing cognitive load.

4. **Immediate next probe**
   - Define three subtitle confidence labels: "High," "Medium," and "Low."

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Improving memory cache policies will enhance the reliability and trustworthiness of name and context recall, ensuring that critical information is readily available to the wearer during real-world interactions.

2. **What small change unlocks it**

   Define a simple local cache eviction policy where each person-memory object retains its most recent encounters within a defined time window (e.g., 10 minutes), with older evidence evicted to make space for new memories and maintain focus on relevant contexts.

3. **Likely payoff**

   By limiting the amount of memory retained in the local cache, the system can reduce the risk of storing outdated or irrelevant information, improving the speed and accuracy of memory recall during live interactions. This will help in maintaining a clear and focused context for the wearer without overwhelming them with too much historical data.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By optimizing what stays phone-local versus falling back to cloud for live subtitle processing, we ensure that critical real-time functionality is maintained without overloading the battery and thermal limits. This balance enhances user trust by ensuring subtitles are always clear and up-to-date, while also reducing latency.

2. **What small change unlocks it**

   Define a specific threshold for when the glasses should trigger a cloud fallback for live subtitle processing based on detected environmental noise or microphone quality issues. For example, if the ambient noise level exceeds 50 dB or the speech clarity score drops below 70%, the glasses should fallback to the phone for real-time transcription.

3. **Likely payoff**

   By keeping critical real-time subtitle processing local, we reduce latency and ensure that subtitles remain stable and clear, even in challenging environments. This improves user trust and satisfaction with the product's core functionality, leading to better daily-use value without overburdening the glasses' hardware.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.
