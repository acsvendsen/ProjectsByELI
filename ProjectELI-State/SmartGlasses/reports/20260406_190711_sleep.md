## Core Mission and Attractors

### Strengthened:
- **Subtitle Clarity (subtitle_clarity)**: Ensuring subtitles are clear, fast, and stable enough to be trusted in live conversations.
- **Memory Trust (memory_trust)**: Providing reliable memory support that helps recall names, faces, and prior context without overstepping or causing confusion.

### Weakened:
- **Low-Friction Assistance (low_friction_assistance)**: Reducing the emphasis on making every interaction frictionless to ensure clarity and trust in core functionalities like subtitles and memory support.

## Core Tensions

### High Pressure:
- **Privacy vs Usefulness (privacy_vs_usefulness)**: Balancing the need for useful assistive features with respecting privacy.
- **Latency vs Richness (latency_vs_richness)**: Striking a balance between providing timely help and adding richer, but potentially slower processing.
- **Discreet UX vs Visual Clarity (discreet_ux_vs_visual_clarity)**: Ensuring the system remains discreet while still being readable and usable.

### Medium Pressure:
- **Core Deepening Over Sprawl (core_deepening_over_sprawl)**: Focusing on deepening core functionalities over broad feature expansion.
- **Frame-Touch Only V1 Interaction (frame_touch_only_v1)**: Maintaining simplicity in interaction methods to avoid unnecessary complexity.

### Hard Grounding:
- **Phone-First Runtime (phone_first_runtime)**: Heavy processing should primarily happen on the phone, with cloud support optional and justified.
- **Core Deepening Over Sprawl (core_deepening_over_sprawl)**: Prioritizing improvements that enhance subtitle quality, memory trust, and visual UX.
