### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Improving subtitle placement rules will enhance the wearer's ability to trust the subtitles in live conversation, reducing cognitive load and increasing comprehension during noisy or hearing-challenged situations.

2. **What small change unlocks it**

   Define two subtitle placement rules: one for high-confidence states where the system is certain about who is speaking (e.g., known speakers), and another for lower-confidence states where uncertainty is higher (e.g., new faces or background noise).

3. **Likely payoff**

   By establishing clear, stable subtitle placement based on confidence levels, the glasses will become more reliable in noisy environments, leading to better wearer trust and understanding during conversations.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

Improving confidence display ensures that the wearer can trust the system's memory and recall, which is crucial for maintaining their trust in real-time interactions. Clear and reliable confidence indicators help the wearer understand when they are being provided with well-supported information versus less certain data.

2. **What small change unlocks it**

Define a simple yet effective format for confidence objects that includes a numeric score, label, and short reason. This format should be consistent across all memory-related outputs to provide clear cues about the reliability of the information presented.

3. **Likely payoff**

By implementing a well-defined confidence display format, the system will gain credibility in real-world use cases. Users will feel more assured that they are being provided with accurate and reliable information, which can significantly enhance their trust in the system's memory and recall capabilities.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Improving the local cache size for memory recall enhances the system's ability to provide relevant, timely information without constant cloud reliance, thereby reducing latency and privacy risks. This ensures that critical context is always available, even when network conditions are poor.

2. **What small change unlocks it**

   Define a local cache eviction policy that keeps recently seen names and faces in memory for up to 30 minutes after initial encounter but evicts them if no further evidence reinforces the memory within this period.

3. **Likely payoff**

   By maintaining recent memories locally, the system can quickly recall familiar names and faces even when network connectivity is intermittent or non-existent. This improves user trust by providing fast, reliable context that feels personal and useful without overloading the cloud with storage requirements.

4. **Immediate next probe**

   Define a local cache eviction policy where names are cached for 30 minutes after initial encounter but evicted if no further evidence reinforces them within this period.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   Ensuring that live subtitle processing remains phone-local optimizes battery usage, reduces latency, and maintains real-time clarity. This focus helps in delivering clear, timely subtitles without overloading the glasses' limited computational resources.

2. **What small change unlocks it**

   Define a specific boundary for live subtitle processing to run entirely on the phone. For example, set a policy that any subtitle processing related to speech-to-text or initial text formatting runs locally, only sending final processed text to the glasses.

3. **Likely payoff**

   By keeping real-time subtitle processing local, we can ensure faster response times and clearer subtitles. This reduces the load on the glasses' battery and ensures that the wearer receives timely and accurate information without delays from cloud latency.

4. **Immediate next probe**

   Define one phone-local vs cloud fallback boundary for exactly one task such as live subtitle processing.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   Ensuring a clear visual hierarchy between subtitles and one-line prompts enhances the wearer's ability to focus on essential information without visual overload. This improves trust in the system by reducing cognitive load, making real-time communication more effective and less distracting.

2. **What small change unlocks it**

   Define a simple coexistence rule where one-line support is visually suppressed or minimized when subtitles are active, but remains visible at low prominence during pauses or quieter moments.

3. **Likely payoff**

   By implementing this visual hierarchy, the system will reduce cognitive overload and improve the wearer's focus on critical information during conversations. This leads to better overall user experience and trust in the assistive capabilities of the glasses.

4. **Immediate next probe**
   - Define one visual priority rule between subtitles and one-line support in V1.
