### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Stable subtitle placement ensures that subtitles remain readable and unobtrusive, reducing cognitive load on the wearer. This stability is crucial for maintaining trust in real-time subtitles, especially in noisy or fast-paced environments.

2. **What small change unlocks it**

   Define 2 to 3 fixed subtitle placement rules based on confidence levels: high-confidence speech, medium-confidence new speakers, and low-confidence background noise.

3. **Likely payoff**

   By establishing clear subtitle placement rules, the system can reduce visual distractions and maintain readability without becoming too intrusive. This will enhance the wearer's trust in the subtitles and improve overall usability.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**
   - By refining the confidence display to use a clear, concise format, the system can enhance the wearer's trust in both subtitles and memory recall. A well-defined confidence object helps users understand the reliability of the information provided, reducing uncertainty and increasing overall user satisfaction.

2. **What small change unlocks it**
   - Define a consistent confidence object format that includes a numeric score, label, and short reason. For example: `score 0.84 + "High" + "Seen recently"` for high-confidence matches or `score 0.42 + "Low" + "Weak match"` for uncertain ones.

3. **Likely payoff**
   - A well-defined confidence object will help the wearer understand the reliability of subtitles and memory, leading to increased trust in the system's outputs. This clarity can reduce cognitive load and improve overall user experience by ensuring that users are aware when information is less certain.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Ensuring that new face and name memories are automatically reinforced over time helps build a reliable memory system for the wearer, reducing reliance on explicit frame touches and enhancing trust in the assistive capabilities. This continuous reinforcement ensures that critical information is not lost and can be quickly recalled when needed.

2. **What small change unlocks it**

   Implementing a simple local cache policy where new faces and names are stored with a short recency threshold (e.g., 7 days) before being considered for removal from the local cache. This ensures that recently encountered individuals are always available for fast lookup, while older entries can be pruned to keep memory usage low.

3. **Likely payoff**

   By automatically reinforcing new memories, the system will become more reliable over time, reducing the need for explicit reinforcement and improving the accuracy of name and face recall in real-time interactions. This will lead to a more seamless and trusted experience for the wearer.

4. **Immediate next probe**
   - Define the recency threshold for new faces and names to be 7 days before they are considered for removal from the local cache.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By defining a clear boundary for phone-local vs cloud processing, we ensure that critical real-time subtitle and memory tasks remain fast and reliable, while less time-sensitive operations can leverage cloud resources when needed. This balance enhances trust by minimizing latency and battery drain, keeping the system discreet yet effective.

2. **What small change unlocks it**

   Define a specific task boundary for live subtitle processing to run phone-local exclusively, with transcript cleanup falling back to the cloud only after initial live processing is complete.

3. **Likely payoff**

   This refined boundary will reduce latency and improve the real-time responsiveness of subtitles, ensuring that critical information is always presented quickly and accurately. It also allows for more efficient use of cloud resources during non-critical tasks, extending battery life and maintaining system reliability.

4. **Immediate next probe**

   Define one phone-local vs cloud fallback boundary for exactly live subtitle processing.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   Ensuring that subtitles remain clear, fast, and stable enough to be trusted in live conversations is crucial for the wearer's understanding and trust in the system. This clarity directly impacts the user's ability to follow along during interactions, reducing cognitive load and increasing overall usability.

2. **What small change unlocks it**

   Define 2 to 3 subtitle placement rules for different confidence levels: high-confidence subtitles placed at the bottom of the field of view (FOV) with less animation, medium-confidence subtitles slightly above the bottom FOV with minimal animation, and low-confidence subtitles temporarily suppressed or displayed in a smaller, more discrete area.

3. **Likely payoff**

   By setting clear placement rules based on confidence, the system can reduce visual distraction while ensuring that the most critical information remains easily accessible to the wearer. This will enhance overall trust and usability without overwhelming the user with too much text.

4. **Immediate next probe**
   - Define one visual priority rule between subtitles and one-line support in V1.
