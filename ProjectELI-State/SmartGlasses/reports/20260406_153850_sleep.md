# Consolidation of Core Signals

## Strengthening Signals

1. **Subtitle Quality and Placement**: 
   - The system should prioritize subtitle placement to be more prominent and readable without becoming distracting.
   - Subtitles must remain near-real-time to maintain trust.

2. **Memory Reinforcement**:
   - Face/name recall must be reinforced over time through explicit remember-touch behavior, ensuring new faces are remembered with confidence objects.
   - Memory policies should support fast lookup for relevant information.

3. **Confidence Display**: 
   - Confidence should be displayed using a label + short reason to build trust and clarity.
   - The phone-first architecture should ensure real-time memory updates and local caching strategies.

4. **Visual Hierarchy**:
   - Subtitles should dominate the visual hierarchy to ensure they are easily readable, with one-line prompts presented clearly but not overwhelming.

## Weakening Signals

1. **Voice Activation**:
   - Voice activation is not part of V1; frame touches will be the primary interaction method.
   
2. **Complex Multimodal UI**:
   - The system should focus on simple interactions and avoid complex multimodal UIs for now, keeping it lightweight.

3. **Heavy Local Inference**:
   - On-glasses processing is not a priority in V1; cloud-based heavy lifting can be explored later if justified by real-world needs.
   
4. **Fancy AR Visuals**:
   - Rich AR visuals are not part of the current V1 scope to keep it simple and focused on core features.

## Contradictions That Must Stay Alive

1. **Privacy vs Usefulness**:
   - The system must balance providing useful information with respecting privacy, avoiding over-reliance on face/name recall for non-essential interactions.
   
2. **Battery and Thermal Constraints**:
   - Always-on sensing is limited by battery and thermal constraints; the glasses should remain lightweight and socially acceptable.

3. **Real-Time vs Offline Flexibility**:
   - Subtitles must be near-real-time but can work offline where necessary, striking a balance between latency and usability.
   
4. **Discreet UX vs Clarity**:
   - The system should strive for a discreet user experience while ensuring clarity in memory displays and confidence indicators.

## Dormant Ideas Worth Reactivating

1. **Advanced Contextual Prompts**:
   - One-line contextual prompts can be explored further to provide relevant, succinct support without overwhelming the wearer.
   
2. **Subtle Confidence Indicators**:
   - Additional subtle confidence indicators might enhance trust over time if the current label + reason approach is not sufficient.

## Concrete Tensions Around Core Features

1. **Subtitle Quality and Latency**:
   - The system must balance subtitle quality (readability, accuracy) with real-time performance to maintain user trust.
   
2. **Memory Trust and Reinforcement**:
   - The memory policy should support fast lookup but also prioritize trust-building through explicit remember-touch behavior and confidence objects.

3. **Confidence Display and Memory Policies**:
   - Confidence display must be clear and consistent, supporting both real-time feedback and long-term memory reinforcement.

4. **Subtitle Placement and Visual Clarity**:
   - Subtitle placement should enhance readability while avoiding distraction, with visual hierarchy optimizing the overall user experience.
   
5. **Battery and Latency Trade-offs**:
   - The system must manage battery usage effectively, ensuring always-on subtitle functionality remains practical in real-world scenarios.

6. **Privacy and Social Acceptability**:
   - The design should avoid over-reliance on intrusive features while still providing useful context and support for the wearer.

## Open Questions

1. **Subtitle Placement**: 
   - What is the optimal placement that ensures subtitles are readable without becoming distracting?
   
2. **Confidence Display Format**: 
   - Should confidence be displayed as a label only, label + short reason, or score + label?

3. **Face/Name Memory Cache Policy**:
   - How much face/name memory should be cached locally on the phone for fast lookup and trust-building?

4. **Phone/Cloud Boundary**:
   - Which interactions should work offline versus requiring cloud support to ensure a balanced user experience?

5. **Visual Hierarchy**:
   - How can subtitles and one-line prompts coexist without overloading the wearer, maintaining a clear visual hierarchy?
