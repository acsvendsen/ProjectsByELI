### Idea 1: Subtitle Placement

1. **Why it benefits the core**

4. **Immediate next probe**

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Enhancing the local caching policy for memory objects ensures that frequently encountered names and faces are always available quickly, reducing latency and maintaining the trust in real-time assistance. This improves both subtitle clarity and confidence display by ensuring that when a name or face is mentioned, the system can provide immediate context without delays.

2. **What small change unlocks it**

   Define a local cache size limit for frequently encountered names and faces. The cache should store up to 10 most recently seen entities with their associated confidence objects and reinforcement history.

3. **Likely payoff**

   By caching top-10 entities, the system will significantly reduce lookup times, ensuring that context is always available quickly during live interactions. This improves subtitle clarity by providing fast recall for names and faces, enhancing the overall trust in real-time assistance.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By optimizing what stays phone-local versus what falls back to cloud for live subtitle processing, we can ensure real-time subtitle clarity while managing battery and thermal constraints effectively. This balance will maintain the wearer's trust in the system by providing timely and accurate subtitles without overloading the glasses with heavy computational tasks.

2. **What small change unlocks it**

   Define a specific threshold where face and name recall lookup falls back to cloud processing, but live subtitle processing remains phone-local. For example, if the system detects high ambient noise or complex speech patterns that could benefit from richer processing, fallback can be triggered only for such cases while keeping real-time subtitles stable.

3. **Likely payoff**

   This change will enhance the wearer’s trust in the system by ensuring consistent and reliable subtitle delivery even in challenging environments. It also allows for more complex memory support without compromising on essential real-time functionality, thereby improving overall user satisfaction and core mission effectiveness.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.
