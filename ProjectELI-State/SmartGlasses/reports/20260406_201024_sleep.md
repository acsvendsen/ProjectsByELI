# Consolidated SmartGlasses V1 Project Signals

## Core Field

### Attractors
- **Subtitle Clarity (high)**: Ensure subtitles are clear, fast, and stable enough for trust in live conversations.
- **Memory Trust (high)**: Provide reliable memory support for names, faces, and prior context without overconfidence or corruption.
- **Low-Friction Assistance (medium)**: Offer one-line help with minimal interaction to reduce social awkwardness.

### Tensions
- **Privacy vs. Usefulness (high pressure)**: Balance the need for useful assistance against potential privacy invasions.
- **Latency vs. Richness (high pressure)**: Prioritize timely responses over richer but slower processing.
- **Discreet UX vs. Visual Clarity (medium pressure)**: Maintain a socially acceptable display while ensuring readability in motion and noise.

### Constraints
- **Frame-Touch-Only V1 Interaction**: Early interactions should be through frame touches, not voice commands.
- **Phone-First Runtime**: Heavy processing should primarily occur on the phone with cloud support optional where clearly justified.
- **Core Deepening Over Sprawl**: Focus improvements on subtitle quality, memory trust, confidence display, and visual UX rather than broad feature expansion.

### Current Mode
- **Core Deepening**: Prioritize core mission improvements (subtitle quality, memory trust) over broader features.
