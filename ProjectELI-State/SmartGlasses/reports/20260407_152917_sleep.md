# Consolidated Signals for SmartGlasses Project

## Strengthened Signals
- **Subtitle Clarity (subtitle_clarity)**: The core mission requires subtitles that are clear, fast, and stable enough to maintain trust in live conversations. This signal is becoming more true.
- **Memory Trust (memory_trust)**: Trustworthy memory support must remember names, faces, and prior context without creating false certainty or corrupted recall. This signal is a strong focus area.
- **Core Deepening**: The project should continue to deepen the core mission of subtitle quality, memory trust, and low-friction assistance. This mode is essential for driving progress.

## Weakened Signals
- **Low-Friction Assistance (low_friction_assistance)**: While this signal remains important, it is becoming less emphasized compared to subtitle clarity and memory trust in recent focus areas.

## Contradictions That Must Stay Alive
- **Privacy vs Usefulness**: The project must balance the need for privacy with the usefulness of assistive features. This contradiction is critical and must remain alive.
- **Latency vs Richness**: The system should provide timely help without overloading the runtime, which could lead to a richer but slower processing experience.

## Dormant Ideas Worth Reactivating
- **Subtitle Placement**: The ideal placement for subtitles remains an open question that deserves further exploration. This idea is worth reactivating.
- **Confidence Display**: There are no clear decisions on how confidence should be represented (numeric score, label, or short reason). This idea needs attention.

## Concrete Tensions Around Subtitle Quality, Confidence Trust, Automatic New-Person Memory, Memory Reinforcement, Fast Lookup, Privacy, Latency, Battery, and Visual UX
- **Subtitle Quality**: Ensure subtitles are clear, fast, and stable enough to maintain trust.
- **Confidence Trust**: Balance the need for confidence without creating false certainty or corrupted recall.
- **Automatic New-Person Memory**: Implement memory reinforcement over time for new faces and names.
- **Memory Reinforcement**: Focus on reliable and timely memory updates and lookups.
- **Fast Lookup**: Prioritize fast, efficient memory retrieval to enhance user experience.
- **Privacy**: Ensure that privacy is not compromised in the pursuit of useful assistive features.
- **Latency**: Maintain low latency to provide timely assistance without overloading the runtime.
- **Battery**: Avoid heavy on-glasses compute to reduce battery drain and thermal issues.
- **Visual UX**: Ensure subtitle placement and visual hierarchy are socially acceptable and readable.

## Open Questions
- **Subtitle Placement (subtitle_placement)**: Determine the best placement for subtitles to maximize readability while minimizing distraction.
- **Confidence Display (confidence_display)**: Define the best format for confidence display (label only, label + short reason, or score + label).
- **Memory/Cache Policy (memory/cache_policy)**: Decide on the appropriate caching strategy for face/name memory.
- **Phone/Cloud Boundary (phone/cloud_boundary)**: Clarify which interactions should work offline versus requiring cloud support.
