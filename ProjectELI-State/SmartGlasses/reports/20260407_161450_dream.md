### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Improving subtitle placement rules based on confidence state can enhance the stability and readability of subtitles, ensuring that critical information is always clear and not distracting to the wearer.

2. **What small change unlocks it**

   Define a new subtitle placement rule that places high-confidence subtitles at the top of the screen and lower-confidence subtitles slightly below, while maintaining consistent spacing between lines.

3. **Likely payoff**

   This change will help reduce distractions by placing more certain information first, making the most critical words easy to read. It also reduces cognitive load by minimizing rapid eye movements across different levels of confidence.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

Improving the confidence display format enhances trust in the system's reliability, which is crucial for the wearer to understand and rely on the subtitles and memory support provided by the glasses. A well-designed confidence format ensures that the wearer can easily assess the certainty of each piece of information, thereby reducing cognitive load and increasing overall user satisfaction.

2. **What small change unlocks it**

To unlock a more effective confidence display, we need to define a clear, concise, and unambiguous format for confidence objects. This involves creating a numeric score combined with a label and short reason that succinctly conveys the level of certainty and how it was derived.

3. **Likely payoff**

By implementing a well-defined confidence format, the glasses can provide more reliable information to the wearer. This will lead to better trust in the system, reduced cognitive strain from constantly questioning the accuracy of displayed subtitles or memory support, and an overall improved user experience.

4. **Immediate next probe**
   - Define the numeric score presentation for the V1 confidence display.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

Improving memory cache policies ensures that the system can provide more accurate and timely assistance to the wearer without overburdening the phone or cloud with excessive data processing. This enhances subtitle clarity and trustworthiness by ensuring that relevant context, such as recently seen faces and names, is readily available for quick reference.

2. **What small change unlocks it**

Define a local cache eviction policy that retains recent face and name encounters but evicts less frequent interactions to manage memory size while preserving essential contextual information.

3. **Likely payoff**

By implementing a more refined local cache eviction strategy, the system can provide faster and more accurate recall of recently encountered people, improving subtitle clarity and memory support during live conversations. This will help maintain trust by ensuring that the assistant is reliable even when internet connectivity is limited or absent.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By optimizing the local vs cloud processing split for live subtitle processing, we ensure that critical real-time data remains available even under battery or network constraints. This enhances trust and reliability in noisy environments where live subtitles are most needed.

2. **What small change unlocks it**

   Define a clear boundary between what runs locally on the phone and what falls back to the cloud for live subtitle processing. Specifically, set local processing as the primary mode unless latency exceeds a threshold that would affect user trust (e.g., over 500ms delay).

3. **Likely payoff**

   This change will ensure that subtitles remain highly reliable and low-latency in critical situations, reinforcing trust and usability without overloading the cloud or draining battery.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   Improving the visual hierarchy between subtitles and one-line support ensures that the wearer remains focused on key information without being overwhelmed by too much text. This helps maintain a balance between providing enough context for understanding and keeping the user interface uncluttered, thus reducing cognitive load.

2. **What small change unlocks it**

   Define a priority rule where subtitles are always shown prominently but one-line support is hidden unless explicitly requested or when confidence in the subtitle content is low. This ensures that critical information remains visible while less important prompts remain hidden.

3. **Likely payoff**

   By optimizing the visual hierarchy, users will have a clearer and more focused view of their environment. This can lead to better comprehension and reduced cognitive strain during interactions, aligning with the core goal of enhancing understanding without overwhelming the user.

4. **Immediate next probe**
   - Define one visual priority rule between subtitles and one-line support in V1.
