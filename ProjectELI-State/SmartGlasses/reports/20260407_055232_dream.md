### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   By defining specific subtitle placement rules for different confidence levels, we can ensure that subtitles are always clear and stable enough to be trusted in live conversations. This will help maintain the core attractor of real-time subtitle clarity while reducing visual distraction.

2. **What small change unlocks it**

   Define three subtitle placement rules: one for high-confidence subtitles (visible on the side without obstructing primary focus), one for medium-confidence subtitles (slightly dimmed and placed at the bottom), and one for low-confidence subtitles (hidden or very faint).

3. **Likely payoff**

   Implementing these specific subtitle placement rules will enhance the trust in real-time subtitles, making them more reliable during live conversations. This can lead to higher user satisfaction and a stronger core experience.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**
   - Improving the confidence display format helps ensure that the wearer understands the certainty level behind each subtitle or memory prompt, which enhances trust and reliability in real-world interactions.

2. **What small change unlocks it**
   - Define a simple numeric score + label + short reason format for confidence objects. For example: `score 0.84 + "High" + "Seen recently"`.

3. **Likely payoff**
   - By providing clear, concise, and easily understood certainty information, the system can maintain high trust levels with users, ensuring that they are confident in the accuracy of subtitles and memory prompts provided by the glasses.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   By defining a local memory threshold for face/name recall, we ensure that the system remembers new people effectively without overwhelming the cache. This improves trust and reliability by reducing false positives and ensuring that frequently encountered individuals are quickly recalled.

2. **What small change unlocks it**

   Define a local memory threshold of 5 recent encounters before marking a person as "familiar" for quick recall, with a maximum of 10 cached entries per individual to prevent cache overflow.

3. **Likely payoff**

   This change will enable the system to reliably recall frequently seen faces and names almost instantly, enhancing the wearer's confidence in the assistant's memory support. It also helps manage the memory footprint, ensuring that less relevant data is cleared out more quickly.

4. **Immediate next probe**
   - Define the local memory threshold to be 5 recent encounters before marking a person as "familiar" for quick recall, with a maximum of 10 cached entries per individual.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By carefully defining what stays phone-local versus what falls back to cloud for live subtitle processing, we can ensure that the glasses deliver clear and timely subtitles while respecting battery and thermal constraints.

2. **What small change unlocks it**

   Define a specific rule where any subtitle rendering requiring real-time accuracy (e.g., during critical conversations) should be handled locally on the phone. For less time-sensitive subtitles, consider falling back to cloud processing.

3. **Likely payoff**

   This approach will ensure that the glasses remain responsive and reliable during crucial interactions, enhancing trust and usability while managing battery consumption more effectively.

4. **Immediate next probe**
   - Define the rule for handling real-time critical subtitles locally on the phone, with all other subtitle processing falling back to cloud.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   By defining a clear visual hierarchy rule between subtitles and one-line support, we ensure that the system remains unobtrusive while still providing essential assistance. This helps in maintaining low social friction and ensuring that critical information is easily visible without overwhelming the wearer.

2. **What small change unlocks it**

   Define a simple visual priority rule: prioritize subtitles over one-line prompts when the confidence of the subtitle content is high, but allow one-line prompts to be more prominent during lower-confidence situations or when there are multiple people speaking rapidly.

3. **Likely payoff**

   This rule will help in maintaining a clear and uncluttered interface, reducing cognitive load on the wearer while ensuring that critical information (subtitles) remains easily readable. It also aligns with the core attractor of low-friction assistance by keeping the one-line support from becoming too dominant.

4. **Immediate next probe**
   - Define one visual priority rule between subtitles and one-line support in V1.
