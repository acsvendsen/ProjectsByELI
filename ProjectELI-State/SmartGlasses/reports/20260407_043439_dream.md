### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   By defining a fixed subtitle placement rule that is stable and unreactive to minor changes in confidence, the system can maintain a consistent visual flow for the wearer. This stability enhances trust as the subtitles do not constantly shift, making it easier for the user to focus on the conversation.

2. **What small change unlocks it**

   Define a fixed subtitle placement rule that is centered at the bottom of the field of view and adjusts only minimally based on confidence levels. For example, if the confidence level drops below 0.8, the subtitles can move slightly up but remain within a predefined range to avoid distraction.

3. **Likely payoff**

   The payoff includes increased user trust due to consistent and predictable subtitle placement. This will help in reducing cognitive load for the wearer by providing a stable reference point for reading subtitles, thereby improving overall understanding during conversations.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Improving the local cache size for memory objects enhances the stability and reliability of name and face recall. By setting a more generous cache threshold, we can ensure that frequently encountered individuals are stored in local memory, reducing latency and improving the accuracy of on-the-fly memory lookups.

2. **What small change unlocks it**

   Define a local cache size limit for person-memory objects, specifically targeting names and faces, to be around 30 items with a periodic refresh mechanism based on recent encounters.

3. **Likely payoff**

   By setting a larger local cache size, the system can maintain a higher level of trust by quickly retrieving relevant memory without relying heavily on cloud fallbacks. This improvement will help in reducing latency and ensuring that common interactions are handled more efficiently, enhancing the overall user experience.

4. **Immediate next probe**
   - Define a local cache size limit for person-memory objects to be 30 items.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By defining a clear boundary for what runs phone-local versus what falls back to cloud, we ensure that the system remains lightweight and socially acceptable while still providing essential assistance. This helps in maintaining privacy and reducing battery drain, which are critical for the daily-use value of the product.

2. **What small change unlocks it**

   Define one task-specific cloud fallback boundary, such as live subtitle processing, transcript cleanup, face/name recall lookup, or memory archive sync, to determine what stays phone-local versus what falls back to cloud.

3. **Likely payoff**

   By setting a clear and specific cloud fallback rule for a high-usage task like live subtitle processing, we can ensure that the system remains responsive and low-friction while still leveraging cloud resources when necessary. This improves real-time performance and memory support without overloading the phone’s limited resources.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   Ensuring a clear visual hierarchy between subtitles and one-line support in V1 helps maintain low-friction assistance while preventing information overload. This balance is critical for the wearer to focus on the conversation without being distracted by too much text or commands.

2. **What small change unlocks it**

   Define a priority rule that ensures subtitles always have higher precedence than one-line prompts, but allows one-line prompts to be shown when no subtitle is needed, such as during pauses in speech.

3. **Likely payoff**

   This prioritization will help the wearer stay focused on the conversation by reducing visual clutter and ensuring that critical information (subtitles) remains prominent while still providing useful, contextual support when appropriate.

4. **Immediate next probe**
