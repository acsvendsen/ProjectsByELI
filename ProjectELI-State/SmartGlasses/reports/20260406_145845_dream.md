### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   By defining a consistent subtitle placement rule that prioritizes readability over distraction, we ensure the wearer can quickly understand critical information without being overwhelmed by visual clutter. This improves overall user experience and trust in the system.

2. **What small change unlocks it**

   Define a single fixed subtitle position on the bottom of the screen with minimal visual overlap for other UI elements, such as one-line prompts or notifications.

3. **Likely payoff**

   Consistent and unobtrusive subtitle placement will help users focus on conversations without feeling overwhelmed by additional information, leading to higher satisfaction and trust in the system’s ability to assist discreetly.

4. **Immediate next probe**

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Improving the local cache size for face/name memory enhances the system's ability to provide fast, reliable assistance without constant cloud queries. This ensures that common interactions are smoother and faster, reducing latency and improving the overall user experience.

2. **What small change unlocks it**

   Define a local cache threshold for storing recently seen faces and names on the phone. This threshold should be set based on the frequency of interactions and the memory's recency.

3. **Likely payoff**

   By setting a well-defined local cache size, the system can significantly reduce latency in face/name recall, leading to faster responses and more reliable memory-based assistance. This will improve the trust users have in the system by ensuring that common names and faces are quickly accessible without the need for cloud requests.

4. **Immediate next probe**

   Define a local cache threshold of 10-20 recent interactions for storing face/name memories on the phone to minimize latency and enhance user trust.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**
   - Ensuring that live subtitles are processed locally on the phone can reduce latency, making them feel near-real-time and thus more useful for the wearer. This local processing also reduces dependency on cloud services, which is crucial for maintaining trust and privacy.

2. **What small change unlocks it**
   - Define a specific task boundary where live subtitle processing should stay local to the phone. For example, define that all subtitle rendering and initial text processing occurs locally until they are transmitted to the glasses, but allow cloud fallbacks for high-resolution text or complex language translations.

3. **Likely payoff**
   - By keeping subtitle processing local, we can achieve faster and more reliable subtitle delivery, reducing jitter and latency. This improves the real-time feel of subtitles, which is crucial for maintaining the wearer's understanding and trust in the system.

4. **Immediate next probe**
   - Define one task-specific cloud fallback boundary for live subtitle processing where the glasses should fall back to the phone or receive cloud assistance when needed. For example, define a policy that high-resolution text or complex language translations are processed locally unless there is a specific need for cloud support due to complexity or data size.
