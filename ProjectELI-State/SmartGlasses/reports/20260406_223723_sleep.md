The project is focused on creating discreet, context-aware smart glasses with live subtitles, face/name recall, conversation memory, and one-line support. Key non-negotiables include early simplicity, frame-touch interaction only in V1, persistent context, and low-friction assistance.

- **Memory Trust**: Enhance name and face memory recall with clear confidence indicators.
- **Low-Friction Assistance**: Ensure that one-line prompts remain unobtrusive and helpful without creating command overhead.
