# Recent Consolidation for SmartGlasses V1

## Summary of Core Becoming More True, Less True, Important, or Contradictory

### Strengthening Signals (More True)
- **Subtitle Clarity**: The importance of real-time subtitle clarity is becoming more evident. Subtitles must remain clear, fast, and stable enough to be trusted in live conversations.
- **Memory Trust**: Trustworthy memory support remains a critical focus. The system should remember names, faces, and prior context without overstating certainty or causing confusion.

### Weakening Signals (Less True)
- **Low-Friction Assistance**: While low-friction assistance is still important, it might not be as immediately critical compared to subtitle clarity and memory trust in the initial V1 release. The primary focus should initially be on core functionality rather than complex one-line prompts.

### More Important
- **Privacy vs Usefulness**: This tension continues to be crucial. The system must balance providing useful assistance without infringing on privacy.
- **Latency vs Richness**: Ensuring timely responses is increasingly important, especially in noisy environments where real-time clarity can make a significant difference.

### Contradictions That Must Stay Alive
- **Discreet UX vs Visual Clarity**: The conflict between maintaining a discreet user experience and ensuring visual clarity remains. This will continue to drive design decisions.
- **Automatic Memory Support vs Confidence and Correction Safety**: Balancing automatic memory support with the need for confidence indicators and correction safety is essential.

### Dormant Ideas Worth Reactivating
- **Subtitle Placement**: Given recent user feedback, this idea could be reactivated to determine the best subtitle placement that balances readability and distraction in noisy environments.
- **Phone/Cloud Boundary**: This idea should be revisited to ensure that early hardware remains simple while still supporting core functionality.

### Concrete Tensions Around Specific Areas
1. **Subtitle Quality**:
   - Ensuring subtitles are clear, stable, and fast.
2. **Confidence Display**:
   - Determining the best format for confidence: label only, label + short reason, or score + label.
3. **Automatic New-Person Memory**:
   - How to store and reinforce new face/name memory without creating corrupted recall.
4. **Fast Lookup Requirements**:
   - Managing real-time memory lookup without overloading the system.

### No Fluff
- The system should remain focused on core functionality, with minimal interaction complexity in V1.
