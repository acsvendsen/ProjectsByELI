# Consolidation of Core Trends and Signals for SmartGlasses Project

## Strengthening Signals
1. **Subtitle Clarity**: The focus on real-time subtitle clarity is critical, especially in noisy environments where trust is essential.
2. **Memory Trust**: Trustworthy memory support for names, faces, and prior context remains a core priority to avoid invasive behavior.

## Weakening Signals
1. **Privacy vs Usefulness**: There's a growing need to balance the helpfulness of assistive features with privacy concerns.
2. **Discreet UX vs Visual Clarity**: The tension between maintaining social acceptability and ensuring readable subtitles in motion remains high.

## Contradictions That Must Stay Alive
1. **Always-on Sensing vs Battery and Thermals**: The project must continue to balance the need for always-on functionality with battery constraints.
2. **Latency vs Richness**: Ensuring timely responses without overwhelming the runtime with richer processing is crucial.

## Dormant Ideas Worth Reactivating
- **Subtitle Placement**: Revisit the optimal placement of subtitles to minimize distraction while ensuring readability in motion and noise.
- **Confidence Display**: Explore different confidence formats (label only, label + short reason, or score + label) to enhance trust without overwhelming the user.
- **Phone/Cloud Boundary**: Consider how much local processing can be offloaded to the phone versus cloud services, especially for heavy analysis tasks.

## Concrete Tensions Around Subtitle Quality, Confidence Trust, Automatic New-Person Memory, Memory Reinforcement, Fast Lookup, Privacy, Battery, and Visual UX
1. **Subtitle Quality**:
   - **Current Status**: Subtitles must remain clear and stable to ensure trust in live conversations.
   - **Tension with Fast Lookups**: Balancing fast and accurate memory recall without compromising subtitle clarity.

2. **Confidence Trust**:
   - **Current Status**: Memory support should not pretend certainty or create corrupted recall.
   - **Tension with Discreet UX**: Ensuring confidence is displayed in a way that is unobtrusive but informative to the wearer.

3. **Automatic New-Person Memory**:
   - **Current Status**: The system must remember new faces and names with confidence objects and reinforcement over time.
   - **Tension with Privacy**: Balancing memory storage and retrieval without infringing on privacy.

4. **Memory Reinforcement**:
   - **Current Status**: Subtitles and one-line prompts should coexist without overloading the wearer.
   - **Tension with Fast Lookup**: Ensuring fast lookup is effective without overwhelming the user with too much information.

5. **Fast Lookup**:
   - **Current Status**: The system should provide timely help without overloading the runtime.
   - **Tension with Richness**: Balancing the need for rich context with the importance of quick responses to maintain user trust.

6. **Privacy**:
   - **Current Status**: The project must continuously surface real-world limitations, including privacy concerns.
   - **Tension with Usefulness**: Ensuring assistive behavior is useful without becoming invasive or overly personal.

7. **Battery**:
   - **Current Status**: Early hardware remains simple to avoid battery drain issues.
   - **Tension with Always-on Sensing**: Balancing the need for always-on features with thermal and battery constraints.

8. **Visual UX**:
   - **Current Status**: Display behavior should remain socially acceptable while still being readable in motion and noise.
   - **Tension with Discreet UX vs Visual Clarity**: Ensuring clear subtitles without becoming distracting.
