## Reality-Checked Directions

### Subtitle Placement: Feasible Now
**Current Context**: The glasses need to display subtitles in a way that is clear but not distracting.

- **Subtitle Clarity (high strength)**: Ensure subtitles are placed where they can be seen without causing distraction. A good starting point might be on the side of the glasses, possibly with adjustable settings for different environments.
- **Visual Hierarchy**: The subtitle should have priority over other UI elements, making sure it stands out but remains unobtrusive.

### Confidence Display: Feasible Now
**Current Context**: The system needs to indicate confidence in its memory and subtitle generation accurately.

- **Memory Trust (high strength)**: Implement a clear display mechanism for names and faces. A label + short reason format might be effective.
- **Low-Friction Assistance (medium strength)**: Ensure the confidence display is minimal but informative, avoiding overloading the wearer with too much information.

### Memory/Cache Policy: Feasible Later
**Current Context**: How to store and reinforce face/name memory for fast lookup and trust.

- **Memory Trust (high strength)**: Develop a caching policy that balances local storage on the phone with frequent updates. This could involve using a combination of persistent and temporary caches.
- **Constraint Pressure (medium pressure)**: Early versions should favor cloud-reliant solutions to keep battery usage low, but develop offline capabilities for future iterations.

### Phone/Cloud Boundary: Feasible Now
**Current Context**: The glasses will primarily rely on the phone for heavy processing with optional cloud support.

- **Core Deepening Over Sprawl (high strength)**: Focus on improving subtitle quality and memory trust rather than expanding the feature set. Ensure that any changes respect the frame-touch-only V1 constraint.
- **Implementation Grounding (high strength)**: Base decisions on current repo files, such as `TranscriptLab`, to understand practical limits.

### Visual Hierarchy: Feasible Now
**Current Context**: How to display subtitles and one-line prompts without overloading the wearer.

- **Subtitle Clarity (high strength)**: Design a visual hierarchy that prioritizes subtitles while allowing for quick access to one-line prompts. Use color and size differences between subtitles and prompts.
- **Low-Friction Assistance (medium strength)**: Ensure one-line prompts are distinct but not distracting, perhaps using a different color or smaller font.

### Assumptions Needing Evidence
**Current Context**: Several aspects of the project require more concrete evidence before proceeding.

- **Subtitle Placement**: Detailed user testing is needed to determine the best placement and visual hierarchy.
- **Confidence Display**: More research is required to find an optimal balance between clarity and minimalism in confidence indicators.
- **Memory Storage**: Further analysis is necessary to define caching policies that enhance memory trust without overwhelming storage constraints.

### Summary
The project has several feasible directions within the current constraints. Subtitle placement, confidence display, and visual hierarchy are all achievable with concrete plans based on existing codebases. Memory policies should be developed incrementally to balance offline and online capabilities. Further user testing and research will be crucial for refining these areas.
