### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Ensuring stable subtitle placement enhances the wearer's ability to focus on conversation, reducing cognitive load and improving overall understanding in noisy environments. A fixed position for subtitles minimizes distractions and ensures that important information remains easily accessible.

2. **What small change unlocks it**

   Define a default subtitle placement rule that keeps subtitles at the bottom of the frame, slightly off-center but always visible, regardless of the confidence level or context.

3. **Likely payoff**

   A stable, unambiguous subtitle position will reduce visual distractions and improve the wearer's ability to follow conversations in real-time, leading to higher trust in the assistive technology.

4. **Immediate next probe**
   - Define a default fixed position rule that places subtitles at the bottom center of the frame.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving the confidence display format ensures that users can trust the system's responses, which is crucial for maintaining their reliance on real-time subtitle clarity and memory support. A well-crafted confidence label and short reason will help reduce uncertainty and provide context when the system is less certain about its responses.

2. **What small change unlocks it**

   Define a simple confidence format that includes a numeric score, a label indicating certainty (e.g., "High," "Medium," "Low"), and a short reason for the level of confidence.

3. **Likely payoff**

   By clearly conveying the system's level of certainty through a well-defined confidence format, users will feel more assured when interacting with the glasses. This trust will enhance the overall user experience by reducing anxiety around misunderstandings or misinterpretations, thereby improving subtitle clarity and memory support reliability.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Improving local memory cache thresholds ensures that critical information remains accessible, reinforcing trust in the system's reliability and responsiveness. This directly supports the core attractors of real-time subtitle clarity and low-friction assistance by ensuring that frequently used or recently encountered names and contexts are readily available without unnecessary latency.

2. **What small change unlocks it**

   Define a recency-first eviction policy for local memory, where more recent interactions and entities have higher priority in the cache, with a fixed size limit to ensure memory efficiency.

3. **Likely payoff**

   By prioritizing recent and frequently used memories, the system can quickly access critical information during live conversations, reducing the need for cloud lookups or delays. This enhances the overall trustworthiness of the system, as the wearer can rely on up-to-date and relevant context without the risk of outdated or irrelevant data being displayed.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   Ensuring that critical tasks like live subtitle processing remain phone-local allows for real-time, stable performance without cloud latency impacts. This keeps the wearer's experience seamless and enhances trust in the system.

2. **What small change unlocks it**

   Define a clear boundary where any live subtitle processing logic runs exclusively on the phone, not relying on cloud fallbacks unless absolutely necessary for richer context or data augmentation.

3. **Likely payoff**

   By maintaining real-time performance locally, the system can deliver subtitles that are crisp and reliable in noisy environments, reducing latency-induced misunderstandings and ensuring the wearer has clear, consistent information during live conversations.

4. **Immediate next probe**

   Define one phone-local subtitle processing boundary for exactly one task: live subtitle generation from raw audio input.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   Improving subtitle placement rules for different confidence states ensures that subtitles are always clear, readable, and unobtrusive, enhancing the wearer's ability to follow conversations in noisy environments without being distracted.

2. **What small change unlocks it**

   Define two subtitle placement modes: a default visible mode with reduced font size for low-confidence subtitles and an optional more prominent mode for high-confidence or critical information.

3. **Likely payoff**

   By offering a choice between subtle and prominent subtitle visibility, the system can better adapt to different contexts while maintaining clarity and trust. This flexibility will help in managing visual clutter without sacrificing readability, especially during high-stress interactions like meetings or noisy social gatherings.

4. **Immediate next probe**
   - Define one visual priority rule between subtitles and one-line support in V1.
