### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   By defining a consistent subtitle placement rule for different confidence states, we ensure that subtitles are always visible and readable without becoming distracting. This improves the core mission of maintaining clear, stable, and trustworthy subtitles in real-time conversations.

2. **What small change unlocks it**

   Introduce two subtitle placement rules: one for high-confidence matches (e.g., names or familiar faces) and another for lower-confidence matches (e.g., new people or less certain encounters). For V1, these can be simple fixed positions that do not react to gaze or speaker changes.

3. **Likely payoff**

   This change will help the wearer quickly recognize and focus on important conversational elements while minimizing distractions from less certain content. It aligns with the core attractor of real-time subtitle clarity by ensuring that critical information is always visible, thereby reducing cognitive load and social awkwardness.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   By refining the confidence display format to include a numeric score alongside a label and short reason, we enhance the wearer's trust in the system’s accuracy. This approach ensures that the wearer understands the level of certainty behind each piece of information provided by the glasses, which is crucial for real-time interaction support.

2. **What small change unlocks it**

   Define a confidence format that includes a numeric score (e.g., 0.84), a label (e.g., "High"), and a short reason (e.g., "Seen recently"). This can be represented as: `score 0.84 + "High" + "Seen recently"`.

3. **Likely payoff**

   Implementing this confidence format will help the wearer understand the reliability of the subtitles and memory support, thereby increasing trust in the system during critical interactions. It provides a clear indication of when to rely on the glasses’ assistance and when to be more cautious.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   By defining a local memory threshold for name recall, we ensure that the system retains only the most relevant memories while maintaining low thermal and battery overhead. This helps in balancing the need for trustworthiness with the constraints of always-on processing.

2. **What small change unlocks it**

   Define a local cache size limit of 5-10 recent interactions for name recall, ensuring that memory is reinforced over time but not indefinitely.

3. **Likely payoff**

   This approach will reduce thermal and battery load while still providing reliable support for likely new people, thus maintaining trust without overloading the system.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

It will also provide a clear path forward for V1 interactions that stay discreet and focused, enhancing the wearer's trust in the system by ensuring timely responses without overburdening the device.
