### Idea 1: Subtitle Placement

1. **Why it benefits the core**
   - By establishing stable subtitle placement rules, V1 can ensure that subtitles remain readable and unobtrusive throughout interactions, enhancing the wearer's trust in real-time assistance without causing distraction.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving the confidence display format will enhance the wearer's trust in the system by clearly indicating the certainty of the information provided, thus reducing social and cognitive friction.

2. **What small change unlocks it**

   Define a new confidence format that combines a numeric score with a label and a short reason for the estimate. For example: "score 0.84 + 'High' + 'Seen recently';" this format will provide clear, actionable information to the wearer without overwhelming them.

3. **Likely payoff**

   By implementing this improved confidence display, users will better understand the reliability of the subtitles and memory support provided by the system, leading to increased trust and usage frequency. This clarity can help the wearer feel more confident during interactions, thereby enhancing the overall user experience.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   By optimizing the local memory thresholds for face/name recall, we ensure that critical information is readily available to the wearer without overwhelming their visual field or battery capacity. This improves the trustworthiness of memory support and ensures that key interactions are reliable even in low-latency scenarios.

2. **What small change unlocks it**

   Define a recency-based eviction policy for local face/name memories, keeping only the most recently interacted-with entities within a specified cache size limit.

3. **Likely payoff**

   This change will enhance the reliability and accuracy of face/name recall, ensuring that important interactions are not hindered by expired or irrelevant data. It will also help in managing battery usage effectively by limiting the amount of memory that needs to be processed locally.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.
