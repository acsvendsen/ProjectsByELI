### Idea 1: Subtitle Placement

1. **Why it benefits the core**
   - Improving subtitle placement rules ensures that subtitles are clear, readable, and not overly distracting, which directly supports the core attractor of real-time subtitle clarity. Stable subtitle positioning helps maintain trust and readability in live conversation.

2. **What small change unlocks it**
   - Define a simple fixed-position rule for subtitles: place subtitles at the bottom center of the display area to avoid visual distractions while ensuring they remain visible and readable. This rule can be adjusted based on user feedback but provides a stable starting point.

3. **Likely payoff**
   - By setting a fixed subtitle placement, V1 can ensure that subtitles are consistently placed in a non-distracting yet easily readable position. This improvement will reduce cognitive load for the wearer and enhance the overall usability of the product.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving confidence display by using a label + short reason format will enhance trust in memory support while maintaining clear and concise visual hierarchy. This approach ensures that the wearer can quickly understand the reliability of the information, which is crucial for their daily use.

2. **What small change unlocks it**

   Define one confidence format candidate for V1 that combines a numeric score with a label and short reason. For example, "score 0.84 + 'High' + 'Seen recently'; score 0.42 + 'Low' + 'Weak match'; score 0.63 + 'Medium' + 'Name heard once in introduction'."

3. **Likely payoff**

   By implementing this confidence format, the system will provide clear and understandable indicators of memory reliability. This will help users trust the memory support more, leading to increased daily-use value and better overall experience.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   By setting a more aggressive local memory threshold for name recall, the system can ensure that frequently encountered names are retained in a form that is quickly accessible and reliable. This reduces the need for cloud fallbacks or frequent reinforcement touches, thus maintaining the wearers' trust and improving their memory of important people.

2. **What small change unlocks it**

   Define a local cache threshold of 5 recent face/name encounters for quick recall and display, with an eviction policy that keeps the top 3 most recently seen names active in memory.

3. **Likely payoff**

   This aggressive local caching will reduce latency during name recall, improve the trust and reliability of memory support, and minimize the need for cloud interactions, thereby enhancing the overall user experience by making the system more responsive and dependable.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   Ensuring that live subtitle processing is handled primarily on the phone while falling back to cloud only for critical tasks or when local resources are strained will maintain real-time clarity and trust, while respecting battery and thermal constraints.

2. **What small change unlocks it**

   Define a policy where live subtitle processing runs locally on the phone until the glasses sensor data exceeds a certain threshold (e.g., high ambient noise) or the transcript complexity increases to a level that benefits from cloud processing. This allows for dynamic switching without compromising real-time performance.

3. **Likely payoff**

   By keeping subtitle processing local, we ensure that subtitles remain clear and stable in noisy environments, enhancing the wearer's trust in the system’s ability to provide accurate information. Cloud fallback can be used when necessary without introducing latency that might degrade the user experience.

4. **Immediate next probe**

   Define one phone/cloud fallback boundary for live subtitle processing: switch to cloud-based processing if ambient noise exceeds 80 dB or transcript complexity exceeds a certain threshold of words per minute.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   By refining the visual hierarchy to ensure subtitles remain clear and unobtrusive while coexisting with one-line prompts, we can maintain the wearer's focus on real-time communication without overwhelming them with too much information.

2. **What small change unlocks it**

   Define a clear precedence rule that ensures subtitles have higher priority during live conversations, but also allows for subtle, non-intrusive one-line support when necessary.

3. **Likely payoff**

   This will enhance the wearer's ability to follow real-time conversations without distraction while still receiving helpful contextual cues in moments of need, thereby increasing daily-use value and trust in the system.

4. **Immediate next probe**

   Define one visual priority rule between subtitles and one-line support that ensures subtitles remain primary during live interactions but allow for brief, non-intrusive prompts when necessary.
