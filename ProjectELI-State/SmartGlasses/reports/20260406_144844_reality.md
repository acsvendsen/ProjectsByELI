## Reality Check for SmartGlasses V1 Direction

### Subtitle Placement: Feasible Now
- **Current Decision**: Ensure subtitles are placed at the bottom of the field of view, just below the line of sight, with minimal overlap between lines. This placement minimizes distraction while providing clear visibility.
- **Reasoning**: Given current hardware constraints and user experience goals, this approach strikes a balance between readability and non-intrusiveness.

### Confidence Display: Feasible Now
- **Current Decision**: Use a simple "Not Sure" or "Uncertain" label to indicate the confidence level of memory matches. For example:
  - **"Not Sure"** if the match is weak.
  - **"Confident"** if there's high certainty.
- **Reasoning**: This approach keeps the UI clear and avoids overwhelming the user with too much information, aligning with the core goal of non-intrusiveness.

### Memory/Cache Policy: Feasible Now
- **Current Decision**: Cache recent face and name interactions on the phone for quick access. Use a sliding window cache that expires based on recency.
- **Reasoning**: This balances the need for fast lookup against battery and memory constraints, ensuring useful data is retained without excessive storage demands.

### Phone/Cloud Boundary: Feasible Now
- **Current Decision**: Keep core functionality on the phone, leveraging cloud services only when necessary. For example, use the cloud for model updates or heavy data processing.
- **Reasoning**: This approach leverages the strengths of both devices while minimizing the thermal and battery impact of always-on features.

### Visual Hierarchy: Feasible Now
- **Current Decision**: Prioritize subtitles over other UI elements to ensure they are the most visible. Use a simple, unobtrusive design for confidence indicators and memory prompts.
