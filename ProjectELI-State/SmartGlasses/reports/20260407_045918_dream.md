### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Improving subtitle placement rules ensures that subtitles remain clear and stable, enhancing the wearer's ability to follow conversations in real-time without being distracted or overwhelmed by the display.

2. **What small change unlocks it**

   Define two subtitle placement rules: one for high-confidence speech segments (e.g., primary speakers) and another for low-confidence segments (e.g., background noise, uncertain speakers). This will help maintain focus on key information while reducing visual clutter.

3. **Likely payoff**

   By implementing these specific placement rules, the system can reduce distraction and improve readability, leading to better understanding and more trust in the subtitle functionality. This refinement will also set a strong foundation for future improvements in subtitle clarity and stability.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving confidence display helps ensure that the wearer can trust the system's output, which is critical for real-time subtitle clarity and memory support. A well-designed confidence format will provide clear feedback on the certainty of information, reducing social friction and enhancing the overall assistive experience.

2. **What small change unlocks it**

   Define a consistent confidence format using a numeric score (e.g., 0-1 scale) combined with a label (High, Medium, Low) and a short reason for the score. This format should be clear and concise to help users quickly understand the reliability of the displayed information.

3. **Likely payoff**

   By implementing a clear confidence format, the system can better manage expectations about its accuracy, leading to higher trust in real-time subtitles and memory support. Users will feel more confident that they are getting accurate and reliable information, which is crucial for effective communication in noisy or hearing-challenged environments.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Improving local memory thresholds for face/name recall ensures that the system can quickly provide relevant information without relying heavily on cloud syncs, thereby reducing latency and maintaining trust by ensuring responses are timely and accurate.

2. **What small change unlocks it**

   Define a local cache size limit of 10 entries for people, names, and topics, with a recency threshold of one week for each entry to prioritize recent interactions over older ones.

3. **Likely payoff**

   This change will significantly reduce the need for frequent cloud syncs, enhancing real-time response speed and trust by ensuring that frequently encountered faces and names are readily available locally. It also helps manage battery usage effectively while maintaining a reasonable memory size for daily-use scenarios.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By defining a specific task boundary for live subtitle processing that stays phone-local, we can ensure real-time subtitle quality is maintained without overloading the cloud. This improves trust and daily-use value by keeping critical assistive behavior responsive and reliable.

2. **What small change unlocks it**

   Define one subtitle placement rule for different confidence states where low-confidence subtitles are shown as a single line with minimal visual disruption, while high-confidence subtitles can be more detailed and stable.

3. **Likely payoff**

   This tweak will help in maintaining the wearer's trust by ensuring that even when the system is unsure, it does not overwhelm the user with too much information. It will also free up cloud resources for more complex tasks like memory lookup and context processing without sacrificing real-time subtitle clarity.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**
   
   Ensuring a clear visual hierarchy between subtitles and one-line support helps maintain the wearer's focus on critical information without overwhelming them with too many elements. This balance supports real-time subtitle clarity (attractor) while minimizing distraction, thereby enhancing overall user experience.

   Define a priority rule that routes one-line prompts to be visually less prominent than subtitles but still easily accessible when needed. This can be achieved by setting the default visual precedence so that subtitles are always shown prominently above one-line support text.

3. **Likely payoff**

   By establishing clear visual precedence, the system will provide more reliable and timely assistance without overwhelming the wearer. This improves focus during critical moments of conversation, thereby strengthening trust in the product’s ability to help without distracting the user.
