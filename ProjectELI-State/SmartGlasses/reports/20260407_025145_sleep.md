# Recent Signals Consolidation

## Strengthening Signals
- **Subtitle Clarity**: The subtitle system must remain clear, fast, and stable to ensure the wearer can trust them in live conversations.
- **Memory Trust**: Names, faces, and prior context should be remembered without creating false certainty or recall issues. This is critical for building trust.
- **Low-Friction Assistance**: One-line prompts should provide necessary help while maintaining a low-friction interaction experience.

## Weakening Signals
- **Privacy vs Usefulness**: There's an ongoing pressure to balance the need for useful assistive behavior with privacy concerns, but this tension remains important and must be managed carefully.
- **Latency vs Richness**: The system needs to provide timely help without becoming overly complex. This is a key consideration that should be prioritized in design decisions.

## Contradictions That Must Stay Alive
- **Core Deepening Over Sprawl**: Work should focus on improving core features (subtitle quality, memory trust, visual UX) rather than broad feature expansion.
- **Frame-Touch-Only V1 Interaction**: Early interaction should remain simple and touch-based, avoiding voice commands or complex UI layers.

## Dormant Ideas Worth Reactivating
- **Subtitle Placement and Visual Hierarchy**: These are important but currently inactive areas that could benefit from renewed focus. Decisions here will impact the wearer’s experience significantly.

## Concrete Tensions Around Subtitle Quality, Confidence Trust, Automatic New-Person Memory, Memory Reinforcement, Fast Lookup, Privacy, Latency, Battery, and Visual UX
- **Subtitle Quality**: Ensuring subtitles are clear and fast enough to be trusted.
- **Confidence Trust**: Representing confidence accurately without misleading the wearer.
- **Automatic New-Person Memory**: Building reliable memory for new faces and names over time.
- **Memory Reinforcement**: Enhancing memory recall through consistent reinforcement.
- **Fast Lookup**: Providing quick access to remembered information.
- **Privacy**: Balancing useful assistive behavior with privacy concerns.
- **Latency**: Ensuring timely responses without compromising on complexity.
- **Battery**: Managing power consumption, especially for always-on features.
- **Visual UX**: Designing an interface that is both clear and unobtrusive.

## Open Questions
- **Subtitle Placement**: Determining the most usable subtitle placement without becoming distracting.
- **Confidence Display**: Choosing a confidence format (label only, label + short reason, score + label) that builds trust best.
- **Memory/Cache Policy**: Deciding how much face/name memory should be cached locally on the phone.
