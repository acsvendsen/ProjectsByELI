### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Improving subtitle placement rules can enhance overall readability and trustworthiness during live conversations. By ensuring subtitles are placed in a stable, unobtrusive position that remains visible and legible, the system can provide consistent, reliable assistance to the wearer without becoming distracting or causing cognitive overload.

2. **What small change unlocks it**

   Define two subtitle placement rules: one for high-confidence speaker interactions (e.g., face and name recognition) where subtitles are displayed prominently but discreetly, and another for lower-confidence scenarios (e.g., unknown speakers or background noise) where subtitles are slightly less visible to avoid distraction.

3. **Likely payoff**

   By implementing these two subtitle placement rules, the system can provide more contextually appropriate visual support without overwhelming the wearer, thereby enhancing overall user trust and satisfaction in noisy environments.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Ensuring a clear and consistent confidence format helps in building trust with the wearer. A well-designed confidence label and short reason will make the wearer more confident in the accuracy of subtitles, memory support, and one-line prompts.

2. **What small change unlocks it**

   Define the confidence object format to include a numeric score, a label (e.g., "High," "Medium," "Low"), and a short reason (e.g., "Seen recently," "Weak match"). This structured format will provide transparency and reduce ambiguity.

3. **Likely payoff**

   By implementing a clear and consistent confidence format, the system will be more transparent about its certainty levels, thereby increasing user trust and reliability in real-time interactions. This clarity will help users understand when to rely on the assistant's suggestions and when they should take their own actions.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   By defining a clear local memory threshold for cached face/name recall, we ensure that frequently encountered individuals are remembered with high confidence, reducing the risk of memory overload and maintaining focus on the most relevant interactions.

2. **What small change unlocks it**

   Define one specific local-cache size limit for face/name memory objects, setting an upper bound to prevent excessive storage while ensuring key entities remain cached.

3. **Likely payoff**

   This threshold will help balance memory utility with system performance and battery life, enhancing the wearer's trust in the assistant’s reliability by keeping the recall process efficient and focused on high-priority interactions.

4. **Immediate next probe**

   Define a local-cache size limit of 10 face/name objects for V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By defining a clear phone/cloud fallback boundary for live subtitle processing, we ensure that subtitles remain reliable and fast in real-time conversations. This reduces the risk of latency-induced errors, which could break the wearer's trust in the system.

2. **What small change unlocks it**

   Define one specific task boundary where subtitle processing falls back to the cloud only if local processing fails or takes too long. For example, set a rule that live subtitles should always prefer phone processing, and fallback to cloud only for complex audio environments that are hard to transcribe locally.

3. **Likely payoff**

   This change will ensure high-quality real-time subtitle delivery in noisy or challenging environments, maintaining the wearer's trust and confidence in the system. It also helps surface battery and thermal constraints early by focusing on what can be done on-device versus offloading complex tasks to the cloud.

4. **Immediate next probe**

   Define one specific task boundary where live subtitles should prefer phone processing over cloud fallbacks for high-latency scenarios.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**
   Improving the visual hierarchy between subtitles and one-line support ensures that the wearer can focus on the most important information without being overwhelmed by additional text, thereby enhancing their understanding in noisy or complex environments.

2. **What small change unlocks it**
   Define a rule that prioritizes subtitle display over one-line support when confidence is high but suppresses both if low-confidence content might be misleading.

3. **Likely payoff**
   This rule will help the wearer stay focused on clear, accurate information without being distracted by less certain or contextually irrelevant text, thus improving overall comprehension and trust in the system.

4. **Immediate next probe**
