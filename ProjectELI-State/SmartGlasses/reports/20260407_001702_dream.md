### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   By defining a fixed subtitle placement rule that remains stable across different confidence states, we can ensure that subtitles remain readable and unobtrusive in noisy environments, thereby enhancing the wearer's ability to follow conversations without distraction.

2. **What small change unlocks it**

   Define a single fixed subtitle placement mode for all confidence states, such as always placing subtitles at the bottom of the display area.

3. **Likely payoff**

   A consistent and stable subtitle placement will reduce visual distractions and ensure that important information is always visible, improving overall user trust in the system's real-time assistance capabilities.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

This transparency enhances trust and allows the wearer to make informed decisions based on the system’s reliability, thereby improving overall user experience and satisfaction.

4. **Immediate next probe**

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   By setting a local cache threshold for name recall, we can ensure that frequently encountered faces and names are quickly accessible to the wearer without relying heavily on cloud services. This reduces latency and improves the trustworthiness of memory support by providing fast lookups based on recent interactions.

2. **What small change unlocks it**

   Define a specific recency threshold in the local cache policy, such as keeping name recall entries active for at least 10 minutes after the last interaction.

3. **Likely payoff**

   This change will significantly enhance the speed and accuracy of face/name recall during critical interactions, reducing latency and ensuring that the wearer can rely on recent memories without delays or cloud dependency. It also aligns with the core attractor of memory trust by providing a reliable local fallback for commonly encountered people.

4. **Immediate next probe**

   Set a recency threshold of 10 minutes for name recall entries in the local cache policy.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**
   - By defining clear rules for what stays phone-local versus what falls back to cloud processing, we ensure that V1 can deliver real-time subtitles and memory support without excessive battery drain or latency issues. This helps in maintaining high subtitle clarity and trustworthiness of memory recall.

2. **What small change unlocks it**
   - Define a specific task boundary for live subtitle processing where the glasses handle all audio processing locally, while transcript cleanup and face/name recall lookup fall back to the phone. This ensures that subtitles remain crisp and real-time even in noisy environments.

3. **Likely payoff**
   - By keeping subtitle processing local, we can avoid battery drain from continuous cloud requests and ensure fast, reliable subtitle delivery. Additionally, offloading memory tasks like face/name recall to the phone allows for more efficient use of both devices while maintaining high trust in real-time support.

4. **Immediate next probe**
