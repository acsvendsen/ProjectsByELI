**Reasoning:** The project is currently in the "Core Deepening" mode, which means efforts should be focused on improving subtitle quality, memory support, confidence behavior, and phone/cloud boundaries. Broad feature expansion without core improvements would likely waste time and deviate from the mission.

### Constraint Pressure
**Reasoning:** Given the constraints of battery, latency, privacy, and usability outlined in `v1_real_world_limits.md`, it is essential to surface these early so that weak directions can be quickly ruled out. The current implementation respects these constraints by keeping processing localized and ensuring subtitles remain readable and stable.
