### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Ensuring that subtitle placement rules are carefully defined can significantly enhance the wearer's ability to focus on the conversation while maintaining readability and reducing distraction. Stable, well-placed subtitles help in creating a seamless user experience, which is crucial for the core mission of the project.

2. **What small change unlocks it**

   Define two placement modes: one for high-confidence content (like names and faces) that should remain stable to build trust, and another for lower-confidence content (like general conversation snippets) that can be more flexible but still prioritized in the wearer's field of view.

3. **Likely payoff**

   By setting clear rules for subtitle placement, we can reduce visual clutter while ensuring key information remains prominent. This will improve the overall user experience, making the product more reliable and easier to use, which directly benefits the core mission of helping the wearer understand better in noisy environments.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   By refining the confidence display format, we can ensure that the system's certainty in memory and context is communicated clearly to the wearer. This clarity helps maintain trust by avoiding misleading or overconfident claims, which are critical for the core mission of helping the wearer stay present and informed.

2. **What small change unlocks it**

   Define a confidence format using a numeric score plus a label with a short reason. For example: "score 0.84 + 'High' + 'Seen recently'; score 0.42 + 'Low' + 'Weak match'; score 0.63 + 'Medium' + 'Name heard once in introduction'."

3. **Likely payoff**

   A clear and concise confidence format will help the wearer understand the reliability of the system's memory support, enhancing trust without overwhelming them with unnecessary details. This clarity is crucial for maintaining a low-friction assistance experience.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   By defining a local memory threshold for face/name recall, we ensure that critical information is always accessible to the wearer without overwhelming their cognitive load. This helps maintain trust by ensuring quick and reliable access to relevant memories, enhancing the overall user experience.

2. **What small change unlocks it**

   Define a local cache size limit of 5-7 entries for frequently encountered names and faces, with a recency policy that evicts older entries when new ones are added.

3. **Likely payoff**

   A well-defined memory threshold will reduce the likelihood of memory failures during critical interactions, thereby increasing trust in the system’s reliability and consistency. This will help maintain the wearer's confidence and improve the overall user experience by ensuring relevant memories are readily available.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By defining clear phone-local and cloud boundaries for live subtitle processing, we ensure that real-time subtitles are always available in low-latency scenarios, maintaining trust and utility. This focus on local processing helps manage battery and thermal constraints while providing the wearer with reliable, fast assistance.

2. **What small change unlocks it**

   Define a single task-specific fallback boundary where critical subtitle processing falls back to the cloud only under certain conditions (e.g., high latency or degraded network). For V1, live subtitle processing should remain phone-local to ensure low-latency, stable performance and trust.

3. **Likely payoff**

   This change will enable V1 to deliver consistently reliable subtitles by leveraging local processing power, which is crucial for maintaining the wearer's trust in real-time scenarios. It also helps manage battery consumption and thermal constraints, ensuring that the product remains usable over extended periods without interruptions.

4. **Immediate next probe**

   Define one phone/cloud fallback boundary for live subtitle processing where critical subtitle data falls back to cloud only under high latency conditions.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   Ensuring that subtitles remain clear, fast, and stable enough to be trusted in live conversations directly enhances the wearer's ability to follow and engage with spoken content. By prioritizing subtitle clarity, the system can maintain high trust levels and ensure that the wearer feels supported rather than overwhelmed or confused.

2. **What small change unlocks it**

   Define a specific subtitle placement rule that ensures subtitles are placed above the speaker’s face in live conversation scenarios. This static placement rule will help the subtitles remain unobtrusive yet visible, reducing cognitive load on the wearer and enhancing their trust in the system.

3. **Likely payoff**

   By consistently placing subtitles above the speaker's face, the system can reduce distraction while still ensuring that the subtitles are easily readable. This will lead to higher satisfaction and better engagement during conversations, reinforcing the core mission of helping wearers understand real-world interactions more effectively.

4. **Immediate next probe**
   - Define one visual priority rule between subtitles and one-line support in V1.
