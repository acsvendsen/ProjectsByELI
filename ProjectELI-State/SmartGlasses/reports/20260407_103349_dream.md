### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Improving subtitle placement rules can enhance the wearer's ability to focus on live conversation without being distracted. Stable and well-placed subtitles will reduce cognitive load, making the wearer more present in interactions.

2. **What small change unlocks it**

   Define two subtitle placement rules: one for low-confidence names or faces (e.g., "medium" confidence threshold) where subtitles appear in a less intrusive position but are still visible, and another for high-confidence entities that can be placed at the edge of the frame without causing distraction.

3. **Likely payoff**

   By refining subtitle placement based on confidence levels, V1 can provide more useful and less distracting support to the wearer, improving overall understanding and interaction quality without overwhelming the user with too much information.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving the confidence display format helps establish clear and trustworthy interactions for the wearer. By refining how certainty is conveyed through labels, scores, and short reasons, the system can better manage expectations and reduce confusion. This directly supports the "Trustworthy memory support" attractor by ensuring that the memory system does not overcommit or mislead.

2. **What small change unlocks it**

   Define a new confidence format for V1 that combines a numeric score with a label and a short reason. For example, use a format like: `score 0.8 + "High" + "Seen recently"`. This small change will provide a consistent and understandable way to communicate the level of certainty about a person or piece of information.

3. **Likely payoff**

   By using a clear confidence format, the system can enhance user trust in memory support and subtitle accuracy. This clarity can reduce uncertainty for the wearer and make interactions more reliable and intuitive. The improved consistency will also help align expectations with the actual level of certainty provided by the system.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By defining a clear boundary for what stays on the phone versus what falls back to cloud for live subtitle processing, we ensure that subtitles remain fast and stable enough to be trusted in real-time conversations. This focus helps maintain the attractor of real-time subtitle clarity while respecting battery constraints.

2. **What small change unlocks it**

   Define a local cache threshold for face/name memory that triggers cloud fallback only when certain confidence levels are met, ensuring real-time responsiveness while still leveraging cloud intelligence where necessary.

3. **Likely payoff**

   This boundary will enable the system to provide near-real-time subtitles without overwhelming the phone's resources, maintaining trust and clarity during critical interactions. Simultaneously, it allows for richer memory support by periodically syncing with the cloud when confidence levels are high enough.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**
   Enhancing the visual hierarchy by prioritizing subtitles over one-line prompts ensures that the wearer can trust real-time subtitles more effectively during live conversations. This improves the core attractor of subtitle clarity, which is crucial for the wearer's understanding and confidence in noisy environments.

2. **What small change unlocks it**
   Define a single subtitle placement rule where subtitles are always shown above or adjacent to one-line prompts unless the prompt is of high importance (e.g., "urgent" or "important").

3. **Likely payoff**
   By prioritizing subtitles, the system will remain more useful in noisy environments and enhance the wearer's trust in real-time information. This improves overall subtitle clarity and reduces cognitive load by ensuring that critical speech content remains prominently visible.

4. **Immediate next probe**
   Define one visual priority rule between subtitles and one-line support where subtitles always appear above or adjacent to prompts unless a prompt is explicitly marked as "urgent" or "important."
