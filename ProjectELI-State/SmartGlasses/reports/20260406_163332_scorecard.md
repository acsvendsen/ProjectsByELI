## Project Summary
The SmartGlasses project is focused on delivering a lightweight, discreet personal assistant in V1 that supports live subtitles, face/name recall, conversation memory, and one-line prompts. The current configuration ensures the system remains simple with frame-touch interactions and minimal on-glasses compute, while also prioritizing privacy and trust. Key areas of focus include subtitle placement, confidence display, memory policy, and phone/cloud processing boundaries.
