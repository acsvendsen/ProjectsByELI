### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   By establishing clear and stable subtitle placement rules, we can ensure that subtitles remain readable and unobtrusive in noisy environments. This stability will enhance user trust and understanding without creating distractions or social awkwardness.

2. **What small change unlocks it**

   Define three specific subtitle placement modes: one for high-confidence speech (e.g., 0.85+), one for medium-confidence speech (e.g., 0.65-0.84), and one for low-confidence speech (e.g., below 0.65). Each mode will have a distinct visual priority to minimize distractions.

3. **Likely payoff**

   Stable subtitle placement that respects the wearer’s cognitive load will lead to more accurate and reliable understanding, reducing social friction and enhancing daily-use value. This will help the wearer stay present and informed in real-world interactions without being overwhelmed by subtitles.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**
   
   Improving confidence display ensures that the wearer can trust the system's assistance more reliably, which is crucial for maintaining real-time subtitle clarity and trustworthy memory support. Better confidence indicators help in understanding the reliability of displayed information and remembered context.

2. **What small change unlocks it**

   Define a new confidence format that combines a numeric score with a label and a short reason. For example, "score 0.84 + 'High' + 'Seen recently'". This format provides clear, concise, and actionable feedback about the reliability of the displayed information.

3. **Likely payoff**

   By implementing this new confidence format, the system can provide more transparent and trustworthy assistance, reducing cognitive load and increasing user trust. This clarity in confidence will make it easier for wearers to focus on the conversation without questioning the accuracy or relevance of the system’s inputs.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Improving the local memory cache threshold ensures that frequently encountered names and faces are quickly accessible, reducing latency and increasing trust in the system's ability to recall relevant information. This directly supports the **memory_trust** attractor by making the system more reliable for names and prior context.

2. **What small change unlocks it**

   Define a local memory cache threshold of 5 recent face/name encounters that triggers additional reinforcement or display rules when exceeded, ensuring these entities are quickly recalled and reinforced over time.

3. **Likely payoff**

   By setting a local cache threshold, the system can maintain fast lookup times for frequently encountered names and faces, reducing latency and increasing trust in memory recall. This improvement will help the wearer feel more confident that their interactions are being accurately supported by the glasses.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   Ensuring that live subtitle processing stays phone-local allows for faster, more responsive subtitle delivery, which is critical for maintaining trust in real-time communication. By keeping this process on-device, we can minimize latency and ensure that subtitles are as clear and fast as possible, without relying on cloud delays.

2. **What small change unlocks it**

   Define a local subtitle processing pipeline that handles live transcription and rendering of subtitles directly on the phone, with minimal dependency on cloud services for real-time updates.

3. **Likely payoff**

   By keeping subtitle processing phone-local, we can significantly reduce latency, ensuring that subtitles are displayed almost instantaneously after speech is captured. This will enhance trust in the system and provide a more seamless user experience during live conversations.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

Improving subtitle-vs-one-line support prioritization ensures that the wearer can quickly understand critical information without being overwhelmed by excessive text. This directly supports the core attractor of low-friction assistance, making sure the system remains useful and not intrusive.

2. **What small change unlocks it**

Define a visual hierarchy rule that prefers subtitles over one-line prompts when confidence is high, but allows one-lines to override subtitles in critical contexts where immediate understanding is more important than long-term clarity.

3. **Likely payoff**

This change will make the system more intuitive and less likely to distract the wearer with unnecessary text. It will enhance the wearer's trust in the system by ensuring that critical information is presented clearly and unobtrusively, aligning with the core attractor of low-friction assistance.

4. **Immediate next probe**
   - Define one visual priority rule between subtitles and one-line support in V1.
