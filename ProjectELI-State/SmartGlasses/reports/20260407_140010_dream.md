### Idea 1: Subtitle Placement

1. **Why it benefits the core**
   - Improving subtitle placement rules can enhance the wearer's ability to focus on the conversation while reducing distractions, thereby deepening the core attractor of real-time subtitle clarity.

2. **What small change unlocks it**
   - Define a single fixed subtitle placement rule that prioritizes stability over reactivity, ensuring subtitles remain visible but not overly intrusive during conversations.

3. **Likely payoff**
   - By keeping subtitles in a consistent, unambiguous position, the wearer can better trust and rely on them without being distracted by frequent movement or repositioning, thus improving overall conversation understanding and confidence.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**
   Improving confidence display helps maintain trust in both subtitle quality and memory recall by providing clear, consistent, and honest feedback to the wearer.

2. **What small change unlocks it**
   Define a specific format for confidence labels that includes a numeric score, a label (high, medium, low), and a short reason for the score. For example: "Score 0.85 + High + 'Seen recently'".

3. **Likely payoff**
   By providing clear and consistent confidence indicators, the system can reduce user uncertainty and enhance overall trust in both subtitles and memory recall. This clarity will make users more confident in the system's accuracy, which is crucial for its daily-use value.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Ensuring stable subtitle placement rules can enhance the wearer's trust in the system by reducing distractions and ensuring clear, readable subtitles. This consistency is crucial for maintaining a low-friction assistive experience that does not draw attention away from the conversation.

2. **What small change unlocks it**

   Define 3 to 5 specific subtitle placement rules based on confidence levels: high (stable center), medium (slightly above eye level but visible), and low (only displayed when spoken name or phrase matches closely). This approach ensures subtitles remain stable and unobtrusive while still providing essential information.

3. **Likely payoff**

   By implementing stable, confidence-based subtitle placement rules, the system will reduce visual distractions during conversations, leading to a more natural and effective assistive experience. This stabilization can significantly improve user trust and satisfaction with the product.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**
   - By defining a clear boundary for what runs phone-local versus what falls back to cloud, we can optimize subtitle processing and memory support without overloading the glasses or the phone. This ensures real-time performance and privacy while maintaining the core mission of providing high-quality, reliable subtitles and personal memory support.

2. **What small change unlocks it**
   - Define one specific task boundary for live subtitle processing that runs entirely on the phone: "Live subtitle processing should run locally on the phone until the wearer has left a conversation or the glasses are idle for more than 30 seconds."

3. **Likely payoff**
   - This approach will ensure real-time subtitles remain clear and stable, reducing battery drain from constant cloud requests. It also aligns with the core mission of providing immediate assistance without sacrificing privacy.

4. **Immediate next probe**
   - Define one specific task boundary for live subtitle processing that runs entirely on the phone: "Live subtitle processing should run locally on the phone until the wearer has left a conversation or the glasses are idle for more than 30 seconds."

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   By carefully managing the visual hierarchy between subtitles and one-line support, we can ensure that the wearer remains focused on critical information without being overwhelmed by additional text. This balance is crucial for maintaining clarity and reducing cognitive load in noisy or fast-paced environments.

2. **What small change unlocks it**

   Define a clear subtitle-vs-one-line priority rule where subtitles have higher precedence but one-line prompts are displayed prominently enough to catch the wearer's attention when needed. For example, set a policy that one-line support should be shown only when there is no ongoing subtitle or if the confidence of the subtitle is below a certain threshold.

3. **Likely payoff**

   This small change will enhance the wearability and usability of the glasses by ensuring that subtitles remain the primary focus while still providing timely and necessary one-line prompts without overwhelming the wearer. It will also help in maintaining a clean and uncluttered visual interface, which is essential for real-time interaction.

4. **Immediate next probe**
   - Define one visual priority rule between subtitles and one-line support in V1.
