# Consolidated Signals for SmartGlasses Project

## Strengthening Signals
- **Subtitle Clarity**: Enhancing real-time subtitle clarity remains a high-priority attractor, ensuring subtitles are readable and stable enough for live conversation.
- **Memory Support**: Improving the trustworthiness of memory support is crucial to ensure names and prior contexts are remembered accurately without overconfidence or uncertainty.

## Weakening Signals
- **Always-on Sensing vs Battery and Thermals**: Reducing reliance on always-on sensing in favor of more battery-efficient interactions. This aligns with V1 constraints that prioritize frame-touch interaction.
- **Rich Context vs Low-latency Response**: Prioritizing low-latency responses over richer context to maintain a balance between utility and real-time performance.

## Contradictions That Must Stay Alive
- **Privacy vs Usefulness**: The tension between providing useful assistive behavior without invading privacy remains critical. This contradiction must be managed carefully.
- **Discreet UX vs Visual Clarity**: Ensuring the system is socially acceptable while still being readable in motion and noise continues to be a balancing act.

## Dormant Ideas Worth Reactivating
- **Subtitle Placement and Visual Hierarchy**: These are dormant ideas that could benefit from reactivation. The current focus on core-deepening work means these areas may need more attention.
- **Face/Name Memory Storage and Reinforcement**: Considering how face/name memory should be stored for fast lookup and reinforcement is important, given the current low-friction assistance attractor.

## Concrete Tensions Around Subtitle Quality, Confidence Trust, Automatic New-Person Memory, Memory Reinforcement, Fast Lookup, Privacy, Latency, Battery, Visual UX
- **Subtitle Quality**: Ensuring subtitles remain readable and stable.
- **Confidence Trust**: Displaying confidence in a way that builds trust without overconfidence or underconfidence.
- **Automatic New-Person Memory**: Remembering new faces and names with confidence objects and reinforcement over time.
- **Memory Reinforcement**: Improving memory recall through consistent reinforcement of remembered information.
- **Fast Lookup**: Ensuring quick access to relevant memories while maintaining low battery drain.
- **Privacy**: Balancing the need for useful assistive behavior with privacy concerns.

- **Battery**: Managing thermal and battery constraints in V1.

## Summary of Core Field and Recent Project Signals

### Core Attractors
- **Subtitle Clarity**: Real-time subtitles that remain readable in live conversation.
- **Memory Support**: Trustworthy memory for names and prior contexts without overconfidence or underconfidence.
- **Low-Friction Assistance**: Low-overhead, discreet assistance through one-line prompts.

### Core Tensions
- **Privacy vs Usefulness**: Ensuring the system is helpful without invading privacy.
- **Latency vs Richness**: Balancing timely responses with rich context.
- **Discreet UX vs Visual Clarity**: Designing an acceptable UI while ensuring readability.

### Core Constraints
- **Frame-Touch Only V1 Interaction**: Interaction should happen through frame touches, not voice commands.
- **Phone-First Runtime**: Heavy processing primarily on the phone, with cloud optional where clearly justified.
- **Core Deepening Over Sprawl**: Focus on improving subtitle quality, memory trust, and visual UX over broad feature expansion.

### Core Modes
- **Core Deepening**: Bias toward subtitle, memory, confidence, and architecture improvements that increase daily-use value.
- **Constraint Pressure**: Surface battery, latency, privacy, and usability limits early to avoid waste of time on impractical directions.

## Open Questions for Further Exploration

- **Subtitle Placement**: Designing an optimal visual hierarchy for subtitles without distracting the wearer.
- **Confidence Display**: Determining the best format for confidence display: label only, label + short reason, or score + label.
- **Face/Name Memory**: Deciding how face/name memory should be stored and reinforced for fast lookup and trust.
