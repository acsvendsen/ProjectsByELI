# Reality Check

## Subtitle Clarity: Feasible Now

- **Current Status:** The current `TranscriptLab` implementation is focused on validating real-time transcript behavior.
- **Constraints:** Battery and latency are significant concerns, especially for always-on subtitles. However, the current V1 interaction relies on frame touches only, which can be used to toggle subtitle visibility or adjust display settings.
- **Feasibility:** Given that `TranscriptLab` is designed to test real-time transcripts and their readability, it is feasible to implement initial clarity tests now. Ensuring subtitles are clear enough for the wearer to trust them in live conversation should be a priority.

## Memory Trust: Feasible Later

- **Current Status:** The current implementation focuses on subtitle clarity but does not yet incorporate memory recall features.
- **Constraints:** Privacy and battery limitations must be respected. Early versions cannot rely on heavy local processing or cloud storage for memory.
- **Feasibility:** Implementing basic memory trust in V1 is unlikely to be feasible due to the constraints of frame-touch-only interaction and limited processing power. However, preliminary work can begin by storing and reinforcing face/name memories using phone-side processing where battery usage is minimal.

## Low-Friction Assistance: Feasible Now

- **Current Status:** The current `TranscriptLab` implementation allows for one-line prompts through frame touches.
- **Constraints:** Battery and usability constraints must be managed, ensuring that these prompts do not become too frequent or distracting.
- **Feasibility:** Implementing basic low-friction assistance is feasible now. This can include simple one-line prompts based on context, such as reminders to introduce oneself or to follow up with someone after a meeting.

## Privacy vs Usefulness: Likely Waste of Time

- **Feasibility:** Assuming that voice activation will be used in V1 is premature given the constraints. While it may be useful to explore privacy concerns now, assuming a voice-activated interface would be a waste of time for V1.
