# Recent Signals Consolidation

## Strengthened Signals
- **Subtitle Clarity**: The core signal is that real-time subtitles must remain clear, fast, and stable enough for the wearer to trust them in live conversations.
- **Memory Trust**: Memory support should be trustworthy, remembering names, faces, and prior contexts without creating corrupted recall or pretending certainty.
- **Low-Friction Assistance**: Providing one-line help and visible support with minimal command overhead is critical.

## Weakened Signals
- **Latency vs Richness**: The tension has slightly decreased in importance. While it remains important, the focus should now be more on immediate core features rather than broader feature expansion.
- **Privacy vs Usefulness**: This tension is still significant but not as urgent compared to the other signals.

## Contradictions That Must Stay Alive
- **Always-On Sensing vs Battery and Thermals**: The glasses must balance always-on sensing with battery and thermal constraints. This contradiction will guide ongoing design decisions.

## Dormant Ideas Worth Reactivating
- **Subtitle Placement**: There is an active tension around subtitle placement, specifically whether the current solution meets usability without becoming distracting.
- **Confidence Display**: The confidence display format should be reconsidered to build trust best while remaining unobtrusive.

## Concrete Tensions Around Subtitle Quality, Confidence Trust, Automatic New-Person Memory, Memory Reinforcement, Fast Lookup, Privacy, Latency, Battery, and Visual UX
- **Subtitle Quality**: Ensure subtitles are clear, fast, and stable.
- **Confidence Trust**: Maintain a balance between trust and privacy in how confidence is displayed.
- **Automatic New-Person Memory**: Implement memory reinforcement over time for new faces and names without creating false certainty.
- **Memory Reinforcement**: Prioritize core-deepening work that improves subtitle quality, memory trust, and visual UX.

- **Privacy**: Ensure assistive behavior does not quietly slide into invasive capture or retention.
- **Latency**: Provide timely help without overloading the runtime.
- **Battery**: Manage always-on sensing with minimal impact on battery life.
- **Visual UX**: Create a discreet yet clear display that remains socially acceptable.
