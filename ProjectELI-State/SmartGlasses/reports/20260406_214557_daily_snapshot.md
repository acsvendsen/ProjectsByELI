### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   By setting a local cache threshold for name recall, we can ensure that frequently encountered names are quickly accessible without significant battery drain or thermal impact. This improves real-time subtitle quality by allowing faster and more accurate name recognition.

2. **What small change unlocks it**

   Define a recency-based eviction policy where names last seen within the past hour are retained in local cache with high confidence, while older mentions are moved to a lower-priority cloud fallback.

3. **Likely payoff**

   Implementing this threshold will reduce latency for name recall, enhancing subtitle quality and memory support without overloading the phone's battery or thermal resources. This leads to more reliable and faster name recognition in real-time conversations
