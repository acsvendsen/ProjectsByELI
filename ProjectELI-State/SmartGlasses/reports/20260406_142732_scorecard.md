## Project Summary
The project aims to create discreet smart glasses with core functionalities like live subtitles, face/name recall, conversation memory, and one-line support. V1 focuses on frame-touch interactions and a phone-first architecture, prioritizing subtitle quality and memory trust while maintaining social acceptability and battery efficiency.
