# Consolidated Project Signals

## Strengthened Signals
- **Subtitle Clarity**: The focus on maintaining real-time subtitle clarity remains high, with a strong emphasis on readability, stability, and trustworthiness.
- **Memory Trust**: Enhancing the reliability of name and face memory support is crucial. Confidence objects should be refined to ensure clear and honest recall without creating false certainty.

## Weakened Signals
- **Low-Friction Assistance**: The medium strength suggests a need for more refinement in delivering one-line help that minimally impacts the user experience while still providing significant assistance.

## Contradictions That Must Stay Alive
- **Privacy vs. Usefulness**: Balancing helpful assistive behavior with privacy concerns remains a critical tension.
- **Latency vs. Richness**: Ensuring timely responses without overloading the system with richer, slower processing continues to be a key challenge.

## Dormant Ideas Worth Reactivating
- **Subtitle Placement and Visual Hierarchy**: Although not currently prioritized, the need for optimal subtitle placement that is both readable and non-distracting remains relevant. The visual hierarchy of subtitles and prompts should be reconsidered in light of recent findings.
- **Face/Name Memory Storage and Reinforcement**: While not actively under consideration, refining how face/name memory is stored and reinforced could improve memory recall accuracy over time.

## Concrete Tensions Around Subtitle Quality, Confidence Trust, Automatic New-Person Memory, Memory Reinforcement, Fast Lookup, Privacy, Latency, Battery, Visual UX
- **Subtitle Quality**: Need to ensure subtitles are clear, fast, and stable. The recent build summary indicates that the `TranscriptLab` app is functioning well, but improvements in subtitle quality should be pursued.
- **Confidence Trust**: Confidence objects need to provide clear and honest feedback without overloading the user or creating false certainty.
- **Automatic New-Person Memory**: The system must remember new faces and names with confidence but avoid overconfidence that could mislead the wearer.
- **Memory Reinforcement**: Memory should be reinforced through repeated interactions, ensuring that remembered information is retained and updated over time.
- **Fast Lookup**: Balancing memory richness with fast lookup requires careful design to ensure that relevant information can be quickly accessed without slowing down the user experience.
- **Privacy**: Assistive behavior must respect privacy constraints, avoiding any practices that could be perceived as invasive or creepy.
- **Latency**: Responses should remain timely and not introduce unnecessary delays that break trust.
- **Battery**: Always-on sensing must be managed to minimize battery drain while maintaining core functionality.
- **Visual UX**: Subtitle placement and visual hierarchy need refinement to ensure they are both functional and non-distracting.

## Recent Actions
- The `TranscriptLab` app is functioning well, providing a reusable test bed for real-time transcripts. This will continue to be used to validate subtitle quality and confidence behavior.
- The focus remains on core-deepening improvements that increase daily-use value while surface constraints like battery, latency, privacy, and usability limits early.

- **Confidence Display**: Test various confidence formats (label only, label + short reason, score + label) to determine which provides the best balance of clarity and trust.
