# Core Field Consolidation for SmartGlasses V1

## Strengthening Signals
1. **Subtitle Quality**: Real-time subtitle placement is becoming more crucial as it directly impacts user trust and comprehension.
2. **Face/Name Recall Confidence**: The confidence objects in face/name recall must be more robust to avoid giving incorrect impressions of understanding.

## Weakening Signals
1. **Overcomplicated Interaction**: Frame-touch interaction is still the primary method, but there's a trend towards minimizing touch interactions to maintain simplicity and user comfort.
2. **Complex One-Line Prompts**: These are becoming less important as they risk cluttering the UI with unnecessary information.

## Contradictions that Must Stay Alive
1. **Privacy vs Usefulness**: There is an ongoing tension between providing useful memory support without compromising privacy.
2. **Battery Constraints**: Always-on sensing must balance against battery life, especially for real-time processing requirements like subtitles and face recognition.

## Dormant Ideas Worth Reactivating
- **Local Processing Limits**: Consider more local processing capabilities to reduce reliance on the phone or cloud where feasible.

## Concrete Tensions Around Core Domains

### Subtitle Quality vs. Battery and Thermals
1. **Subtitle Placement**: More prominent subtitle placement is being favored over less visible options, but this must balance with preventing distraction.
2. **Real-Time Processing**: Real-time subtitle rendering must remain fast to avoid latency issues, which can break trust.

### Confidence Trust vs. Memory Policy
1. **Confidence Display**: A label + short reason format is more trusted than a numeric score alone.
2. **Memory Reinforcement**: Recency-first memory caching helps with quick lookups but may need to be balanced against privacy concerns.

### Fast Lookup vs. Privacy
1. **Local Cache Size**: Local caching of face/name data can improve fast lookup but must respect user privacy and comfort levels.
2. **Cloud Processing**: Using the cloud for heavy processing tasks, like complex memory recall, is valuable but should not compromise local battery life or usability.

### Discreet UX vs. Visual Clarity
1. **Subtitle Visibility**: Subtitles need to be clear enough to read without being too obtrusive.
2. **Visual Hierarchy**: The visual hierarchy of subtitles and one-line prompts must be carefully managed to ensure the wearer can focus on what's most important.

### Interaction Constraints
1. **Frame-Touch Only**: This remains a critical constraint, but there may be opportunities to introduce more subtle interactions as technology evolves.

## Open Questions

- **Subtitle Placement**: What is the optimal balance between prominence and non-intrusiveness?
- **Confidence Display**: How can we best convey confidence without overwhelming or misleading the user?
- **Memory Policy**: Should memory caching prioritize recency for speed, or should there be a compromise to maintain privacy?
- **Phone/Cloud Boundary**: Where are the best lines to draw between local and cloud processing for optimal performance?

## Current Core Mission

The system must remain focused on providing real-time, context-aware assistance through live subtitles, face/name recall, conversation memory, and one-line prompts while respecting hardware constraints and user privacy.
