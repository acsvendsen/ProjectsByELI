## Consolidated Insights for SmartGlasses Project

### Strengthening Signals
1. **Subtitle Clarity**: Continued emphasis on clear, stable, and timely subtitles is crucial. The system should remain trustworthy during live conversations.
2. **Memory Support**: Trustworthy memory support, including name and face recall, remains essential. This feature must avoid overconfidence or creating false memories.
3. **Low-Friction Assistance**: One-line prompts should provide immediate help without adding unnecessary complexity to the user interface.

### Weakening Signals
1. **Privacy Concerns**: The system should not quietly slide into invasive capture or retention of personal data. Privacy remains a critical concern that must be managed carefully.
2. **Always-On Sensing**: The risk of always-on sensing degrading battery and thermal performance is significant, though it has some justified use cases.

### Contradictions That Must Stay Alive
1. **Privacy vs Usefulness**: Balancing the need for privacy with the usefulness of detailed personal memory support remains a key tension.
2. **Latency vs Richness**: The system should avoid overloading the runtime with rich but slower processing, favoring timely responses over overly complex or delayed interactions.

### Dormant Ideas Worth Reactivating
1. **Subtitle Placement and Visual Hierarchy**: While no recent changes suggest active exploration of these areas, continued focus on making subtitles readable in motion without distraction is important.
2. **Confidence Display**: Exploring different formats for confidence display (label only vs label + short reason) could enhance trust.

### Concrete Tensions Around UX and Performance
1. **Discreet UX vs Visual Clarity**: The display should remain socially acceptable while still providing clear, readable subtitles in noisy environments.
2. **Core Deepening Over Sprawl**: Focus on improving subtitle quality, memory trust, and visual UX over broad feature expansion.
