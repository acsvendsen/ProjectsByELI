### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Improving subtitle placement rules based on confidence state helps ensure that subtitles are always in a position where they can be easily read without becoming distracting. This improves real-time subtitle clarity, which is a key attractor for the project.

2. **What small change unlocks it**

   Define two subtitle placement rules: one for high-confidence subtitles (e.g., names and faces) to appear prominently but not obstructively, and another for lower-confidence subtitles (e.g., background noise or less critical information) that can be placed in a less prominent position to avoid distraction.

3. **Likely payoff**

   By ensuring that high-confidence subtitles are easily visible and low-confidence ones are less intrusive, this change will enhance the wearer's ability to focus on crucial information without being overwhelmed by unimportant details. This improves overall subtitle clarity and user trust.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   By refining the confidence display to use a clear numeric score alongside a label and short reason, the system can provide the wearer with more precise and trustworthy information about the reliability of the displayed memory or subtitles. This enhances the trust in both the memory support and subtitle clarity, which are primary attractors for the project.

2. **What small change unlocks it**

   Implementing a simple rule that defines confidence objects as `score 0.84 + "High" + "Seen recently"; score 0.42 + "Low" + "Weak match"; score 0.63 + "Medium" + "Name heard once in introduction"`. This ensures each confidence object is clearly formatted and provides a quick understanding of the reliability.

3. **Likely payoff**

   The likely payoff includes:
   - Increased trust in memory recall and subtitle accuracy.
   - Easier for the wearer to understand the level of certainty provided by the system.
   - Improved user experience by reducing confusion about the reliability of the displayed information.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.
