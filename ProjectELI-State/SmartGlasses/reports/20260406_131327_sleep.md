# Consolidation of Key Signals

## Strengthening Signals
1. **Subtitle Quality and Real-Time Delivery**: The system should maintain high-quality, real-time subtitles to reduce latency and ensure trust.
2. **Memory for New People**: Automatically storing likely new people with confidence objects helps in reinforcing memory over time.
3. **Confidence Display**: Using a numeric score, label, and short reason format improves the transparency of the system's certainty levels.

## Weakening Signals
1. **Complex AR Visuals**: These are not prioritized for V1 as they add complexity without immediate utility.
2. **Rich Gesture Vocabulary**: Simplifying interactions to frame touches only reduces confusion and enhances usability.
3. **Heavy On-Glasses AI Processing**: Early versions should rely heavily on phone processing to reduce battery and thermal strain.

## Contradictions That Must Stay Alive
1. **Privacy vs Usefulness**: Balancing the need for useful features with privacy concerns remains a critical tension.
2. **Always-On Sensing vs Battery/Thermal Constraints**: The system must remain lightweight while ensuring it does not drain batteries or overheat.

## Dormant Ideas Worth Reactivating
1. **Automatic Memory for Likely New People**: This should continue to be a core feature, especially in noisy environments.
2. **Confidence Objects and Reinforcement History**: These are essential for building trust without overwhelming the wearer with complex features.

## Concrete Tensions Around Core Domains

### Subtitle Quality, Confidence Trust
- **Subtitle Placement and Visual Hierarchy**: Ensure subtitles do not distract while still providing clear information. The system must display text in a way that minimizes visual clutter.
- **Confidence Display**: Use labels and short reasons to convey uncertainty clearly, building trust without overwhelming the wearer.

### Automatic Memory Behavior vs Explicit Remember-Touch Behavior
- **Automatic New-Person Memory**: This should remain active but with clear user controls for correction and override.
- **Explicit Remember-Touch Behavior**: Provide touch-based interactions for memory capture when needed. Ensure these touches are discrete and do not disrupt the conversation flow.

### Fast Lookup Requirements
- **Memory Reinforcement Over Time**: Store memories with confidence objects that update as new evidence appears. This ensures the system remains useful without becoming cluttered.
- **Fast Retrieval Indexes**: Create efficient indexes for people, names, topics, and context to enable quick recall of relevant information.

## Real Implementation Constraints

### Privacy and Consent
- **Transparent Memory Behavior**: Ensure users can easily review, correct, and delete stored data. Maintain clear controls and conservative defaults where needed.
- **User-Centric Design**: Focus on the wearer's needs rather than trying to be an autonomous assistant that makes decisions for them.

### Interaction Constraint
- **Frame Touches Only**: V1 should not introduce voice commands or complex gestures. This ensures simplicity and social acceptability.

## Open Questions

- **Subtitle Placement and Visual Hierarchy**: How can subtitles be placed and formatted to enhance readability without causing distraction?
- **Confidence Format**: What is the best way to represent confidence to build trust in the system's accuracy?
- **One-Line Prompts vs Subtitles Coexistence**: How can one-line prompts coexist with subtitles to provide additional context without overwhelming the wearer?

## Summary

The system should focus on providing high-quality, real-time subtitles and automatic memory for new people while maintaining clear and transparent confidence displays. Interaction should be kept simple and discrete through frame touches only. Memory reinforcement over time will ensure the system remains useful and relevant. Privacy and usability constraints must be surfaced early to guide design decisions effectively.
