### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Improving subtitle placement rules ensures that subtitles remain clear, readable, and unobtrusive during live conversations. This enhances the wearer's ability to follow the conversation without distraction, thereby strengthening the core mission of real-time subtitle clarity.

2. **What small change unlocks it**

   Define 3 to 5 subtitle placement rules based on confidence levels: 
   - High confidence (score > 0.9): Fixed position at bottom center.
   - Medium confidence (0.7 < score ≤ 0.9): Floating near speaker with minimal animation.
   - Low confidence (0.4 < score ≤ 0.7): Temporarily hidden but quickly revealed.

3. **Likely payoff**

   By establishing clear placement rules, the system will reduce subtitle clutter and ensure that critical information is always visible without overwhelming the wearer. This will improve overall user trust in the subtitles during real-time interactions.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

This reduces latency and ensures that the wearer gets immediate feedback when interacting with familiar people or topics.

4. **Immediate next probe**

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   Ensuring that live subtitle processing stays on the phone helps maintain real-time responsiveness, which is crucial for trust and clarity in noisy environments. By keeping this task local, we can minimize latency and ensure subtitles are displayed as soon as possible without relying on potentially slower cloud services.

2. **What small change unlocks it**

   Define a clear boundary where live subtitle processing must always occur locally on the phone, with no fallback to the cloud under any circumstances during V1.

3. **Likely payoff**

   By keeping live subtitles local, we ensure that the system remains responsive and provides timely support, which is vital for maintaining user trust in noisy environments. This approach also helps in reducing battery drain associated with continuous cloud requests and ensures a smoother overall user experience.

4. **Immediate next probe**

   Define one phone-local vs cloud fallback boundary for live subtitle processing.
