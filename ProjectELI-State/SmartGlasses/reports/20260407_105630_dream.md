### Idea 1: Subtitle Placement

1. **Why it benefits the core**

Improving subtitle placement rules will enhance the wearer's trust in the system by ensuring that subtitles are always clear and unobtrusive, which is crucial for real-time understanding in noisy environments.

2. **What small change unlocks it**

Define 3 to 5 subtitle placement rules based on confidence levels: high-confidence (always visible), medium-confidence (conditional visibility based on context), and low-confidence (only shown with explicit user touch).

3. **Likely payoff**

This change will allow the system to dynamically adjust subtitle visibility, ensuring that subtitles are always clear without overwhelming the wearer. It will also help in maintaining a balance between providing enough assistance and not becoming too distracting.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving confidence display can significantly enhance the trustworthiness of the system by providing clear and reliable indicators of how certain the AI is about its predictions. This will help users understand when to rely on the subtitles and face/name recognition, thereby reducing cognitive load and increasing overall user satisfaction.

2. **What small change unlocks it**

   Define a consistent confidence label format that includes a numeric score, a short reason, and a certainty level (e.g., "High", "Medium", "Low"). For example, a subtitle might be labeled as: "score 0.84 + 'High' + 'Seen recently'".

3. **Likely payoff**

   By clearly indicating the confidence of the system, users can better trust the subtitles and face/name recognition during live conversations. This will reduce misunderstandings and increase overall user satisfaction, making the glasses a more reliable tool for real-world interactions.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

2. **What small change unlocks it**

3. **Likely payoff**

4. **Immediate next probe**

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By defining clear cloud fallback boundaries for specific tasks, such as face/name recall lookup, we can ensure that critical memory support remains reliable even when the glasses are under thermal or battery pressure. This improves daily-use value by providing more stable and useful assistance without overwhelming the hardware.

2. **What small change unlocks it**

   Define one task-specific cloud fallback boundary for exactly one task such as face/name recall lookup, where the local cache size is limited to 10 entries per person and falls back to the cloud if more than 5 entries are added in a session.

3. **Likely payoff**

   This approach ensures that critical memory support remains robust and reliable by offloading heavy processing when needed, thus maintaining trust and usefulness even under thermal or battery constraints. It allows for faster response times during high-intensity sessions while ensuring long-term data integrity and user privacy.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   By refining the visual hierarchy to prioritize subtitles over one-line prompts, we ensure that the wearer's primary focus remains on understanding live conversation through clear and stable subtitles. This prioritization supports the core attractor of real-time subtitle clarity while reducing cognitive load by minimizing distractions from less critical information.

2. **What small change unlocks it**

   Define a visual hierarchy rule where subtitles are displayed in a larger, more prominent font size compared to one-line prompts, ensuring that subtitles are always the highest priority for the wearer's attention.

3. **Likely payoff**

   By making subtitles the primary focus, we enhance the wearer’s ability to follow live conversations without being distracted by less critical information. This will improve the overall user experience and reinforce trust in the system’s real-time subtitle capabilities.

4. **Immediate next probe**
