# Consolidation of Recent Signals

## Strengthening Signals
- **Subtitle Clarity**: The real-time subtitle clarity must remain clear, fast, and stable to maintain the wearer's trust during live conversations.
- **Memory Trust**: Names, faces, and prior context should be remembered accurately without creating false certainty or corrupted recall.

## Weakening Signals
- **Low-friction Assistance**: This aspect has seen a slight decrease in importance compared to core subtitle clarity and memory support. Efforts should focus more on ensuring subtitles are clear and reliable before optimizing one-line prompts for minimal interference.

## Contradictions That Must Stay Alive
- **Privacy vs Usefulness**: The balance between providing useful assistive behavior and maintaining privacy must be carefully managed, especially as the project evolves.
- **Latency vs Richness**: The system should prioritize timely responses over richer but slower processing that could delay helpful feedback.

## Dormant Ideas Worth Reactivating
- **Subtitle Placement**: The current V1 interaction constraint of frame touches only may limit subtitle placement options. Exploring other placements, such as earpiece or wristband displays, might offer a better user experience.
- **Confidence Display**: While the current score is good at 0.78 for memory trust, there is room to improve how confidence in name and face recognition is displayed to users.

## Concrete Tensions Around Key Areas
1. **Subtitle Quality, Confidence Trust**:
   - Subtitles must remain clear and stable without distracting or overwhelming the wearer.
   - Confidence objects should be clearly presented but not overly complex or intrusive.

2. **Automatic Memory Behavior vs Explicit Remember-Touch Behavior**:
   - Automatic memory behavior should reinforce explicit remember-touch actions to build trust over time.
   - Fast lookup requirements must be balanced with privacy and usability constraints.

3. **Battery, Latency, Privacy, and Usability Constraints**:
   - Early versions of the glasses should remain lightweight and socially acceptable.
   - The system must handle real-world limitations like battery drain and latency without breaking the core mission.

4. **Subtitle Placement and Visual UX**:
   - Subtitle placement needs to be carefully considered for low distraction but high readability, especially in noisy environments.
   - Visual hierarchy should prioritize clear and unobtrusive presentation of subtitles and prompts.

5. **Automatic Memory vs Confidence Objects**:
   - Automatic memory behavior must support confidence objects that help users understand the reliability of recognized faces and names.
   - Fast lookup requires a balance between quick access and respecting privacy concerns.

## Open Questions
- How should subtitle placement best serve the wearer's needs while minimizing distractions?
- What is the optimal balance between automatic memory reinforcement and explicit remember-touch actions for building trust?
- Which confidence format—label only, label + short reason, or score + label—builds the most trust without overwhelming the user?

## Summary
The current project should focus on strengthening subtitle clarity and memory support while managing core tensions like privacy vs. usefulness and latency vs. richness. Exploring new subtitle placements and refining confidence display methods are key areas for improvement. The system must remain mindful of real-world constraints to ensure a usable and reliable daily-use assistant.
