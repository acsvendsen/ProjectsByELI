### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Keeping subtitle placement stable and predictable helps the wearer trust the subtitles more in live conversations, reducing cognitive load and increasing overall understanding.

2. **What small change unlocks it**

   Define two fixed subtitle placement rules: one for confident matches (e.g., names and faces seen multiple times) at a lower part of the field-of-view, and another for less certain matches (e.g., new people or weak speech recognition) slightly above or to the side.

3. **Likely payoff**

   By keeping subtitles in predictable positions, the system will reduce confusion and visual distraction, allowing the wearer to focus more on the conversation itself. This improves overall user trust and satisfaction with the subtitles.

4. **Immediate next probe**
   - Define two fixed subtitle placement rules: one for confident matches at a lower part of the field-of-view, and another for less certain matches slightly above or to the side.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Improving memory cache policies helps ensure that the system retains relevant information for fast lookup and reinforcement over time, thus strengthening the core mission of providing trustworthy memory support without invading privacy.

2. **What small change unlocks it**

   Define a local cache threshold for face/name memories based on recency and confidence levels. For example, keep memories with high confidence or recent encounters but discard weaker matches after a set period.

3. **Likely payoff**

It will enhance trust by ensuring that the wearer can rely on accurate and up-to-date memories, thereby improving overall user experience.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By defining a clear boundary for what runs phone-local versus cloud, we ensure that critical real-time processing remains local to preserve low latency and high accuracy. This focus on local computation helps maintain the system's reliability and responsiveness, which are crucial for the wearer's trust in the product.

2. **What small change unlocks it**

   Define one specific task boundary where live subtitle processing happens phone-local, with transcript cleanup falling back to cloud when needed.

3. **Likely payoff**

   By keeping subtitle processing local, we reduce latency and improve stability, ensuring that subtitles are always readable and timely during conversations. This enhances the wearer's trust in the system, making it a more reliable tool for real-time communication assistance.

4. **Immediate next probe**

   Define one phone-local vs cloud fallback boundary for exactly one task such as live subtitle processing.
