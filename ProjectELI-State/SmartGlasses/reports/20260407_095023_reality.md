# Reality Check for SmartGlasses Core Field

## Subtitle Clarity (subtitle_clarity)

- **Feasible Now:** 
  - The `TranscriptLab` app provides a real-time transcript test bed that can help us assess subtitle clarity. Given the current focus on simplicity and low-friction, we should aim to achieve subtitles that are clear, fast, and stable enough for live conversation. This is highly feasible now with ongoing testing and refinement.
  
- **Assumptions Needing Evidence:**
  - The exact placement of subtitles (top center vs bottom center) needs more specific testing to determine what minimizes distraction while maintaining readability.

## Memory Trust (memory_trust)

- **Feasible Now:** 
  - Implementing a basic memory support system using the phone-first architecture is feasible. Initial implementations can focus on caching and reinforcing face/name recall with explicit confidence objects that convey uncertainty when appropriate.
  
- **Assumptions Needing Evidence:**
  - Determining how often to update and reinforce memory without overwhelming the user requires empirical testing.

## Low-Friction Assistance (low_friction_assistance)

- **Feasible Now:** 
  - One-line prompts can be implemented through simple frame touches, providing low-friction support. The current `TranscriptLab` app can help validate this by integrating one-line hints into live scenarios.
  
- **Assumptions Needing Evidence:**
  - Defining the optimal format for these one-line hints (label only vs label + short reason) needs user testing to ensure they are helpful without being overwhelming.

## Frame-Touch Interaction

- **Feasible Now:** 
  - Ensuring that V1 interaction is controlled through frame touches only is feasible given the current architecture. This can be tested and refined using `TranscriptLab`.
  
- **Assumptions Needing Evidence:**
  - The interaction design should consider different use cases (e.g., switching modes, confirming actions) to ensure it remains low-friction.

## Phone-First Architecture

- **Feasible Now:** 
  - Leveraging the phone for heavy processing is feasible. The `TranscriptLab` app provides a good framework to test this architecture and iteratively improve performance.
  
- **Assumptions Needing Evidence:**
  - Determining which parts of memory and lookup should be cached locally versus offloaded to the cloud requires balancing battery constraints with real-world utility.
