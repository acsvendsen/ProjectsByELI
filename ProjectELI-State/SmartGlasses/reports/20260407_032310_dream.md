### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   By refining subtitle placement rules based on confidence levels, we can ensure that subtitles are always in a readable and unobtrusive position. This improves the wearer's trust in the system by maintaining clarity and reducing distractions during live conversations.

2. **What small change unlocks it**

   Define two subtitle placement rules: one for high-confidence text (e.g., names or topics heard multiple times) that places subtitles slightly above the speaker, and another for low-confidence text (e.g., first-time mentions of names or unfamiliar words) that keeps subtitles to the bottom of the field-of-view.

3. **Likely payoff**

   This change will reduce visual distractions during high-confidence interactions while ensuring critical information is always visible, enhancing overall subtitle clarity and user trust without overwhelming the wearer's view.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

This improvement can significantly reduce cognitive load and increase overall user satisfaction by ensuring that the system is not overestimating or underestimating its own reliability.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Ensuring that new faces and names are remembered with a simple, stable cache policy helps build trust in the system's memory support. By automatically linking new evidence to existing person-memory objects, the system can provide accurate and timely assistance without overloading the wearer.

2. **What small change unlocks it**

   Define one entity-linking rule for attaching new evidence to an existing person-memory object based on name similarity and recent encounters. This ensures that when a new face or name appears, the system reinforces the memory object with fresh interactions, keeping the cache up-to-date without unnecessary complexity.

3. **Likely payoff**

   By implementing this entity-linking rule, the system will automatically strengthen memories of recently encountered people and events over time, enhancing the wearer's confidence in the system’s ability to recall relevant information when needed. This reduces the need for explicit reinforcement through frame touches while maintaining high accuracy and reliability.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.
