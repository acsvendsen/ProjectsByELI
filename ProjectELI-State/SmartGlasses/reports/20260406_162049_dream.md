   By clearly displaying confidence scores, labels, and short reasons for memory recall, the system can enhance trust by showing the wearer when a memory is uncertain or recently recalled. This transparency helps reduce social awkwardness and increases the user's confidence in the assistant's reliability.

2. **What small change unlocks it**

   Define a simple confidence object format that combines a numeric score with a label and a short reason for each memory recall, such as "score 0.84 + 'High' + 'Seen recently'; score 0.42 + 'Low' + 'Weak match'; score 0.63 + 'Medium' + 'Name heard once in introduction'."

3. **Likely payoff**

   This change will enable the system to communicate its level of confidence more effectively, which can lead to better user trust and acceptance. Users are more likely to engage with a transparent memory assistant that openly shares its certainty levels.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.
