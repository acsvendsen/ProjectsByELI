# Consolidated SmartGlasses V1 Direction

## Strengthening Signals
- **Subtitle Quality**: Subtitles must remain near-real-time to maintain trust, which is critical for noisy environments and hearing-challenged situations.
- **Memory Trust**: Memory recall should be reinforced through explicit confidence objects that grow with repeated interactions over time.

## Weakening Signals
- **Complex AR Features**: Avoid adding complex augmented reality features or multimodal UI elements in V1. Focus on essential functionality first.

## Contradictions That Must Stay Alive
- **Battery and Latency Constraints vs Always-On Sensing**: The glasses must balance always-on sensing with battery and latency constraints to ensure a practical user experience.
- **Discreet UX vs Rich Context**: Ensure the visual hierarchy supports discreet UX while providing sufficient contextual information for effective assistance.

## Dormant Ideas Worth Reactivating
- **One-Line Support Enhancements**: Explore how one-line prompts can be more effective without overwhelming the wearer. Consider subtle, context-specific cues that enhance understanding.
- **Subtitle Placement Optimization**: Reassess subtitle placement to ensure it is both usable and non-distracting, addressing any open questions identified.

## Concrete Tensions
1. **Subtitle Quality vs Battery Drain**:
   - Subtitles must be fast enough to maintain trust but not so resource-intensive as to drain the battery quickly.
2. **Rich Memory vs Fast Lookup**:
   - The system should provide rich memory for context, but this must not hinder quick lookups and responses during real-time interactions.
3. **Discreet UX vs Low Social Friction**:
   - The visual design must balance clarity with social acceptability to ensure the glasses are used comfortably in various environments.

## Open Questions
- What is the best subtitle placement that ensures clear visibility while minimizing distractions?
- How should one-line prompts visually differ from subtitles and still be effective?

## Recent Core Field Signals

### Core Field: SmartGlasses V1 Direction

#### Mission
Create smart glasses that act as a discreet, context-aware personal assistant focused on live subtitles, face/name recall, conversation memory, and one-line support to help the wearer understand and respond better in real-world interactions.

#### Non-negotiables
- The glasses help the wearer; they do not pretend knowledge the wearer does not have.
- Early hardware remains simple: display text, record audio/visual input; phone/cloud handles heavy processing.
- V1 interaction is frame-touch only; do not assume voice activation or spoken command control.
- Context must persist across sessions.
- New faces and names should be remembered with confidence objects and reinforcement over time.
- Real-world constraints must be surfaced early: latency, battery, privacy, social acceptability, on-device limits.

#### Core Attractors
- Real-time subtitle assistance in noisy environments
- Personal memory support for names and prior conversations
- One-line contextual prompts rather than overwhelming paragraphs
- Low-friction human experience; assistive, not deceptive

#### Core Tensions
- Privacy vs usefulness
- Always-on sensing vs battery and thermals
- Local processing vs cloud intelligence
- Rich memory vs fast lookup
- Discreet UX vs enough visual clarity

#### Drift Risks
- Becoming a gimmick instead of a daily-use assistant
- Feature sprawl before core subtitle/memory loop is excellent
- Interaction sprawl that adds command modes or hardware complexity before the touch-first V1 is excellent
- High-latency responses that break trust
- Storing low-value information instead of weighted relevant memory

#### Why It Matters
The system should reduce social and cognitive friction for the wearer, especially in noisy environments, hearing-challenged situations, memory-challenged situations, and dense multi-person contexts. It should help the wearer stay present, informed, and confident without pretending understanding.

#### Evolution Rule
The project is allowed to evolve beyond its original form if that evolution strengthens the core mission, improves real-world usefulness, or increases trust, clarity, and assistive value. Expansion is good when it deepens the core, not when it distracts from it.

#### Reality-Check Rule
The system should continuously surface real-world limitations early, including hardware, battery, thermal, latency, privacy, and usability constraints, so the project does not waste time optimizing impossible or low-value directions.

#### Current Open Questions
- What is the best V1 split between glasses, phone, and cloud?
- How should face/name memory be stored and reinforced for fast lookup and trust?
- How should confidence be represented: numeric score, label, and short reason?
- How should subtitles and one-line prompts coexist without overloading the wearer?
- What is the best subtitle placement and visual hierarchy for fast reading with low distraction?

## V1 Guardrails

- Mission: discreet, context-aware personal assistance through live subtitles, face/name recall, conversation memory, and one-line support.
- V1 interaction must use frame touches only.
- Do not propose voice activation or spoken command control in V1.
- Prefer phone-first architecture; use cloud only when clearly justified.
- Favor improvements that deepen subtitle quality, memory trust, confidence display, and low-friction visual UX.
- Respect battery, thermals, latency, privacy, usability, and social acceptability.
- The system should help the wearer understand better, not fake understanding.
- Avoid broad feature sprawl and unnecessary hardware or interaction complexity.

## Action Inbox

- **Subtitle Placement**: Consider non-intrusive yet effective placement strategies to minimize distraction while ensuring clear visibility.
- **Confidence Display**: Evaluate different confidence formats (label only, label + short reason, score + label) to find the best balance between clarity and simplicity.
- **Memory/Cache Policy**: Define a caching strategy that prioritizes relevant memory for fast lookup but does not overwhelm the user with low-value information.
- **Phone/Cloud Boundary**: Determine the optimal use of cloud processing while maintaining real-time responsiveness on the glasses.
- **Visual Hierarchy**: Design the visual layout to balance information richness with ease of use and minimal distraction.
