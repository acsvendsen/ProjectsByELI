### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   By defining specific subtitle placement rules based on confidence levels, we can ensure that subtitles are always readable and stable, which is crucial for maintaining trust in live conversation.

2. **What small change unlocks it**

   Define two subtitle placement rules: one for high-confidence matches (e.g., names or faces seen multiple times) to be placed prominently but not overly obtrusive, and another for low-confidence matches (e.g., names heard once) to be placed more discreetly.

3. **Likely payoff**

   This change will enhance the wearer's trust in the system by ensuring that critical information is always visible while minimizing visual distraction during less important interactions.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

Improving confidence display formats in V1 can enhance trust by clearly communicating the system's certainty levels to the wearer. This helps maintain the balance between providing useful assistance and avoiding overreliance on uncertain information.

2. **What small change unlocks it**

Define a simple, clear confidence format that uses a numeric score, label, and short reason for each memory object. For example: "score 0.84 + 'High' + 'Seen recently'; score 0.42 + 'Low' + 'Weak match'; score 0.63 + 'Medium' + 'Name heard once in introduction'."

3. **Likely payoff**

This change will help the wearer quickly understand when memory objects are reliable, reducing cognitive load and increasing trust in the system's accuracy and reliability.

4. **Immediate next probe**
   - Define the numeric score format for confidence display in V1.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**
   - Strengthening the memory support by optimizing local cache thresholds ensures that relevant names and faces are quickly accessible to the wearer, enhancing their confidence in recalling previous interactions without overloading the phone's memory.

2. **What small change unlocks it**
   - Define a local cache size limit for name recall that balances memory retention with battery usage. For instance, set a threshold of storing up to 10 recent names and faces locally on the phone.

3. **Likely payoff**
   - By setting a clear and efficient cache size limit, the system can provide faster and more reliable memory support, reducing latency in name recall and ensuring that common names are readily available without excessive battery consumption.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By defining a clear boundary between what runs on the phone and what falls back to the cloud for live subtitle processing, we ensure that critical real-time subtitles are always available, reducing latency and maintaining trust. This alignment with V1 interaction constraints also keeps the system lightweight and socially acceptable.

2. **What small change unlocks it**

   Define a single explicit rule stating that all live subtitle processing must remain on the phone unless it requires complex cloud-based transcription and can be reliably cached locally for offline use.

3. **Likely payoff**

   This decision will ensure real-time subtitles are always stable, reducing latency and enhancing trust in the system. It also prevents unnecessary data transmission, saving battery life and maintaining privacy by keeping heavy processing off the glasses hardware.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   By defining a clear visual hierarchy between subtitles and one-line support, we ensure that the most important information is prioritized and displayed in a way that minimizes distraction while still providing necessary assistance.

For example, if there is not enough space on-screen, subtitles should be hidden to make room for the one-line prompt that provides immediate context or assistance.

3. **Likely payoff**

   This change will improve the wearer's focus by ensuring they see the most relevant information first, reducing cognitive overload and maintaining their ability to follow conversations effectively without being overwhelmed by too much text.

4. **Immediate next probe**
