### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   By defining specific subtitle placement rules based on confidence levels, we ensure that subtitles remain clear and stable enough to be trusted during live conversations. This helps in maintaining high subtitle clarity while reducing distractions.

2. **What small change unlocks it**

   Define 3 different subtitle placement modes: fixed position for low confidence states, dynamic centering for medium confidence states, and dynamic edge positioning for high confidence states.

3. **Likely payoff**

   This approach will enhance the user's trust in the subtitles by ensuring they are always visible and readable, even during challenging speaking conditions. It also reduces the likelihood of distractions that could arise from inconsistent subtitle placement.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving the confidence display format helps ensure that users can trust the system's assistance while maintaining privacy and usability. A well-designed confidence object provides clear, concise feedback about the certainty of the information displayed, which is crucial for real-time subtitle clarity and memory support.

2. **What small change unlocks it**

   Define a simple numeric score + label + short reason format for confidence objects that is both informative and easy to understand. For example, "score 0.84 + 'High' + 'Seen recently'; score 0.42 + 'Low' + 'Weak match'; score 0.63 + 'Medium' + 'Name heard once in introduction'."

3. **Likely payoff**

   By providing clear and concise confidence information, users can better trust the system's real-time subtitles and memory support. This improves overall user satisfaction and reinforces the core mission of helping wearers understand and respond better without overloading them with unnecessary or uncertain information.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**
   
   Improving local memory thresholds ensures that new faces and names are remembered with high confidence over time, enhancing the wearer's trust in the system’s ability to recall critical information without relying on cloud fallbacks.

2. **What small change unlocks it**

   Define a local cache size limit for face/name memory objects, ensuring that only the most recent and frequent encounters are cached locally, while older or less relevant entries are evicted based on recency and frequency.

3. **Likely payoff**

   By limiting local cache size and using recency to prioritize memory, the system can reduce battery drain from continuous background syncing while maintaining high confidence in critical face/name recognition for up to a week of interactions.

4. **Immediate next probe**

   Define one local-cache size limit between 50 and 200 entries for face/name memory objects, with a priority on recency over frequency.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By refining the phone/cloud boundary for live subtitle processing, we can ensure that critical real-time data stays local to minimize latency and thermal load. This focus on local processing improves trust by reducing delays and preventing unnecessary network usage.

2. **What small change unlocks it**

   Define a clear rule: For live subtitle processing, always keep the most recent 10 seconds of audio within the phone's memory for real-time transcription, then asynchronously upload to cloud for archive purposes only after the conversation ends or transitions to background mode.

3. **Likely payoff**

   This change ensures that subtitles remain crisp and responsive during active conversations while offloading less critical storage tasks to the cloud. It enhances trust by maintaining low latency and reducing the burden on the phone's thermal management, which is crucial for a long-lasting user experience.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   By optimizing the visual hierarchy between subtitles and one-line support, we can ensure that critical information remains prominent while reducing distractions. This improves real-time subtitle clarity and low-friction assistance, aligning with our attractors for subtitle clarity and low-friction assistance.

2. **What small change unlocks it**

   Define a clear precedence rule where subtitles take priority over one-line prompts when both are present on the screen. This can be achieved by setting a simple visual hierarchy rule that ensures subtitles remain visible even if they overlap with one-line prompts, but the one-liner is slightly reduced in size or prominence.

3. **Likely payoff**

   A well-defined visual hierarchy will enhance the user's ability to focus on critical information during conversations, reducing cognitive load and improving overall understanding. This can be measured by observing how often users report needing to look away from subtitles due to distracting prompts.

4. **Immediate next probe**

   Define one subtitle-vs-one-line priority rule where subtitles take precedence over one-line prompts when both are present on the screen.
