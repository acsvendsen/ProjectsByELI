# Reality Check

## Subtitle Clarity - Feasible Now
- **Subtitle Placement**: The glasses should display subtitles in a way that is readable but not distracting. Current tests with `TranscriptLab` suggest that subtitles should be placed at the bottom of the field of view, slightly above the horizon line to avoid occlusion by the user's gaze. This placement should remain stable and unobtrusive.
- **Visual Hierarchy**: The subtitle display should use a simple, clear font (e.g., sans-serif) with a large enough size for readability in motion without being overwhelming.

## Memory Trust - Feasible Now
- **Memory Storage & Reinforcement**: Implementing face and name recognition using a confidence-based system that can remember new faces and names over time. This could involve storing embeddings of known faces on the phone and updating them with additional data points (e.g., multiple images, context). The memory should be reinforced through interactions, such as confirming correct memories.
- **Confidence Display**: Using labels like "likely," "possibly," or "unconfirmed" to indicate the reliability of the memory. This can help users understand when the system is uncertain and avoid relying on incorrect information.

## Low-Friction Assistance - Feasible Now
- **One-Line Prompts**: Implementing one-line prompts that appear briefly (e.g., 5 seconds) at the bottom of the field of view, ensuring they are brief enough to be read quickly without causing distraction. The content should focus on helping the wearer recall information or respond appropriately in the context of a conversation.

## Privacy vs Usefulness - Likely Waste of Time
- **Privacy Concerns**: Implementing extensive privacy measures might distract from the core mission of providing real-time assistance. For example, adding complex encryption protocols for storing face and name data could be overkill given that the primary goal is to provide reliable memory support rather than building a full-fledged identity management system.

## Latency vs Richness - Feasible Now
- **Subtitle Clarity**: Ensuring subtitles are displayed within 100ms of speech recognition. This can be tested using `TranscriptLab` by measuring the time between speech input and subtitle display on the phone.
- **Memory Lookup**: Implementing fast lookups for names and faces, aiming for sub-second response times to maintain trust.

## Discreet UX vs Visual Clarity - Feasible Now
- **Subtitle Placement & Visual Hierarchy**: The glasses should have a clear, unobtrusive display that is readable in various lighting conditions. Testing this can involve using the `TranscriptLab` app with different environmental settings and adjusting subtitle placement based on user feedback.

## Core Deepening Over Sprawl - Feasible Now
- **Subtitle Quality & Memory Trust**: Prioritizing improvements to subtitle clarity and memory trust over adding new features that might dilute focus. This can be tracked by continuously measuring the effectiveness of these core components through user testing and analytics.

## V1 Real World Limits - Feasible Now
- **Frame Touch Interaction**: Ensuring all interactions are frame-touch based, as dictated by current constraints.
- **Phone Processing**: Relying on the phone for heavy processing while keeping the glasses hardware simple. This can be validated using `TranscriptLab` to ensure that real-time subtitles and memory recall work effectively without draining the battery.

## V1 Architecture Direction - Feasible Now
- **Glasses Hardware & Phone/Cloud Boundaries**: Keeping the glasses lightweight with minimal local logic, while using the phone for heavy processing. This can be tested by implementing a prototype in `TranscriptLab` that simulates real-world interactions and verifying its performance.

## Interaction Constraints - Feasible Now
- **Frame Touch Input Only**: Ensuring all user controls are frame-touch based as per current constraints. This should be tested iteratively with the `TranscriptLab` app to ensure usability without adding voice commands or other complex interaction modes.

### Summary
The project is currently on a path that aligns with the core mission of providing real-time subtitles and memory support in a discreet, user-friendly manner. The focus should remain on improving subtitle clarity, memory trust, and low-friction assistance while adhering to the constraints of V1 real-world limits and interaction rules. Extensive privacy measures might be overkill for this stage and could distract from core mission improvements.
