### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Improving subtitle placement rules for different confidence states ensures that subtitles are always clear and easy to read, maintaining trust in live conversations. Stable placement helps the wearer focus on the conversation without being distracted by moving or poorly placed text.

2. **What small change unlocks it**

   Define a fixed subtitle placement rule that keeps subtitles at the bottom of the field of view (FOV) for high-confidence matches and slightly above the center for medium-confidence matches, with low-confidence matches showing as brief one-line prompts to avoid distraction.

3. **Likely payoff**

   By keeping subtitles stable in a non-distracting position based on confidence, users will experience less cognitive load during conversations. This enhances trust in real-time subtitle assistance, making the product more useful and reliable for wearers who rely on it heavily.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving the confidence display format will enhance trust in the memory support system by making the certainty of remembered names and faces clearer to the wearer. This clarity ensures that the wearer can rely on the system's recall without over-relying or underestimating its accuracy.

2. **What small change unlocks it**

   Define a new confidence format for name recall that includes both a numeric score, a label indicating the level of certainty (e.g., High, Medium, Low), and a short reason to explain the source of the confidence (e.g., "Seen recently," "Weak match").

3. **Likely payoff**

   By providing a clear and concise confidence format, the system will be more transparent about its memory reliability. This increased transparency can lead to better trust in the system’s ability to recall names and faces accurately, thereby enhancing the wearer's overall experience.

4. **Immediate next probe**
   - Define the numeric score format for the V1 confidence display.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Improving the local memory cache size helps ensure that frequently encountered names and faces are always available for fast lookup and trust-building. By setting a higher threshold for local caching, we can reduce latency and improve the reliability of quick lookups, thereby enhancing the overall user experience.

2. **What small change unlocks it**

   Define a larger local cache size limit for face/name memory objects that are frequently encountered in the wearer’s context.

3. **Likely payoff**

   A larger local cache will allow more names and faces to be stored on the phone without frequent cloud interactions, reducing latency and improving the speed of name recall. This will make the system feel more responsive and reliable, enhancing user trust and satisfaction.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**
   
   By defining a clear boundary for what runs phone-local versus what falls back to cloud, we can optimize both privacy and performance while ensuring that critical real-time functionality remains uninterrupted.

2. **What small change unlocks it**

   Define one specific task-boundary rule for live subtitle processing: all live subtitles should be processed locally on the phone unless explicit user consent is given for a cloud fallback.

3. **Likely payoff**

   This approach will enhance trust by keeping sensitive data local, reduce latency and ensure real-time responsiveness, and provide a clear privacy boundary that users can choose to opt into if needed.

4. **Immediate next probe**

   Define one specific task-boundary rule for live subtitle processing: all live subtitles should be processed locally on the phone unless explicit user consent is given for a cloud fallback.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   By optimizing the visual hierarchy to prioritize subtitles over one-line support when confidence is high, we can ensure that the wearer's primary focus remains on understanding spoken content without being overloaded by additional prompts. This improves overall clarity and trust in the system.

2. **What small change unlocks it**

   Define a subtitle-vs-one-line priority rule where subtitles have higher precedence than one-line prompts when confidence in the subtitle text is above a certain threshold (e.g., 0.95).

3. **Likely payoff**

   This change will reduce cognitive load by ensuring that critical information from subtitles is prioritized, thereby maintaining focus and trust during conversations.

4. **Immediate next probe**
   - Define one visual priority rule between subtitles and one-line support in V1.
