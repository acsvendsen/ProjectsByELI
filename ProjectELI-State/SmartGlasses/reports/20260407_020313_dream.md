### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Ensuring stable subtitle placement rules will improve the wearer's trust in the system by providing consistent, reliable visual cues that do not distract from the conversation. This stability is crucial for building a dependable assistive tool.

2. **What small change unlocks it**

   Define two fixed subtitle placement modes: one at the bottom of the field of view (FOV) and another slightly above the center. Use a default mode based on the current confidence level, with an option to switch modes through frame touches if needed.

3. **Likely payoff**

   By providing consistent subtitle placement, the system will reduce visual distraction and maintain trust. This stability will make it easier for users to focus on the conversation while ensuring they do not miss any important information conveyed by the subtitles.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**
   
   By refining the confidence display to include a numeric score alongside a label and short reason, the system can provide more precise and trustworthy information about the reliability of the displayed text or memory. This enhances the user's trust in the assistant by offering clear indications of certainty, which is crucial for maintaining real-time subtitle clarity.

2. **What small change unlocks it**

   Implementing a simple configuration that allows the display to show confidence scores as numeric values (e.g., 0.84) alongside labels (e.g., "High") and short reasons (e.g., "Seen recently"), such as in the format: `score 0.84 + "High" + "Seen recently"`.

3. **Likely payoff**

   This change will enable users to quickly understand the reliability of the displayed subtitles or memory, which is critical for maintaining trust and ensuring that the wearer can make informed decisions during real-world interactions. It also aligns with the core attractor of "Trustworthy memory support" by providing clear feedback on the confidence level.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Improving local memory thresholds ensures that frequently accessed information remains available quickly without overwhelming the cache. This enhances real-time subtitle clarity by reducing latency in recall, thereby maintaining trust and ensuring the wearer can rely on accurate context during conversations.

2. **What small change unlocks it**

   Define a local cache threshold for frequently recalled people and names, setting a recency limit that evicts less recently accessed entities to make room for more critical memory items.

3. **Likely payoff**

   By optimizing the local memory thresholds, we can reduce the delay in retrieving names and context during conversations, which improves subtitle clarity and overall trustworthiness of the system. This leads to better daily-use value by ensuring that important memories are readily available without unnecessary cloud requests, thus saving battery and improving user experience.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   Sticking to a phone-first architecture for critical processing tasks ensures that V1 remains lightweight and socially acceptable, aligning with the core attractor of low-friction assistance and the constraint of early hardware simplicity.

2. **What small change unlocks it**

   Define one phone/cloud fallback boundary for live subtitle processing, ensuring subtitles remain clear and stable in real-time by leveraging the phone's computational capabilities.

3. **Likely payoff**

   By keeping critical processing local on the phone, V1 can deliver timely, high-quality subtitles that are reliable even under varying network conditions, enhancing trust and utility without adding unnecessary complexity or latency.

4. **Immediate next probe**

   Define one phone/cloud fallback boundary for live subtitle processing to ensure real-time clarity and stability.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   Improving subtitle vs one-line support coexistence ensures that the wearer can easily distinguish between essential contextual cues (subtitles) and fleeting, non-essential prompts (one-liners). This helps in maintaining focus on crucial information without overwhelming the user.

2. **What small change unlocks it**

   Define a visual hierarchy rule that prioritizes subtitles over one-line support by default but allows for temporary coexistence during high-concentration tasks where both are needed.

3. **Likely payoff**

   By optimizing subtitle vs one-line support coexistence, the system can reduce cognitive load and improve overall user experience. This ensures that critical information remains prominent while still providing necessary contextual assistance without visual clutter.

4. **Immediate next probe**
   - Define one visual priority rule between subtitles and one-line support in V1.
