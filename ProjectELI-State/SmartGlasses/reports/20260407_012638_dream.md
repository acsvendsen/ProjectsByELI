### Idea 1: Subtitle Placement

1. **Why it benefits the core**
   - Improving subtitle placement stability enhances the wearer's trust in real-time subtitles, making them more reliable for live conversation.

2. **What small change unlocks it**
   - Define a fixed subtitle position mode that places subtitles at the bottom of the screen regardless of head motion or gaze direction.

3. **Likely payoff**
   - By removing subtitle repositioning based on head movement, users will experience more consistent and predictable subtitle placement, reducing cognitive load and increasing trust in the system's ability to provide accurate information.

4. **Immediate next probe**
   - Define a fixed subtitle position mode that places subtitles at the bottom of the screen regardless of head motion or gaze direction.

### Idea 2: Confidence Display

1. **Why it benefits the core**
   Improving confidence display helps ensure that the wearer can trust the system's memory and recall capabilities, which is crucial for maintaining the product’s core mission of being a reliable personal assistant in noisy environments.

2. **What small change unlocks it**
   Define a simple numeric score format for confidence objects, where scores range from 0 to 1 with clear labels such as "Low", "Medium", and "High" alongside a short reason like "Seen recently" or "Weak match".

3. **Likely payoff**
   By clearly displaying the confidence of name and face recall, the system can build trust and avoid giving incorrect or misleading information. This will enhance the wearer’s confidence in using the glasses for important interactions.

4. **Immediate next probe**
   - Define the numeric score format for confidence objects as `score 0 to 1 with labels Low, Medium, High`.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Improving memory cache size and eviction rules will strengthen the core attractor of *Trustworthy memory support*. By ensuring that frequently encountered names and faces are cached locally, the system can provide faster, more reliable recall without overloading the cloud or draining the phone's resources.

2. **What small change unlocks it**

   Define a local cache threshold for face/name memory objects on the phone, setting a limit of 50 most recent interactions to be stored in a low-latency format.

3. **Likely payoff**

   This change will enable faster lookup and more confident face/name recall, reducing latency and improving trustworthiness without overwhelming the device's limited resources. It will also help maintain a balance between privacy and utility by limiting the amount of data stored locally.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**
   - By defining clear boundaries for what runs phone-local versus cloud, we ensure that the system remains lightweight and responsive, which is crucial for real-time subtitle clarity and memory support.

2. **What small change unlocks it**
   - Define a specific task boundary for live subtitle processing that stays local to the phone, ensuring minimal latency and high reliability.

3. **Likely payoff**
   - This will enable V1 to provide near-real-time subtitles without battery drain or thermal issues, enhancing trust and user experience.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   Ensuring a clear visual hierarchy between subtitles and one-line support helps maintain the wearer's focus on real-time conversation while minimizing distraction. This improves overall trust in the system by reducing cognitive load and social awkwardness.

2. **What small change unlocks it**

   Define a priority rule that shows subtitles with higher confidence first, then suppress or reduce the prominence of lower-confidence one-line prompts. For instance, if the subtitle has a high confidence score (e.g., >0.9), show it prominently; otherwise, show one-line support in a less intrusive manner.

3. **Likely payoff**

   By prioritizing subtitles with higher confidence and suppressing or de-emphasizing lower-confidence one-line prompts, the system will maintain trust without overwhelming the wearer. This reduces cognitive overload during critical moments of conversation, making the assistive features more effective and user-friendly.

4. **Immediate next probe**
   - Define one visual priority rule between subtitles and one-line support in V1.
