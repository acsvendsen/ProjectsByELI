# Reality Check for SmartGlasses Project

## Feasibility Assessment

### Subtitle Placement: 
- **Subtitle Clarity**  
  - **Reasoning**: The glasses need to provide clear, fast subtitles that are readable and stable enough for live conversation. Given the current focus on real-time clarity, placing subtitles at the bottom center of the field of view (FOV) is feasible now. This placement avoids obstructing the wearer's primary visual attention while ensuring subtitles remain visible.
  - **Feasibility**: Feasible now.

### Confidence Display: 
- **Low-Friction Assistance**
  - **Reasoning**: Delivering one-line help and visible support without creating command overhead or social awkwardness is a core attractor. A simple, non-intrusive confidence indicator (e.g., a label with a short reason) can be used to convey the reliability of memory recall.
  - **Feasibility**: Feasible now.

### Memory/Cache Policy: 
- **Memory Trust**
  - **Reasoning**: Face/name recall must expose uncertainty clearly. Implementing a confidence object that shows when memory is uncertain (e.g., "Uncertain: John Doe") can help build trust and avoid misleading the wearer.
  - **Feasibility**: Feasible now.

### Phone/Cloud Boundary: 
- **Phone-First Runtime**
  - **Reasoning**: Early versions should rely heavily on phone processing. The current `TranscriptLab` app provides a good foundation for testing subtitle clarity without heavy reliance on cloud services, making this feasible.
  - **Feasibility**: Feasible now.

### Visual Hierarchy: 
- **Subtitle Placement**
  - **Reasoning**: The subtitle should be placed in a way that it remains readable and unobtrusive. Placing subtitles at the bottom center of the FOV is both visually clear and non-distracting.
  - **Feasibility**: Feasible now.

### Privacy vs Usefulness: 
- **Privacy Constraints**
  - **Reasoning**: The glasses should not pretend knowledge the wearer does not have, which aligns with the core attractor of memory trust. Implementing memory recall that shows uncertainty when appropriate (e.g., "Uncertain: John Doe") can maintain privacy and usefulness.
  - **Feasibility**: Feasible now.

### Latency vs Richness: 
- **Real-Time Clarity**
  - **Reasoning**: Early versions should focus on real-time clarity, which is critical for trust. The current `TranscriptLab` app provides a baseline to ensure subtitles are clear and stable.
  - **Feasibility**: Feasible now.

### Discreet UX vs Visual Clarity: 
- **Subtitle Placement**
  - **Reasoning**: Placing subtitles at the bottom center of the FOV ensures they remain readable while being unobtrusive. This aligns with the goal of a discreet user experience.
  - **Feasibility**: Feasible now.

## Future Work

### Privacy vs Usefulness:
