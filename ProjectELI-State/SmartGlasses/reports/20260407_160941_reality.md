# Reality Check for SmartGlasses Core Field

## Subtitle Clarity (feasible now)
- **Current Status:** Keep subtitles clear, fast, and stable enough that the wearer can trust them in live conversation.
- **Reality Check:**
  - **Latency:** The `TranscriptLab` app has shown that real-time transcripts are possible on a phone. The build summary indicates no warnings or errors.
  - **Battery Draw:** Initial tests focus on minimal processing to keep battery draw low, aligning with the `phone-first runtime` constraint.
  - **Thermal Pressure:** Simple display logic should not significantly impact thermal constraints in V1.

**Conclusion: Feasible now.**

## Memory Trust (feasible later)
- **Current Status:** Remember names, faces, and prior context without pretending certainty or creating corrupted recall.
- **Reality Check:**
  - **Memory Policy:** The shared transcript layer is intentionally not a chat stack but focuses on basic real-time behavior, setting the groundwork for richer memory support in future versions.
  - **Latency:** Early versions can use cached data from the phone to provide quick responses. More complex reinforcement learning or cloud-based solutions may be necessary later.
  - **Privacy Perception:** Local storage and display of names and faces without overreliance on heavy processing aligns with privacy concerns.

**Conclusion: Feasible later, pending further development in memory caching and local processing capabilities.**

## Low-Friction Assistance (feasible now)
- **Current Status:** Deliver one-line help and visible support without creating command overhead or social awkwardness.
- **Reality Check:**
  - **Interaction Constraints:** Frame-touch interaction is the core V1 constraint, making one-line prompts through touch a straightforward implementation.
  - **UI Design:** The `TranscriptLab` app provides a reusable transcript UI that can be adapted for one-line assistance without requiring complex multimodal interactions.

**Conclusion: Feasible now.**

## Core Deepening vs Sprawl (feasible now)
- **Current Status:** Bias toward subtitle, memory, confidence, and architecture improvements that increase daily-use value.
- **Reality Check:**

  - **Implementation Grounding:** The `TranscriptLab` app provides a clear path to test and refine these core functionalities.

**Conclusion: Feasible now.**
