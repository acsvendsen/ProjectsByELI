### Idea 1: Subtitle Placement

1. **Why it benefits the core**
   - Improving subtitle placement rules can ensure that subtitles remain clear, stable, and unobtrusive, which directly supports the attractor of real-time subtitle clarity. This improvement helps in maintaining trust during live conversations by ensuring that the subtitles do not distract the wearer.

2. **What small change unlocks it**
   - Define a fixed position for subtitles that is consistent across different confidence states but allows minor adjustments based on speaker identity and environment noise levels.

3. **Likely payoff**
   - A well-defined subtitle placement rule can significantly enhance user trust by ensuring subtitles remain readable without becoming distracting, thus improving the overall user experience and aligning with the core attractor of real-time subtitle clarity.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

Improving the confidence display format will enhance trust by clearly indicating the certainty of information to the wearer, thereby reducing ambiguity and ensuring that the wearer knows when to rely on the subtitles and memory support.

2. **What small change unlocks it**

Define a simple but clear confidence label and short reason format for both subtitles and memory entries. For example, use "High" + "Seen recently" or "Low" + "Weak match".

3. **Likely payoff**

This change will help the wearer understand the reliability of the information provided by the system more intuitively. It will reduce cognitive load by making it clear when to give more weight to the system's output, thereby improving overall trust and user experience.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   By setting a clear local cache threshold for name recall, the system can balance memory retention with battery and thermal constraints. This helps in maintaining a useful amount of context without overloading the device's resources.

2. **What small change unlocks it**

   Define one specific local-cache size limit for names, such as 5-10 recent interactions, which are automatically reinforced through frame touches but not continuously refreshed.

3. **Likely payoff**

   This approach ensures that common names and faces are remembered reliably without draining the battery or overheating the device. It also respects the wearer's privacy by not storing unnecessary information long-term.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By refining the phone-cloud boundary for live subtitle processing, we can ensure that critical real-time data remains on the phone, maintaining low-latency and high-quality subtitle delivery while respecting battery constraints.

2. **What small change unlocks it**

   Define a clear local cache eviction policy where transcripts older than 1 minute are stored locally but those less than 30 seconds are processed fully on-device to reduce latency.

3. **Likely payoff**

   This will ensure that subtitles remain highly responsive and stable, enhancing the core mission of providing real-time, reliable assistance in noisy environments without overburdening the battery or cloud resources.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   Improving subtitle-vs-one-line priority ensures that subtitles remain clear and readable without overwhelming the wearer with too much text. This balance is crucial for maintaining trust in real-time assistance, especially in noisy environments where clear, concise information can make a significant difference.

2. **What small change unlocks it**

   Define a visual hierarchy rule that prioritizes subtitles over one-line prompts when confidence in the subtitle content is high and ensures one-line support remains visible but less prominent otherwise.

3. **Likely payoff**

   By optimizing subtitle-vs-one-line priority, the system will provide clearer, more reliable real-time subtitles, reducing cognitive load and enhancing understanding during conversations. This improvement will contribute to a smoother user experience and stronger trust in the assistant's ability to provide accurate information.

4. **Immediate next probe**
   - Define one visual priority rule between subtitles and one-line support in V1.
