### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Improving subtitle placement rules based on confidence states will ensure that subtitles remain clear and stable enough to be trusted during live conversations. This will directly address the `subtitle_clarity` primary attractor, enhancing the wearer's ability to follow real-time interactions without being distracted by poorly placed or unstable text.

2. **What small change unlocks it**

   Define a set of subtitle placement rules where subtitles are:
   - Fixed at the bottom center for low confidence states (newly recognized faces/names).
   - Floating slightly above the speaker’s mouth for high confidence states.
   - Hidden during periods of no speech to prevent visual clutter.

3. **Likely payoff**

   By implementing these subtitle placement rules, the glasses will:
   - Reduce distraction and maintain focus on the conversation.
   - Ensure that critical information is always visible and legible.
   - Improve trust in the subtitle system by providing a consistent and unobtrusive display.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving the confidence display format ensures that the wearer can trust the system's outputs more easily. A clear, concise, and honest representation of the system's certainty will enhance the overall reliability of subtitles and memory recall, which are crucial for the core mission.

2. **What small change unlocks it**

   Define a simple confidence format that combines a numeric score with a label and a short reason. For example: "score 0.85 + 'High' + 'Seen recently in conversation'".

3. **Likely payoff**

   By implementing a clear and honest confidence display, the system will build trust more effectively. This improved trust can lead to better acceptance of the product by users who rely on it for critical interactions, such as in noisy environments or important meetings.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Improving the local memory cache size and eviction rule directly enhances the trustworthiness and reliability of name recall for the wearer. By carefully defining how and when memories are stored and evicted, we can ensure that the most relevant information is available quickly without consuming excessive resources.

2. **What small change unlocks it**

   Define a simple yet effective memory cache policy where names and faces encountered within the last 30 minutes have priority for local storage, with a maximum cache size of 50 entries per person to prevent overflow.

3. **Likely payoff**

   By ensuring that commonly encountered names and faces are readily available locally, we can reduce latency in name recall, improve confidence objects during interactions, and enhance the overall trustworthiness of the system for daily use scenarios.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By defining a clear boundary for what runs on the phone versus the cloud, we can ensure that critical processing happens locally to maintain real-time performance and privacy. This focus helps in delivering a reliable and discrete assistive experience while respecting user privacy.

2. **What small change unlocks it**

   Define one specific task-boundary where live subtitle processing remains fully local (e.g., face/name recall lookup) unless explicitly justified for cloud support, with all other transcript-related tasks falling back to the phone or cloud only as a last resort.

3. **Likely payoff**

   This approach ensures that critical real-time subtitle processing happens on-device, maintaining low latency and preserving user privacy. It also simplifies the system architecture, making it easier to reason about and optimize for real-world use cases.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   Ensuring a clear visual hierarchy between subtitles and one-line support helps maintain the wearer's focus on real-time information without overwhelming them with too much text or distracting from the conversation.

2. **What small change unlocks it**

   Define a subtitle-vs-one-line priority rule that ensures subtitles remain visible and prominent while one-line prompts are shown in a secondary, non-intrusive way when necessary.

3. **Likely payoff**

   A well-defined visual hierarchy can reduce cognitive load and social friction by ensuring the wearer remains focused on critical information without being distracted by less important text. This improves overall understanding and engagement during interactions.

4. **Immediate next probe**

   Define one visual priority rule between subtitles and one-line support, prioritizing subtitles for live conversation clarity over one-line prompts.
