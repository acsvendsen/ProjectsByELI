### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   By defining a fixed subtitle placement rule that prioritizes readability over reactivity, we ensure that subtitles remain stable and unobtrusive during live conversations. This stability reduces cognitive load for the wearer and maintains their ability to focus on the conversation at hand.

2. **What small change unlocks it**

   Define a single fixed subtitle placement mode where subtitles are always displayed in a central, non-animating position, regardless of the confidence level or speaker identification status.

3. **Likely payoff**

   This simple change will improve the wearer's trust in the system by providing consistent and unambiguous visual cues during live interactions. It minimizes distractions and ensures that critical information is always easily readable, enhancing the overall user experience.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**
   Enhancing the confidence display format can improve user trust in both subtitles and memory recall. A clear and consistent way to show certainty can help users understand when they should pay extra attention or rely more on their own judgment.

2. **What small change unlocks it**
   Define a specific confidence format that combines a numeric score, label, and short reason for both subtitles and memory cues. For example: `score 0.85 + "High" + "Seen recently"` for subtitles, and `score 0.70 + "Medium" + "Name heard once in introduction"` for memory recall.

3. **Likely payoff**
   By providing clear confidence indicators, users can better manage their attention during conversations. This can lead to more effective understanding and less cognitive load on the wearer, improving overall user experience without adding complexity or latency issues.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   By setting a specific local memory threshold for new-person recall, we ensure that likely new people are automatically remembered without overloading the phone's cache or creating unnecessary privacy concerns. This helps maintain trust and useful behavior while keeping memory management efficient.

2. **What small change unlocks it**

   Define one local-cache size limit for new-person memory objects on the phone to be 50 items, with a grace period of 3 days before eviction.

3. **Likely payoff**

   The likely payoff is improved trust in memory recall without unnecessary privacy risks or cache bloat. This setup allows the system to remember names and faces effectively while ensuring that old memories are cleared out after use, maintaining a clean state for new interactions.

4. **Immediate next probe**
   - Define the local-cache size limit for new-person memory objects on the phone to be 50 items.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**
   - Improving subtitle clarity and stability directly supports the SmartGlasses' primary attractor of real-time subtitle clarity. By optimizing subtitle placement rules, we can ensure that subtitles remain visible, readable, and non-distracting during live conversations, enhancing the wearer's ability to understand spoken content without visual overload.

2. **What small change unlocks it**
   - Define 2 to 3 subtitle placement rules for different confidence states. For example:
     - **High Confidence**: Place subtitles directly below the speaker’s face or mouth.
     - **Medium Confidence**: Place subtitles slightly above or beside the speaker, with a slight delay to avoid immediate overlap.
     - **Low Confidence**: Use more conservative placement that does not block important facial features and can be adjusted based on visual context.

3. **Likely payoff**
   - Better subtitle placement rules will reduce distractions during live conversations, improve readability, and enhance overall trust in the subtitles. This improvement directly supports the core attractor of real-time subtitle clarity while minimizing visual intrusion and ensuring that subtitles remain clear and legible.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.
