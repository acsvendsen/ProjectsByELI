# Consolidation of Core Field for SmartGlasses V1

## Strengthening Signals
- **Subtitle Quality:** The need for near-real-time subtitles is becoming more critical as users encounter more noisy environments and hearing-challenged situations.
- **Memory Policy:** The importance of memory reinforcement and confidence objects is increasing, especially for new faces and names.
- **Confidence Display:** Users are showing higher interest in clear, actionable confidence levels to reduce uncertainty.

## Weakening Signals
- **Interaction Complexity:** There's a growing awareness that V1 should remain simple with frame-touch interactions only, avoiding voice commands or complex multimodal UIs.
- **Feature Sprawl:** The tendency to add more features beyond the core mission is weakening as users prefer simplicity and focused assistance over a cluttered interface.

## Contradictions That Must Stay Alive
- **Privacy vs Usefulness:** There’s a constant tension between providing useful memory support and maintaining user privacy, especially regarding how face/name memories are stored and used.
- **Battery Management:** Always-on features need to balance real-time functionality with battery life constraints, highlighting the importance of efficient on-device processing.

## Dormant Ideas Worth Reactivating
- **Subtitle Placement and Visual Hierarchy:** These ideas should be reactivated as they significantly impact user experience and wearability. The current preference is for subtitles to dominate the visual hierarchy without becoming distracting.

## Concrete Tensions Around Core Areas

### Subtitle Quality, Confidence Trust, Automatic Memory, Memory Reinforcement, Fast Lookup
- **Subtitle Placement and Visual Hierarchy:**
  - **Tension:** What subtitle placement best balances usability and non-distracting visibility?
  - **Current Preference:** Subtitles should dominate the visual hierarchy but remain unobtrusive.
  
- **Confidence Display:**
  - **Tension:** How to represent confidence in a way that builds trust without overwhelming the user?
  - **Recommendation:** Use labels with short reasons for memory accuracy.

- **Automatic Memory Behavior vs Explicit Remember-Touch Behavior:**
  - **Tension:** How much automatic memory is appropriate compared to explicit remember-touch behavior?
  - **Current Preference:** Leverage automatic memory for new faces and names, but provide clear touch options to reinforce these memories.

- **Memory Policy:**
  - **Tension:** How should face/name memory be stored and reinforced for fast lookup while respecting privacy?
  - **Recommendation:** Use recency first caching on the phone with explicit touch reinforcement for new entries.

### Privacy, Battery, Latency, Social Acceptability
- **Privacy vs Usefulness:**
  - **Tension:** Balancing the need for rich memory support with user privacy concerns.
  - **Current Preference:** Optimize for rich context and fast lookup while being transparent about data usage.

- **Battery Management:**
  - **Tension:** Ensuring subtitles feel near-real-time or risk breaking trust vs managing battery constraints.
  - **Recommendation:** Prioritize efficient subtitle generation and display to minimize thermal and battery impact.

### Visual UX
- **Subtitle Reasoning vs Memory Policy:**
  - **Tension:** How do effective subtitle displays influence the overall memory policy?
  - **Current Preference:** Subtitles should be clear and actionable, supporting fast lookup and confidence trust without overwhelming the wearer.

## Current Open Questions
- What is the best V1 split between glasses, phone, and cloud to balance real-time functionality with battery and privacy concerns?
- How should face/name memory be stored and reinforced for fast lookup and trust?
- How should confidence be represented: numeric score, label, and short reason?
- How should subtitles and one-line prompts coexist without overloading the wearer?
- What is the best subtitle placement and visual hierarchy for fast reading with low distraction?

## Summary
The current signals strongly support a focus on core features like live subtitles, face/name recall, and memory reinforcement while maintaining simplicity and user privacy. The primary tensions lie in achieving high-quality subtitles, managing battery life, and balancing rich memory support with clear confidence displays. Reactivating ideas around subtitle placement and visual hierarchy will help address these challenges effectively.
