### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Improving subtitle placement rules ensures that subtitles remain clear, stable, and not distracting during live conversations. This enhances the wearer's ability to understand spoken content in noisy environments without the risk of visual overload or confusion.

2. **What small change unlocks it**

   Define 3 fixed subtitle placement rules based on confidence levels: 
   - Low-confidence subtitles displayed below the one-line support text.
   - Medium-confidence subtitles centered but slightly smaller than typical size.
   - High-confidence subtitles prominently placed at the top of the display with a larger font size.

3. **Likely payoff**

   By implementing fixed subtitle placement rules, the system can reduce visual clutter and maintain high clarity in critical moments when confidence is low or medium. This will help the wearer focus on the most important information without being overwhelmed by less certain text.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving the confidence display format helps ensure that the wearer can trust the subtitles and memory support provided by the glasses. A clear, concise, and reliable confidence indication will reduce uncertainty and build more trust in the system's accuracy.

2. **What small change unlocks it**

   Define a simple confidence format for V1: use a numeric score + label + short reason. For example, "score 0.84 + 'High' + 'Seen recently';" this format provides a quick indication of certainty without overwhelming the wearer with too much information.

3. **Likely payoff**

   By providing a clear and concise confidence display, the system can help the wearer better understand the reliability of the subtitles and memory support. This will lead to more trust in the system and potentially reduce the cognitive load on the user by reducing their need to constantly verify the accuracy of the information provided.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

This improves the overall reliability of real-time subtitle clarity and personal memory assistance without relying heavily on cloud resources.

2. **What small change unlocks it**

   Define a local cache threshold for name recall where the phone retains recent face and name encounters for quick lookup, with a maximum size that balances battery and thermal constraints.

3. **Likely payoff**

   The likely payoff is an improved user experience in noisy environments or during offline sessions, as frequently encountered names are quickly recalled without the need to query the cloud. This reduces latency, enhances trust, and aligns with the core attractor of memory trust.

4. **Immediate next probe**

   Define one local cache threshold for name recall that balances battery and thermal constraints while ensuring quick lookup for recent encounters.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By defining a clear boundary between what runs on the phone and what falls back to cloud for live subtitle processing, we ensure that subtitles remain stable and responsive in real-time scenarios. This alignment with V1's interaction constraints (frame-touch only) prevents delays or interruptions that could degrade the user experience, maintaining trust and ensuring the core mission of providing clear, reliable real-time subtitles.

2. **What small change unlocks it**

   Define a specific task boundary for live subtitle processing where:
   
   - Live subtitle rendering is done entirely on-device using the phone's local resources.
   - Subtitle data preprocessing (e.g., initial speech-to-text transcription) can fall back to cloud services if necessary, but final rendering and display must remain local.

3. **Likely payoff**

   By keeping live subtitle processing local, we ensure that subtitles are delivered without latency or disruption, enhancing the wearer's trust in the system. This stability is crucial for maintaining the core mission of providing clear real-time assistance, especially in noisy environments where timely information is vital.

4. **Immediate next probe**
   - Define the rule for live subtitle rendering to always occur on-device, with cloud services handling initial transcription only if local resources are overwhelmed, ensuring real-time stability and responsiveness.
