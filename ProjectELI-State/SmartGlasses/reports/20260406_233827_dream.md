### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Ensuring stable subtitle placement rules helps maintain readability and trust in real-time conversations. Stable placement reduces cognitive load by minimizing eye movement, allowing the wearer to focus on the conversation more effectively.

2. **What small change unlocks it**

   Define fixed subtitle position rules based on confidence levels: low-confidence subtitles at the bottom of the screen with high confidence ones centered for better visibility.

3. **Likely payoff**

   By defining stable placement rules, V1 can provide a more predictable and reliable user experience. This will enhance trust in the system’s accuracy and help reduce cognitive effort required to follow subtitles during conversations.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving the confidence display format ensures that the wearer can trust the system's output more effectively. By clearly indicating certainty levels with a numeric score, label, and short reason, the system can help the wearer understand when to rely on the subtitles or memory aids provided by the glasses.

2. **What small change unlocks it**

   Define a specific confidence format for V1 that includes a numeric score, a simple label (like "High", "Medium", or "Low"), and a short reason (e.g., "Seen recently" or "Weak match").

3. **Likely payoff**

   By providing clear and concise confidence indicators, the system can build trust with the wearer. The wearer will be able to discern when the subtitles are highly reliable and when they should seek additional context, leading to more effective use of the glasses.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Ensuring a stable and reliable memory cache policy helps maintain the trustworthiness and utility of the SmartGlasses' face/name recall feature. A well-defined cache size and eviction rule will prevent unnecessary data retention while ensuring that recently encountered individuals are remembered accurately.

2. **What small change unlocks it**

   Define a local cache threshold for name recall, setting an upper limit on how many names can be stored locally before they start being evicted based on recency of interaction.

3. **Likely payoff**

   By limiting the number of names in the local cache and ensuring that only recently encountered individuals are remembered, the memory system will remain efficient and focused, reducing battery usage and storage demands while maintaining high recall accuracy for frequently interacting people.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   Ensuring that live subtitle processing remains phone-local helps maintain real-time responsiveness and reduces battery drain, which is crucial for trust and usability in noisy environments where subtitles are most needed.

2. **What small change unlocks it**

   Define a specific task boundary where live subtitle processing always runs locally on the phone, with any face/name recall or memory lookup tasks falling back to the cloud only if absolutely necessary due to limited local resources.

3. **Likely payoff**

   By keeping subtitle rendering and initial processing entirely on the phone, we can ensure that subtitles remain fast and reliable even in low-bandwidth environments, enhancing user trust and satisfaction.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   Improving the visual hierarchy by defining a clear precedence rule between subtitles and one-line support will ensure that the most critical information is always visible, enhancing the wearer's understanding and confidence without overwhelming them.

2. **What small change unlocks it**

   Define a single visual priority rule that gives higher precedence to subtitles over one-line prompts in all normal interaction scenarios.

3. **Likely payoff**

   By prioritizing subtitles, we ensure that the core mission of providing clear, real-time assistance is met first, reducing cognitive load and maintaining trust in the system's ability to provide critical information quickly.

4. **Immediate next probe**
   - Define a single visual priority rule that gives higher precedence to subtitles over one-line prompts in all normal interaction scenarios.
