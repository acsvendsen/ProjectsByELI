### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   By defining specific subtitle placement rules for different confidence states, we can ensure that subtitles remain clear and stable enough to be trusted in live conversation while minimizing distraction. This improves real-time subtitle clarity (subtitle_clarity) and low-friction assistance (low_friction_assistance), aligning with the project's core mission.

2. **What small change unlocks it**

   Define three subtitle placement rules: 
   - For high confidence, place subtitles at the bottom of the frame.
   - For medium confidence, position subtitles slightly above eye level but not obstructing view.
   - For low confidence, keep subtitles minimal and in a corner to avoid distraction.

3. **Likely payoff**

   These rules will reduce visual clutter, especially during high-confidence moments when users are more engaged. This improves readability and trustworthiness without overloading the wearer's field of vision, enhancing the overall user experience and reducing cognitive load.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving the confidence display format ensures that the wearer can trust the subtitles more effectively. A clear and concise confidence score will help the wearer understand when to rely on the assistant’s understanding, which is crucial for maintaining user trust in a noisy or complex environment.

2. **What small change unlocks it**

   Define a simple numeric score + label + short reason format for confidence objects. For example: "score 0.85 + 'High' + 'Seen recently'". This format provides the wearer with immediate clarity on the assistant's certainty level and the basis of that certainty.

3. **Likely payoff**

   By providing a clear and concise confidence display, users will have better trust in the subtitles, leading to more effective use of the product in noisy environments. This improved trust can significantly enhance the overall user experience and encourage daily use.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**
   - Improving memory cache size and eviction policy directly enhances the wearer's trust in face and name recall, ensuring that relevant memories are available when needed without overwhelming local storage.

2. **What small change unlocks it**
   - Define a local cache threshold for face and name memory on the phone, setting an upper limit to the number of recent interactions stored before older entries are evicted based on recency and confidence.

3. **Likely payoff**
   - By limiting the amount of memory stored locally, the system can maintain faster lookup times and reduce the risk of storing irrelevant or outdated information, thus improving overall performance and user trust in memory recall accuracy.

4. **Immediate next probe**

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By defining a clear boundary for what runs on the phone versus what falls back to the cloud, we can ensure that critical real-time subtitle processing and memory lookup occur locally, maintaining low latency and high reliability. This focus helps in preserving battery life and ensuring that sensitive user data remains private.

2. **What small change unlocks it**

   Define a single task-specific fallback boundary for live subtitle processing where all subtitle-related data and computation remain local on the phone unless explicitly needed from the cloud. For example, if a face or name needs to be recalled, the system should first try the local cache before falling back to the cloud.

3. **Likely payoff**

   By keeping real-time subtitle processing locally, we can ensure that subtitles are delivered with minimal latency and high quality, enhancing user trust and satisfaction. Additionally, this approach will help in maintaining privacy by not sending sensitive audio data to the cloud unnecessarily.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

Improving subtitle-vs-one-line priority in the visual hierarchy ensures that the most important information is always clear and prioritized for the wearer, enhancing their understanding without overwhelming them with too much text.

2. **What small change unlocks it**

Define a visual hierarchy rule where subtitles are given higher precedence over one-line prompts when confidence levels are high but can coexist or be suppressed when confidence is low to minimize distraction.

3. **Likely payoff**

This visual hierarchy rule will reduce cognitive load by ensuring that critical information like real-time subtitles take priority, while less crucial contextual support (one-line prompts) remains accessible without overwhelming the wearer. This improves overall usability and trust in the system.

4. **Immediate next probe**
   - Define one visual priority rule between subtitles and one-line support in V1.
