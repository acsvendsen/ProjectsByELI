### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   By defining specific subtitle placement rules based on confidence levels, V1 can ensure that subtitles remain clear and unobtrusive while still providing necessary assistance. This improves the wearer's trust in real-time subtitles by making them more reliable and less likely to distract from the conversation.

2. **What small change unlocks it**

   Introduce a simple subtitle placement rule: Place subtitles at the bottom of the screen when confidence is high, and at the top center when confidence is low or uncertain. This change allows for a clear visual hierarchy that prioritizes critical information without overwhelming the wearer.

3. **Likely payoff**

   This small change will enhance the overall user experience by balancing clarity with minimal distraction. High-confidence subtitles can be placed at the bottom where they are less likely to interfere, while low-confidence subtitles appear more prominently but still maintain a discreet position. This improves subtitle readability and trustworthiness, making the product more useful in real-world interactions.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving confidence display ensures that the wearer can trust the system's memory and one-line support without over-relying on false certainty. This builds a stronger foundation for daily use, ensuring that the assistant is seen as reliable and valuable.

2. **What small change unlocks it**

   Define a simple but clear confidence format: score + label + short reason. For example, "score 0.84 + 'High' + 'Seen recently';" this format provides immediate clarity on how certain the system is about its recall or one-line support.

3. **Likely payoff**

   A well-defined confidence format will enhance user trust by making it clear when the system is confident versus uncertain. This can prevent over-reliance on inaccurate memories and promote a more reliable assistive experience, which in turn increases daily use and value.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   By setting a local cache size threshold for memory objects, we ensure that the system retains only the most relevant information while managing battery and thermal constraints effectively. This helps in maintaining a balance between providing useful memory support and avoiding unnecessary memory overhead.

2. **What small change unlocks it**

   Define a specific number of recent memory entries (e.g., 5-10 face/name encounters) to be cached locally on the phone, with older or less relevant memories being evicted based on recency and usage patterns.

3. **Likely payoff**

   This setup ensures that the system can provide timely and accurate memory support without consuming excessive battery or thermal resources. It also maintains a high level of trust by not overloading the wearer's context with irrelevant information, thereby keeping the UX clear and focused.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By defining a clear boundary for what stays phone-local versus what falls back to cloud processing for live subtitle processing, we ensure that subtitles remain fast and reliable in real-time interactions. This helps maintain the core attractor of "real-time subtitle clarity" by offloading heavier computational tasks like speech-to-text transcription and confidence enhancement to the phone, where performance is more predictable.

2. **What small change unlocks it**

   Define a specific task boundary for live subtitle processing that prioritizes what can be done locally on the phone without significant delay or battery drain. For instance, define rules around which parts of the speech transcription and confidence processing should run on the phone to ensure minimal latency and stability.

3. **Likely payoff**

   By keeping critical real-time tasks local, we can deliver faster, more reliable subtitles that remain clear and stable during conversations. This improves user trust in the system’s ability to provide accurate and timely support, aligning with our core attractor of "real-time subtitle clarity."

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.
