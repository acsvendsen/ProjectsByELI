# Recent Signals Consolidation

## Strengthening Signals
- **Subtitle Clarity**: The real-time subtitle clarity must remain clear, fast, and stable to ensure the wearer can trust them in live conversation.
- **Memory Trust**: Names, faces, and prior context should be remembered with confidence objects and reinforced over time for accurate recall.
- **Low-Friction Assistance**: One-line help and visible support should provide minimal command overhead while being socially acceptable.

## Weakening Signals
- **Privacy vs Usefulness**: The balance between providing useful assistive behavior without creeping into invasive capture or retention practices must be managed carefully.
- **Latency vs Richness**: The system should aim to provide timely help without overloading the runtime with slower, richer processing that could compromise performance.
- **Discreet UX vs Visual Clarity**: Display behavior should remain socially acceptable while still being readable in motion and noise.

## Contradictions That Must Stay Alive
- **Always-On Sensing vs Battery and Thermals**: The system must manage always-on sensing to avoid excessive battery drain and thermal issues.
- **Rich Context vs Low-Latency Response**: Balancing rich contextual memory support with low-latency real-time responses is crucial for effective assistive behavior.

## Summary of Core Fields and Recent Signals

The SmartGlasses project aims to create a discreet personal assistant focused on real-time subtitles, face/name recall, conversation memory, and one-line support. Key non-negotiables include simplicity in early hardware, frame-touch-only interaction, persistent context across sessions, and realistic constraints like privacy, battery life, and social acceptability.

### Recent Signals
- **Strengthening**: High emphasis on subtitle clarity, reliable memory support, and low-friction assistance.
- **Weakening**: Continued focus on managing privacy, latency, and visual UX tensions.
- **Contradictions**: Persist with balancing always-on sensing against battery concerns and enriching context without compromising response speed.
- **Open Questions**: Revisit subtitle placement, confidence display mechanisms, and memory caching policies.

By addressing these areas, the project can maintain its core mission while continuously improving real-world usability and assistive value.
