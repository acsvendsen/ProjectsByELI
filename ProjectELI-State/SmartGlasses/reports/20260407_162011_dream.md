### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By defining a clear boundary for what runs phone-local versus falling back to cloud for live subtitle processing, we can ensure that subtitles remain stable and fast in real-time scenarios. This prevents potential latency issues from cloud processing from affecting the wearer's ability to follow conversations in noisy environments.

2. **What small change unlocks it**

   Define explicit rules for when live subtitle processing should run phone-local versus falling back to the cloud. For example, if the system detects that the wearer is in a noisy environment or has low battery, subtitles can default to phone-local processing.

3. **Likely payoff**

   By keeping critical real-time functions like live subtitles on-device, we reduce latency and ensure that the subtitles are always available when needed. This improves the trustworthiness of the system and enhances the wearer's ability to understand spoken interactions in noisy environments.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   By carefully defining the visual hierarchy between subtitles and one-line support, we can ensure that the primary form of assistance (subtitles) remains easily readable while still providing necessary contextual cues without overwhelming the wearer. This clarity will enhance trust by making the system's role as a discreet assistant more transparent.

2. **What small change unlocks it**

   Define a visual priority rule where subtitles have higher precedence than one-line support, but both are displayed in ways that respect social acceptability and readability. For example, subtitles could be larger and bolder, with one-line support appearing smaller or semi-transparent when available.

3. **Likely payoff**

   This small change will make the system more usable by ensuring that critical information (subtitles) remains easily visible while still providing necessary contextual cues through one-line prompts. It will reduce cognitive load and maintain trust in the system's role as a discreet assistant.

4. **Immediate next probe**
   - Define one visual priority rule between subtitles and one-line support in V1.
