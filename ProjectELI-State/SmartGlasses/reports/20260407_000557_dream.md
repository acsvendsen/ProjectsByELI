### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Improving subtitle placement rules ensures that subtitles remain clear, stable, and unobtrusive, which is crucial for maintaining real-time clarity and trust during live conversations.

2. **What small change unlocks it**

   Define a fixed subtitle placement rule where subtitles are always displayed at the bottom center of the field of view, with a slight offset to avoid occlusion by the wearer's gaze or head movements.

3. **Likely payoff**

   By maintaining a consistent and unobtrusive placement, users will have more trust in the subtitles, leading to better understanding and reduced cognitive load during interactions.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving the confidence display format in V1 will enhance the trustworthiness and reliability of subtitle assistance. By clearly indicating the certainty level, the wearer can better understand when to rely on the subtitles or seek additional context.

2. **What small change unlocks it**

   Define a simple numeric score + label + short reason format for confidence objects. This involves setting up a basic structure where each confidence object includes a numeric score (e.g., 0.85), a label like "High," and a brief reason such as "Seen recently" or "Weak match."

3. **Likely payoff**

   Introducing this confidence format will provide the wearer with clear, concise feedback on the reliability of subtitles in real-time conversations. This transparency can significantly boost trust and reduce uncertainty during critical interactions.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Ensuring that new-person memory is automatically cached on the phone with a clear reinforcement rule helps maintain privacy while providing trustworthy support. By caching and reinforcing memories, the system can ensure that names and faces are remembered accurately over time without overly invasive data collection practices.

2. **What small change unlocks it**

   Define a local cache size limit for new-person memory objects that ensures they are stored on the phone for at least one week before being automatically purged if no further reinforcement occurs. This limits the amount of data kept while still reinforcing key memories effectively.

3. **Likely payoff**

   By caching and reinforcing memories locally, the system can provide more accurate name recall over time without creating a privacy concern. The wearer will feel more confident in the system's ability to remember important people, leading to better trust and daily-use value.

4. **Immediate next probe**

   Set a local cache size limit of 50 new-person memory objects for at least one week before automatic purging if no further reinforcement occurs.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   Ensuring that live subtitle processing remains local to the phone minimizes battery drain and latency, preserving real-time clarity and trust. By keeping subtitle processing on-device, we avoid unnecessary data transfers to the cloud, which can be slow and energy-intensive.

2. **What small change unlocks it**

   Define a clear boundary where only critical, low-latency subtitle processing runs locally on the phone, while other tasks like transcript cleanup fall back to the cloud when needed. This requires setting up a local cache for recently processed subtitles that can be quickly re-displayed without additional cloud requests.

3. **Likely payoff**

   By keeping real-time subtitle processing local, we ensure that subtitles remain crisp and responsive, enhancing the wearer's trust in the system during live interactions. This also reduces the overall energy consumption of the glasses, making them more comfortable to wear for extended periods.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   Ensuring clear visual hierarchy between subtitles and one-line support improves the wearer's ability to focus on critical information without visual overload or distraction. This clarity helps maintain trust in the system by making the assistive text more readable and less intrusive, which is essential for real-time understanding.

2. **What small change unlocks it**

   Define a single visual priority rule that ensures subtitles remain prominent while one-line support remains readable but secondary. This rule should prioritize subtitle placement over one-line prompts to avoid visual clutter during critical conversation moments.

3. **Likely payoff**

   By prioritizing subtitle clarity, the system will reduce visual distractions and maintain focus on essential information, thereby enhancing the wearer's trust in the assistive functionality. This improved clarity can lead to better real-time understanding and more effective memory support without overwhelming the user with too much information at once.

4. **Immediate next probe**
