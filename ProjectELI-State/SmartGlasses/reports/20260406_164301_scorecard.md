## Project Summary
The SmartGlasses project is focused on creating discreet, context-aware personal assistants for live subtitles, face/name recall, and conversation memory. The current V1 direction emphasizes frame-touch interactions, phone-first architecture, minimal hardware complexity, and real-time subtitle delivery to ensure usability and user trust.

- limitation pressure: battery and thermal pressure
