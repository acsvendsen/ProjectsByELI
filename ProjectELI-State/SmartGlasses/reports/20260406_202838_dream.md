### Idea 1: Subtitle Placement

1. **Why it benefits the core**
   - By defining specific subtitle placement rules based on confidence levels, the system can ensure that subtitles are always visible and clear when needed, enhancing the wearer's understanding without overwhelming them.

2. **What small change unlocks it**
   - Define two subtitle placement modes: one for high-confidence content (always visible) and another for low-confidence content (visible only if gaze direction indicates interest).

3. **Likely payoff**
   - This will improve the reliability of subtitles, making sure that critical information is not missed when confidence in the transcription is low but still important.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   By refining how confidence objects are displayed, we can ensure that the wearer is always aware of the reliability of the information provided by the glasses. This transparency builds trust and helps the wearer make informed decisions during conversations.

2. **What small change unlocks it**

   Define a new confidence format that includes both a numeric score and a label with a short reason for the certainty level. For example, "score 0.84 + 'High' + 'Seen recently'". This format will provide immediate context to the wearer about how reliable the information is.

3. **Likely payoff**

   By providing clear confidence levels, the glasses can be more trusted in noisy environments or situations where real-time accuracy is critical. The wearer will feel more confident using the subtitles and memory support, leading to better overall experience and understanding during interactions.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   By defining a specific local cache size threshold for face and name memory, we ensure that the system retains relevant memories while managing storage efficiently. This improves trust by avoiding overwhelming the wearer with too much information or outdated data.

2. **What small change unlocks it**

   Define a cache size limit of 10 entries for both faces and names in the local memory on the phone.

3. **Likely payoff**

   A fixed cache size will help maintain a balance between having enough relevant memories to support conversations and avoiding clutter that could distract or overwhelm the wearer. This will enhance trust by providing just-in-time, useful information without overloading the user interface.

4. **Immediate next probe**

   Define one local-cache size limit of 10 entries for both faces and names on the phone.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By defining a clear boundary for what runs locally on the phone versus falling back to the cloud, we can ensure that V1 remains focused and reliable. This helps maintain the system's low-latency response times, which are crucial for real-time subtitles and memory support. Properly managed boundaries also enhance privacy by keeping sensitive data closer to home.

2. **What small change unlocks it**

   Define one phone/cloud fallback boundary specifically for live subtitle processing. For example, set a rule that all live subtitles should be processed locally on the phone, with cloud fallback only as a last resort if local processing fails or is too resource-intensive.

3. **Likely payoff**

   This focused approach will improve overall system reliability and user trust. Local subtitle processing ensures real-time responsiveness in noisy environments, while allowing for occasional cloud assistance when needed can provide backup without compromising on speed or privacy.

4. **Immediate next probe**

   Define one phone/cloud fallback boundary for live subtitle processing: all subtitles should be processed locally unless local resources exceed a certain threshold, at which point the cloud will assist.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   By carefully defining the visual hierarchy between subtitles and one-line support, we ensure that the most critical information is always clear and easy to read. This improves the wearer's ability to understand and respond effectively in real-time conversations without being overwhelmed by too much text or distracting elements.

2. **What small change unlocks it**

   Define a single rule that prioritizes subtitles over one-line prompts when both are available, with a fallback mechanism for when neither can be displayed due to space constraints.

3. **Likely payoff**

   This rule will ensure that the wearer focuses on the most important information first, reducing cognitive load and improving overall usability. It also helps maintain a clean visual interface, enhancing social acceptability and trust in the system's reliability.

4. **Immediate next probe**

   Define one visual priority rule between subtitles and one-line support: prioritize subtitles over one-line prompts when both are available.
