   By setting a clear local cache threshold for face/name memory, we can ensure that likely new-person memories are reinforced quickly while maintaining privacy and reducing battery drain. This helps balance the richness of personal memory support with the need for efficient, low-latency response.

2. **What small change unlocks it**

   Define a specific recency threshold (e.g., 30 minutes) beyond which face/name evidence is considered outdated and not cached locally on the phone unless explicitly remembered by frame touch.
