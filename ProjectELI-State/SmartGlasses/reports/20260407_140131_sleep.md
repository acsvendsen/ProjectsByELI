# Recent Project Signals Consolidation

## Strengthening Signals
- **Subtitle Clarity**: The importance of clear, fast, and stable subtitles is becoming more true as the system must maintain real-time trust in noisy environments.
- **Memory Trust**: The need for memory support that avoids pretending certainty or creating corrupted recall remains a key strength. This ensures that face/name recognition and prior conversation support are reliable without overconfident errors.

## Weakening Signals
- **Low-Friction Assistance**: The initial focus on low-friction assistance is becoming less true as the system should aim to deliver more useful, though not overwhelming, one-line prompts for better contextual understanding.

## Contradictions That Must Stay Alive
- **Privacy vs. Usefulness**: The tension between providing helpful assistance and respecting privacy must be managed carefully. This contradiction ensures that the system remains both useful and respectful of user boundaries.
- **Latency vs. Richness**: The need to balance timely responses with richer, though potentially slower, processing capabilities is a critical ongoing tradeoff.

## Dormant Ideas Worth Reactivating
- **Subtitle Placement and Visual Clarity**: Early signals suggest a focus on subtitle placement that remains socially acceptable while being readable in motion and noise. This idea should be reactivated as it will play a crucial role in the user experience.
  
## Concrete Tensions Around Core Focus Areas
1. **Subtitle Quality**:
   - **Fluff**: Ensure subtitles are clear, fast, and stable to build trust.
   - **Latency**: Balance real-time quality with processing constraints.

2. **Memory Reinforcement**:
   - **Automatic Memory Behavior vs Explicit Remember-Touch Behavior**: The system should rely on automatic memory reinforcement but allow explicit remember-touch behavior for critical corrections or reinforcements over time.
   - **Confidence Objects**: Use confidence objects to show the reliability of remembered information without overconfidence.

3. **Visual UX**:
   - **Subtitle Placement and Visual Hierarchy**: Design subtitles that are readable in motion and noise, ensuring they do not become distracting while remaining useful.

4. **Battery Constraints**:
   - **Always-On Sensing vs Battery Life**: Prioritize always-on sensing for critical features but manage battery usage through efficient processing strategies.

5. **Privacy Considerations**:
   - **Data Retention**: Ensure that memory and data retention practices respect user privacy without compromising on the system's usefulness.
   
## Open Questions to Address
- **Subtitle Placement**: Determine the best position and style of subtitles for readability in various environments.
- **Confidence Display**: Decide between a label-only, label + short reason, or score + label format for confidence display.
- **Memory/Cache Policy**: Define how much face/name memory should be cached locally on the phone to balance speed with privacy concerns.

## Core Mission Deepening
The system is becoming more focused on enhancing subtitle clarity and memory trust while reducing social friction through low-friction assistance. These improvements are critical for maintaining user trust and real-world utility in noisy environments, hearing-challenged situations, and dense multi-person contexts.
