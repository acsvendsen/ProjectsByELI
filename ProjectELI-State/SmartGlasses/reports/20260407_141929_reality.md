## Reality Check for SmartGlasses Project

### Subtitle Clarity: Real-time subtitle clarity (strength: high)

**Feasible now:**  
- **V1 Interaction:** The glasses should focus on delivering clear, fast subtitles that can be trusted in live conversation. Given the current setup with a phone-first architecture and minimal local processing, this is feasible through optimizing the `TranscriptLab` app for real-time transcript stability and clarity.

**Assumptions needing evidence:**
- Ensure that the subtitle rendering process is optimized to handle real-time updates without lag or distortion.
- Validate the subtitle placement and visual hierarchy using the current prototype in `TranscriptLab`.

### Memory Trust: Trustworthy memory support (strength: high)

**Feasible now:**  
- **V1 Interaction:** Implement basic face/name recognition and recall, ensuring that the system does not overpromise on certainty. The confidence objects should be designed to surface uncertainty clearly.
- Use the current `TranscriptLab` app to test real-time name and face memory support with clear indications of trust.

**Assumptions needing evidence:**
- Determine the best way to represent confidence in names and faces without creating false certainty.
- Test various confidence display formats (label only, label + short reason, score + label) for clarity and user trust.
