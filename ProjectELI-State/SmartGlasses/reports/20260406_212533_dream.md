### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Stabilizing subtitle placement rules helps ensure that subtitles remain clear, readable, and unobtrusive during live conversations. This improves the wearer's trust in the system by reducing visual distractions and ensuring consistent, reliable information flow.

2. **What small change unlocks it**

   Define a fixed subtitle position for V1 that remains stable across different confidence states. For example, always place subtitles at the bottom of the screen, slightly above the horizon line, with minimal horizontal offset to avoid overlapping with face regions or other critical UI elements.

3. **Likely payoff**

   By setting a consistent and unobtrusive subtitle position, V1 can deliver clearer, more reliable subtitles that help the wearer stay present during conversations without causing visual disruptions. This will enhance the overall user experience by maintaining focus on real-world interactions rather than on-screen information.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving the confidence display format can enhance the wearer's trust in the system by providing clear, concise, and reliable information about the accuracy of the subtitles and memory recall. This clarity helps the wearer understand when to rely on the system and when to seek additional context.

2. **What small change unlocks it**

   Define a confidence label that includes both a numeric score and a short reason for the score. For example, "score 0.9 + 'High' + 'Seen recently'" or "score 0.45 + 'Low' + 'Weak match'".

3. **Likely payoff**

   By providing clear and concise confidence information, the system can increase trust in its subtitle accuracy and memory recall. This will help users feel more confident when relying on the glasses for support, leading to a better overall user experience.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Improving local memory thresholds allows for faster and more reliable recall of names and faces during conversations. This directly supports the core attractors by enhancing memory trust, ensuring that the wearer can rely on accurate and up-to-date information without unnecessary cloud reliance.

2. **What small change unlocks it**

   Define a local cache size limit for face/name memory objects that triggers reinforcement over time based on recent encounters but does not continuously update in the background.

3. **Likely payoff**

   By setting a clear threshold for when new memories are cached locally versus being sent to the cloud, we can reduce latency and battery usage while ensuring that common interactions remain smooth and trustworthy. This will help maintain high memory trust without overloading the phone or cloud.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By defining a clear boundary for what stays phone-local versus what falls back to cloud for transcript cleanup, we can ensure real-time subtitle clarity and memory support remain stable and reliable without overloading the device. This helps in maintaining high confidence in the system's ability to assist the wearer effectively.

2. **What small change unlocks it**

   Define a specific task boundary where live subtitles processing remains phone-local, but background transcript cleanup falls back to the cloud when necessary. For example, keep real-time transcription and display on-device, but use the cloud for refining and archiving transcripts post-session.

3. **Likely payoff**

   This approach ensures that critical subtitle clarity is not compromised by network latency or cloud processing delays, maintaining trust in the system’s real-time assistance capabilities. It also allows for more robust memory support through off-device refinement without affecting immediate usability.

4. **Immediate next probe**
   - Define the boundary where live subtitle processing remains phone-local, but background transcript refinement falls back to the cloud.

   Ensuring a clear visual hierarchy between subtitles and one-line support helps maintain the wearer's focus on critical information while reducing cognitive load. This balance enhances both subtitle clarity and low-friction assistance, aligning with the core attractors of real-time subtitle clarity and low-friction assistance.

3. **Likely payoff**

It supports the core mission of providing clear and reliable assistance while minimizing unnecessary visual clutter.
