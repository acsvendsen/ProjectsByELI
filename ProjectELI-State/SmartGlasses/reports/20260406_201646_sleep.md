# Consolidation of Key Signals for SmartGlasses V1

## Strengthening Signals
- **Subtitle Clarity**: The real-time subtitle clarity must remain clear, fast, and stable to ensure the wearer can trust them during live conversations.
- **Trustworthy Memory Support**: Ensure memory support is reliable without overpromising or creating inaccurate recall. This includes remembering names and faces with confidence objects.

## Weakening Signals
- **Low-Friction Assistance**: Reduce the focus on low-friction one-line assistance, as it might become too intrusive or reduce social acceptability.
- **Automatic Memory Support**: Decrease emphasis on automatic memory support that lacks clear confidence and correction safety. This ensures the system is transparent in its recall accuracy.

## Contradictions That Must Stay Alive
- **Privacy vs Usefulness**: The balance between providing useful assistance and respecting privacy must be maintained to ensure the system is both helpful and respectful.
- **Latency vs Richness**: Strive for timely responses while avoiding overloading the runtime with richer but slower processing, ensuring a good balance.

## Dormant Ideas Worth Reactivating
- **Subtitle Placement and Visual Clarity**: Revisit the placement of subtitles to ensure they are readable in motion and noise without becoming distracting.
- **Confidence Display**: Explore different formats for confidence display (label only, label + short reason, score + label) to find the best balance between transparency and readability.

## Concrete Tensions Around Core Domains
1. **Subtitle Quality**:
   - **Tension**: The system must provide subtitles that are clear, fast, and stable without compromising on battery or thermal constraints.
   - **Current Focus**: Prioritize subtitle clarity over additional features that might degrade performance.

2. **Memory Policy**:
   - **Tension**: How much face/name memory should be cached locally versus relying on the cloud?
   - **Current Focus**: Cache minimal information necessary for fast lookup and reinforcement, ensuring this does not compromise privacy or trust.

3. **Visual UX**:
   - **Tension**: The system must maintain a discreet appearance while providing enough visual clarity to help the wearer.
   - **Current Focus**: Ensure that subtitle placement is optimized for readability without becoming visually intrusive.

4. **Privacy and Trust**:
   - **Tension**: Balancing the need for rich memory support with privacy concerns.
   - **Current Focus**: Use explicit remember-touch behavior and confidence objects to enhance trust while respecting user privacy.

## No Fluff
- **Subtitle Placement**: Ensure subtitles are placed in a way that is readable yet minimally intrusive, especially in noisy environments.
- **Confidence Display**: Develop a clear and simple confidence display format that builds trust without overwhelming the wearer.
- **Memory Policy**: Implement memory caching with clear reinforcement mechanisms to ensure names and faces are remembered accurately but not overly aggressively.

## Key Decision Areas
1. **Subtitle Quality**:
   - Focus on clarity, stability, and minimal latency.
2. **Memory Trust**:
   - Ensure names and faces are remembered accurately without creating false confidence.
3. **Discreet UX**:
   - Balance between social acceptability and sufficient visual clarity.

## Recent Open Questions
- **Subtitle Placement**: What is the best placement for subtitles to ensure readability in motion and noise?

By focusing on these key areas, we can strengthen the core mission of SmartGlasses V1 while maintaining a balance between utility and user experience.
