### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   By defining a fixed subtitle placement rule that ensures subtitles remain visible yet unobtrusive, we can enhance the wearer's ability to trust and understand the subtitles in real-time conversations without creating distractions. This stability will reinforce the core mission of improving understanding through clear, reliable visual aids.

2. **What small change unlocks it**

   Define a single subtitle placement rule that sets a fixed position on the glasses display, such as always appearing at the bottom-center of the field of view with minimal text overlap and consistent font size. This simple change will ensure subtitles are always visible without blocking key elements in the wearer's visual context.

3. **Likely payoff**

   By establishing a stable subtitle placement rule, we can reduce cognitive load for the wearer, ensuring they focus on the conversation rather than adjusting to varying subtitle positions. This consistency will enhance trust and understanding, aligning with the core mission of providing real-time assistance without distraction.

4. **Immediate next probe**
   - Define a fixed position subtitle placement rule that always appears at the bottom-center of the display with minimal text overlap and consistent font size.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving the confidence display format ensures that the wearer can trust the system's responses in real-time scenarios. By providing clear, concise, and understandable confidence labels and short reasons, the system can maintain its integrity while also making the user feel more secure about the information being presented.

2. **What small change unlocks it**

   Define a new confidence object format that combines a numeric score with a label and a short reason. For example: "score 0.84 + 'High' + 'Seen recently'; score 0.42 + 'Low' + 'Weak match'; score 0.63 + 'Medium' + 'Name heard once in introduction'. This format provides both precision and clarity, allowing the wearer to quickly understand the reliability of the information.

3. **Likely payoff**

   A well-defined confidence object format will enhance trust in the system by providing clear feedback on the certainty of the displayed information. This will help the wearer make better decisions based on the smart glasses' suggestions, leading to a more reliable and trustworthy user experience.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   By optimizing the local memory cache size to balance between rich memory support and fast lookup performance, we can ensure that the system remains responsive and useful without overwhelming the wearer's cognitive load.

2. **What small change unlocks it**

   Define a single local memory threshold for cached face/name data based on recent encounter frequency and recency. For example, prioritize caching faces/names seen within the last 30 days with at least three encounters each.

3. **Likely payoff**

   This small change will help in maintaining a streamlined yet comprehensive memory cache, ensuring that frequently encountered individuals are reliably remembered while not overburdening the local storage and processing capacity.

4. **Immediate next probe**
   - Set the cache size for face/name data to prioritize entries seen within the last 30 days with at least three encounters each.

The system can handle occasional cloud handoffs without breaking the wearer's experience, maintaining fast and accurate subtitles even under heavy load or limited on-device resources.
