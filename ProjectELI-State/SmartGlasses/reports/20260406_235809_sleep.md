# Consolidated Signals for SmartGlasses Project

## Strengthened Signals
1. **Subtitle Clarity**: Continue focusing on real-time subtitle clarity to ensure they remain clear, fast, and stable enough for trust in live conversations.
2. **Memory Trust**: Enhance memory support by ensuring names, faces, and prior context are remembered accurately without creating false certainty or recall errors.
3. **Low-Friction Assistance**: Prioritize low-friction assistance through one-line prompts to avoid unnecessary command overhead.

## Weakened Signals
1. **Always-On Sensing vs Battery and Thermals**: Reduce the focus on always-on sensing to minimize battery drain, as this is a hard constraint.
2. **Latency vs Richness**: Balance between timely responses and richer processing that might introduce latency issues. Optimize for real-time behavior first.

## Contradictions That Must Stay Alive
1. **Privacy vs Usefulness**: Maintain the tension between privacy concerns and the utility of assistive features to ensure the system remains both useful and respectful.
2. **Discreet UX vs Visual Clarity**: Keep the balance between maintaining a discreet user experience while ensuring subtitles are readable, especially in noisy environments.

## Dormant Ideas Worth Reactivating
1. **Subtitle Placement and Visual Hierarchy**: Revisit decisions on subtitle placement and visual hierarchy to ensure they remain socially acceptable yet clear for quick reading.
2. **Memory Cache Policy**: Consider the balance between caching face/name memory locally and cloud support for faster lookup and trust-building.

## Concrete Tensions Around Core Mission
1. **Subtitle Quality, Memory Reinforcement, Fast Lookup**:
   - **Subtitle Quality**: Ensure subtitles are clear, fast, and stable to maintain user trust.
   - **Memory Reinforcement**: Develop a system that reinforces memory over time without creating false certainty or privacy issues.
   - **Fast Lookup**: Prioritize fast lookup for commonly remembered names and faces while maintaining battery efficiency.

2. **Confidence Display**:
   - Ensure confidence is represented in a way that builds trust but does not overpromise accuracy.

3. **Automatic Memory Behavior vs Explicit Remember-Touch Behavior**:
   - Balance between automatic memory behavior that remembers new faces/names with explicit remember-touch behavior for correction and reinforcement.

4. **Visual UX**: Maintain low-friction UI while ensuring subtitles remain readable, especially in noisy environments.
   
5. **Battery Management**:
   - Focus on minimizing battery usage by optimizing subtitle clarity and real-time processing without overcomplicating the hardware.

6. **Privacy and Usability**:
   - Ensure that privacy concerns are addressed early to maintain user trust, but also provide useful features to enhance the wearer's experience.
