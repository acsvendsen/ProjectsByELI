### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Improving subtitle placement rules based on confidence levels will enhance the wearer's trust in the subtitles by ensuring they are always readable and not distracting, especially when the system is less certain about the speaker or context.

2. **What small change unlocks it**

   Define three subtitle placement rules: one for high-confidence scenarios (speaker is clearly visible and audible), one for medium-confidence scenarios (some uncertainty but still understandable), and one for low-confidence scenarios (speaker is hard to see or hear, requiring more stable placement).

3. **Likely payoff**

   By providing clear and stable subtitles based on the confidence level of the speaker, the system will maintain a high level of trust and reduce cognitive load during conversations. This ensures that even in less certain situations, the wearer can rely on the subtitles without distraction.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   By refining how confidence is displayed, we can ensure that the wearer always understands the reliability of the information being provided in real-time subtitles and memory support. This improves trust by making transparency a key feature of the system.

2. **What small change unlocks it**

   Define one format for confidence display that includes both a numeric score and a label with a short reason. For example, "Score 0.84 + 'High' + 'Seen recently'".

3. **Likely payoff**

   This approach will help the wearer quickly grasp the reliability of subtitles and memory support, leading to increased trust in the system's accuracy. It also sets clear expectations for when the information is most likely to be correct.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Ensuring that memory of names and faces is stored and reinforced with confidence objects helps maintain the wearer's trust in the system by providing accurate and reliable recall during conversations. This improves the overall assistive experience, making the wearer more confident in relying on the glasses for contextual support.

2. **What small change unlocks it**

   Define a local cache threshold for face/name memory that triggers periodic reinforcement checks with high-confidence matches only. This ensures that likely new-person memories are automatically stored and reinforced without overwhelming the phone's storage or battery.

3. **Likely payoff**

   By implementing a well-defined local cache threshold, the system can more effectively manage memory without excessive resource usage, leading to improved trust and reliability in face/name recall during conversations.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By refining the phone/cloud boundary for live subtitle processing, we ensure that real-time subtitle clarity is maintained, which directly supports the primary attractor of real-time subtitle clarity. This refinement helps in balancing local and cloud processing to minimize latency while ensuring that critical subtitle information is processed quickly and accurately.

2. **What small change unlocks it**

   Define a specific task boundary for live subtitle processing: prioritize all live subtitle generation tasks to run locally on the phone, with minimal fallback to the cloud unless absolutely necessary. This change ensures that the glasses can handle real-time subtitle demands without delay or reliance on potentially slower cloud services.

3. **Likely payoff**

   By keeping live subtitle processing local, we reduce latency and ensure that subtitles are displayed quickly and reliably, enhancing the wearer's trust in the system during conversations. This improvement will make the SmartGlasses more reliable for noisy environments where real-time accuracy is crucial.

4. **Immediate next probe**
   - Define the conditions under which live subtitle processing will fallback from the phone to the cloud.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   By defining a clear precedence rule between subtitles and one-line prompts, we ensure that the most critical information (subtitles) remains front and center while supplementary support (one-line prompts) does not overwhelm or distract the wearer. This helps maintain clarity and focus in noisy environments where real-time understanding is paramount.

2. **What small change unlocks it**

   Define a simple precedence rule: subtitles have higher visual prominence than one-line prompts, except when no subtitle is needed, in which case one-line prompts can take center stage.

3. **Likely payoff**

   This decision will enhance the wearer's trust in real-time information by ensuring that critical subtitles are always legible and not overshadowed by less urgent one-line prompts. It also reduces cognitive load by allowing the system to prioritize content based on its importance, which is crucial for maintaining situational awareness.

4. **Immediate next probe**

   Define a visual hierarchy rule where subtitles have higher precedence than one-line prompts, except when no subtitle is active.
