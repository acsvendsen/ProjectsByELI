# Consolidated Insights for SmartGlasses Project

## Strengthening Signals
1. **Subtitle Clarity**: Ensuring subtitles are clear, stable, and readable is crucial for maintaining trust during live conversations.
2. **Memory Trustworthiness**: Improving the reliability of face/name memory recall to support the wearer without overcommitting certainty or creating false memories.
3. **Low-Friction Assistance**: Enhancing one-line prompts and assistance to remain unobtrusive while providing helpful support.

## Weakening Signals
1. **Privacy vs Usefulness**: The tension between privacy concerns and the need for useful memory support should be managed to ensure effective assistive behavior without invasive data collection.
2. **Latency vs Richness**: Balancing the need for timely responses with the desire for richer, more detailed context requires careful trade-offs.

## Contradictions That Must Stay Alive
1. **Discreet UX vs Visual Clarity**: Ensuring the glasses remain socially acceptable while still providing clear and usable subtitles in noisy environments.
2. **Always-On Sensing vs Battery and Thermals**: The system must operate reliably but also manage power consumption to avoid overheating or draining the battery too quickly.

## Dormant Ideas Worth Reactivating
1. **Subtitle Placement and Visual Hierarchy**: Exploring optimal subtitle placements and visual hierarchies that enhance readability without causing distraction.
2. **Confidence Display Formats**: Investigating different confidence display formats (labels, scores, short reasons) to improve trust in the system's memory support.

## Concrete Tensions Around Subtitle Quality, Confidence Trust, Memory Reinforcement, Fast Lookup, Privacy, Latency, Battery, and Visual UX
1. **Subtitle Quality**:
   - Ensure subtitles are clear, stable, and readable (current score: 1.0).
2. **Confidence Trust**:
   - Manage the balance between providing helpful memory support and avoiding overcommitment to certainty.
3. **Memory Reinforcement**:
   - Develop a system for remembering names and prior conversations with confidence objects and reinforcement techniques.
4. **Fast Lookup Requirements**:
   - Balance the need for fast, reliable memory recall against the limitations of battery and thermal constraints.
5. **Privacy**:
   - Ensure that assistive behavior does not quietly slide into invasive data capture or retention practices.
6. **Latency**:
   - Maintain a balance between timely responses and the need to avoid overwhelming the runtime with rich processing.
7. **Battery**:
   - Minimize power consumption while ensuring reliable operation, especially for always-on features.
8. **Visual UX**:
   - Design subtitles and prompts that are clear, unobtrusive, and visually appealing.

## Open Questions
1. **Subtitle Placement**: Determine the best placement for subtitles to balance readability with social acceptability.
2. **Confidence Display**: Decide on the optimal format for confidence display (label only, label + short reason, score + label).
3. **Memory/Caching Policy**: Define how much face/name memory should be cached locally and how it should be reinforced over time.

## Next Steps
- Focus on improving subtitle clarity and stability.
- Enhance memory support to ensure trust without overcommitment.
- Manage the balance between low-friction assistance and social acceptability.
- Continuously surface real-world constraints early in development.
- Test different confidence display formats and subtitle placements to optimize user experience.

By addressing these priorities, the project can strengthen its core mission while respecting the current constraints and tensions.
