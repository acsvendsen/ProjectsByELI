## Core Field Consolidation

### Mission
Create smart glasses that act as a discreet, context-aware personal assistant focused on live subtitles, face/name recall, conversation memory, and one-line support to help the wearer understand and respond better in real-world interactions.

### Non-negotiables
- The glasses should assist without pretending knowledge the wearer does not have.
- Early hardware remains simple: display text, record audio/visual input; phone/cloud handles heavy processing.
- V1 interaction is frame-touch only; no voice activation or spoken command control.
- Context must persist across sessions.
- New faces and names should be remembered with confidence objects and reinforcement over time.

### Core Attractors
- **Subtitle Clarity**: Keep subtitles clear, fast, and stable enough to maintain trust in live conversations.
- **Memory Trust**: Ensure reliable name and face recall without creating false certainty or corrupted recall.
- **Low-Friction Assistance**: Provide one-line prompts that do not create unnecessary interaction overhead.

### Core Tensions
- **Privacy vs Usefulness**: Ensure assistive behavior does not intrude on privacy while providing valuable support.
- **Always-On Sensing vs Battery and Thermals**: Prioritize always-on sensing only when it can be done with minimal impact on battery life.
- **Local Processing vs Cloud Intelligence**: Prefer local processing where possible to reduce latency but ensure it remains practical given current hardware constraints.
