### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Stable subtitle placement rules in V1 help ensure that subtitles remain readable and do not become distracting, thereby maintaining trust and improving the wearer's ability to follow conversations in real-time.

2. **What small change unlocks it**

   Define a fixed subtitle placement mode where subtitles are positioned at the bottom of the screen, slightly above the center, with minimal movement unless there is a high-confidence speech event.

3. **Likely payoff**

   By keeping subtitles consistently placed and minimally animated, the user can maintain focus on the conversation without being distracted by constantly moving text, which enhances trust in the system's reliability.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving confidence display ensures that the wearer can trust the system's memory support and subtitle quality, which are key to maintaining a high level of assistance without creating social awkwardness or privacy concerns.

2. **What small change unlocks it**

   Define a consistent format for confidence objects, using a numeric score + label + short reason combination, to provide clear feedback on the reliability of the system's memory and subtitle accuracy.

3. **Likely payoff**

   By providing clear and concise confidence indicators, users will trust the system more, leading to better engagement and use of both memory support and subtitles in real-world interactions.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   By setting a local cache threshold for name recall, we can ensure that common names are quickly available without relying on cloud latency or frequent retraining, thus improving memory trust and overall assistive value.

2. **What small change unlocks it**

   Define a recency-based eviction policy that keeps frequently recalled names in the phone's local cache while evicting less used ones to maintain low memory usage.

3. **Likely payoff**

   This change will reduce latency for name recall, enhance the accuracy and trust of the system by ensuring common names are readily available, and align with the core deepening mission without adding complexity or battery strain.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**
   - By defining a clear boundary for what stays on the phone versus what falls back to the cloud, we can ensure that V1 remains focused and low-friction while still providing essential memory and confidence support.

2. **What small change unlocks it**
   - Define one specific task where live subtitle processing should stay entirely phone-local (e.g., real-time transcript cleanup), with any heavy lifting falling back to the cloud as needed for fallback or offline scenarios.

3. **Likely payoff**
   - By keeping subtitle rendering and initial processing on the phone, we can achieve near-real-time responses without draining battery or causing thermal issues. This will help maintain the core goal of real-time clarity and trustworthiness in live conversations.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**
   Enhancing the visual hierarchy ensures that subtitles remain prominent and readable while coexisting with one-line prompts in a way that does not overwhelm or distract the wearer. This helps maintain clarity and focus, which is crucial for real-time understanding.

2. **What small change unlocks it**
   Define a single subtitle placement rule where subtitles are always placed above the one-line support text but can be hidden if the confidence level is low enough to avoid visual clutter.

3. **Likely payoff**
   By ensuring that subtitles remain prominent and readable, the wearer can trust the real-time subtitles more easily during conversations. This reduces cognitive load and enhances the overall user experience by maintaining clear and unambiguous visual cues.

4. **Immediate next probe**
   - Define one visual priority rule between subtitles and one-line support in V1.
