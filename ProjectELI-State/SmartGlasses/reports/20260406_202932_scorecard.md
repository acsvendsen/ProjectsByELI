## Project Summary
The project is focused on creating smart glasses that provide real-time subtitles, memory support, and low-friction assistance while maintaining a discreet design. The current V1 aims to keep the hardware lightweight and dependent on minimal on-glasses computation, with heavy processing happening on the phone and cloud as needed.
