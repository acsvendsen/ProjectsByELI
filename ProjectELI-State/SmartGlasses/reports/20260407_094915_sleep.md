# Consolidation of Recent Project Signals

## Strengthening Signals
- **Subtitle Clarity**: The importance of real-time subtitle clarity has been reaffirmed, emphasizing that subtitles must remain readable, stable, and trust-preserving in live conversations.
- **Memory Trust**: Memory support is critical for remembering names, faces, and prior context without overconfidence or misleading the wearer. This aspect will continue to receive significant attention.

## Weakening Signals
- **Low-Friction Assistance**: While still important, the emphasis on low-friction assistance has slightly weakened. This suggests that the project might be shifting focus from minimizing command overhead to other core features such as subtitle clarity and memory trust.
  
## Contradictions That Must Stay Alive
- **Privacy vs Usefulness**: There remains a persistent tension between providing useful assistive behavior without infringing on privacy.

## Dormant Ideas Worth Reactivating
- **Subtitle Placement**: While no specific choice has been made, the need to determine an optimal subtitle placement that balances readability with non-distracting display is worth re-evaluating.
  
## Concrete Tensions Around Core Subtitle Quality, Confidence Trust, Automatic New-Person Memory, Memory Reinforcement, Fast Lookup, Privacy, Battery, and Visual UX
- **Subtitle Quality**: Ensuring subtitles are clear, fast, and stable remains a critical focus. This tension will continue to influence design decisions.
- **Confidence Trust**: The confidence display format (label, label+short reason, score+label) should be carefully considered to build trust without overloading the wearer.
- **Automatic New-Person Memory**: Establishing a robust automatic memory system for new faces and names is essential. This involves reinforcing memory over time while maintaining privacy.
- **Memory Reinforcement**: Local processing on the phone versus cloud intelligence must be balanced, ensuring memory is reinforced effectively but efficiently.
- **Fast Lookup**: The tradeoff between providing timely help and avoiding excessive latency remains a key tension.
- **Discreet UX vs Visual Clarity**: Display behavior should remain socially acceptable while still being readable in motion and noise.

## Key Open Questions
1. **Subtitle Placement**: What subtitle placement is most usable without becoming distracting?
2. **Confidence Display**: What confidence format builds trust best: label only, label + short reason, or score + label?
3. **Memory/Cache Policy**: How much face/name memory should be cached locally on the phone to support fast lookup and reinforcement?

## Current Core Deepening Focus
- The project will continue to deepen its core capabilities around subtitle clarity, memory trust, and low-friction assistance while surfacing real-world constraints early.

## Reality Check Rule
The system must continuously surface hardware, battery, thermal, latency, privacy, and usability limitations so that weak directions are identified quickly. This rule ensures the project stays grounded in practical realities.

## Core Field Summary
- The SmartGlasses mission remains to provide real-time subtitle assistance, memory support for names and prior conversations, and low-friction one-line prompts.
- V1 interaction will remain frame-touch only, with heavy processing primarily on the phone, and cloud optional where clearly justified.
