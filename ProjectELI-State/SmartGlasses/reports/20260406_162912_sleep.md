# Consolidation of SmartGlasses Project Insights

## Strengthening Signals
1. **Subtitle Quality**: Increasing focus on real-time subtitle accuracy and clarity is crucial for user trust and satisfaction.
2. **Face/Name Memory**: Enhancing the confidence in face/name recall with explicit remember-touch behavior will improve memory reinforcement and reliability.
3. **Memory Policy**: Implementing a recency-first caching policy to ensure that recent interactions are prioritized.

## Weakening Signals
1. **Overcomplex Interaction Patterns**: Avoiding early complexity in interaction methods, focusing on frame touches only.
2. **Feature Bloat**: Resisting the addition of unnecessary features such as voice commands or additional sensors before V1 is solidified.
3. **User Control Assumptions**: Avoiding assumptions about advanced user control modes like voice activation until explicitly justified.

## Contradictions That Must Stay Alive
1. **Privacy vs Usefulness**: Balancing the need for rich memory with the risk of privacy invasion.
2. **Battery and Thermals**: Ensuring that always-on features do not drain battery or cause excessive heat, impacting user comfort.
3. **Latency**: Maintaining low-latency responses to prevent trust issues.

## Dormant Ideas Worth Reactivating
1. **Subtitle Placement and Visual Hierarchy**: Revisit the balance between subtitle prominence and visual distractions to optimize readability without overloading the wearer.

## Concrete Tensions Around Subtitle Quality, Confidence Trust, Automatic New-Person Memory, Memory Reinforcement, Fast Lookup, Privacy, Battery, and Visual UX
1. **Subtitle Quality vs. Speed**: Striking a balance between real-time accuracy and minimal latency.
2. **Confidence Display**: Deciding on the best format for confidence (label only, label + short reason, score + label) to build trust without overwhelming the user.
3. **Automatic New-Person Memory vs. User Control**: Ensuring that new person memory is reinforced but not overly intrusive or dependent on frequent interactions.
4. **Memory Reinforcement**: Deciding how often and under what conditions to remind the wearer about previously seen faces/names for reinforcement.
5. **Fast Lookup**: Balancing between rich memory details and quick access to relevant information without cluttering the user interface.

## No Fluff
1. **Subtitle Placement**: Subtitles should be placed in a way that enhances readability but avoids distracting the wearer.
2. **Confidence Display**: Confidence should be displayed clearly but concisely, using labels or short reasons as needed.
3. **Memory Policy**: Memory should be stored and reinforced based on recency to ensure relevant information is readily accessible.
4. **Battery Management**: Optimize subtitle rendering and memory operations to minimize battery consumption.
5. **Visual UX**: Ensure the visual hierarchy prioritizes subtitles while maintaining a low-friction interface for one-line prompts.

## Open Questions
1. **Subtitle Placement and Visual Hierarchy**: What is the best placement for subtitles without causing distraction?
2. **Confidence Display**: How should confidence be represented (label only, label + short reason, score + label)?
3. **Memory Policy**: How much face/name memory should be cached locally on the phone versus stored in the cloud?
4. **Interaction Constraints**: What interactions should work offline and which require cloud support?
