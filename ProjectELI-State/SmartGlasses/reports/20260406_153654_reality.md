## Core Mission Feasibility

### Subtitle Placement: More Prominent
- **Feasible Now**: The glasses can display subtitles prominently but should avoid overwhelming the wearer with too much text. A balanced approach is needed to ensure readability while minimizing distraction.

### Confidence Display: Label + Reason
- **Feasible Now**: Implementing a simple label (e.g., "Confident", "Uncertain") along with a brief reason (e.g., "Based on recent interaction") can help users understand the system's reliability without overwhelming them. This approach strikes a balance between providing necessary information and maintaining usability.

### Memory/Cache Policy
- **Feasible Now**: Use best effort within the memory/cache policy to store new faces and names with automatic reinforcement over time. Explicit remember-touch behavior can be used for critical or prioritized cases where context supports it.

### Phone/Cloud Boundary: Phone First
- **Feasible Now**: Given the current V1 direction, focusing on a phone-first architecture is feasible. This approach minimizes hardware complexity while allowing the phone to handle more complex processing tasks.

### Visual Hierarchy: Subtitles Dominate
- **Feasible Now**: Ensure subtitles dominate the display but are readable and unobtrusive. The visual hierarchy should prioritize readability over feature density, ensuring that the most critical information is easily accessible.

## Interaction Constraints

### Frame Touch Only
- **Feasible Now**: Stick to frame touches for interaction in V1. Avoid introducing voice commands or other complex interactions until a clear justification arises later in the project lifecycle.

## Real-world Limits and Constraints

### Hardware, Battery, Latency, Privacy, and Usability
- **Battery Draw and Thermal Pressure**: Minimize battery draw by keeping local processing minimal. For example, use lightweight sensors for frame touches but rely on the phone for heavy processing.
- **Latency and Trust**: Ensure subtitles feel near-real-time to maintain trust. Any noticeable delay should be avoided as it can break the illusion of immediate understanding.
- **Privacy Perception**: Implement clear uncertainty indicators in memory recall to manage privacy concerns. Users should be able to understand when the system is uncertain about a face or name.

### Core-deepening Changes Over Broad Expansion
- **Core Mission Focus**: Prioritize improvements that deepen subtitle quality, memory trust, and confidence display over broader feature additions. This ensures V1 remains focused on core mission goals.
