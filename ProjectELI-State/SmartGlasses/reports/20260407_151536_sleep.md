# Consolidation of Recent Project Signals

## Becoming More True
- **Subtitle Clarity**: The importance of real-time subtitle clarity in noisy environments is increasing. Ensuring subtitles remain readable, stable, and trustworthy is crucial for the core mission.
- **Memory Trust**: There's a growing emphasis on building memory support that helps recall names, faces, and prior context without overpromising or creating corrupted recall. This aligns with the need to deliver helpful but honest assistance.

## Becoming Less True
- **Low-Friction Assistance**: The current focus is shifting slightly from low-friction one-line prompts towards a more reliable core loop that prioritizes subtitle quality and memory trust.

## Contradictions That Must Stay Alive
- **Privacy vs. Usefulness**: There's an ongoing tension between providing useful assistive behavior without compromising privacy, which must remain central to the project.
- **Latency vs. Richness**: The system should strive for timely responses while avoiding overloading the runtime with richer but slower processing.

## Dormant Ideas Worth Reactivating
- **Subtitle Placement and Visual Clarity**: These ideas are worth reactivating as they remain critical for usability, particularly in dynamic environments where clear subtitle placement is essential.
- **Face/Name Memory**: The need to remember names and faces with confidence objects and reinforcement over time remains a dormant idea that should be revisited.

## Concrete Tensions Around Core Mission
1. **Subtitle Quality vs. Memory Trust**:
   - **Subtitle Clarity**: Ensure subtitles are clear, fast, and stable.
   - **Memory Trust**: Build memory support without creating corrupted recall or overpromising certainty.

2. **Privacy vs. Usefulness**:
   - **Privacy Constraints**: Avoid quietly sliding into invasive capture or retention practices while still providing useful assistive behavior.

3. **Latency vs. Richness**:
   - **Real-Time Subtitles**: Maintain real-time responsiveness to avoid breaking trust.
   - **Rich Context**: Provide timely help without overloading the system with richer, slower processing.

4. **Discreet UX vs. Visual Clarity**:
   - **Subtitle Placement**: Ensure subtitles are placed and displayed in a way that is readable yet discreet.
   - **Visual Hierarchy**: Maintain a visual hierarchy that supports fast reading while minimizing distraction.

5. **Automatic Memory Behavior vs. Explicit Remember-Touch Behavior**:
   - **Automatic Memory**: Strengthen automatic memory support for names, faces, and prior context.
   - **Explicit Remember-Touch**: Preserve explicit remember-touch behavior to ensure the wearer's actions are respected in memory storage.

6. **Battery and Thermal Constraints**:
   - **Always-On Sensing**: Balance always-on sensing with battery and thermal constraints, ensuring V1 remains lightweight and socially acceptable.

7. **Cloud vs. Phone Processing**:
   - **Phone-First Runtime**: Bias towards phone-first processing for early iterations while allowing cloud support where clearly justified.
   
8. **Confidence Display**:
   - **Label + Short Reason**: Explore confidence formats that build trust, such as using a label with a short reason.

9. **Core Loop Deepening vs. Feature Sprawl**:
   - **Core Deepening**: Focus on subtitle quality, memory trust, and visual UX improvements rather than broad feature expansion.
   
10. **Interaction Constraints**:
    - **Frame-Touch Only V1**: Ensure all interactions remain controlled through frame touches, not voice commands.

## Open Questions
- **Subtitle Placement**: Determine the best placement without becoming distracting.
- **Confidence Display**: Decide on a confidence format that builds trust best (label only, label + short reason, score + label).
- **Memory/Cache Policy**: Determine how much face/name memory should be cached locally on the phone.

## Summary
The core mission of creating smart glasses for real-time subtitle clarity and trustworthy memory support remains central. The project must balance these goals with constraints around privacy, usability, and battery efficiency while focusing on refining core functionality rather than broad feature expansion.
