### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   By defining specific subtitle placement rules based on confidence levels, we can ensure that subtitles remain stable and unobtrusive while still providing clear and timely assistance to the wearer. This approach helps maintain trust in the system by balancing readability with minimal distraction.

2. **What small change unlocks it**

   Define two subtitle placement modes: one for high-confidence interactions where subtitles appear directly below the speaker, and another for lower-confidence interactions where subtitles are displayed slightly above or off-center but remain visible and readable.

3. **Likely payoff**

   This approach will reduce visual distraction during high-confidence interactions while ensuring that important information is always accessible. It will enhance the wearer's trust in the system by providing clear and timely assistance without overwhelming them with constant, potentially incorrect subtitles.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving the confidence display format helps ensure that the wearer can trust the subtitles and memory support provided by the glasses. A clear, concise, and reliable confidence indication is crucial for maintaining the user's trust in the system's ability to provide accurate information.

2. **What small change unlocks it**

   Define a simple yet effective confidence format using a numeric score combined with a short reason. For example, "Score 0.9 + 'Recent'" or "Score 0.45 + 'Weak match'". This format provides both a numerical indication of certainty and a qualitative hint about the source of the information.

3. **Likely payoff**

   By clearly indicating confidence in the subtitles and memory support, users can better understand when to trust the system's output. This reduces cognitive load by eliminating unnecessary doubt and enhances overall user trust and satisfaction.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Improving local memory thresholds ensures that likely new-person memories are stored more robustly on the phone, reducing reliance on cloud processing and enhancing V1's ability to handle real-time interactions effectively.

2. **What small change unlocks it**

   Define a local cache threshold for storing face/name recognition data, prioritizing new entities over older ones based on recent interaction frequency.

3. **Likely payoff**

   By setting a clear threshold for local memory storage, the system can maintain higher trust and reliability in name recall during critical interactions without overloading the cloud or compromising battery life.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   Staying within a phone-first architecture ensures that V1 remains lightweight and socially acceptable while preserving a path to stronger local capability later. This approach helps maintain battery efficiency, reduces thermal strain, and keeps the glasses hardware simple in early iterations.

2. **What small change unlocks it**

   Define one explicit fallback boundary between live subtitle processing on the phone versus cloud support for transcript cleanup or memory archive sync. For example, critical real-time subtitles should stay local to avoid latency issues that could break trust, while background tasks like cleaning up transcripts can safely use cloud resources.

3. **Likely payoff**

   By clearly defining this fallback boundary, V1 will have a more reliable and trustworthy user experience for critical real-time interactions. This ensures that the core mission of providing clear, stable subtitles is not compromised by potential latency issues when using cloud services.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   By defining a clear visual hierarchy between subtitles and one-line support, we ensure that the wearer can easily focus on live subtitles while still benefiting from low-friction contextual prompts without feeling overwhelmed or distracted.

2. **What small change unlocks it**

   Define a single subtitle placement rule where subtitles are always displayed at the bottom of the screen, with one-line support text appearing above them when needed, but not overlapping the main subtitles.

3. **Likely payoff**

   This approach maintains real-time subtitle clarity and stability while ensuring that low-friction assistance is still available without creating visual clutter. It respects the core mission by reducing social friction and enhancing readability in noisy environments.

4. **Immediate next probe**
   - Define one visual priority rule between subtitles and one-line support in V1.
