### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   By defining a fixed subtitle placement rule that ensures subtitles remain unobtrusive yet legible, the system can maintain focus on real-time clarity and trustworthiness in noisy environments. This helps the wearer stay present and informed without being distracted by variable or intrusive display behavior.

2. **What small change unlocks it**

   Define one static subtitle placement rule for V1 that keeps subtitles at a fixed position, such as directly below the speaker's face on screen. This eliminates the need for reactive adjustments based on confidence levels or visual context, ensuring consistent and unobtrusive placement.

3. **Likely payoff**

   A fixed subtitle placement will enhance the wearer's trust in the system by providing a stable and predictable interface. It also reduces battery usage compared to continuously adjusting subtitle positions, which can be computationally intensive. This stability supports the core mission of discreetly helping the wearer understand conversations better without unnecessary visual distractions.

4. **Immediate next probe**

   Define one static subtitle placement rule for V1 that places subtitles directly below the speaker's face on screen.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By defining a clear boundary for what stays phone-local versus what falls back to cloud, we can ensure that V1 interactions remain lightweight and efficient. This will help maintain the glasses' battery life and thermal management while ensuring critical functionality is handled locally where necessary.

2. **What small change unlocks it**

   Define explicit rules for live subtitle processing: all real-time subtitles should be processed on-device, while transcript cleanup (like adding timestamps or improving clarity) can fall back to the cloud if needed. This distinction will clarify what data needs local processing and what can leverage cloud resources when appropriate.

3. **Likely payoff**

   By keeping subtitle generation entirely phone-local, we can ensure that the glasses remain responsive and battery-efficient during live conversations. This will maintain trust and usability, allowing the wearer to rely on real-time subtitles without concerns about lag or power drain.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.
