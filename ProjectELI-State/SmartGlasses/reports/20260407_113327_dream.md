### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Ensuring stable subtitle placement that minimizes distraction while maximizing readability helps in maintaining real-time subtitle clarity (subtitle_clarity attractor). By defining clear placement rules, the system can ensure subtitles are always visible and legible without becoming intrusive during conversations.

2. **What small change unlocks it**

   Define a default subtitle position at the bottom center of the field of view that minimizes occlusion from hand gestures and maintains a stable layout regardless of head movement or gaze direction.

3. **Likely payoff**

   By setting a consistent, non-distracting subtitle placement rule, the system can enhance user trust in the subtitles’ reliability during conversations, contributing to higher real-time subtitle clarity (subtitle_clarity attractor).

4. **Immediate next probe**
   - Define a fixed position at the bottom center of the field of view for subtitle placement to minimize occlusion from hand gestures and maintain stability during head movement or gaze direction.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving the confidence display format will enhance the wearer's trust in the system by clearly communicating the certainty of the information presented. This is crucial for the core attractor of real-time subtitle clarity and memory support, as a well-designed confidence indicator helps the wearer understand when to rely on the subtitles or remember names with high confidence.

2. **What small change unlocks it**

   Define a simple numeric score + label + short reason format for confidence objects. This format will provide clear and concise information about the certainty of any given piece of memory or subtitle text, reinforcing the wearer's trust in the system.

3. **Likely payoff**

   By implementing a straightforward confidence display format, V1 can establish a reliable foundation for both subtitle clarity and memory support. Clear indicators will help the wearer understand when to rely on the system confidently, reducing cognitive load and enhancing overall user experience.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   By setting a clear local memory threshold for face/name recall, we ensure that the system efficiently uses phone resources while maintaining strong memory support. This balance helps in reducing unnecessary data storage and processing overhead, thereby conserving battery and thermal resources. The focus on local caching also improves response times and reduces latency, enhancing the overall trustworthiness of memory recall.

2. **What small change unlocks it**

   Define a local cache size limit for face/name memories that is large enough to handle typical daily interactions but not so expansive as to waste phone storage or processing power.

3. **Likely payoff**

   Implementing this local cache threshold will lead to faster and more reliable memory recall, reducing the burden on cloud services and improving the system’s responsiveness. It will also help in maintaining a balance between rich memory support and efficient resource usage, ensuring that the glasses remain socially acceptable and battery-efficient.

4. **Immediate next probe**

   Define one local-cache size limit for face/name memories, setting it to 20-30 entries to handle typical daily interactions while conserving resources.

4. **Immediate next probe**
