# Consolidated Insights for SmartGlasses Project

## Strengthening Signals

1. **Subtitle Clarity**: The importance of real-time subtitle clarity is increasing as it directly impacts the wearer's trust and understanding during live interactions. This signal underscores the need to prioritize a clear, stable, and fast subtitle display.
   
2. **Memory Trust**: Trustworthy memory support remains critical for remembering names, faces, and prior context without creating false certainty or recall issues. Enhancing this aspect will bolster user confidence in the system.

3. **Core Deepening Mode**: The focus on core deepening is strengthening. This mode encourages improvements in subtitle quality, memory trust, and visual UX over broad feature expansion, which is essential for maintaining the project's core mission.

## Weakening Signals

1. **Low-Friction Assistance**: While still important, this signal has somewhat weakened compared to the other two primary attractors due to its medium strength score (0.68). This suggests that efforts should be more concentrated on subtitle clarity and memory trust to ensure a stronger project focus.

2. **Constraint Pressure**: The emphasis on early surfacing of real-world constraints is weakening slightly as the project progresses, but this remains a critical ongoing process to prevent wasting time on non-viable directions.

## Contradictions That Must Stay Alive

1. **Privacy vs Usefulness**: This tension must continue to be managed carefully, ensuring that the system provides useful assistance without compromising user privacy.
   
2. **Latency vs Richness**: The balance between providing timely help and avoiding overloading the runtime with richer but slower processing needs constant attention.

3. **Discreet UX vs Visual Clarity**: Maintaining a low-friction UI while still delivering readable subtitles is an ongoing challenge that requires careful consideration of both design and functionality.

## Dormant Ideas Worth Reactivating

1. **Subtitle Placement and Visual Hierarchy**: These ideas remain dormant but are worth revisiting to find the best balance between readability and social acceptability.
   
2. **Cloud vs Phone Processing**: While currently not a primary focus, the decision on where heavy processing should occur (phone first or cloud) is important for future scalability.

## Concrete Tensions Around Subtitle Quality, Confidence Trust, Automatic New-Person Memory, Memory Reinforcement, Fast Lookup, Privacy, Latency, Battery, and Visual UX

1. **Subtitle Quality**: Ensuring subtitles are clear, stable, and readable in noisy environments remains a top priority.
   
2. **Confidence Trust**: The system must accurately represent its level of certainty to avoid creating false understanding or recall issues.

3. **Automatic New-Person Memory**: Managing the memory of new faces and names with confidence objects is crucial for building trust over time.

4. **Memory Reinforcement**: The process of reinforcing correct memories while avoiding incorrect ones should be optimized to enhance overall system reliability.

5. **Fast Lookup Requirements**: Ensuring that relevant information can be quickly accessed without overwhelming the wearer is essential for maintaining user trust and satisfaction.

6. **Privacy**: Striking a balance between providing useful assistance and respecting user privacy remains a critical tension.

7. **Latency**: The system must respond in real-time to maintain its value as an assistive tool, but this should not come at the cost of overloading the runtime with too much processing.

8. **Battery**: Balancing always-on sensing and subtitle generation against battery constraints is crucial for long-term wearability and usability.

9. **Visual UX**: Ensuring that subtitles and prompts are visually clear without becoming distracting or overwhelming is a significant challenge.

## Open Questions

1. **Subtitle Placement**: What placement ensures readability while remaining socially acceptable?
   
2. **Confidence Display**: How should confidence be represented to build trust (e.g., label only, label + short reason, score + label)?
   
3. **Memory/Cache Policy**: How much face/name memory should be cached locally on the phone?

4. **Phone/Cloud Boundary**: When and how should cloud processing be utilized in V1?

5. **Visual Hierarchy**: How can subtitles and prompts coexist to provide clear guidance without overloading the wearer?
