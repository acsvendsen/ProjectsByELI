### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Ensuring stable subtitle placement rules helps maintain consistent and predictable behavior, which is crucial for trust and reliability in real-time communication. Stable placement prevents distraction and ensures that subtitles remain readable and relevant without jumping or disappearing unexpectedly.

2. **What small change unlocks it**

   Define a set of fixed subtitle placement modes based on confidence levels: high-confidence (fixed position), medium-confidence (slightly adjustable but stable), and low-confidence (more flexible but still visible).

3. **Likely payoff**

   By implementing stable subtitle placement rules, the system will provide a more reliable user experience. Wearers can trust that subtitles will remain in their field of view without sudden movements or disruptions, which enhances overall usability and confidence.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   By refining the confidence display format to include a numeric score along with a label and short reason, we can provide more precise feedback to the wearer about the reliability of the information being displayed. This enhances trust by showing that the system is not only making assumptions but also providing evidence for those assumptions.

2. **What small change unlocks it**

   The small change involves modifying the confidence display format in the `TranscriptLab` app and ensuring that this updated format is reflected in the core subtitle and memory modules of the glasses software.

3. **Likely payoff**

   Implementing a more detailed confidence display will allow users to better understand the reliability of the subtitles and memory support provided by the glasses, thereby increasing trust and overall system acceptance. This enhanced transparency can lead to more accurate and useful interactions for the wearer in real-world scenarios.

4. **Immediate next probe**
   - Define the numeric score format for the confidence display in V1.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Improving memory cache policies for face/name recall ensures that new people are remembered accurately and with appropriate confidence over time. This strengthens the core mission by providing reliable support in noisy environments where recognizing and recalling names is crucial.

2. **What small change unlocks it**

   Define a local cache threshold that limits the number of recent face/name encounters stored on the phone, ensuring that the memory system remains efficient while still reinforcing recently seen entities.

3. **Likely payoff**

   By setting a clear local cache threshold, the system can focus on frequently encountered individuals and handle new faces more effectively without overwhelming the phone's memory or processing power. This improves the accuracy and reliability of face/name recall over time.

4. **Immediate next probe**
   - Define the local cache threshold to store up to 15 recent face/name encounters to balance memory efficiency with reinforcement effectiveness.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   Improving the phone/cloud boundary for live subtitle processing ensures that subtitles remain stable, clear, and timely. By keeping this critical function on-device, we prevent latency issues that could disrupt real-time understanding.

2. **What small change unlocks it**

   Define a rule that keeps all subtitle-related processing (transcription, rendering, and display) strictly phone-local until explicit user interaction or cloud fallback is necessary.

3. **Likely payoff**

   By keeping subtitle processing local, we ensure faster, more reliable subtitle delivery. This enhances the wearer's trust in the system during live conversations, aligning with our core attractor of real-time subtitle clarity.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   By optimizing the visual hierarchy to ensure subtitles remain clear and unobtrusive while also providing distinct visibility for one-line prompts, the system can enhance both subtitle clarity and low-friction assistance. This improves the wearer's ability to trust the subtitles in real-time conversations while ensuring they are not overwhelmed by additional information that might distract from their primary task of listening.

2. **What small change unlocks it**

   Define a visual hierarchy rule that prioritizes subtitles over one-line prompts when both are visible, with the subtitle placement mode set to `stable` and `consistent`. For scenarios where only one-line prompts are needed, ensure they do not overlap with subtitles or distract from them visually.

3. **Likely payoff**

   This change will likely result in a more harmonious visual environment that supports high subtitle clarity while minimizing distractions. It enhances the wearer's trust in the subtitles by ensuring they remain prominent and unobtrusive, thereby improving their overall understanding of real-time conversations.

4. **Immediate next probe**
   - Define one visual priority rule between subtitles and one-line support in V1.
