### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   By defining a fixed subtitle placement rule, we ensure that subtitles remain stable and predictable in different confidence states. This reduces cognitive load for the wearer, as they can focus on understanding the conversation without worrying about where to look next.

2. **What small change unlocks it**

   Define a single, default subtitle placement mode that positions subtitles at the bottom center of the field of view (FOV), regardless of confidence level or other factors.

3. **Likely payoff**

   Implementing this fixed subtitle placement rule will help maintain stability and reduce distractions for the wearer. It ensures that subtitles remain in a consistent location, making it easier to follow conversations even when the system's confidence in speaker identification is low.

4. **Immediate next probe**
   - Define a default subtitle placement mode that positions subtitles at the bottom center of the field of view (FOV).

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving the confidence display format helps ensure that the wearer can trust the system's output. By providing a clear and concise way to show the certainty of the information, the wearer can better understand when they should rely on the subtitles or seek clarification.

2. **What small change unlocks it**

   Define a new confidence format that includes both a numeric score and a short reason for the accuracy level. For example: "Score 0.84 (High) - Seen recently". This format provides more context than just a label, helping the wearer understand the reliability of the subtitle.

3. **Likely payoff**

   By implementing this new confidence format, the system will provide clearer and more transparent information to the user. This increased transparency can lead to higher trust in the subtitles, reducing misunderstandings during conversations and improving overall usage satisfaction.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

Improving memory cache retention ensures that frequently recalled entities, such as names and faces, remain available in the wearer's working memory without unnecessary refreshes or evictions. This enhances trust by ensuring that the system can quickly provide relevant information during conversations.

2. **What small change unlocks it**

Define a local cache eviction policy where recently used face and name memories are retained for a longer period (e.g., 1 hour) compared to other contextual data, which is only retained for a shorter duration (e.g., 10 minutes).

3. **Likely payoff**

By retaining frequently accessed memory items for longer periods, the system can reduce the need for the wearer to explicitly recall or re-enter information, thereby improving conversation flow and reducing cognitive load. This also reinforces the trust in the system's ability to provide relevant assistance without constant user interaction.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By defining a clear boundary for what stays on the phone versus falling back to the cloud, we can ensure that critical real-time subtitle processing happens locally, maintaining low latency and high reliability. This focus will enhance the core mission of providing trustable and timely assistance.

2. **What small change unlocks it**

   Define one specific task-boundary rule for live subtitle processing: all subtitles generated in real time should be processed on-device and never fallback to cloud-based processing unless explicitly justified by a critical need for additional computational resources or complex context analysis that cannot be handled locally within acceptable latency constraints.

3. **Likely payoff**

   By keeping the core real-time subtitle processing local, we can maintain high trust, reduce battery drain from constant connectivity, and ensure fast, reliable delivery of subtitles in noisy environments. This will also set a precedent for other critical tasks like live face/name recall to remain on-device until proven necessary otherwise.

4. **Immediate next probe**

   Define one specific rule for real-time subtitle processing that keeps all local subtitle generation within the phone's capabilities, avoiding cloud fallback unless there is an explicit and justified need for additional computational resources or complex context analysis.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   Ensuring a clear visual hierarchy between subtitles and one-line prompts enhances the wearer's ability to focus on essential information without distraction, thereby improving real-time understanding and reducing cognitive load.

2. **What small change unlocks it**

   Define a subtitle-vs-one-line priority rule that ensures one-line support text is displayed in a secondary visual layer, always visible but with reduced prominence compared to subtitles.

3. **Likely payoff**

   By clearly distinguishing between the primary (subtitles) and secondary (one-line prompts) display priorities, the wearer can more easily follow conversations while still being informed of critical contextual clues or reminders without feeling overwhelmed.

4. **Immediate next probe**
   - Define a visual hierarchy rule where subtitles have higher prominence than one-line prompts.
