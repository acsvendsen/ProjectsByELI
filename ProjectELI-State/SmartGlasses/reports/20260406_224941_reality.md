## Reality Check Summary

### Subtitle Placement
- **feasible now**: Ensure subtitles are placed where they can be read without distraction but remain unobtrusive. For instance, placing them at the bottom edge of the glasses might work well given that the wearer is looking ahead and can glance down quickly.

### Confidence Display
- **feasible now**: Use a simple label format to show confidence. A binary "high" or "low" label might suffice for initial V1 releases, with plans to refine this as more user feedback comes in.
  
### Memory/Cache Policy
- **feasible later**: Implement face and name memory caching on the phone but ensure it is minimalistic at first. Initial implementation could cache recent faces with a timestamp to refresh periodically.

### Phone/Cloud Boundary
- **feasible now**: Focus on making the current `TranscriptLab` app as close as possible to the future glasses experience while keeping cloud dependency optional where latency and battery constraints allow.
  
### Visual Hierarchy
- **feasible now**: Design subtitles and one-line prompts to coexist without overloading the wearer. Use different colors or fonts for subtitles vs. prompts, ensuring that subtitles are more prominent but not too distracting.

### Core Deepening Over Sprawl
- **feasible now**: Continue prioritizing subtitle quality improvements, memory trust, and visual UX enhancements. Any broader feature expansions should be grounded in concrete project needs rather than speculative ideas.

### Privacy vs Usefulness
- **feasible later**: Develop a privacy-preserving strategy that ensures the system does not silently capture or retain more data than necessary. Early focus on clear communication about what data is being used and why.
  
### Latency vs Richness
- **feasible now**: Ensure real-time subtitles remain stable and readable in live conversation, with minor latency trade-offs for richer features balanced against battery constraints.

### Discreet UX vs Visual Clarity
- **feasible now**: Design the subtitle placement to be socially acceptable while still being clear enough for quick reading. For instance, placing subtitles at the bottom of the glasses could ensure they are visible but not too distracting.

### Interaction Constraints
- **feasible now**: Keep V1 interaction through frame touches only, avoiding voice commands until explicit direction changes the core mode from `core deepening`.
