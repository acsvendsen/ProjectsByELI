- **Memory Reinforcement:** Use recency first caching on the phone to provide quick lookups and reinforce confidence in remembered faces/names.

### Core Field Summary

#### Mission
Create a discreet, context-aware personal assistant through live subtitles, face/name recall, conversation memory, and one-line support.

#### Non-negotiables
- Glasses help the wearer; do not pretend knowledge.
- V1 interaction is frame-touch only.
- Early hardware remains simple: display text, record audio/visual input; phone/cloud handles heavy processing.
- Context must persist across sessions.
- New faces/names should be remembered with confidence objects and reinforcement over time.

#### Core Tensions
- **Privacy vs. Usefulness:** Balance between providing helpful memory recall and maintaining user privacy.
- **Always-on Sensing vs. Battery and Thermals:** Ensure the system is always useful while minimizing battery drain and thermal issues.
- **Local Processing vs. Cloud Intelligence:** Use phone-first architecture for early versions, with cloud only where clearly justified.

#### V1 Real World Limits
- Keep glasses hardware simple in V1.
- Bias toward phone-first processing.
- Use cloud where it adds clear value and latency remains acceptable.
- UI should favor clarity over feature density.

#### Interaction Constraints
- V1 interaction controlled through frame touches only.
- No voice activation or spoken commands for subtitle management, mode switching, or confirmations in V1.
