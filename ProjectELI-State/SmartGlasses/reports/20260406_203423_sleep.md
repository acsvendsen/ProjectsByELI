# Consolidation of Recent Project Signals

## Strengthening Signals
1. **Subtitle Clarity**: The subtitle system must remain clear, fast, and stable enough for the wearer to trust them in live conversations. This emphasis is crucial as it directly impacts user trust.
2. **Memory Trust**: Names, faces, and prior context should be remembered accurately without creating false confidence or corrupted recall. Ensuring this helps maintain the system's credibility.

## Weakening Signals
1. **Low-friction Assistance**: While important, this signal has been slightly downgraded to a medium strength compared to subtitle clarity and memory trust. This reflects a need for more balance in the assistive features.

## Contradictions That Must Stay Alive
- **Privacy vs Usefulness**: The system must provide useful assistance without compromising privacy or creating an invasive capture scenario.
- **Latency vs Richness**: Timely responses are critical but should not come at the cost of overloading the runtime with richer, slower processing.

## Dormant Ideas Worth Reactivating
- **Subtitle Placement and Visual Hierarchy**: These ideas remain relevant for ensuring that subtitles are readable in motion and noise while not being distracting. This is a key UX consideration.
- **Confidence Display Format**: The choice between a label-only format versus a score + label format needs further exploration to build trust.

## Concrete Tensions Around Core Areas
1. **Subtitle Quality vs Battery Management**:
   - The system must provide near-real-time subtitles without draining the battery too quickly, which is critical for maintaining user trust and usability.
2. **Memory Trust vs Social Acceptability**:
   - While memory support should be accurate and reliable, it also needs to avoid creating a social awkwardness that might deter usage.

## Open Questions
- **Subtitle Placement**: What subtitle placement is most usable without becoming distracting?
- **Confidence Display Format**: How can we format confidence to build trust best: label only, label + short reason, or score + label?
