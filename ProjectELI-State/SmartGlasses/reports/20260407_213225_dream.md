### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   By defining a fixed subtitle placement rule for V1 that prioritizes stability over reactivity, we ensure that subtitles remain readable and unobtrusive during live conversations. This helps maintain trust in the system by providing consistent visual cues without overwhelming the wearer.

2. **What small change unlocks it**

   Define a single fixed subtitle placement mode where subtitles are displayed at the bottom of the screen, always visible but not overlapping with critical content like names or faces.

3. **Likely payoff**

   A stable subtitle placement that remains unobtrusive and readable will enhance the wearer's trust in the system during live interactions. This consistency reduces cognitive load and ensures that subtitles remain a reliable aid without distracting from the conversation flow.

4. **Immediate next probe**
   - Define a fixed position rule where subtitles are placed at the bottom of the screen for all V1 interactions.

   Improving the confidence display format ensures that the wearer can trust the subtitles and memory support more reliably. By clearly indicating the certainty level, the system can avoid creating false positives or misleading information, which is crucial for maintaining the core mission of helping the wearer understand better without pretending.

2. **What small change unlocks it**

   Define a simple confidence format using numeric scores, labels, and short reasons that are easy to read even in fast-moving conversations. For example, use "score 0.84 + 'High' + 'Seen recently'; score 0.42 + 'Low' + 'Weak match'; score 0.63 + 'Medium' + 'Name heard once in introduction'."

3. **Likely payoff**

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.
