### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   By establishing specific subtitle placement rules based on confidence levels, V1 can ensure that subtitles are always readable and trust-preserving in live conversation. This improves the overall real-time subtitle clarity attractor and aligns with the core mission of providing clear, fast, and stable support.

2. **What small change unlocks it**

   Define three fixed subtitle placement rules for different confidence states: 
   - High confidence (0.8+): Always on top of the frame.
   - Medium confidence (0.4-0.79): Placed in a corner or less prominent area but still visible.
   - Low confidence (<0.4): Suppressed to avoid distracting the wearer.

3. **Likely payoff**

   This small change will enhance subtitle readability and trustworthiness, ensuring that high-confidence subtitles are prioritized for clarity while lower-confidence ones do not overwhelm the wearer. It also aligns with the core attractor of real-time subtitle clarity and helps in managing the balance between useful information and visual distraction.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

Improving the local cache size and eviction policy for face/name memory helps ensure that frequently used or recently seen people are always quickly available to the wearer, enhancing the reliability of name recall during live interactions. This directly supports the "Trustworthy memory support" attractor by reducing the likelihood of needing cloud fallbacks or slow local searches.

2. **What small change unlocks it**

Define a simple cache eviction rule that keeps the most recently seen names and faces in local memory for up to 7 days, with less frequent contacts evicted after fewer interactions.

3. **Likely payoff**

By caching frequently used names and faces locally, the system can quickly provide name recall without needing cloud fallbacks, reducing latency and improving trust by ensuring fast, reliable recognition of known individuals during live interactions.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By defining a clear boundary for what runs phone-local versus cloud, we can optimize subtitle processing to remain real-time and stable, which is critical for trust in live conversations. This ensures that the glasses provide timely and accurate support without introducing latency that could break user confidence.

2. **What small change unlocks it**

   Define a specific task boundary: live subtitle processing should be done phone-local until memory archive syncs are required, but face/name recall lookup can fall back to cloud if needed.

3. **Likely payoff**

   By keeping subtitle processing local and only offloading memory-intensive tasks like face/name recall, we can ensure that subtitles remain fast and reliable in real-time interactions. This will strengthen the core mission of providing clear, trustworthy assistance without overburdening the glasses or introducing unnecessary latency.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   Ensuring a clear visual hierarchy between subtitles and one-line support helps maintain focus and readability for the wearer. By defining a specific precedence rule, we can ensure that critical information (subtitles) remains prominently displayed while supplementary information (one-line prompts) does not overwhelm or distract.

2. **What small change unlocks it**

   Define a simple visual priority rule: prioritize subtitles over one-line support when both are present. This can be achieved by adjusting the display precedence and prominence rules in V1 to route subtitle text above any one-line prompt during frame touches.

3. **Likely payoff**

   By clearly prioritizing subtitles, we enhance the wearer's ability to focus on critical information during conversations. This reduces cognitive load and improves overall usability, aligning with our core attractors of real-time subtitle clarity and low-friction assistance.

4. **Immediate next probe**

   Define one visual priority rule where subtitles are given precedence over one-line support during frame touches.
