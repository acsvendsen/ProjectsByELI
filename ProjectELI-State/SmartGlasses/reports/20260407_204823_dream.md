### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   By defining specific subtitle placement rules for different confidence states, we ensure that subtitles remain readable while minimizing distraction. This helps maintain real-time clarity and trust in live conversations.

2. **What small change unlocks it**

   Define three subtitle placement modes: default (fixed position), low-confidence (slightly lower on screen with less prominent visual styling), and high-confidence (maintained at the default position but with a more stable display).

3. **Likely payoff**

   This approach will improve subtitle readability and trust without overwhelming the wearer, thereby enhancing their overall understanding in noisy environments.

4. **Immediate next probe**
   - Define the default subtitle placement mode as a fixed position at the bottom center of the screen.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   By refining the confidence display format to include a numeric score, label, and short reason, we can enhance the trustworthiness and clarity of the system's output. This approach ensures that the wearer understands the level of certainty behind each piece of assistance provided, thereby reinforcing their belief in the system’s reliability.

2. **What small change unlocks it**

   The small change is to define a confidence object format for V1 that includes both a numeric score and a label with a short reason. For example:
   
   - Score 0.84 + "High" + "Seen recently"
   - Score 0.42 + "Low" + "Weak match"
   - Score 0.63 + "Medium" + "Name heard once in introduction"

3. **Likely payoff**

   This refinement will likely pay off by:
   
   - Increasing the trustworthiness of the system’s output through clear and concise confidence indicators.
   - Helping the wearer understand when to rely more on a piece of assistance versus when it might be less certain.
   - Reducing cognitive load by providing just enough information without overwhelming the user.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Improving the local cache size threshold for face/name memory helps ensure that frequently encountered individuals are remembered quickly and accurately, reducing the need for cloud-based fallbacks and improving overall trust in the system's memory support.

2. **What small change unlocks it**

   Define a local cache size limit for stored face/name objects, ensuring that only the most recently seen or frequently recalled entities remain cached on the phone.

3. **Likely payoff**

   By setting a clear threshold for local caching, the system can maintain faster and more reliable memory recall without overwhelming the device's limited storage space. This will enhance the wearer’s trust in the system's ability to remember names and faces effectively during real-time interactions.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By defining clear boundaries for what stays phone-local versus what falls back to cloud, we can ensure that V1 remains focused on delivering reliable real-time subtitle assistance and memory support without overloading the glasses hardware or compromising privacy.

2. **What small change unlocks it**

   Define a specific task boundary for live subtitle processing as being phone-local, with all other transcript-related tasks falling back to cloud.

3. **Likely payoff**

   This clear definition will reduce battery and thermal load on the glasses, ensuring that the core real-time subtitle functionality remains robust and usable in noisy environments. It also aligns with the project's focus on local processing while maintaining the ability to handle richer tasks when necessary.

4. **Immediate next probe**

   Define one phone-local vs cloud fallback boundary for exactly one task such as live subtitle processing.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**
   Improving subtitle placement rules can enhance the wearer's ability to focus on real-time conversation without visual distractions. Stable, unobtrusive subtitle placement ensures that subtitles remain readable and do not interfere with the natural flow of interaction.

3. **Likely payoff**
   This change will reduce visual distractions, improve readability in various scenarios, and reinforce the core mission of enhancing real-time understanding without overwhelming the wearer.

4. **Immediate next probe**
