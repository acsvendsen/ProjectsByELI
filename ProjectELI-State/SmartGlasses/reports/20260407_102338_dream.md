### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   By defining a fixed subtitle placement rule that minimizes distraction while ensuring readability, we can enhance the wearer's trust in the subtitles. This stability in placement will help reduce cognitive load and ensure that the subtitles are always visible and easy to read, even during rapid changes in conversation.

2. **What small change unlocks it**

   Define a single fixed subtitle placement rule that positions subtitles at the bottom of the screen, slightly above the baseline, and keep them there regardless of head or gaze movement. This simple rule will reduce the need for reactive adjustments and provide a consistent visual anchor.

3. **Likely payoff**

   Implementing this fixed subtitle placement rule will reduce distraction and ensure that the subtitles remain always visible and readable. This stability will help build trust in the system, making it more useful and reliable during live conversations.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving the confidence display format will enhance trust in subtitle accuracy and memory support. A clear and concise confidence label combined with a short reason will help users understand the reliability of the information provided, thereby reducing cognitive load and increasing user satisfaction.

2. **What small change unlocks it**

   Define a consistent confidence object format that includes both a numeric score and a short reason for its certainty level. For example: `score 0.84 + "High" + "Seen recently"`.

3. **Likely payoff**

   By providing clear and concise confidence information, users will feel more confident in the system's accuracy, leading to better overall trust and higher satisfaction with the product. This will also help users make informed decisions about when to rely on the system's memory or subtitles.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Memory cache policy that optimizes local memory thresholds for fast name recall enhances both subtitle clarity (real-time support) and memory trust (reliable face/name recognition). By setting a robust local cache size, we ensure names are quickly accessible without unnecessary cloud requests, reducing latency and preserving privacy.

2. **What small change unlocks it**

   Define a two-tiered caching policy where common faces/names are cached locally on the phone with frequent updates, while less-frequent encounters have a longer refresh interval. This tiered approach ensures that frequently encountered names are always available for quick lookup.

3. **Likely payoff**

   By implementing this tiered cache policy, we can reduce the number of cloud requests significantly, improving subtitle clarity and response time. This will also enhance memory trust as users will see consistent, fast recall without privacy concerns from frequent cloud queries.

4. **Immediate next probe**

   Define one local-cache size limit for common faces/names with a short refresh interval (e.g., 1 day) and another larger cache size for less-frequent encounters with longer intervals (e.g., 7 days).

### Idea 4: Phone/Cloud Boundary

   By refining the subtitle placement rules to prioritize stable, non-distracting positions, we can enhance the wearer's trust in the subtitles without overwhelming their visual field. This stability improves real-time clarity and ensures that the subtitles remain a reliable aid during conversations.

This will likely result in a smoother user experience and increased trust in the subtitles' accuracy.

4. **Immediate next probe**
