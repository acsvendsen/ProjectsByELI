### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Stabilizing subtitle placement rules ensures that subtitles remain readable and unobtrusive, reducing cognitive load on the wearer and maintaining trust in the system's assistance.

2. **What small change unlocks it**

   Define two fixed subtitle placement modes: one for high-confidence speech (e.g., clear speakers) where subtitles can be placed at a lower visual priority, and another for low-confidence situations (e.g., noisy environments or hard-to-identify speakers) where subtitles should be more prominent.

3. **Likely payoff**

   By providing stable subtitle placement rules, the system will maintain readability in all contexts while minimizing distraction, thereby enhancing user trust and the overall assistive experience without adding complexity to V1 interactions.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   By refining the confidence display format to use a numeric score + label + short reason, we can provide users with a clearer understanding of the system's certainty in its memory and face/name recognition. This approach enhances trust by offering a transparent and precise measure of accuracy.

2. **What small change unlocks it**

   Introduce a new confidence object format that includes a numeric score (e.g., 0.84), a label describing the level of certainty (e.g., "High"), and a short reason for why this score was assigned (e.g., "Seen recently").

3. **Likely payoff**

   This refined confidence display will help users understand the system's reliability in real-time, thereby increasing their trust in the memory and face/name recall features. Clear and consistent confidence indicators can reduce uncertainty during critical interactions, making the glasses more effective as a daily-use assistant.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Ensuring that likely new-person memory is automatically remembered by default helps maintain a low-friction user experience while reinforcing the system's trustworthiness through consistent and reliable behavior. This approach minimizes the need for explicit memory capture, thereby reducing social awkwardness and cognitive load on the wearer.

2. **What small change unlocks it**

   Define a simple entity-linking rule that automatically attaches new evidence to existing person-memory objects when a likely new face or name is encountered, with minimal user intervention required.

3. **Likely payoff**

   This approach will reduce the need for explicit memory capture and reinforce the system's trustworthiness by showing consistent, reliable behavior in recognizing and remembering new people. It will also minimize social awkwardness and cognitive load on the wearer, leading to a more natural and helpful experience.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By defining a clear phone/cloud boundary for transcript cleanup, we ensure that real-time subtitle processing remains efficient on-device while more complex memory and context handling can leverage cloud resources when needed without compromising battery life or thermal performance.

2. **What small change unlocks it**

   Define one task-specific cloud fallback boundary, specifically for the live subtitle processing task. This will allow critical operations like subtitle generation to remain local while delegating less time-sensitive tasks such as face/name recall lookup and memory archive sync to the phone/cloud whenever necessary.

3. **Likely payoff**

   Establishing a clear and specific cloud fallback boundary for live subtitle processing will reduce battery drain and thermal load on the glasses, ensuring that subtitles are always fast and reliable. This improvement also allows for more complex background tasks like detailed face recognition and memory reinforcement to be handled off-device without affecting real-time performance.

4. **Immediate next probe**

   Define one phone/cloud fallback boundary for exactly live subtitle processing: when should local subtitle generation fail over to the cloud?

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   By defining a clear visual hierarchy between subtitles and one-line support, we ensure that the wearer can easily follow the conversation while receiving necessary contextual prompts without feeling overwhelmed. This improves daily-use value by maintaining focus and reducing cognitive load.

2. **What small change unlocks it**

   Define a single visual priority rule where subtitles always take precedence over one-line support when both are present on screen simultaneously, with one-line support fading or being suppressed if necessary to avoid distraction.

3. **Likely payoff**

   This approach will enhance the wearer's ability to follow conversations in real-time without feeling overwhelmed by too much information. It will maintain trust and reduce cognitive strain, leading to a more seamless and effective assistive experience.

4. **Immediate next probe**

   Define one visual priority rule between subtitles and one-line support: subtitles always take precedence when both are present on screen simultaneously.
