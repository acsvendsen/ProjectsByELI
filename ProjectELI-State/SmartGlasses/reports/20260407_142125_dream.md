### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Ensuring stable subtitle placement enhances the wearer's trust in real-time subtitles, which is crucial for maintaining their focus and understanding during live conversations.

2. **What small change unlocks it**

   Define two fixed subtitle placement rules: one for high-confidence states (e.g., well-known speakers) where subtitles should remain visible but not obstructive, and another for low-confidence states (e.g., new or less familiar speakers) where subtitles can be more prominent to ensure clarity.

3. **Likely payoff**

   By implementing stable placement rules based on confidence levels, the system will provide a consistent and reliable experience that enhances trust and understanding without causing visual distractions during critical moments of conversation.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving the confidence display format in V1 will enhance the wearer's trust in both subtitles and memory support. A clear, concise confidence indicator helps the wearer understand the reliability of the information being provided without overwhelming them with technical details.

2. **What small change unlocks it**

   Change the confidence display to use a numeric score + label + short reason format for all confidence objects. For example, "score 0.84 + 'High' + 'Seen recently'".

3. **Likely payoff**

   By implementing this improved confidence format, we can ensure that the wearer has better insight into the reliability of the subtitles and memory support. This clarity will help in maintaining trust and reducing cognitive load by providing succinct yet meaningful feedback.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Improving the local cache threshold for face/name memory ensures that frequently encountered individuals are stored in a fast, accessible location on the phone. This reduces latency and improves trust by ensuring that key people are always readily available when needed.

2. **What small change unlocks it**

   Define a specific recency or frequency threshold for storing new faces and names locally on the phone. For example, store any face/name encounter more than once in the last 30 minutes in local memory with high confidence.

3. **Likely payoff**

   By implementing a clear threshold, the system can quickly recall important individuals during conversations without requiring cloud assistance, enhancing real-time performance and trust in the memory support provided to the wearer.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By defining a clear boundary for what runs on the phone versus what falls back to cloud, we can ensure that V1 remains focused and reliable. This decision will help maintain low latency and battery efficiency while preserving the core functionality of real-time subtitles and memory support.

2. **What small change unlocks it**

   Define one task-specific cloud fallback boundary, such as live subtitle processing, which should run on the phone to avoid excessive cloud calls and ensure fast response times.

3. **Likely payoff**

   By keeping live subtitle processing local, we can reduce latency, ensure reliability, and maintain high-quality real-time subtitles without burdening the battery or network. This will enhance user trust and satisfaction by providing a seamless and responsive experience.

4. **Immediate next probe**
   - Define the cloud fallback boundary for live subtitle processing to run locally on the phone.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   By defining a clear precedence rule between subtitles and one-line support, we ensure that subtitles remain the primary focus for real-time understanding, while one-line support provides relevant contextual information without overwhelming the wearer.

2. **What small change unlocks it**

   Define a visual hierarchy rule that gives priority to subtitles during fast-moving conversations, with one-line support displayed when necessary but not distracting.

3. **Likely payoff**

   This will enhance the overall user experience by maintaining clarity and focus on real-time subtitles while still providing useful one-line support without causing cognitive overload or distraction.

4. **Immediate next probe**

   Define a subtitle-vs-one-line priority rule, setting the subtitle display to always take precedence during active conversations, with one-line support shown only when needed and not overlapping the subtitles.
