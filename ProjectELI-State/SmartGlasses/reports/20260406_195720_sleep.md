# Recent Consolidation for SmartGlasses V1

## Strengthening Signals

### Subtitle Clarity
- **Consolidation**: Real-time subtitle clarity remains a top priority. The system must provide clear, fast, and stable subtitles to ensure the wearer can trust them in live conversation.
- **Implication**: Focus on refining subtitle algorithms to improve readability and stability.

### Memory Trust
- **Consolidation**: Memory support should be trustworthy, helping the wearer recall names, faces, and prior context without creating misleading certainty or corrupted recall.
- **Implication**: Develop robust memory reinforcement mechanisms that can be reinforced over time with confidence objects.

### Low-Friction Assistance
- **Consolidation**: One-line contextual prompts should provide low-friction assistance that enhances understanding without introducing command overhead or social awkwardness.
- **Implication**: Prioritize designing one-line prompts that are concise and actionable, ensuring they do not overwhelm the user.

## Weakening Signals

### Discreet UX vs Visual Clarity
- **Consolidation**: While discreet UX is important, visual clarity remains a critical factor. The system must balance social acceptability with readability in noisy environments.
- **Implication**: Focus on optimizing subtitle placement and visual hierarchy to ensure they are both visually clear and socially acceptable.

### Battery and Thermals vs Always-On Sensing
- **Consolidation**: Early versions should prioritize battery and thermal constraints over always-on sensing. This will help manage the initial hardware load effectively.
- **Implication**: Limit continuous live processing on the glasses and rely more heavily on phone-side processing to reduce power consumption.

## Contradictions that Must Stay Alive

### Privacy vs Usefulness
- **Consolidation**: The system must strike a balance between providing useful assistive features and respecting user privacy. Invasive capture or retention should be avoided.
- **Implication**: Implement clear privacy policies and ensure all memory is handled with the utmost care to maintain user trust.

## Dormant Ideas Worth Reactivating

### Confidence Display
- **Consolidation**: The need for a robust confidence display that builds trust while avoiding overconfidence remains relevant. This includes deciding on the best format (label, score + label, etc.) and implementation.
- **Implication**: Revisit confidence display design to ensure it effectively communicates the reliability of the information provided.

## Concrete Tensions around Core Components

### Subtitle Quality vs Memory Richness
- **Consolidation**: The system must balance subtitle quality with memory richness. High-quality subtitles should not come at the cost of useful contextual memory support.
- **Implication**: Develop a mechanism to prioritize memory reinforcement for new or important interactions while maintaining clear and stable subtitles.

### Confidence Objects vs Fast Lookup
- **Consolidation**: Ensuring confidence objects are well-established and can be reinforced over time is crucial. However, this must not compromise the ability to provide fast lookup capabilities.
- **Implication**: Design a system that can dynamically adjust between detailed memory reinforcement and quick, relevant lookups based on context.

### Memory Policy vs Visual Hierarchy
- **Consolidation**: The memory policy should be designed to support both rich contextual memory and a clean visual hierarchy for subtitles. This will ensure the user can easily follow along without feeling overwhelmed.
- **Implication**: Implement a clear strategy that integrates memory reinforcement with subtitle placement and visual clarity.

## Open Questions

### Subtitle Placement
- **Consolidation**: The best V1 subtitle placement is still an open question. It needs to be both readable in motion and noise, yet not overly distracting.
- **Implication**: Continue exploring different subtitle placements to find the optimal balance between readability and social acceptability.

### Confidence Format
- **Consolidation**: Deciding on the best confidence format (label only, label + short reason, score + label) is still unresolved. This will impact how users trust the system.
- **Implication**: Conduct further research or testing to determine the most effective way to communicate confidence levels.

### Memory Caching
- **Consolidation**: The optimal amount of face/name memory that should be cached locally on the phone remains an open question. This affects both battery and performance.
- **Implication**: Develop a caching strategy that balances local storage with cloud access, ensuring efficient use of resources while maintaining useful recall.

## Summary

The core mission of SmartGlasses V1 is to provide real-time subtitles, face/name recall, conversation memory, and one-line support in a discreet and low-friction manner. The system must continuously balance these elements against constraints like privacy, battery, and social acceptability. Strengthening subtitle clarity, ensuring memory trust, and maintaining a low-friction experience are key priorities. Open questions around subtitle placement, confidence display, and memory caching need further exploration to find the best implementation paths.
