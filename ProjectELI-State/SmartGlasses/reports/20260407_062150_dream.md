### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   By defining stable subtitle placement rules that prioritize readability and minimize distraction, V1 can ensure that subtitles remain clear and unobtrusive during live conversations. This improves the wearer's ability to follow the conversation without feeling overwhelmed by visual clutter.

2. **What small change unlocks it**

   Define three fixed subtitle placement modes: top-center (default), bottom-right (secondary), and bottom-left (third). These modes will apply based on confidence levels, with higher confidence subtitles appearing in the default position for ease of reading.

3. **Likely payoff**

   This approach ensures that high-confidence subtitles are always placed in a stable, prominent location, enhancing readability and trust. Lower-confidence subtitles can be relegated to less intrusive positions, reducing visual clutter without compromising understanding.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving the confidence display format ensures that the wearer can easily understand the reliability of the memory support and subtitles. This clarity helps in building trust and ensuring that the wearer can make informed decisions based on the system's outputs.

2. **What small change unlocks it**

   Define a simple, clear confidence format that uses both a numeric score and a short reason. For example: `score 0.85 + "High" + "Seen recently"`.

3. **Likely payoff**

   By clearly indicating the confidence level of each memory or subtitle, the wearer can better trust the system's outputs. This will lead to higher user satisfaction and more effective use of the product in real-world scenarios.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   By defining a clear local memory threshold for face/name recall, we ensure that the system retains only relevant and frequently encountered entities, which strengthens trust through stable behavior and reduces cognitive overload on the wearer.

2. **What small change unlocks it**

   Define a local cache size limit of 10 recent face/name encounters per person, with a recency threshold of 7 days for each entry.

3. **Likely payoff**

   This change will help maintain a balanced memory support system that retains only highly relevant and frequently encountered names/faces while ensuring fast lookup times without overwhelming the wearer's cognitive load.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By defining clear boundaries for what runs phone-local versus what falls back to cloud for live subtitle processing, we ensure that real-time subtitles remain stable and fast enough to be trusted in live conversations. This helps maintain high clarity and consistency in the wearer's experience, which is critical for the core attractor of "Real-time subtitle clarity."

2. **What small change unlocks it**

   Define a single task boundary: **live subtitle processing**. For this specific task, all heavy processing should remain phone-local to ensure real-time performance without cloud latency.

3. **Likely payoff**

   By keeping live subtitle processing local, we can maintain a consistent and stable subtitle experience for the wearer. This reduces battery drain from frequent cloud queries and ensures that subtitles are always available in noisy or low-connection environments. The result is higher trust in the system's reliability and real-time performance.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   By defining a visual hierarchy that prioritizes subtitles over one-line prompts in low-confidence scenarios, we ensure that the wearer remains focused on critical information. This deepens the core attractor of real-time subtitle clarity by maintaining trust and reducing cognitive load during high-noise or uncertain situations.

2. **What small change unlocks it**

   Define a rule to show subtitles as primary visual elements until the confidence level drops below a certain threshold, at which point one-line prompts should take precedence without disrupting the subtitle flow.

3. **Likely payoff**

   This change will enhance the wearer's ability to follow conversations by maintaining clear and continuous subtitles while still providing necessary contextual support when needed. It balances the core attractors of real-time clarity and low-friction assistance, improving overall user experience without overwhelming the wearer with too much information.

4. **Immediate next probe**
   - Define one visual priority rule between subtitles and one-line support in V1.
