### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Improving subtitle placement rules will enhance the wearer's ability to trust and understand real-time subtitles, which is critical for the core attractor of real-time subtitle clarity. Stable and unobtrusive subtitle placement ensures that the wearer can focus on the conversation without being distracted by inconsistent or shifting text.

2. **What small change unlocks it**

   Define a fixed subtitle placement rule that positions subtitles below the speaker’s face but above the current frame edge, ensuring they remain in view while minimizing visual intrusion during movement.

3. **Likely payoff**

   This simple yet effective placement rule will reduce subtitle lag and visual distraction, enhancing the wearer's ability to follow conversations accurately. It also aligns with the core attractor of real-time subtitle clarity by providing a stable and predictable layout that supports trust in the system.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Improving the local cache size for face/name memory ensures that frequently encountered individuals are remembered more accurately and quickly, reducing the need to rely on cloud-based lookups or manual reinforcement. This enhances trust by providing consistent and reliable memory support without overloading the wearer with too much information.

2. **What small change unlocks it**

   Define a local cache size limit for face/name entities that balances between storing enough recent encounters to provide quick recall and minimizing thermal and battery impact. For example, setting a maximum of 50 unique faces/names with a recency threshold of the last week.

3. **Likely payoff**

   By limiting the local cache size but ensuring high recency, the system will be able to quickly retrieve recently seen names and faces without frequent cloud queries. This reduces latency and power consumption while maintaining strong memory support for daily interactions.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By defining a specific boundary for what stays phone-local versus what falls back to cloud, we ensure that V1 focuses on delivering high-value, low-latency subtitle and memory support without overloading the glasses or creating privacy concerns.

2. **What small change unlocks it**

   Define one task-specific cloud fallback boundary for exactly one critical operation, such as live subtitle processing.

3. **Likely payoff**

   This approach will reduce battery drain on the glasses by keeping heavy processing off-device and prevent privacy issues by ensuring that only essential data is transmitted to the cloud. It also allows for more robust memory support through background syncing without compromising real-time responsiveness.

4. **Immediate next probe**

   Define one cloud fallback boundary for live subtitle processing where the glasses send audio input to the phone for transcription, then display subtitles on-device with minimal latency.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   By defining a clear visual hierarchy between subtitles and one-line prompts, we can ensure that the wearer focuses on crucial information without being overwhelmed by additional UI elements. This helps maintain clarity and reduces cognitive load, aligning with our mission to provide low-friction assistance.

2. **What small change unlocks it**

   Define a subtitle-vs-one-line priority rule where subtitles are always shown first, but one-line prompts can temporarily suppress the subtitle display if they contain critical information that needs immediate attention from the wearer.

3. **Likely payoff**

   By implementing this visual hierarchy, we can ensure that the most important information (subtitles) remains visible and readable while still providing necessary contextual support (one-line prompts) without causing distraction or confusion.

4. **Immediate next probe**

   Define one visual priority rule between subtitles and one-line support where subtitles always take precedence in display order.
