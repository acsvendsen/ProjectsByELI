### Idea 1: Subtitle Placement

1. **Why it benefits the core**

Subtitle placement rules that are stable and predictable improve user trust and understanding by providing a consistent experience across interactions. This consistency ensures that the subtitles remain unobtrusive while still being easily readable, which aligns with the core attractor of "Real-time subtitle clarity."

2. **What small change unlocks it**

Define fixed subtitle placement modes for different confidence levels: high-confidence, medium-confidence, and low-confidence placements.

3. **Likely payoff**

By defining these fixed modes, V1 can ensure that subtitles are always placed in a way that minimizes distraction but still provides clear visibility. This approach will help maintain user trust by providing reliable placement rules, which is crucial for the core attractor of "Real-time subtitle clarity."

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   By refining the confidence display format to use a simple numeric score with a clear label and short reason, we can enhance the wearer's trust in the system without overwhelming them with complex or narrative information. This approach ensures that the user understands the reliability of the displayed content, which is crucial for maintaining their confidence in real-time interactions.

2. **What small change unlocks it**

   The small change involves defining a new confidence format that uses a numeric score combined with a label and short reason. For example, "score 0.84 + 'High' + 'Seen recently'; score 0.42 + 'Low' + 'Weak match'; score 0.63 + 'Medium' + 'Name heard once in introduction'."

3. **Likely payoff**

   Implementing this confidence format will provide the wearer with a clear and concise indication of the system's certainty, which can help them better understand the reliability of the displayed information. This clarity can reduce cognitive load and increase trust, making the smart glasses more effective as an assistive tool in real-world interactions.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   By setting a local cache size limit for face/name memory objects, we ensure that the system maintains a balance between rich memory support and fast lookup performance. This helps in reducing latency and improving trust by quickly retrieving relevant information without overloading the phone's processing power.

2. **What small change unlocks it**

   Define a local cache size of 10-15 face/name memory objects on the phone, ensuring that only the most recently interacted with people are stored locally for fast retrieval. This limit can be adjusted based on real-world usage data and testing.

3. **Likely payoff**

   By limiting the local cache to a small number of recent interactions, we reduce the risk of privacy concerns due to excessive memory storage while still providing relevant support for frequently encountered individuals. This approach also optimizes battery use by minimizing continuous cloud syncs and reducing thermal strain on the device.

4. **Immediate next probe**

   Define a local cache size limit of 10 face/name memory objects on the phone for fast lookup and reinforcement over time.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By defining a clear boundary for what stays phone-local versus falling back to cloud processing, we can ensure that critical subtitle and memory tasks are handled efficiently on the device, reducing latency and preserving battery life. This helps maintain real-time responsiveness and trust, which are core attractors of the project.

2. **What small change unlocks it**

   Define a simple rule for live subtitle processing: all audio input and initial transcription should be processed locally on the phone before any fallback to cloud-based improvements or corrections.

3. **Likely payoff**

   By keeping critical audio processing local, we can achieve faster response times, lower power consumption, and more reliable performance in noisy environments. This enhances trust by ensuring that subtitles are accurate and timely, meeting the core attractor of real-time subtitle clarity.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.
