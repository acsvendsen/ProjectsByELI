# Reality Check Summary

## Subtitle Placement: Feasible Now
- **Subtitle Clarity**: The glasses must provide real-time subtitles that are clear enough for the wearer to trust them in live conversations.
- **Constraints**: Given current hardware constraints, subtitle placement needs to be designed such that it does not become distracting. A bottom-center placement is feasible and likely minimizes distraction while still providing sufficient visual clarity.

## Confidence Display: Feasible Now
- **Label Only vs Label + Short Reason vs Score + Label**: Use a label only approach in V1 as it strikes the best balance between clarity and simplicity.
- **Constraints**: Battery and latency constraints must be considered, but given the focus on core-deepening work, this is currently feasible.

## Memory/Cache Policy: Feasible Now
- **Face/Name Memory Storage**: Store face and name memory on the phone with periodic reinforcement to ensure trust. Use a confidence object approach where new memories are initially marked as uncertain and gain certainty over time.
- **Constraints**: Local storage must respect battery limits, so frequent updates should be managed carefully.

## Phone/Cloud Boundary: Feasible Now
- **Phone First Runtime**: The system should primarily rely on the phone for heavy processing with cloud support only where clearly justified. This aligns with current V1 constraints and keeps the implementation simple.
- **Constraints**: Battery and thermal limits must be respected, so avoid over-relying on cloud services.

## Visual Hierarchy: Feasible Now

- **Constraints**: The design must ensure low friction for the user, which can be achieved through careful placement and color differentiation.
