### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Stable subtitle placement rules improve the wearer's trust in real-time subtitles by ensuring that the text remains visually consistent and predictable, even as attention shifts or the environment changes. This reduces cognitive load and enhances comprehension during live interactions.

2. **What small change unlocks it**

   Define a fixed subtitle placement rule where subtitles are always displayed at the bottom of the frame, slightly to one side but not covering important visual information, and update this rule only when explicit user input is provided through frame touches.

3. **Likely payoff**

   By stabilizing subtitle placement, wearers can rely on a consistent visual format that remains unobtrusive yet visible, leading to better real-time understanding in noisy environments. This will also help in maintaining the discreet UX design goal without overwhelming the wearer's peripheral vision.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**
   - By refining the confidence display format, we can ensure that the wearer has a clear and trustworthy understanding of the system's certainty about the information being provided. This will enhance the overall trust in the subtitle and memory support features, which are critical for the core mission.

2. **What small change unlocks it**
   - Define a simple numeric score + label + short reason format for confidence objects. For example: "score 0.84 + 'High' + 'Seen recently'; score 0.42 + 'Low' + 'Weak match'; score 0.63 + 'Medium' + 'Name heard once in introduction'".

3. **Likely payoff**
   - A clear and concise confidence format will reduce cognitive load for the wearer, as they can quickly understand the reliability of the information being provided. This will lead to a more trusting interaction experience, which is crucial for maintaining the core mission of helping the wearer understand better without pretending understanding.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Ensuring that memory recall is reliable and fast enhances the wearer's trust in the system, which is crucial for the core mission of helping the wearer understand better without creating social awkwardness or command overhead.

2. **What small change unlocks it**

   Define a local cache threshold for name recall on the phone to ensure quick access to recently seen faces and names, reducing the need for cloud fallbacks and minimizing latency.

3. **Likely payoff**

   By setting a specific threshold for local name recall, the system can provide fast and accurate memory support, enhancing user trust and satisfaction without increasing battery drain or thermal load.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   Ensuring that subtitle processing remains phone-local for live captioning tasks aligns with the project's mission of providing real-time, reliable subtitles in noisy environments without burdening the glasses or draining their battery.

2. **What small change unlocks it**

   Define a specific task boundary where live subtitle processing runs on the phone and only falls back to the cloud as a last resort for memory lookups or other tasks that can tolerate higher latency.

3. **Likely payoff**

   By keeping live subtitles local, we ensure faster, more reliable performance in critical real-time scenarios, enhancing trust and utility without straining battery resources.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   Ensuring a clear visual hierarchy between subtitles and one-line prompts helps maintain the wearer's focus on critical information without overwhelming them with too much text. This balance enhances overall understanding and reduces cognitive load, ensuring that the assistive behavior remains both helpful and unobtrusive.

2. **What small change unlocks it**

   Define a subtitle vs. one-line priority rule where subtitles have higher precedence but are not automatically hidden when one-line prompts are displayed. Instead, allow for coexistence with one-line prompts showing above or to the side of subtitles in a non-overlapping manner.

3. **Likely payoff**

   By maintaining a clear visual hierarchy, users can trust that critical information (subtitles) will always be visible and prominent, while still receiving contextual support when needed through shorter one-line prompts. This approach enhances the wearer's understanding and confidence without creating visual clutter or social awkwardness.

4. **Immediate next probe**

   Define one subtitle-vs-one-line priority rule where subtitles have higher precedence but are not automatically hidden when one-line prompts are displayed.
