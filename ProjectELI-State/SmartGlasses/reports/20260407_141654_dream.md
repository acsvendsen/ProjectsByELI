### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Improving subtitle placement rules in V1 will enhance the wearer's trust by ensuring subtitles remain readable and stable during live conversations, even when the frame is moved or the environment changes.

2. **What small change unlocks it**

   Define two fixed subtitle placement rules: one for static environments (e.g., meetings) where the glasses are likely to stay in place, and another for dynamic environments (e.g., walking) where the glasses may move frequently.

3. **Likely payoff**

   By providing consistent and stable subtitle placement, users will feel more confident that they can rely on the subtitles during critical moments of conversation. This consistency also helps reduce cognitive load by minimizing distractions from constantly adjusting to changing placements.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving the confidence display format enhances trust in memory recall, which is crucial for the wearer's ability to rely on the system during real-world interactions. Clear and accurate confidence indicators help the user understand the reliability of the memory assistance provided.

2. **What small change unlocks it**

   Define a consistent confidence object format that includes both a numeric score and a qualitative label along with a brief reason, e.g., "score 0.84 + 'High' + 'Seen recently'". This format provides the user with a clear indication of the certainty level and context behind each memory recall.

3. **Likely payoff**

   By implementing a clear and consistent confidence display, the system will build trust through transparent communication about the reliability of its memory assistance. This improved trust can lead to better user adoption and more effective use of the SmartGlasses during critical interactions.

4. **Immediate next probe**
   - Define the format for presenting confidence scores in V1, including a numeric score, qualitative label, and brief reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Enhancing the local cache threshold for face/name memory objects can improve the stability and trustworthiness of person recall, ensuring that likely new people are remembered correctly without overwhelming the system with frequent refreshes or unnecessary memory updates.

2. **What small change unlocks it**

   Define a local cache threshold for face/name memory objects based on recent encounters. For example, set a recency rule where names heard in the last 15 minutes should be cached locally to ensure fast recall and confidence over time.

3. **Likely payoff**

   By setting a reasonable recency threshold, V1 can provide more reliable and timely name recall without overburdening the system with frequent cloud syncs or local updates. This will enhance trust in memory support during live interactions.

4. **Immediate next probe**

   Define one face/name memory cache eviction rule where names heard in the last 15 minutes are cached locally for fast lookup, while older memories use a less frequent refresh policy.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   Ensuring that live subtitle processing remains phone-local allows V1 to maintain minimal latency and clear, stable subtitles in noisy environments. This directly supports the primary attractor of real-time subtitle clarity.

2. **What small change unlocks it**

   Define a local subtitle processing boundary such that all speech-to-text transcription happens on the phone before any data is sent to the cloud for additional processing or memory updates.

3. **Likely payoff**

   By keeping subtitle processing locally, V1 can ensure near-real-time responses and stable, readable subtitles in noisy environments. This enhances user trust and the overall core mission of helping the wearer understand better in real-world interactions.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   By defining a clear visual hierarchy between subtitles and one-line support, we ensure that the wearer can focus on essential information without feeling overwhelmed by too much text at once. This improves their ability to follow conversations, recall important details, and respond appropriately.

2. **What small change unlocks it**

   Define a priority rule where subtitles are always shown first, with higher confidence levels given more prominence. One-line support should be displayed only when there is space and high-confidence subtitles do not require additional context.

3. **Likely payoff**

   By focusing on essential information, the wearer can process conversations faster and retain important details better. This enhances overall understanding without overwhelming the user, leading to a more effective and less distracting assistive experience.

4. **Immediate next probe**
   - Define one visual priority rule between subtitles and one-line support in V1.
