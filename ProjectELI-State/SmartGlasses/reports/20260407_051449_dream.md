### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Ensuring stable subtitle placement helps maintain consistent, predictable behavior that builds trust with the wearer. Reliable subtitle positioning reduces cognitive load by making the subtitles easily readable and unobtrusive, which is crucial for real-time understanding in noisy environments.

2. **What small change unlocks it**

   Define a fixed subtitle placement rule that positions subtitles slightly above and to the right of the speaker's face on the display. This minimizes overlap with facial features while ensuring the text remains easily readable.

3. **Likely payoff**

   By implementing this fixed placement rule, the system will provide more predictable and stable subtitle behavior, reducing visual clutter and enhancing the wearer’s ability to follow conversations in real-time. This can lead to higher trust and better user satisfaction.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving confidence display by defining a clear format that combines numeric scores with concise labels and short reasons will enhance trust in the system's memory and subtitle accuracy. This will help the wearer understand when they can rely on the system without overloading them with unnecessary details.

2. **What small change unlocks it**

   Define a simple confidence format: `score [label] + " [reason]"`. For example, a high-confidence match could be displayed as `0.95 High + "Recent mention"`, and a low-confidence match as `0.40 Low + "Weak match"`.

3. **Likely payoff**

   By clearly displaying confidence levels, the system will appear more reliable and less prone to errors or false positives. This will build trust in the wearer's mind that the system is providing accurate information when they need it most.

4. **Immediate next probe**

   Define one confidence format candidate for V1: `score [label] + " [reason]"`.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Improving local memory thresholds helps ensure that frequently encountered people are remembered quickly and accurately, enhancing overall trust in the system's face/name recall capabilities. By setting a lower threshold for caching new evidence on the phone, the system can more reliably provide fast lookups for names and faces, which is crucial for the wearer to feel supported without delay.

2. **What small change unlocks it**

   Define a local cache size limit of 10-15 entries that triggers automatic memory updates from the cloud only when an entry drops below a threshold confidence score (e.g., 0.6 or lower). This ensures that frequently encountered individuals are cached locally for faster recall, while less common interactions still benefit from cloud support.

3. **Likely payoff**

   By setting this local cache size limit, the system will more effectively manage memory overhead and provide fast, reliable face/name recall. This improves user trust in the system’s ability to remember important people without causing performance issues or excessive data usage.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   Ensuring that live subtitle processing remains phone-local optimizes battery life and thermal management while maintaining real-time responsiveness. This focus on local processing ensures that critical assistive features like subtitles are not hindered by potential latency issues, which could reduce trust.

2. **What small change unlocks it**

   Define a clear rule that all live subtitle processing must remain on the phone, with no fallback to cloud under any circumstances for V1.

3. **Likely payoff**

   By keeping live subtitle processing entirely on the phone, we ensure real-time responsiveness and stable placement of subtitles, enhancing user trust and the overall core functionality of providing real-time assistance in noisy environments.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   By defining a clear visual hierarchy between subtitles and one-line support, the system can ensure that critical information is always visible and easy to read, while non-essential prompts do not interfere with the main conversation. This enhances the wearer's trust in the product by maintaining a clean and focused interface.

2. **What small change unlocks it**

   Define two subtitle placement rules: one for high-confidence face/names and another for general context or low-confidence content. Use a simple coexistence rule to ensure that both types of information are displayed without clashing, with higher-priority items (high-confidence faces/names) given more prominence.

3. **Likely payoff**

   This change will improve the overall user experience by ensuring that critical information is always readable and not overshadowed by less important prompts. It will help maintain a clean interface while still providing necessary support, thereby reinforcing trust in the product's capabilities.

4. **Immediate next probe**
   - Define one visual priority rule between subtitles and one-line support in V1.
