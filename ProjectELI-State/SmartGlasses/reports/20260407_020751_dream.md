### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Improving subtitle placement rules based on confidence levels will ensure that subtitles are always readable and do not become distracting. This will maintain trust in real-time subtitle assistance, which is crucial for the wearer's understanding and overall user experience.

2. **What small change unlocks it**

   Define two subtitle placement rules: one for high-confidence faces/names where subtitles can be placed closer to the visual center, and another for low-confidence situations where subtitles should appear at the bottom of the display to avoid distraction.

3. **Likely payoff**

   By optimizing subtitle placement based on confidence, the system will reduce cognitive load and maintain focus during critical interactions. This will enhance trust in real-time assistance and improve overall user satisfaction.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   By refining the confidence display format to include a numeric score along with a label and short reason, we can provide users with more nuanced feedback on the reliability of the memory and subtitle information. This improves trust by showing that the system is aware of its own limitations, which aligns with the mission of not pretending understanding.

2. **What small change unlocks it**

   Modify the confidence display to include a numeric score as part of the label format, ensuring it appears alongside a short reason for the confidence level. For example, if the system identifies someone by name, it could show "Name: John (Score 0.9 + 'Recent encounter')." This small change leverages existing memory and confidence objects but adds numerical transparency.

3. **Likely payoff**

   The addition of a numeric score to the confidence display will enhance the user's trust in the system's accuracy by providing concrete evidence of its reliability. Users will better understand when they can rely on the information provided, leading to more effective use of the assistant during critical conversations.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Improving memory cache thresholds helps ensure that relevant and frequently encountered names and faces are always available for quick recall, enhancing the wearer's understanding and confidence in social interactions without overwhelming the local storage.

2. **What small change unlocks it**

   Define a local-memory threshold rule that prioritizes caching new people based on recent encounters and repeated face detection, while allowing older or less frequent entries to be evicted to keep memory cache size manageable.

3. **Likely payoff**

   By optimizing memory cache thresholds, the system can ensure that critical names and faces are readily available for fast recall, improving the wearer's ability to stay present and engaged in conversations without the risk of information overload. This also helps maintain privacy by limiting the retention of less relevant data.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**
   - By defining clear boundaries for local processing versus cloud fallback, we ensure that critical real-time subtitle assistance remains stable and fast on-device, while less time-sensitive tasks can leverage cloud resources to enhance overall system capability.

2. **What small change unlocks it**
   - Define one specific task boundary for live subtitle processing: all live subtitles should be generated locally on the phone to ensure real-time performance and stability. For transcript cleanup or memory archive sync tasks, fall back to the cloud when feasible.

3. **Likely payoff**
   - By keeping live subtitle generation local, we can maintain consistent and reliable subtitle placement without introducing latency from network requests. This will enhance user trust in the system’s ability to provide real-time support in noisy environments.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   Ensuring that subtitles are prioritized correctly in visual hierarchy can improve the wearer's ability to focus on real-time conversations while minimizing distraction. By clearly defining how subtitles and one-line prompts coexist, we can enhance the overall user experience without overwhelming the wearer.

2. **What small change unlocks it**

   Define a clear visual priority rule that ensures subtitles are given higher precedence over one-line prompts when both are visible. This rule should favor subtitles by making them more prominent or by temporarily suppressing one-line prompts when subtitles need to be read.

3. **Likely payoff**

   By prioritizing subtitles, we can improve the wearer's ability to follow live conversations in noisy environments, leading to better comprehension and reduced cognitive load. This improvement will directly support the core attractors of real-time subtitle clarity and low-friction assistance.

4. **Immediate next probe**

   Define one visual priority rule between subtitles and one-line support where subtitles are given higher precedence when both are visible.
