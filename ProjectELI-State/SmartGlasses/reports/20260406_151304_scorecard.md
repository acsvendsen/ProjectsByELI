## Project Summary
The SmartGlasses project is focusing on delivering discreet, context-aware personal assistance through live subtitles, face/name recall, conversation memory, and one-line support. The V1 will use frame-touch interaction exclusively, with minimal hardware compute to ensure lightweight design. Key areas of focus include optimizing subtitle placement for readability without distraction, implementing a clear confidence display format, and defining effective memory policies that balance utility with privacy.
