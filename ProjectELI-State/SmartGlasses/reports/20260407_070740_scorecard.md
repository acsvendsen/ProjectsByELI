## Project Summary
The SmartGlasses project is focused on delivering real-time subtitles that are clear and trustworthy while supporting contextual memory in a discreet manner. The current V1 architecture prioritizes frame-touch interactions, phone-first processing, and minimal hardware complexity to maintain social acceptability and battery efficiency.
