# Reality Check

## Subtitle Clarity: Real-time subtitle clarity (strength: high)

### Feasible Now:
- **Subtitle Placement**: The current `TranscriptLab` app allows testing different subtitle placements on the screen without adding heavy hardware dependencies. This is a feasible and critical task for ensuring subtitles are readable in noisy environments.
  
  - **Assessment**: Use `TranscriptLab` to test various subtitle placement options, such as bottom center or side margins, while ensuring they do not interfere with the wearer's peripheral vision.

### Feasible Later:
- **Visual Hierarchy and Placement**: Once basic subtitle clarity is established in V1, consider refining visual hierarchy for better readability during motion. For instance, testing dynamic adjustments based on head movements could be a future direction.
  
  - **Assessment**: Conduct tests to see if dynamically adjusting subtitle placement based on the wearer's head position improves readability without adding significant latency.

### Likely Waste of Time:
- **Complex AR Visuals and Effects**: Adding complex augmented reality visuals or special effects to subtitles, such as animations or pop-ups, is likely a waste of time for V1. These features can be distracting and increase complexity without immediate benefit.
  
  - **Assessment**: Focus on basic clarity first; if the need arises in future iterations, revisit this consideration.

## Memory Trust: Trustworthy memory support (score: 0.78; strength: high)

### Feasible Now:
- **Face/Name Recall Implementation**: Implement basic face/name recall by storing and reinforcing confidence objects using simple touch interactions. This can be done on the phone for V1.
  
  - **Assessment**: Use `TranscriptLab` to test how stored face data is recalled in real-time and ensure it provides a smooth, non-intrusive experience.

### Feasible Later:
- **Memory Reinforcement Over Time**: Enhance memory support by reinforcing remembered faces and names over time through repeated interactions. This can be done using cloud-based reinforcement learning.
  
  - **Assessment**: Develop algorithms that track how frequently stored face data is accessed and use this information to prioritize updates.

### Likely Waste of Time:
- **Automatic Memory Support Without User Feedback**: Adding automatic memory support without user feedback mechanisms could lead to false positives or incorrect recall, potentially damaging trust. Focus on user-driven interactions for now.
  
  - **Assessment**: Ensure any memory support features are tied to explicit user actions and provide clear options for correction.
