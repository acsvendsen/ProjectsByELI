### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Ensuring stable subtitle placement rules enhances the wearer's trust in the system by providing a predictable experience. Stable subtitle placement helps maintain readability and focus, which is crucial for understanding live conversations. By defining clear and consistent subtitle positioning, the system can better support the wearer without causing distraction or confusion.

2. **What small change unlocks it**

   Define two subtitle placement rules: one for high-confidence speakers (e.g., frequent participants in current conversations) and another for low-confidence speakers (new or less familiar individuals). This simple rule set ensures that critical information is always prioritized, while less certain information remains readable but secondary.

3. **Likely payoff**

   By implementing stable subtitle placement rules based on confidence levels, the system can significantly improve the wearer's ability to follow conversations and retain important details. This will enhance the overall user experience by reducing cognitive load and ensuring that crucial information is always at hand.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   By refining the confidence display to use a clear numeric score alongside a label and short reason, we can enhance trust in the system's judgments without overwhelming the wearer with too much information. This will help maintain a balance between providing enough context for the user and keeping the interface clean.

2. **What small change unlocks it**

   Define a single confidence format that combines a numeric score, a label (like "High," "Medium," or "Low"), and a short reason (e.g., "Seen recently," "Weak match"). For example: "0.84 High Seen recently."

3. **Likely payoff**

   This change will provide the wearer with more precise feedback on the reliability of the system's judgments, thereby increasing trust and confidence in the subtitles and memory support. It also ensures that the display remains readable and uncluttered.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Memory support is crucial for maintaining trust in name recall and conversation memory. By optimizing how new faces and names are stored and reinforced, we can ensure that the system correctly remembers and retrieves important information over time without overwhelming the wearer with unnecessary details.

2. **What small change unlocks it**

   Define a local cache threshold for face/name memory objects on the phone. This threshold will limit the number of face/name entries kept in local memory to reduce clutter while ensuring recent interactions are remembered with high confidence.

3. **Likely payoff**

   By setting an appropriate local cache size, we can balance the need for reliable name recall with the limited storage capacity of the device. This will help maintain a clear and useful memory without overloading the wearer's attention or battery life.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By optimizing which tasks are handled on the phone versus falling back to the cloud, we can ensure that critical real-time subtitle processing is always local, reducing latency and maintaining trust. This focus ensures that the core mission of providing clear, stable, and timely subtitles remains strong while minimizing the risk of privacy concerns associated with cloud data handling.

2. **What small change unlocks it**

   Define a specific task boundary for live subtitle processing where only the phone handles real-time transcription and rendering, falling back to the cloud only when absolutely necessary (e.g., during initial setup or in cases where offline processing is not possible).

3. **Likely payoff**

   This approach ensures that subtitles are consistently clear and reliable, which is crucial for the core mission of enhancing understanding in noisy environments. By keeping subtitle generation on-device, we reduce latency, improve battery efficiency, and maintain a more consistent user experience.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   Ensuring that subtitles coexist with one-line support in a way that minimizes visual clutter while maintaining clarity and readability is crucial for both subtitle quality and overall assistive value. This balance helps the wearer stay focused on conversation without being overwhelmed by additional text, thereby enhancing their understanding and confidence.

2. **What small change unlocks it**

   Define a clear precedence rule where subtitles take priority over one-line support when the context requires attention to spoken words. This rule can be simple: if there is an active speaker in the subtitle stream, suppress or reduce the visual prominence of any one-line support text that does not directly relate to the current speaker.

3. **Likely payoff**

   By prioritizing subtitles during active speech, the system ensures that the wearer’s attention is directed towards critical information. This minimizes cognitive overload and enhances trust in the system by aligning its behavior with real-world needs, leading to a more seamless user experience.

4. **Immediate next probe**
   - Define one visual priority rule between subtitles and one-line support in V1.
