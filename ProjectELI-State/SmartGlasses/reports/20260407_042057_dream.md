### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Ensuring stable subtitle placement is crucial for maintaining trust in real-time conversation assistance. Stable subtitles help users understand and respond correctly without the distraction of frequent repositioning, which could break their focus and reduce the overall effectiveness of the assistant.

2. **What small change unlocks it**

   Define a fixed subtitle placement rule that prioritizes readability over repositioning. This involves setting a default vertical position at the bottom center of the frame with slight padding from the edges to avoid overlap with other UI elements, ensuring subtitles remain visible and do not move during speech.

3. **Likely payoff**

   By maintaining consistent subtitle visibility, users can rely on the subtitles without being distracted by their movement. This stability will enhance trust in the system's ability to provide accurate real-time assistance, which is critical for daily use scenarios such as noisy environments or complex conversations.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

Improving the confidence display format helps ensure that the wearer can trust the subtitles and memory support provided by the glasses. A clear, concise, and accurate confidence indication will reduce confusion and increase the reliability of the system.

2. **What small change unlocks it**

Define a new confidence format that combines a numeric score with a label and a short reason. This format will help convey certainty levels in a way that is both understandable and unobtrusive.

3. **Likely payoff**

A well-designed confidence display can significantly enhance the wearer's trust in the system, ensuring they feel confident when relying on subtitles or memory support. This trust is crucial for the core mission of helping the wearer understand better without pretending to know things they do not.

4. **Immediate next probe**
   - Define the format for presenting confidence scores, labels, and short reasons for different certainty levels.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

Improving local memory thresholds for face/name recall enhances the core mission by ensuring that frequently encountered individuals are recognized with high confidence, reducing the need for cloud-based lookups and thereby minimizing latency and battery usage.

2. **What small change unlocks it**

Define a local cache size limit of 10 recent faces/names with frequent encounters (e.g., those seen more than once in the last hour) that will be prioritized for fast lookup on-device.

3. **Likely payoff**

This change will significantly reduce latency by allowing the glasses to quickly retrieve common names and faces without needing to interact with the cloud, thus improving overall responsiveness and user trust.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

By optimizing which tasks fall back to the cloud versus staying local on the phone, we can ensure that critical real-time subtitle processing remains stable and reliable while offloading less time-sensitive tasks to more powerful but potentially slower resources. This balance enhances trust by keeping the most important functionality fast and responsive.

2. **What small change unlocks it**

Define a clear boundary for live subtitle processing as a primary task that must run locally on the phone. All other related memory and confidence behaviors can be stored or processed in the cloud, with fallback to the local cache only when necessary.

3. **Likely payoff**

This change will ensure that subtitles remain real-time and reliable, maintaining trust by delivering timely support. The cloud can handle less time-critical tasks like memory lookup and context refinement without impacting live subtitle quality. This separation helps manage battery usage while preserving critical functionality.

4. **Immediate next probe**

Define one phone-local vs cloud fallback boundary for exactly one task: live subtitle processing.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   By ensuring that subtitles coexist effectively with one-line support, we maintain a clear, uncluttered visual hierarchy without overwhelming the wearer. This balance is crucial for both clarity and trust, allowing the wearer to focus on the conversation while still receiving necessary contextual support.

2. **What small change unlocks it**

   Define a subtitle-vs-one-line priority rule that keeps subtitles always visible but slightly reduces their prominence when one-line prompts are active, ensuring that one-line support remains legible without competing with subtitled dialogue.

3. **Likely payoff**

   This subtle change will enhance the overall user experience by maintaining clear visibility of both subtitles and one-line support, reducing cognitive load and social awkwardness while preserving the core functionality of real-time subtitle clarity and low-friction assistance.

4. **Immediate next probe**
   - Define one visual priority rule between subtitles and one-line support in V1.
