# Consolidated Insights for SmartGlasses Project

- **Memory Trust**: Enhance name and context recall with confidence objects and reinforcement mechanisms.
- **Core Deepening**: Prioritize subtitle quality, memory trust, and visual UX over broad feature expansion.

- **Privacy vs Usefulness**: Balancing assistive behavior with privacy concerns by avoiding invasive data capture.

## Contradictions That Must Stay Alive
- **Always-On Sensing vs Battery and Thermals**: Manage always-on sensing for context while mitigating battery drain.

## Concrete Tensions Around Core Mission Components

- **Subtitle Placement**:
  - Current effort: Determine the best placement for subtitles to balance readability with unobtrusiveness.
  
- **Confidence Display**:
  - Current effort: Define a confidence format that builds trust without overwhelming the wearer.

### Low-Friction Assistance and Interaction Constraints
- **Frame-Touch-Only V1 Interaction**: Ensure all interactions remain through frame touches, avoiding voice commands for now.
- **One-Line Prompts vs Overload**: Optimize one-line prompts to provide essential support without creating unnecessary cognitive load.

### Privacy and Usability Tradeoffs
- **Privacy vs Usefulness**:
  - Current effort: Avoid collecting data that could be seen as invasive while ensuring the system remains helpful.
  
- **Battery and Thermal Constraints**:
  - Current effort: Optimize subtitle rendering to minimize battery drain without compromising on live clarity.

### Technical Architecture and Implementation Grounding
- **Phone-First Runtime**: Continue prioritizing phone-side processing for initial stages, with cloud support as needed.
- **Core Deepening Over Sprawl**: Focus on improving core components like subtitles, memory, and confidence rather than expanding features.

## Reality-Check Insights

- **V1 Real World Limits**:
  - Glasses should remain lightweight and socially acceptable in V1.
  - Early versions should not depend on heavy on-glasses compute.
  
- **Interaction Constraints**:
  - Interaction should be controlled through frame touches only; avoid voice commands for now.

## Open Questions to Address

- What subtitle placement is most usable without becoming distracting?
- How should one-line prompts visually differ from subtitles?
- What confidence format builds trust best: label only, label + short reason, or score + label?
- How much face/name memory should be cached locally on the phone?

By addressing these signals and tensions, we can refine our approach to better meet the core mission of SmartGlasses while adhering to real-world constraints.
