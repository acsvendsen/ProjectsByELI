### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   By refining subtitle placement rules based on confidence states, we can ensure that subtitles are always visible and understandable to the wearer in noisy environments. This improves real-time subtitle clarity, a primary attractor of the project.

2. **What small change unlocks it**

   Define two subtitle placement rules: one for high-confidence contexts where subtitles should be placed near the bottom center of the frame (for stability), and another for lower-confidence contexts where subtitles can be slightly adjusted to avoid overlap but remain legible (to minimize distraction).

3. **Likely payoff**

   This change will enhance the wearer's ability to follow conversations in noisy environments by making subtitles more predictable and less distracting, thus increasing trust in the system’s real-time subtitle clarity.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**
   - Improving confidence display ensures that the wearer can trust the subtitles and memory support more effectively. A clear and concise confidence format will help in reinforcing the reliability of the system, which is crucial for daily use.

2. **What small change unlocks it**
   - Define a consistent confidence format that combines a numeric score with a label and short reason. For example: "score 0.84 + 'High' + 'Seen recently'; score 0.42 + 'Low' + 'Weak match'; score 0.63 + 'Medium' + 'Name heard once in introduction'.

3. **Likely payoff**
   - By providing a clear and understandable confidence format, the system can build trust with the wearer. This will make it easier for them to rely on the subtitles and memory support, leading to better daily use and understanding.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   To benefit the core memory trust attractor, we need to ensure that new-person recall is reliable but not over-reinforced. This will help maintain a balance between privacy and utility, ensuring that the system remembers likely new people automatically without creating an intrusive or overly confident memory.

2. **What small change unlocks it**

   Define a local cache threshold for new-person memories on the phone that limits the number of new persons cached based on recent interactions. For example, keep only the last 5-10 new persons encountered in the past hour.

3. **Likely payoff**

   By setting a reasonable limit on new-person memories, we can reduce the risk of privacy concerns while still providing useful support for likely new people. This will enhance trust by showing that the system is cautious and respects user privacy, but also helps the wearer remember important interactions.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   Ensuring a clear visual hierarchy between subtitles and one-line prompts enhances the wearer's ability to focus on critical information without visual overload, thereby improving the overall experience of real-time understanding and memory support.

2. **What small change unlocks it**

   Define a prioritization rule that gives subtitles higher precedence in the display order over one-line prompts when both are present during live interaction. This can be done by setting a subtitle-vs-one-line priority rule where subtitles always appear first, followed by one-line prompts if space permits.

3. **Likely payoff**

   By ensuring subtitles have priority, we reduce cognitive load and maintain focus on the primary assistive information. This results in more effective real-time understanding and memory support without overwhelming the wearer with multiple layers of contextual support.

4. **Immediate next probe**
   - Define the subtitle-vs-one-line priority rule where subtitles always have higher precedence in display order during live interaction.
