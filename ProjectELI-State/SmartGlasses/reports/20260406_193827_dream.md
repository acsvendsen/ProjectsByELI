### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Subtitle placement rules that are stable and predictable benefit the core by ensuring the wearer can trust subtitles in real-time interactions without unnecessary distractions or changes. Consistent subtitle placement helps maintain focus and reduces cognitive load, allowing the wearer to concentrate on understanding and responding.

2. **What small change unlocks it**

   Define a fixed subtitle placement rule where subtitles appear at the bottom of the field of view, offset slightly from center, and remain there regardless of speaking speed or confidence level. This simple change ensures that subtitles are always visible yet unobtrusive.

3. **Likely payoff**

   By implementing a stable subtitle placement rule, users will experience consistent and reliable subtitles, which enhances trust in the system's real-time assistance. This stability reduces cognitive strain for the wearer, making the SmartGlasses more effective in noisy environments and during fast-paced conversations.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Ensuring that confidence objects are displayed in a clear, unambiguous format helps build trust with the wearer. By using a numeric score, label, and short reason to convey certainty, the system can provide precise feedback on the reliability of its memory and subtitle outputs.

2. **What small change unlocks it**

   Define a new confidence object format that combines a numeric score, a label, and a brief reason for why the confidence level is what it is. For example: "score 0.84 + 'High' + 'Seen recently'; score 0.42 + 'Low' + 'Weak match'; score 0.63 + 'Medium' + 'Name heard once in introduction'."

3. **Likely payoff**

   Implementing this confidence format will make the system more transparent and trustworthy, helping the wearer better understand when to rely on the assistant’s memory and subtitles. This clarity can reduce confusion and build user trust over time.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Improving the local memory cache threshold ensures that frequently encountered faces and names are stored with high confidence, reducing the need for cloud lookups and enhancing the wearer's trust in the system’s memory support.

2. **What small change unlocks it**

   Define a local cache size limit of 50 entities (faces/names) for frequent encounters, ensuring that only commonly seen people are cached locally to avoid overloading the phone while maintaining essential memory recall.

3. **Likely payoff**

   By setting a clear threshold for local caching, the system can balance between reducing cloud traffic and maintaining reliable memory support, thereby enhancing the overall trustworthiness of name and face recall in real-world interactions.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   Ensuring that live subtitle placement is stable and predictable enhances the wearer's trust in the system, making them more likely to rely on subtitles in noisy environments. Stable subtitle placement also reduces cognitive load by providing a consistent visual reference, allowing the wearer to focus more on the conversation.

3. **Likely payoff**

   By implementing these rules, the system will provide subtitles in a way that feels natural and predictable to the wearer. This predictability reduces cognitive overhead and ensures that important information is always visible when needed, thereby increasing trust and usability.

4. **Immediate next probe**

3. **Likely payoff**
