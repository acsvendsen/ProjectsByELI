# Reality Check for SmartGlasses Project Cognition System

## Core Mission Relevance

### Subtitle Placement: More Prominent (Feasible Now)
- **Current Decision:** Glasses should place subtitles more prominently, with a clear visual hierarchy where subtitles dominate the view.

**Reasoning**: This aligns with reducing social friction and ensuring that the wearer can easily read subtitles without being overwhelmed. The glasses should prioritize fast reading over distraction to maintain usability in noisy environments. 

### Confidence Display: Label + Reason (Feasible Now)
- **Current Decision:** Use a label paired with a short reason for confidence levels.

**Reasoning**: This provides enough context to build trust while keeping the UI simple and uncluttered. A label such as "Low", "Medium", or "High" combined with a brief explanation helps users understand when they should pay more attention, enhancing the reliability of the system.

### Memory/Cache Policy: Recency First (Feasible Now)
- **Current Decision:** Implement memory caching based on recency rather than storing everything.

**Reasoning**: Storing only recent interactions or faces names reduces storage and processing demands while still providing useful context. This approach respects battery limits and thermal constraints, making the system more reliable for real-time use.

### Phone/Cloud Boundary: Phone First (Feasible Now)
- **Current Decision:** Use the phone as the primary runtime for speech, context, memory lookup, and orchestration with cloud support only when necessary.

**Reasoning**: This balances local processing needs with the ability to leverage remote computing resources where beneficial. It keeps V1 simple in terms of on-glasses hardware and allows for future expansion without overcomplicating the initial design.

### Visual Hierarchy: Subtitles Dominate (Feasible Now)
- **Current Decision:** Ensure subtitles are visually dominant, allowing one-line prompts to coexist but not overwhelm.

**Reasoning**: Dominant subtitles ensure that critical information is always visible and readable. One-line prompts can be used for additional context without causing visual clutter or distraction.
