# Consolidation for SmartGlasses V1 Direction

## Strengthening Signals
- **Subtitle Quality**: Enhance subtitle accuracy and placement to ensure clarity without distraction.
- **Face/Name Memory**: Prioritize fast, reliable face/name recall with clear confidence indicators.

## Weakening Signals
- **Complex Interaction Patterns**: Avoid adding voice commands or complex multimodal interfaces in V1. Stick to frame-touch interaction only.

## Contradictions That Must Stay Alive
- **Privacy vs Usefulness**: Ensure memory and subtitle features enhance the wearer's understanding without compromising privacy.
- **Battery Constraints**: Balance always-on functionality with battery life, especially for critical features like live subtitles.

## Dormant Ideas Worth Reactivating
- **Cloud Optional**: Explore scenarios where cloud processing can add significant value while keeping V1 lightweight and focused on core interactions.

## Concrete Tensions Around Core Areas

### Subtitle Quality, Confidence Trust, Memory Lookup
- **Subtitle Placement**: Optimize subtitle placement to be useful but non-intrusive. This includes balancing visibility with the need for unobstructed vision.
- **Confidence Display**: Develop a clear and effective confidence display system that builds trust without overwhelming the wearer.

### Visual UX and Privacy
- **Memory Policy**: Design face/name memory caching policies that respect privacy while providing useful recall capabilities.
- **Subtle UI**: Ensure the visual hierarchy of subtitles, one-line prompts, and other notifications is clear but unobtrusive.

### Real-world Constraints
- **Latency Management**: Address real-time processing needs to maintain trust in subtitle quality and response times.
- **Battery and Thermals**: Implement strategies to manage battery use effectively without compromising on critical features like live subtitles.

## Open Questions

1. **Subtitle Placement and Visual Hierarchy**:
   - What is the optimal placement for subtitles to ensure they are visible but not distracting?
   - How should one-line prompts visually differ from subtitles in terms of size, color, and duration?

2. **Confidence Format**:
   - Should confidence be displayed as a label only, with a short reason, or a numeric score plus label? What format builds the most trust?

3. **Face/Name Memory Storage**:
   - How much face/name memory should be cached locally on the phone to ensure fast recall while respecting privacy?

4. **Interaction Constraints**:
   - Which interactions should work offline and which require cloud support in V1?
   - Can cloud processing be used to enhance subtitle quality or provide additional context without overburdening the device?

## Summary

- Focus on enhancing subtitle accuracy and placement.
- Prioritize clear face/name recall with confidence indicators.
- Stick to frame-touch interaction only in V1.
- Explore cloud options for added value while keeping local processing minimal.
- Balance real-time functionality with battery constraints and privacy concerns.

By addressing these areas, the project can maintain its core mission of providing discreet, context-aware personal assistance without overcomplicating the initial version.
