# SmartGlasses Consolidation

## Strengthening Signals
1. **Subtitle Clarity**: The emphasis on real-time subtitle clarity remains high and crucial for the wearer's trust and understanding in live conversations.
2. **Memory Trust**: The need to provide trustworthy memory support is becoming more important, as it directly impacts the reliability of name and face recall.

## Weakening Signals
1. **Low-Friction Assistance**: This signal has slightly weakened in importance compared to subtitle clarity and memory trust, but it remains significant for ensuring a smooth user experience.

## Contradictions That Must Stay Alive
- **Privacy vs Usefulness**: The tension between providing useful assistive features without infringing on privacy is critical. Ensuring that the system does not become overly intrusive while still delivering value is essential.
- **Latency vs Richness**: Balancing the need for timely responses with richer, more detailed memory and subtitle support remains a key challenge.

## Dormant Ideas Worth Reactivating
- **Subtitle Placement and Visual Hierarchy**: While not currently in focus, these areas are worth revisiting to ensure that subtitles do not become intrusive while still being readable and useful.
- **Face/Name Memory Cache Policy**: Exploring how much face/name memory should be cached locally on the phone for quick access is important but has been dormant.

## Concrete Tensions Around Core Areas
1. **Subtitle Quality, Confidence Trust, Automatic New-Person Memory, Memory Reinforcement, Fast Lookup, Privacy, Latency, Battery, and Visual UX**:
   - **Subtitle Quality**: Subtitles must remain clear, fast, and stable to maintain trust.
   - **Confidence Display**: How should confidence be represented—numeric score, label, or short reason?
   - **Automatic Memory Behavior vs Explicit Remember-Touch Behavior**: Balancing the automatic remembering of new people with explicit user confirmation for increased accuracy.
   - **Fast Lookup Requirements**: Ensuring memory and context can be quickly accessed without overwhelming the wearer.

## Open Questions
1. **Subtitle Placement**: What is the best V1 subtitle placement to ensure readability without becoming distracting?
2. **Confidence Display**: How should confidence be displayed—numeric score, label, or short reason?
3. **Memory/Cache Policy**: How much face/name memory should be cached locally on the phone for quick access?

## Summary
The core mission remains focused on real-time subtitle clarity, trustworthy memory support, and low-friction assistance. The tensions between privacy and usefulness, as well as latency and richness, continue to shape design decisions. Subtitle quality, confidence display, automatic new-person memory, fast lookup, and visual UX are critical areas that require ongoing attention. Reactivating dormant ideas like subtitle placement and face/name memory cache policy can help refine the user experience further.
