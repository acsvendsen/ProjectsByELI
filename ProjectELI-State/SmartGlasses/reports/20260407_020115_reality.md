- **Feasibility**: Feasible now

Given that `TranscriptLab` is already testing live transcript behavior, subtitle placement can leverage this existing infrastructure to ensure subtitles are visible and readable. Early placements like bottom-center or side display can be tested for clarity without overcomplicating the UI.

### Confidence Display (Memory Trust)
- **Feasibility**: Feasible now
