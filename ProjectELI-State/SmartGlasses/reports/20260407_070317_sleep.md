# Consolidation of Recent Signals

## Strengthening Signals
1. **Subtitle Clarity**: The real-time subtitle clarity is crucial for trust and usability. Ensuring subtitles remain clear, fast, and stable in live conversations will enhance the wearer's understanding and confidence.
2. **Memory Trust**: Memory support should be trustworthy, remembering names, faces, and prior context without creating false certainty or corrupted recall. This improves the overall usefulness of the system.

## Weakening Signals
1. **Low-Friction Assistance**: The current low-friction assistance is less emphasized compared to subtitle clarity and memory trust. While still important, it should not overshadow the core mission of providing clear subtitles and reliable memory support.

## Contradictions That Must Stay Alive
1. **Privacy vs Usefulness**: Balancing privacy with usefulness is a critical tension. Helpful assistive behavior must not quietly slide into invasive capture or retention.
2. **Latency vs Richness**: The system should provide timely help without overloading the runtime with richer but slower processing.

## Dormant Ideas Worth Reactivating
- **Subtitle Placement and Visual Hierarchy**: These ideas are worth revisiting to ensure subtitles are both readable and non-distracting, optimizing for visual UX without compromising clarity.
  
## Concrete Tensions Around Core Mission
1. **Subtitle Quality vs. Memory Trust**:
   - Ensuring subtitles are clear (subtitle_clarity) while maintaining the trust in memory support (memory_trust).
2. **Low Friction Interaction**:
   - Frame-touch interaction is essential, and any new interactions should be carefully considered to maintain simplicity.
3. **Privacy Constraints**:
   - Memory caching and face/name recall must balance between usefulness and privacy.

## Open Questions

2. **Confidence Display**: How can confidence be represented (label only, label + short reason, or score + label) to build trust effectively?

## Reality Rules
