### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   By defining fixed subtitle placement rules that are stable and unreactive, the system can ensure consistent, non-distracting real-time subtitles. This improves trust by providing reliable, predictable information to the wearer.

2. **What small change unlocks it**

   Define a set of default subtitle placement modes: one for high-confidence speech, another for lower-confidence interactions, and a third for memory recall prompts. These rules would be applied based on the confidence level of the spoken text.

3. **Likely payoff**

   By having fixed, stable subtitle placement rules, the system can reduce visual distractions during conversations. This will enhance the wearer's trust in the subtitles and improve overall comprehension without overwhelming them with constant movement or repositioning.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   By refining the confidence display format, we can ensure that the wearer understands the reliability of the displayed information, thereby building trust in the system's ability to provide accurate and timely assistance. This clarity will help in maintaining the wearer's confidence during critical interactions.

2. **What small change unlocks it**

   Define a clear and concise confidence label with an accompanying short reason for each piece of subtitle or memory support provided by the system. For example, use labels like "High," "Medium," and "Low" along with reasons such as "Seen recently," "Weak match," or "Name heard once."

3. **Likely payoff**

   Implementing a refined confidence display will reduce misunderstandings and misinterpretations of the system's reliability. This clarity can prevent confusion during critical moments, ensuring that the wearer trusts the subtitles and memory support provided by the glasses.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Ensuring a robust memory cache policy that prioritizes likely new-person memory while reinforcing confidence over time strengthens the core mission by enhancing trust and real-world usefulness. This improves how names and faces are remembered, aiding in clearer personal memory support.

2. **What small change unlocks it**

   Define one local cache eviction rule based on recent interaction frequency and confidence level to ensure new or frequently seen people are prioritized in memory lookup while older entries are less likely to be evicted.

3. **Likely payoff**

   By setting a clear eviction policy, the system can maintain a balance between rich memory and fast lookup. This will help in reducing memory noise without compromising on the ability to recall important names and faces quickly during interactions.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By defining clear boundaries for what runs phone-local versus what falls back to cloud, we ensure that critical subtitle processing happens immediately on the device, maintaining low latency and ensuring real-time clarity in noisy environments. This reduces battery drain from constant network activity and maintains the wearer's trust by providing timely assistance.

2. **What small change unlocks it**

   Define a specific task boundary for live subtitle processing to run phone-local: For V1, define that all live subtitle generation and rendering must occur on the phone, with no fallback to cloud unless absolutely necessary (e.g., in cases of extremely poor local conditions).

3. **Likely payoff**

   This small change will ensure that subtitles remain clear, stable, and responsive during critical interactions, maintaining high user trust and satisfaction without compromising battery efficiency or privacy.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   Ensuring clear, stable, and trust-preserving subtitle placement is crucial for the wearer's understanding and engagement in live conversations. This benefit directly supports the primary attractor of real-time subtitle clarity, which aims to keep subtitles readable, stable, and trustworthy in dynamic environments.

2. **What small change unlocks it**

   Define 2 to 3 subtitle placement rules that prioritize readability over distraction. For example:
   
   - Rule 1: Place subtitles at the bottom center of the screen with minimal overlap.

   - Rule 3: Ensure stable subtitle position even during head movements.

3. **Likely payoff**

   By establishing clear placement rules, we can significantly reduce distractions and maintain readability, which will enhance the wearer's trust in the subtitles and improve their overall understanding of conversations. This will also help in aligning with the project’s core attractors for real-time subtitle clarity and low-friction assistance.

4. **Immediate next probe**
