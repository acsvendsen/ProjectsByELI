### Idea 1: Subtitle Placement

1. **Why it benefits the core**
   - Stabilizing subtitle placement rules enhances user trust by ensuring that subtitles remain in a predictable and unobtrusive position, which is crucial for maintaining the wearer's focus during live conversations.

2. **What small change unlocks it**
   - Define two fixed subtitle placement modes: one for high-confidence content (e.g., names, faces) and another for low-confidence content (e.g., generic speech).

3. **Likely payoff**
   - By implementing distinct placement rules for different confidence levels, the system can avoid distracting visual clutter while still providing clear, trustworthy subtitles when needed. This improves overall user experience and trust in the assistant's reliability.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving the confidence display format helps ensure that the wearer can trust the system's memory and one-line support. A clear, concise, and honest representation of the system’s certainty in remembering names or faces will build trust over time. This clarity is crucial for maintaining the wearer's confidence in relying on the glasses without feeling like they are being misled.

2. **What small change unlocks it**

   Define a simple confidence format that uses a numeric score (0-1) combined with a label and short reason. For example, "score 0.84 + 'High' + 'Seen recently'" or "score 0.42 + 'Low' + 'Weak match'". This small change ensures that the wearer can quickly understand how certain the system is about each piece of information.

3. **Likely payoff**

   By providing a clear and honest confidence format, the glasses will be more trustworthy to the wearer. This trust will lead to better engagement with the memory support features, as the wearer will feel confident in relying on accurate and reliable information provided by the glasses.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Ensuring that new person memory is cached locally with a defined threshold helps maintain privacy while providing useful and timely support. By setting a local cache size limit, we can balance the need for fast recall with the importance of not storing sensitive information unnecessarily.

2. **What small change unlocks it**

   Define one local-cache size limit for face/name memory that caps the number of entities stored on the phone before they are pushed to cloud storage or forgotten.

3. **Likely payoff**

   By limiting the amount of data stored locally, we can reduce privacy concerns while ensuring that commonly encountered faces and names remain easily accessible during live conversations. This reduces the likelihood of overloading the local memory with less relevant information and keeps the system lightweight and responsive.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By clearly defining what stays phone-local versus what falls back to cloud for live subtitle processing, we can ensure real-time subtitle clarity and stability while managing battery and thermal constraints effectively.

2. **What small change unlocks it**

   Define a single task-specific rule: "Live subtitle processing should run locally on the phone unless the wearer is in a high-latency environment or the glasses need to be powered down for extended periods."

3. **Likely payoff**

   This definition ensures that critical real-time subtitles are not delayed by cloud latencies, maintaining trust and usability. It also helps manage battery usage by reducing unnecessary data transfers, ensuring the core subtitle quality is preserved.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   By defining a clear visual hierarchy between subtitles and one-line prompts, we can ensure that the wearer remains focused on the most critical information without being overwhelmed by too much text. This improves both the clarity of real-time subtitles and the efficiency of low-friction assistance.

2. **What small change unlocks it**

   Define a subtitle-vs-one-line priority rule that routes higher-confidence or more urgent information to subtitles, while lower-priority or less urgent information is shown as one-line prompts.

3. **Likely payoff**

   This visual hierarchy will enhance the wearer's ability to quickly process critical information during real conversations, reducing cognitive load and increasing overall understanding without overwhelming them with too much text.

4. **Immediate next probe**
   - Define one visual priority rule between subtitles and one-line support in V1.
