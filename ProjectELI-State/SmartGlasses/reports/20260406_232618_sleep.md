# Recent Consolidation for SmartGlasses

## Strengthening Signals
1. **Subtitle Clarity**: The real-time subtitle clarity must remain clear, fast, and stable to ensure the wearer can trust them in live conversations.
2. **Memory Trust**: Names, faces, and prior context should be remembered accurately without creating corrupted recall or pretending certainty.
3. **Core Deepening**: Focus on improving subtitle quality, memory support, confidence display, and visual UX to enhance daily-use value.

## Weakening Signals
1. **Low-Friction Interaction**: The emphasis is shifting slightly away from overly simplistic interactions that might sacrifice assistance quality for minimalism.

## Contradictions That Must Stay Alive
1. **Privacy vs Usefulness**: The balance between providing useful assistive behavior and respecting privacy constraints must be maintained.
2. **Latency vs Richness**: The system should provide timely help without overloading the runtime with richer but slower processing.

## Dormant Ideas Worth Reactivating
- **Subtitle Placement and Visual Hierarchy**: These are worth revisiting to ensure the UI remains usable without becoming distracting.

## Concrete Tensions Around Subtitle Quality, Confidence Trust, Automatic New-Person Memory, Memory Reinforcement, Fast Lookup, Privacy, Latency, Battery, and Visual UX

1. **Subtitle Quality vs Clarity**:
    - Ensure subtitles remain readable and stable in noisy environments.
2. **Confidence Display**:
    - Determine the best format for confidence display (label only, label + short reason, score + label) to build trust without overwhelming the wearer.
3. **Automatic New-Person Memory**:
    - Implement a mechanism for remembering new faces and names with confidence objects and reinforcement over time.
4. **Memory Reinforcement**:
    - Focus on reinforcing memory of names and prior contexts rather than storing low-value information.
5. **Fast Lookup Requirements**:
    - Ensure that memory lookup is quick and reliable to support one-line contextual prompts effectively.
6. **Privacy vs Usefulness**:
    - Avoid invasive capture or retention practices while providing useful assistive behavior.
7. **Latency vs Richness**:
    - Prioritize timely responses over richer, slower processing where possible.

## Current Open Questions
- What is the best subtitle placement and visual hierarchy for fast reading with low distraction?
- How should face/name memory be stored and reinforced for fast lookup and trust?
- Which interactions should work offline versus requiring cloud support?

## Conclusion
The project should continue to focus on core deepening, ensuring that improvements in subtitle quality, memory trust, and confidence display are prioritized. These changes will enhance the daily-use value of the SmartGlasses without compromising privacy or adding unnecessary complexity.
