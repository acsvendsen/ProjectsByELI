## Low-Friction Assistance (Phone/Cloud Boundary)

- **Feasibility**: Feasible now  
- **Reasoning**: The V1 interaction is frame-touch only, and heavy processing remains on the phone. Implementing low-friction assistance can be tested in `TranscriptLab` by adding one-line prompts that provide help without creating command overhead. This will help ensure that any new functionality integrates seamlessly with the existing user experience.

## Phone/Cloud Boundary

- **Feasibility**: Feasible now  
- **Reasoning**: The project is currently focused on a phone-first approach, with cloud support optional where clearly justified. Implementing this boundary can be tested in `TranscriptLab` by gradually introducing cloud-based features and evaluating their impact on the overall system.
