# Consolidation for SmartGlasses V1

## Strengthening Signals
- **Subtitle Quality**: Emphasize near-real-time subtitles that feel immediate and assistive, not intrusive.
- **Memory Trust**: Focus on building confidence objects and fast lookup requirements through explicit remember-touch behavior.
- **Low Friction UX**: Ensure subtitle placement is prominent yet non-distracting, with clear visual hierarchy.

## Weakening Signals
- **Complex Interactions**: Reduce the complexity of interactions; frame touches are the primary control method in V1.
- **Voice Activation**: Avoid incorporating voice commands or spoken controls until after the core functionality is validated and refined.

## Contradictions That Must Stay Alive
- **Battery Constraints vs Always-On Sensing**: Maintain a balance that respects battery limits but does not sacrifice always-on sensing capabilities.
- **Rich Context vs Low-Latency Response**: Ensure memory and context are robust, even if it means occasional latency.

## Dormant Ideas Worth Reactivating
- **Phone/Cloud Boundary**: Revisit the necessity of cloud support for non-critical background processing without compromising core functionality.

## Concrete Tensions Around Core Decision Areas

### Subtitle Quality vs Battery Consumption
- **Tension**: Always-on subtitle generation versus battery management.
- **Recommendation**: Optimize subtitle rendering to be energy-efficient while maintaining near-real-time updates.

### Memory Trust vs Privacy
- **Tension**: Building a robust memory system that reinforces confidence objects without compromising privacy.
- **Recommendation**: Implement explicit remember-touch behavior and local caching policies that minimize cloud reliance while enhancing trust.

### Discreet UX vs Visual Clarity
- **Tension**: Ensuring subtitles are prominent enough for the wearer to read easily, yet not too distracting.
- **Recommendation**: Test various subtitle placements and visual hierarchies in real-world scenarios to find the optimal balance.

### Face/Name Memory Caching vs Cloud Dependency
- **Tension**: Local caching versus cloud-based memory updates.
- **Recommendation**: Use phone-first architecture with local caching for fast lookups, but allow cloud support for model updates where latency is acceptable.

## Open Questions

### Subtitle Placement and Visual Hierarchy
- **Open Question**: What subtitle placement and visual hierarchy best balance clarity and non-distractiveness?

### Confidence Display Formats
- **Open Question**: How should confidence be displayed to the user (label only, label + short reason, or score + label) to build trust effectively?

### Face/Name Memory Policy
- **Open Question**: What is the optimal caching strategy for face/name memory on the phone versus cloud?

## Core Mission Deepening

- **Subtitle First Guidance Mode**: Ensure subtitles are the primary focus of guidance in V1.
- **Frame Touch Interaction**: Maintain frame-touch as the sole interaction method to keep the system simple and reliable.

## Reality Check

- **Real-Time Constraints**: Surface real-world constraints early, including hardware limitations, battery management, and thermal considerations.
- **User-Centric Design**: Focus on a user-centric design that enhances understanding and confidence without overwhelming the wearer.

By maintaining these signals and addressing these tensions, the project can evolve while staying true to its core mission of providing discreet, context-aware personal assistance through live subtitles, face/name recall, conversation memory, and one-line support.
