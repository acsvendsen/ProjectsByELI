   - Focus on readability and stability.

2. **Trustworthy Memory Support (memory_trust)**:
   - Prioritize accurate name and face memory recall without overreliance or misrepresentation.
   - Maintain transparency in confidence levels.

3. **Low-Friction Assistance (low_friction_assistance)**:
   - Deliver concise, helpful one-line prompts that do not create command overhead.
   - Ensure the system remains socially acceptable and minimally intrusive.

2. **Rich Context vs Low-Latency Response**:
   - Balance between rich contextual support and timely responses.
   - Avoid overloading the system with excessive processing that delays real-time interactions.
