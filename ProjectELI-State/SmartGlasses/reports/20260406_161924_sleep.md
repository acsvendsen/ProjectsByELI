# Consolidation of Recent Project Signals for SmartGlasses V1

## Strengthening Signals

### Core Attractors
- **Subtitle Clarity**: Ensure subtitles are clear and fast enough to be trusted in real-time interactions.
- **Memory Trust**: Implement reliable memory support without creating false certainty or corrupting recall.

### Core Tensions
- **Privacy vs Usefulness**: Prioritize transparent and helpful behavior over invasive features that could harm privacy.
- **Latency vs Richness**: Balance the need for timely assistance with avoiding overly complex processing that can degrade performance.

### V1 Real World Limits
- **Frame Touch Only Interaction**: Focus on frame touches as the primary interaction method.
- **Phone-First Processing**: Utilize the phone primarily for heavy processing, keeping glasses hardware minimal to reduce thermal and battery strain.

## Weakening Signals

### Core Attractors
- **Low-Friction Assistance**: Reduce the complexity of interactions and visual clutter while maintaining core functionality.

### Core Tensions
- **Discreet UX vs Visual Clarity**: While striving for a discreet user experience, ensure that subtitles are readable enough to be effective in noisy environments.

## Contradictions That Must Stay Alive

### Core Attractors
- **Real-Time Subtitle Clarity**: Ensure subtitles remain clear and stable without being overly complex.
- **Memory Trustworthiness**: Maintain the balance between providing helpful memory support and avoiding overconfidence or privacy issues.

## Concrete Tensions Around Subtitle Quality, Confidence Trust, Automatic New-Person Memory, Memory Reinforcement, Fast Lookup, Privacy, Latency, Battery, and Visual UX

### Subtitle Quality
- **Subtitle Clarity**: Ensure subtitles are clear, readable, and stable in real-time interactions.
- **Visual Hierarchy**: Optimize subtitle placement for readability without becoming distracting.

### Confidence Trust
- **Confidence Display**: Use labels and short reasons to build trust while avoiding overconfidence.
- **Memory Reinforcement**: Implement a recency-first memory cache policy that reinforces confidence through repeated interactions.

### Automatic New-Person Memory
- **Face/Name Recall**: Ensure face/name recall respects user privacy and builds trust by exposing uncertainty clearly.

### Memory Reinforcement
- **Recency First Cache Policy**: Use recent interactions to enhance memory recall accuracy and build trust over time.
- **Confidence Objects**: Employ confidence objects for fast lookup and automatic new-person memory to maintain trust.

### Fast Lookup
- **Phone-First Processing**: Utilize the phone for quick lookups while keeping heavy processing off-glasses to reduce thermal and battery strain.

### Privacy
- **Transparent Memory Support**: Provide clear feedback on what data is being remembered without overstepping privacy boundaries.
- **User Control**: Ensure users can manage their memory support preferences easily.

### Latency
- **Low-Latency Responses**: Prioritize real-time assistance while avoiding overly complex processing that can increase latency.

### Battery
- **Efficient Power Management**: Implement power-efficient techniques to extend battery life without compromising core functionality.
- **Thermal Management**: Optimize hardware design and software to manage heat effectively, especially for always-on sensing capabilities.

### Visual UX
- **Discreet UX**: Design the visual interface to be unobtrusive while still providing necessary information.
- **Low-Friction Interactions**: Ensure interactions remain simple and intuitive without adding unnecessary complexity.

## Summary

### Core Mission
Create discreet, context-aware personal assistance through live subtitles, face/name recall, conversation memory, and one-line support.

### V1 Interaction
Focus on frame touches only; do not assume voice activation or spoken command control. Utilize the phone for heavy processing while keeping glasses hardware minimal to reduce thermal and battery strain.

### Core Tensions
- Privacy vs Usefulness: Prioritize transparent and helpful behavior.
- Latency vs Richness: Balance timely assistance with avoiding overly complex processing.
- Discreet UX vs Visual Clarity: Ensure readability without becoming distracting.

### Open Questions
1. **Subtitle Placement**: Optimize for readability while minimizing distraction.
2. **Confidence Display**: Use clear labels and reasons to build trust.
3. **Memory Cache Policy**: Implement a recency-first strategy for fast lookup and memory reinforcement.
4. **Phone/Cloud Boundary**: Determine when cloud processing is necessary.

By focusing on these core elements, the project can strengthen its core mission while addressing real-world constraints and user needs effectively.
