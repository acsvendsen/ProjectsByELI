### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Ensuring stable subtitle placement rules for different confidence states helps maintain a consistent user experience, reducing cognitive load and ensuring that important information is always easily readable. This consistency builds trust by providing reliable visual cues.

2. **What small change unlocks it**

   Define 2 to 3 subtitle placement rules based on the confidence level of the detected speech. For example:
   - High-confidence matches (e.g., frequently seen names or words) are placed more prominently.
   - Medium-confidence matches (e.g., new but likely correct faces or names) are slightly lower and still visible.
   - Low-confidence matches (e.g., unlikely to be correct but worth checking) might be subtly offset from the main text.

3. **Likely payoff**

   By providing stable subtitle placement, the system can reduce visual distractions while ensuring that important information remains accessible. This stability helps in building trust with the wearer by maintaining a predictable and reliable user interface.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.
