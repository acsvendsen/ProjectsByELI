### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Ensuring stable subtitle placement rules for different confidence states improves the wearer's trust in the system by reducing visual distractions and ensuring that subtitles remain clear and unobtrusive during live conversations.

2. **What small change unlocks it**

   Define two subtitle placement rules: one for high-confidence subtitles (e.g., names, faces) to be displayed prominently but not obstructively, and another for lower-confidence subtitles (e.g., background noise, context) to be less visible or potentially hidden if they do not add significant value.

3. **Likely payoff**

   By defining clear placement rules based on confidence levels, the system can enhance the wearer's understanding without overwhelming them with too much information. This improves overall trust and usability in noisy environments.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

This clarity helps ensure that the wearer can rely on the system when it matters most, such as remembering important names or recognizing faces accurately.

4. **Immediate next probe**

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By defining a clear boundary for what runs phone-local versus what falls back to cloud, we ensure that V1 interactions remain stable and responsive, maintaining trust in the system's performance. This helps in balancing real-time subtitle quality with memory support and one-line assistance without overwhelming the battery or introducing latency.

2. **What small change unlocks it**

   Define a specific task boundary for live subtitle processing that runs phone-local to maintain near-real-time performance. For example, set all live subtitle processing to run on the phone first, only falling back to cloud for post-processing tasks like confidence refinement or rare memory lookups.

3. **Likely payoff**

   By keeping live subtitle processing local, we can ensure subtitles are delivered quickly and reliably, enhancing user trust in real-time performance. This reduces the likelihood of dropped frames or latency issues that could break the wearer's experience, especially in noisy environments where timely assistance is crucial.

4. **Immediate next probe**

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   By defining a clear visual hierarchy that prioritizes subtitles over one-line prompts, we ensure the wearer can quickly understand and respond to spoken content without feeling overwhelmed by too much information at once. This reduces cognitive load and enhances the wearer's ability to focus on the conversation, thereby improving real-time understanding and interaction.

2. **What small change unlocks it**

   Define a subtitle-vs-one-line priority rule that ensures subtitles always take precedence over one-line prompts unless the prompt is critical for immediate action or clarification. For example, if there is an overlap in time, the subtitle should be displayed first with the one-line prompt suppressed until the next subtitle window.

3. **Likely payoff**

   This change will lead to a more streamlined and uncluttered user experience, where the wearer can trust subtitles as primary information and use one-line prompts only when necessary for quick context or action. This reduces the risk of visual overload and enhances overall usability in noisy environments.

4. **Immediate next probe**
   - Define one visual priority rule between subtitles and one-line support in V1.
