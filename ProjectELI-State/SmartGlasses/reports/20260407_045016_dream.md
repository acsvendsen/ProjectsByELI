### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Improving subtitle placement rules ensures that subtitles remain readable, stable, and trust-preserving during live conversations. This benefits the core by enhancing real-time subtitle clarity (attractor: `subtitle_clarity`), making the product more useful in noisy environments and hearing-challenged situations.

2. **What small change unlocks it**

   Define a fixed subtitle placement rule that places subtitles at the bottom center of the frame, ensuring they are always visible without overlapping with critical visual information or becoming distracting.

3. **Likely payoff**

   By setting a stable subtitle placement rule, we can ensure consistent and reliable subtitle visibility during live conversations. This will improve the wearer's ability to trust the subtitles, reducing cognitive load and enhancing overall user experience (attractor: `subtitle_clarity`).

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving the confidence display ensures that the wearer can trust the system's output more reliably. A well-crafted confidence format will help in maintaining the balance between usefulness and privacy, ensuring that the wearer understands when to rely on the system without feeling like their privacy is being invaded.

2. **What small change unlocks it**

   Define a simple numeric score + label + short reason format for confidence objects. This can be as basic as "score 0.85 + 'High' + 'Seen recently'" or "score 0.40 + 'Low' + 'Weak match'". The key is to make the format clear and concise.

3. **Likely payoff**

   By implementing a straightforward confidence display, users will gain more trust in the system’s outputs. This improved trust can lead to better engagement with the assistive features, as the wearer will be more willing to rely on the subtitles and memory support when needed.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   By setting a clear local memory threshold for face/name recall, we ensure that the system retains enough relevant memories to support trust and confidence without overloading the phone's limited resources or compromising privacy.

2. **What small change unlocks it**

   Define a fast-lookup index policy that prioritizes frequently seen faces and names within a certain recency window (e.g., last 30 minutes).

3. **Likely payoff**

   This change will enhance memory recall accuracy while reducing the burden on cloud storage, leading to faster response times and lower battery consumption.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   Improving the phone/cloud boundary for live subtitle processing ensures that subtitles remain clear, fast, and stable enough to be trusted in real-time conversations. By keeping this critical process local on the phone, we reduce latency, which is essential for maintaining the wearer's trust and understanding.

2. **What small change unlocks it**

   Define a rule where all live subtitle processing remains local on the phone until the memory archive sync task boundary is reached. This means that every real-time subtitle will be generated and displayed immediately by the phone without any cloud delay.

3. **Likely payoff**

   By ensuring real-time subtitles are processed locally, we can maintain the critical low latency required for trust and clarity in live interactions. This improves the core attractor of "Real-time subtitle clarity" significantly, making the product more useful and reliable for the wearer.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   By defining a visual hierarchy rule that prioritizes subtitles over one-line support when confidence is high, we ensure that critical information remains clear and uncluttered. This improves trust in real-time subtitle clarity (subtitle_clarity) by reducing cognitive load on the wearer during important conversations.

2. **What small change unlocks it**

   Define a rule where if the confidence score for a face or name is above 0.9, subtitles should be given higher visual prominence and one-line support suppressed to avoid distraction. This can be achieved through adjusting the `displayOrder` property in the UI layer.

3. **Likely payoff**

   The high-confidence subtitle display rule will lead to clearer understanding during key moments of interaction, enhancing trust in the system's real-time capabilities while maintaining a low cognitive load on the wearer.

4. **Immediate next probe**
   - Define one visual priority rule between subtitles and one-line support in V1.
