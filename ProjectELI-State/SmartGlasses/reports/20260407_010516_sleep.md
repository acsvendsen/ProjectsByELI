2. **Memory Trust** - Balancing memory support with the need to avoid creating false or unreliable recall.
3. **Confidence Display** - Determining the best format for confidence (label only, label + short reason, score + label) without compromising on battery efficiency.
4. **Visual UX** - Striking a balance between discreetness and readability in subtitle placement and visual hierarchy.

3. **Memory/Cache Policy**: How much face/name memory should be cached locally on the phone to ensure fast lookup while respecting privacy?

## Summary
The recent signals indicate a strong focus on subtitle clarity, memory trust, and core deepening mode. While low-friction assistance remains important, its emphasis is currently secondary to these critical areas. The balance between privacy and usefulness, as well as latency and richness, must be carefully managed. Subtitle placement, confidence display, and memory caching policies are dormant ideas that should be revisited soon. These priorities will help ensure the project stays on track with its core mission without drifting into broader or less relevant features.
