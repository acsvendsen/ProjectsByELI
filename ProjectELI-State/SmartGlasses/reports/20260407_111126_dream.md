### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   By refining subtitle placement rules based on confidence levels, we ensure that subtitles are always visible and readable without becoming distracting. This helps maintain the wearer's focus and trust in the system during live conversations.

2. **What small change unlocks it**

   Define a set of fixed subtitle placement rules for different confidence states: high confidence (always visible), medium confidence (visible with visual hints), and low confidence (minimal or no visual presence).

3. **Likely payoff**

   This change will make subtitles more reliable and less intrusive, improving the overall user experience by ensuring that critical information is always clear while minimizing distraction during non-critical parts of the conversation.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

This enhances trust in the system, which is crucial for daily-use value. A well-designed confidence format will help the wearer know when to rely more on the system and when to pay closer attention.

4. **Immediate next probe**

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Improving local memory thresholds ensures that likely new-person memories are cached efficiently without overwhelming the phone's limited storage or battery capacity. This enhances trust and recall reliability, which is crucial for the core mission of helping the wearer understand and respond better in real-world interactions.

2. **What small change unlocks it**

   Define a local cache size limit for storing names and faces that balances memory reinforcement with thermal and battery constraints. For example, allow caching 10 new face/name pairs per day but automatically evict older entries to maintain performance.

3. **Likely payoff**

   By setting a clear local cache threshold, the system can reinforce new memories effectively while ensuring that existing data remains accessible through periodic updates from the phone or cloud. This reduces memory churn and improves overall trust in the face/name recall functionality.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.
