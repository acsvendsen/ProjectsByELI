# Consolidation of Signals for SmartGlasses V1

## Strengthening Signals
- **Subtitle Clarity**: Continuously improving subtitle quality to ensure they are clear, fast, and stable enough for the wearer to trust them in live conversations.
- **Memory Trust**: Enhancing the reliability of memory support by ensuring that names, faces, and prior contexts are remembered accurately without overconfidence or misleading recall.

## Weakening Signals
- **Low-Friction Assistance**: Reducing the complexity and command overhead of one-line prompts to ensure they do not create social awkwardness.
- **Rich Context vs Low-Latency Response**: Prioritizing timely responses that avoid overwhelming the wearer with rich, but slower processing contexts.

## Contradictions That Must Stay Alive
- **Privacy vs Usefulness**: Balancing the need for helpful assistive behavior without encroaching on privacy concerns. This contradiction must be managed to ensure both benefits are achieved.
- **Always-On Sensing vs Battery and Thermals**: Managing power consumption while maintaining always-on sensing capabilities, which can impact battery life and device heat.

## Dormant Ideas Worth Reactivating
- **Subtitle Placement**: Exploring optimal subtitle placement that balances readability with minimal distraction.
- **Confidence Display**: Investigating the best format for confidence display (label only, label + short reason, or score + label) to build trust in the system's reliability.

## Concrete Tensions Around Subtitle Quality, Confidence Trust, Automatic New-Person Memory, Memory Reinforcement, Fast Lookup, Privacy, Latency, Battery, and Visual UX
- **Subtitle Quality**: Ensuring subtitles are clear, fast, and stable without creating visual distraction.
- **Confidence Trust**: Using appropriate confidence displays to maintain user trust in the system's accuracy.
- **Automatic New-Person Memory**: Implementing a mechanism for remembering new faces and names with confidence objects and reinforcement over time.
- **Memory Reinforcement**: Ensuring memory recall is reliable through frequent usage and context reinforcement.
- **Fast Lookup Requirements**: Prioritizing efficient lookups to avoid delays that could break trust in the system.
- **Privacy Concerns**: Balancing the need for useful assistive behavior with user privacy, avoiding over-reliance on intrusive data collection methods.
- **Latency Considerations**: Maintaining low-latency responses to prevent breaking the flow of conversation or creating lag.
- **Battery Management**: Ensuring hardware and processing choices do not drain battery too quickly while maintaining necessary functionality.
- **Visual UX**: Designing subtitles and visual cues that are clear, unobtrusive, and easy to read in motion.

## No Fluff
- The system should focus on core functionalities: live subtitles, face/name recall, conversation memory, and one-line support. Any new features or interactions must be carefully evaluated against the existing constraints and attractors.
- Frame-touch-only V1 interaction remains a non-negotiable aspect of V1 development.

## Specific Guidance for SmartGlasses V1
- **Subtitle Placement**: Focus on placements that are readable yet minimal in visual impact, such as bottom center or side margins.
- **Confidence Display**: Implement confidence displays that provide clear and concise feedback without overwhelming the wearer.
- **Memory/Cache Policy**: Develop a caching strategy that balances rich memory with fast lookups to avoid overloading the system.
- **Phone/Cloud Boundary**: Design the system to leverage cloud capabilities where they add value, such as model updates or background processing.

## Conclusion
The SmartGlasses V1 project should continue to deepen its core functionalities while addressing key tensions and maintaining a focus on user privacy, practical usability, and battery efficiency. The attention to detail in subtitle quality, memory trust, and confidence display will ensure the system remains both useful and discreet.
