# Sleep Cycle Consolidation

## Strengthening Signals
1. **Subtitle Clarity**:
   - The core goal of real-time subtitle clarity remains high-strength and critical for the project's success.
   
2. **Memory Trust**:
   - Ensuring memory support is trustworthy without creating false certainty or confusion is a key attractor.

3. **Low-Friction Assistance**:
   - Delivering one-line help effectively while maintaining social acceptability continues to be important, though less pressing than the first two signals.

## Weakening Signals
1. **Always-On Sensing vs Battery and Thermals**:
   - The tension of always-on sensing versus battery conservation has reduced in importance due to a current V1 focus on frame-touch interactions and phone-first processing.

2. **Rich Context vs Low-Latency Response**:
   - The need for rich context over fast response is less emphasized as the project moves towards real-time, low-latency subtitle delivery and memory support.

## Contradictions That Must Stay Alive
- **Privacy vs Usefulness**: 
  - This tension remains critical. The system must provide useful assistive behavior without infringing on privacy or creating invasive data collection.
  
- **Discreet UX vs Visual Clarity**:
  - Balancing the need for a discreet user experience with sufficient visual clarity to be effective.

## Dormant Ideas Worth Reactivating
1. **Subtitle Placement and Visual Hierarchy**:
   - While not currently high-priority, these aspects should continue to be considered as the design evolves.
   
2. **Confidence Display Formats**:
   - Experimenting with different confidence display methods (label only, label + short reason, score + label) could provide valuable insights.

## Concrete Tensions Around Core Areas
1. **Subtitle Quality and Memory Trust**:
   - Subtitle clarity and memory support remain high priorities, but must be balanced to avoid overloading the wearer.
   
2. **Battery Constraints**:
   - The glasses should remain lightweight and socially acceptable while minimizing battery drain for always-on features.

3. **Visual UX Friction**:
   - Designing a user interface that is both clear and non-intrusive remains a critical tension.

## Action Items
- Continue to focus on subtitle clarity, memory trust, and low-friction assistance.
- Surface real-world limitations early through iterative testing (e.g., `TranscriptLab`).
- Balance the need for rich context with fast response times.
- Maintain privacy-by-design principles in all interactions.
- Explore different confidence display formats while keeping interaction constraints in mind.

## Current Open Questions

   - What is the best placement that maximizes readability without becoming distracting?
   
2. **Confidence Display**:

3. **Memory/Cache Policy**:
