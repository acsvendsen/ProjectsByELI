# Consolidation of SmartGlasses Core Mission and Signals

## Strengthening Signals
- **Subtitle Quality**: Subtitles should be near-real-time to maintain trust, with clear and readable placement that minimizes distraction.
- **Memory Trust**: Memory for names and conversations must be reinforced over time through explicit remember-touch behavior and confidence objects.
- **Face/Name Recall**: The system should consistently and confidently recall faces and names based on context and past interactions.

## Weakening Signals
- **Complex Interactions**: Avoid adding voice commands or more complex interaction modes in V1. Stick to frame-touch interactions only.
- **Heavy Cloud Dependency**: Reduce reliance on cloud services for basic functionality, focusing instead on phone processing where possible.

## Contradictions That Must Stay Alive
- **Discreet UX vs Clarity**: The system must balance the need for a discreet design with clear and usable visual elements that do not distract from the wearer's environment.
- **Rich Memory vs Fast Lookup**: Maintain the tension between providing detailed contextual memory support and ensuring fast, relevant lookups.

## Dormant Ideas Worth Reactivating
- **Subtitle Placement**: Reassess subtitle placement options to find the most effective balance of readability and non-distracting visual design.
- **Confidence Display**: Explore different formats for confidence display (label only vs. label + short reason) to improve user trust.

## Concrete Tensions Around Core Areas

### Subtitle Quality, Confidence Trust, Automatic New-Person Memory
- **Subtitle Quality**: Ensure subtitles are clear and easily readable in noisy environments.
- **Confidence Trust**: Implement a robust system for displaying confidence levels (e.g., labels with short reasons) to build user trust.
- **Automatic New-Person Memory**: Reinforce memory of new faces and names through explicit remember-touch behavior over time.

### Fast Lookup, Privacy
- **Fast Lookup**: Prioritize fast lookups to ensure real-time assistance without adding unnecessary complexity or latency.
- **Privacy**: Ensure that the system respects privacy by not storing unnecessary information and providing clear, actionable confidence levels.

### Memory Policy, Visual UX
- **Memory Policy**: Balance between rich memory support and quick, relevant lookups.
- **Visual UX**: Design subtitles and one-line prompts with clarity in mind, ensuring they are easily readable without overwhelming the wearer.

## Open Questions

### Subtitle Placement and Visual Hierarchy
- What is the best subtitle placement that balances readability and non-distracting visual design?

### Confidence Display
- How should confidence be displayed to build trust (e.g., label only vs. label + short reason)?

### Memory/Cache Policy
- How much face/name memory should be cached locally on the phone for fast lookups without overburdening battery or storage?

### Phone/Cloud Boundary
- When is cloud processing necessary, and when can local processing suffice to ensure real-time performance and low latency?
