### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Keeping subtitles clear, fast, and stable enough to be trusted in live conversation is crucial for the wearer's ability to follow and understand real-world interactions. Stable subtitle placement ensures that the wearer can focus on the conversation without being distracted by frequent changes or movements of the text.

2. **What small change unlocks it**

   Define 2 to 3 fixed subtitle placement rules based on confidence levels: 
   - High-confidence subtitles should always appear at the bottom center.
   - Medium-confidence subtitles should appear slightly lower and to one side, fading out if too distracting.
   - Low-confidence subtitles should be hidden until confirmed by context or repeated confirmation.

3. **Likely payoff**

   By defining stable placement rules, the system will reduce visual distractions during high-concentration periods (like a critical conversation) while still providing necessary support when needed. This balance ensures that the wearer can trust the subtitles without feeling overwhelmed by frequent movements and changes in text placement.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving confidence display ensures that the wearer can trust the system's behavior, which is crucial for maintaining the core mission of discreetly helping them understand and respond in real-world interactions.

2. **What small change unlocks it**

   Define a confidence format that uses a numeric score (0-1), a label (High, Medium, Low), and a short reason (e.g., "Seen recently," "Weak match").

3. **Likely payoff**

   By clearly showing the certainty level of names, faces, and prior context in a simple yet informative way, the system can build trust with the wearer. This will make the memory support more reliable and usable, aligning closely with the core attractors of real-time subtitle clarity and low-friction assistance.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Ensuring that new face and name memories are reinforced over time improves the overall trust in memory recall, making the system more reliable for the wearer. This reinforcement helps in reducing uncertainty and enhancing the confidence in previously encountered individuals, which is crucial for real-world interactions.

2. **What small change unlocks it**

   Define a local cache eviction or refresh policy that prioritizes recent encounters to maintain a high level of confidence in memory objects. For example, if a person's face or name is seen more frequently, their memory object should be refreshed and stored locally longer than less frequent encounters.

3. **Likely payoff**

   By implementing a refresh policy for memory objects based on the frequency of encounters, the system can ensure that likely new persons are remembered reliably without requiring explicit user intervention. This will reduce the risk of forgetting important contacts or faces over time, thereby enhancing the trust and reliability of the memory support.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   Ensuring a clear visual hierarchy between subtitles and one-line support helps maintain low-friction assistance while preventing visual overload. By prioritizing subtitle clarity, the system can ensure that critical information is easily readable without distracting from ongoing conversation.

2. **What small change unlocks it**

   Define a visual priority rule where subtitles are always displayed prominently unless the one-line support has high confidence and is contextually relevant enough to coexist with subtitles.

3. **Likely payoff**

   This rule will help maintain focus on the most critical information, ensuring that subtitles remain clear and readable while still providing essential contextual prompts when necessary. It will reduce cognitive load by minimizing visual clutter and enhancing the wearer's ability to follow conversations in real-time.

4. **Immediate next probe**
