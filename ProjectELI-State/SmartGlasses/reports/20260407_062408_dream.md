### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Ensuring stable subtitle placement rules in V1 helps maintain a consistent and predictable user experience, which is crucial for trust and understanding. Stable placement ensures that subtitles remain within the wearer's field of view without being overly distracting, thereby enhancing the wearer's ability to focus on the conversation.

2. **What small change unlocks it**

   Define two subtitle placement rules: one for high-confidence speech and another for lower-confidence speech or background noise.

3. **Likely payoff**

   By defining these rules, V1 can provide a clearer and more predictable experience, reducing visual clutter during clear conversations while still ensuring that subtitles are easily readable when needed. This improves overall user trust and satisfaction.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**
   Improving the confidence display ensures that the wearer can trust the subtitles and memory support more effectively. A clear and concise confidence format helps in reducing social awkwardness by showing appropriate levels of certainty, which aligns with the low-friction assistance attractor.

2. **What small change unlocks it**
   Define a simple confidence format for V1 using numeric scores, labels, and short reasons that fit within a single line without overwhelming the wearer. For example: "score 0.85 + 'High' + 'Seen recently'; score 0.37 + 'Low' + 'Weak match'; score 0.62 + 'Medium' + 'Name heard once in introduction'. This format provides enough context for the wearer to understand the reliability of the information without adding unnecessary complexity.

3. **Likely payoff**
   A well-defined confidence format will enhance trust and reduce uncertainty, making the subtitles and memory support more reliable. This can significantly improve the wearer's experience by ensuring they are not misled by uncertain or incorrect information, thereby aligning with the low-friction assistance attractor.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   By optimizing local memory thresholds for face/name recall, we can ensure that the system maintains a balance between memory trust and battery efficiency. This helps in reducing unnecessary data storage while still providing reliable support through fast lookup.

2. **What small change unlocks it**

   Define a local cache size limit of 10 most recently seen faces/names with an eviction policy based on least-recently-used (LRU).

3. **Likely payoff**

   Implementing this small change will help in maintaining the core mission by ensuring that the system remains lightweight and efficient, while still providing trustworthy memory support for key interactions.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By defining a clear boundary for what runs locally on the phone versus what is offloaded to the cloud, we can ensure that the system remains lightweight and responsive while still providing critical functionality. This helps in maintaining real-time subtitle clarity, memory support, and low-friction assistance.

2. **What small change unlocks it**

   Define a specific task boundary for live subtitle processing where the glasses send transcribed speech to the phone for subtitle generation and real-time display. The phone then handles this task locally to ensure minimal latency and stability.

3. **Likely payoff**

   This setup will improve subtitle clarity by reducing network latency, allow for faster memory recall lookups on the phone, and maintain a low-friction interaction model where the wearer only needs to interact with the glasses through frame touches. It also keeps the system lightweight, which is crucial for battery and thermal management.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

   Ensuring a clear visual hierarchy between subtitles and one-line support helps maintain low-friction assistance while avoiding overwhelming the wearer with too much information. This alignment with core attractors increases trust in the system's ability to assist without overwhelming the user.
