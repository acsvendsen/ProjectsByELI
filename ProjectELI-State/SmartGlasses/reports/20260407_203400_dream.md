### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   By defining specific subtitle placement rules based on confidence levels, we can ensure that subtitles are always readable and clear, which is crucial for maintaining trust in live conversations. Stable subtitle placement helps the wearer understand the context without distraction, thus deepening the core mission of enhancing real-time understanding.

2. **What small change unlocks it**

   Define a fixed subtitle placement rule that keeps subtitles at the bottom center of the frame, with a margin to avoid obscuring important facial features. This simple change ensures that subtitles remain visible and unobtrusive regardless of head movements or gaze direction.

3. **Likely payoff**

   Implementing this fixed subtitle placement rule will result in more consistent and reliable subtitle visibility, reducing visual distractions during conversations. This will help maintain the wearer's focus on the conversation while providing clear textual support, thus strengthening the core mission.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving confidence display helps maintain trust in the system by clearly indicating the certainty level of the displayed subtitles and memory recall. A well-designed confidence format ensures that the wearer understands when they can rely on the information, which is crucial for effective communication.

2. **What small change unlocks it**

   Define a clear numeric score + label + short reason format for confidence objects. This means each confidence object should have a score (e.g., 0.84), a label (e.g., "High"), and a short reason (e.g., "Seen recently").

3. **Likely payoff**

   By implementing this confidence display, the system will be more transparent and trustworthy. The wearer can better understand when to trust the subtitles or memory recall, reducing uncertainty and increasing overall user satisfaction.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   By setting a local memory threshold for new-person recall, we ensure that only recently encountered faces or names are remembered with high confidence, reducing the risk of cluttering the wearer's memory with less relevant information. This helps maintain trust and reduces cognitive overload.

2. **What small change unlocks it**

   Define a local cache size limit for newly recognized people, ensuring that only recent encounters are cached on the phone until they can be reinforced over time through repeated interactions.

3. **Likely payoff**

   This will help in maintaining a balance between useful memory support and reducing cognitive load, leading to a more reliable and trust-worthy memory system. The wearer will have access to relevant names and faces without being overwhelmed by too much information.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

1. **Why it benefits the core**

   By defining a clear visual hierarchy between subtitles and one-line support, we can ensure that the wearer remains focused on the most critical information without being overwhelmed by additional prompts.
