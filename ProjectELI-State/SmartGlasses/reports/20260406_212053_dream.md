### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Improving subtitle placement rules under different confidence states helps ensure that subtitles remain readable, clear, and stable enough to trust in live conversations. This enhances the wearer's ability to follow the conversation without distraction or confusion.

2. **What small change unlocks it**

   Define 3 to 5 subtitle placement rules based on confidence levels: high (0.8+), medium (0.4-0.79), and low (below 0.4). These rules should prioritize stability and readability, especially for lower-confidence items.

3. **Likely payoff**

   By defining clear placement rules, the system will be more reliable in delivering subtitles that are easily readable, reducing visual distractions and ensuring continuous understanding during conversations.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving the confidence display format ensures that the wearer can trust the system's outputs more effectively. A well-designed confidence label and short reason will help the wearer understand when to rely on the subtitles and when to be cautious, thereby reducing cognitive load and increasing overall trust.

2. **What small change unlocks it**

   Define a new confidence object format: score 0.84 + "High" + "Seen recently".

3. **Likely payoff**

   This new format will provide clearer feedback to the wearer, enhancing their ability to trust the subtitles in noisy environments and complex conversations. It will reduce cognitive effort by making it easier for the wearer to prioritize information based on the system's confidence.

4. **Immediate next probe**
   - Define the label style for high confidence as "High" with a green color.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   By setting a clear local memory threshold for face/name recall, we ensure that the system does not overburden the wearer's privacy while still providing reliable support. This balance helps maintain trust and reduces unnecessary data handling.

2. **What small change unlocks it**

   Define a local cache size limit of 10 recent interactions per person for name recall purposes.

3. **Likely payoff**

   Setting this threshold ensures that the system only stores relevant, frequently encountered people, reducing memory overhead while maintaining effective support. This reduces the risk of privacy concerns and improves overall system efficiency.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By clearly defining what stays phone-local versus what falls back to cloud for live subtitle processing, we ensure that the most critical real-time data and processing remain on-device, reducing latency and ensuring trust in fast, stable subtitles during noisy environments.

2. **What small change unlocks it**

   Define a specific task boundary: "live subtitle processing." For this task, explicitly state which parts of subtitle generation can be handled locally on the phone without cloud assistance, and which parts require cloud processing due to complexity or data requirements.

3. **Likely payoff**

   This clarification will lead to more stable, faster subtitles in real-time interactions, enhancing trust and user experience by ensuring that critical data remains local. It also simplifies the architecture, reducing dependency on the cloud for every subtitle request, which is crucial for battery efficiency and latency management.

4. **Immediate next probe**

   Define one task-specific phone/cloud fallback boundary for live subtitle processing.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   By clearly defining the precedence between subtitles and one-line support in the visual hierarchy, we ensure that the most critical information (subtitles) remains prominent while still providing useful context through shorter prompts without overwhelming the wearer.

2. **What small change unlocks it**

   Define a simple coexistence rule for subtitle placement: subtitles should have priority over one-line support when confidence is high enough to trust the subtitle text, but allow one-line support to remain visible below or alongside subtitles as appropriate.

3. **Likely payoff**

   This approach will maintain high visual clarity and reduce cognitive load by ensuring that the wearer can focus on the most important information while still having access to contextual prompts when needed. It will enhance overall usability without creating distraction.

4. **Immediate next probe**
   - Define one visual priority rule between subtitles and one-line support in V1.
