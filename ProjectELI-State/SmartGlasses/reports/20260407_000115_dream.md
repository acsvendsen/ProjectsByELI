### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   By defining a fixed subtitle placement rule that minimizes distraction while ensuring readability, we can enhance the wearer's trust in the subtitles during live conversations. This stability reduces cognitive load and allows the user to focus on understanding the conversation rather than constantly adjusting their gaze.

2. **What small change unlocks it**

   Introduce a single fixed subtitle placement mode that places subtitles at the bottom center of the field of view, ensuring they are always visible but not obstructing primary visual tasks.

3. **Likely payoff**

   This simple and consistent placement rule will reduce distractions for the wearer, leading to better engagement in conversations and more trust in the system’s assistance. It will also help maintain a discreet UX that respects the social acceptability of the glasses.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

4. **Immediate next probe**

   Define one confidence format candidate for V1 that balances clarity with simplicity.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Improving local memory thresholds helps ensure that relevant names and faces are cached long enough for fast lookup without overwhelming the phone's limited resources. This directly supports the core attractors of real-time subtitle clarity and trustworthiness, as well as low-friction assistance by ensuring that key context is readily available to the wearer.

2. **What small change unlocks it**

   Define a local cache threshold for name recall that balances memory utility with thermal and battery constraints. For example, set a policy where names are cached locally if they have been seen multiple times within a recent time window (e.g., 10 minutes), but expire after a longer period (e.g., 24 hours).

3. **Likely payoff**

   By setting appropriate local cache thresholds, the system can reduce latency in name recall while managing resource usage effectively. This ensures that critical context is always available to the wearer without taxing the phone's battery or thermal performance.

4. **Immediate next probe**

   Define a local cache eviction policy where names are cached locally if they have been seen multiple times within 10 minutes but expire after 24 hours.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   Ensuring that live subtitle processing remains on the phone helps maintain real-time clarity and stability, which are crucial for the wearer's trust in using the product. By keeping this critical task local, we can avoid latency issues that could degrade the subtitles' readability and make them less reliable during conversations.

2. **What small change unlocks it**

   Define a clear boundary where live subtitle processing must always run on the phone, even if there is some cloud fallback for heavy context lookup or memory archive sync.

3. **Likely payoff**

   By keeping live subtitle processing local, we can ensure that subtitles remain fast and stable, which enhances the wearer's trust in using the product. This stability also means that the system can provide reliable real-time support during critical conversations, thereby improving the overall user experience without introducing significant latency or battery drain.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   Ensuring that subtitles are displayed in a way that coexists with one-line support without overloading the wearer is crucial for maintaining the core attractors of real-time clarity, low-friction assistance, and memory trust. By carefully managing the visual hierarchy between subtitles and one-line prompts, we can ensure that both pieces of information remain useful without causing confusion or distraction.

2. **What small change unlocks it**

   Define a priority rule where subtitles are given higher precedence than one-line support when they are present in the same frame, but allow for one-line prompts to be visible in limited spaces (e.g., corners) if necessary. This ensures that critical information is prioritized while maintaining a clean and unobtrusive interface.

3. **Likely payoff**

   By setting this priority rule, we can enhance the wearer's ability to follow conversations effectively by ensuring they see important subtitles first. Additionally, it will help in reducing visual clutter and making one-line prompts more useful as supplementary information rather than primary content.

4. **Immediate next probe**

   Define one subtitle-vs-one-line priority rule where subtitles are given higher precedence over one-line support when both are present in the same frame, but allow for one-line prompts to be visible in limited spaces (e.g., corners) if necessary.
