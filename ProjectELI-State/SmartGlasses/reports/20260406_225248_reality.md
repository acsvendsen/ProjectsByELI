# Reality Check for SmartGlasses Project

## Subtitle Placement

### Current Decision
The subtitle placement should remain usable without becoming distracting.

### Feasibility Assessment
- **Feasible Now**: The current approach, which prioritizes readability over distraction, is feasible now. Given the simplicity of V1 interaction through frame touches and the need for subtitles to be clear and stable in live conversation, placing subtitles at the bottom center or slightly above the glasses' display area could work well.
  
### Constraints
- **Battery Draw**: Subtitle placement should not significantly increase battery draw if it requires frequent updates.
- **Thermal Pressure**: The design should avoid complex visual animations that might generate heat and drain battery.

## Confidence Display

### Current Decision
The confidence format should build trust best: label only, label + short reason, or score + label.

### Feasibility Assessment
- **Feasible Now**: Given the need for low-friction assistance and real-time clarity, a simple label-only approach might be most effective initially. This can be refined later if needed.
  
### Constraints
- **Battery Draw**: The confidence display should not significantly increase power consumption or processing load.
- **Social Acceptability**: The design should ensure that the confidence indicator is subtle enough to avoid drawing too much attention.

## Memory/Cache Policy

### Current Decision
Face/name memory should be cached locally on the phone for fast lookup and trust, with reinforcement over time.

### Feasibility Assessment
- **Feasible Now**: Local caching of face/name memories can help reduce latency and ensure reliable recall. Reinforcement through repeated interactions will build stronger trust.
  
### Constraints
- **Battery Draw**: The memory cache should not consume excessive resources that could drain the battery or increase thermal pressure.
- **Privacy Perception**: The system must handle stored information in a way that minimizes privacy concerns, such as using encryption and secure storage mechanisms.

## Phone/Cloud Boundary

### Current Decision
Heavy processing should primarily happen on the phone, with cloud optional where clearly justified.

### Feasibility Assessment
- **Feasible Now**: Given the V1 interaction constraints and the need for real-time subtitle clarity, local processing is appropriate. The cloud can be used for background model updates and non-critical tasks.
  
### Constraints
- **Battery Draw**: Cloud interactions should minimize battery draw to maintain consistent performance.
- **Latency**: Local processing should ensure low latency for essential features like subtitles.

## Visual Hierarchy

### Current Decision
Display behavior should remain socially acceptable while still being readable in motion and noise.

### Feasibility Assessment
- **Feasible Now**: The visual hierarchy can focus on clarity over feature density. Subtitles placed at the bottom center or slightly above, with a clean layout, will help maintain readability without overwhelming the wearer.
  
### Constraints
- **Battery Draw**: Complex UI elements that consume more battery are not recommended.
- **Social Acceptability**: The design should ensure that the subtitle display is discreet enough to avoid drawing too much attention.

## Summary

Based on the current project inputs and constraints, the following directions are feasible now:

- **Subtitle Placement**: Place subtitles at the bottom center or slightly above for clarity and usability.
- **Confidence Display**: Use a label-only approach initially to minimize complexity and battery draw.
- **Memory/Cache Policy**: Cache face/name memories locally with reinforcement over time for fast lookup and trust.
- **Phone/Cloud Boundary**: Focus on local processing for essential features like subtitles, using the cloud for background tasks.
- **Visual Hierarchy**: Design a clean, readable layout that remains discreet.

These decisions align with the core mission of creating a discreet, context-aware personal assistant that enhances real-world interactions without overwhelming the wearer.
