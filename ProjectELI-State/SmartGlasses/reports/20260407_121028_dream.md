### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Ensuring stable subtitle placement rules in V1 helps maintain consistent trust and readability for the wearer, reducing cognitive load during conversations and improving overall user experience.

2. **What small change unlocks it**

   Define a fixed position rule for subtitles that keeps them below and to the side of the primary video feed, ensuring they remain visible without obstructing the main view.

3. **Likely payoff**

   By setting a stable subtitle placement rule, V1 can maintain consistent visual clarity and trustworthiness in live conversations, enhancing the wearer's understanding and reducing distraction from variable subtitle positions.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   By refining the confidence display format to provide clear, concise, and actionable certainty indicators, the system can better manage the trust dynamic between the wearer and the assistant. This ensures that the wearer is aware of the reliability of the information provided, which in turn fosters a stronger sense of reliability and usability.

2. **What small change unlocks it**

   Introduce a new confidence format: `score 0.85 + "High" + "Seen recently and verified"`. This simple change provides a numeric score with a label and reason that clearly communicate the level of certainty to the wearer.

3. **Likely payoff**

   The improved confidence display will help in building trust by making it clear when information is highly reliable. This can lead to better adoption and usage of the system, as users are more likely to rely on accurate and well-supported information provided by the glasses.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Improving local memory thresholds ensures that the system can handle a consistent number of people and names without overloading the wearer's trust in the device. By setting a clear limit on how many entities are cached locally, we can prevent the memory from becoming overly complex or unreliable, which would undermine the goal of providing trustworthy personal support.

2. **What small change unlocks it**

   Define a local cache size limit for storing name and face recall data, ensuring that the system does not exceed 10-15 entries in the local memory without prompting reinforcement through explicit touch interactions.

3. **Likely payoff**

   By setting a clear and manageable threshold on local caching, the system can ensure that the memory stays reliable and that users are prompted to reinforce their memories regularly. This approach enhances trust by maintaining a balance between rich contextual support and avoidable overload.

4. **Immediate next probe**

   Define one local-cache size limit for name recall data storage, setting it to 10 entries as a starting point.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By refining the phone/cloud boundary for live subtitle processing, we can ensure that critical real-time data remains on-device to maintain low latency and high privacy. This focus on local processing for subtitle generation reduces dependency on cloud resources and ensures that the glasses remain highly responsive and trustworthy during live conversations.

2. **What small change unlocks it**

   Define a specific task boundary where live subtitles are processed locally, such as "live subtitle processing," and ensure this process runs entirely on the phone without falling back to the cloud unless absolutely necessary for context or model updates.

3. **Likely payoff**

   By keeping critical real-time subtitle generation local, we can maintain faster response times, lower latency, and a more privacy-conscious design that avoids transmitting sensitive audio data over potentially insecure networks. This improves the overall trustworthiness and reliability of the system in noisy environments where immediate responsiveness is crucial.

4. **Immediate next probe**

   Define one phone-local processing rule for live subtitle generation that ensures all subtitle text is generated on the phone, with no fallback to the cloud unless explicitly necessary for model updates or context enrichment.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   Ensuring a clear visual hierarchy between subtitles and one-line support helps maintain the wearer's focus on critical information without overwhelming them. This balance enhances the overall clarity of the interface, making it easier for the wearer to follow conversations and understand contextual prompts.

2. **What small change unlocks it**

   Define a single visual priority rule that ensures subtitles are always displayed prominently while one-line prompts appear as secondary support text. This can be achieved by setting higher display precedence for subtitles over one-line prompts in all contexts.

3. **Likely payoff**

   By establishing a clear visual hierarchy, the system will reduce cognitive load and improve the wearer's ability to follow conversations effectively. This clarity supports the core mission of low-friction assistance without adding unnecessary complexity or distraction.

4. **Immediate next probe**
   - Define one visual priority rule between subtitles and one-line support in V1.
