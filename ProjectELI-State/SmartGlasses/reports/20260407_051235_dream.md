### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   By defining specific subtitle placement rules for different confidence states, we ensure that subtitles remain clear and stable enough to be trusted during live conversations while minimizing visual distraction. This improves real-time subtitle clarity and helps maintain the wearer's focus on the conversation.

2. **What small change unlocks it**

   Define three subtitle placement rules: 
   - **High Confidence**: Place subtitles at the bottom of the screen with minimal animation.
   - **Medium Confidence**: Place subtitles slightly above the center, with smooth transition animations.
   - **Low Confidence**: Hide subtitles or place them off-screen until confidence improves.

3. **Likely payoff**

   Implementing these rules will ensure that high-confidence subtitles are easy to read and do not distract the wearer, while medium-confidence subtitles provide useful context without overwhelming the visual field. Low-confidence subtitles can be managed in a way that does not disrupt the conversation flow, thereby maintaining trust and focus.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving confidence display by refining the label format, short reason, and numeric score presentation will enhance trust in the system's reliability and accuracy, making the wearer more confident in the subtitles and memory support provided.

2. **What small change unlocks it**

   Define a confidence object format that uses a simple score (e.g., 0.84), a label (e.g., "High"), and a short reason (e.g., "Seen recently"). This can be implemented as a new default behavior in V1, ensuring that the confidence display is clear and consistent.

3. **Likely payoff**

   By providing a concise yet informative way to show confidence, users will have a better understanding of the system's reliability, leading to increased trust and more effective use of the glasses during live conversations.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   By setting a local cache threshold for name recall, we can ensure that common names and faces are quickly accessible without frequent network requests, thereby reducing latency and improving trust in real-time interactions.

2. **What small change unlocks it**

   Define a local cache eviction policy that retains commonly encountered names and faces on the phone for quick lookup, while evicting less frequently seen entries to manage memory usage.

3. **Likely payoff**

   This change will reduce the time it takes to recall familiar names during conversations, enhancing the wearer's ability to engage confidently without waiting for cloud responses. It also supports the core attractor of trustworthy memory support by ensuring that key entities are always available quickly.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

1. **Why it benefits the core**

   By defining a clear visual hierarchy between subtitles and one-line prompts, the system can ensure that subtitles remain primary and unobtrusive while providing additional support when needed without overwhelming the wearer.
