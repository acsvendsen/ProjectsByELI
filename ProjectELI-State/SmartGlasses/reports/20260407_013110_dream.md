### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Improving subtitle placement rules will ensure that subtitles remain clear, stable, and unobtrusive during live conversations. This directly aligns with the primary attractor of real-time subtitle clarity, which is high in importance.

2. **What small change unlocks it**

   Define three fixed subtitle placement modes: one for low-confidence situations, another for medium-confidence scenarios, and a third for high-confidence contexts. Use confidence levels to route subtitles more appropriately without reacting to each individual frame touch.

3. **Likely payoff**

   By defining these fixed placement rules, the glasses will provide a consistent and reliable viewing experience. This will enhance the wearer's trust in the subtitles, which is critical for maintaining the core mission of helping them understand better in noisy environments.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving the confidence display format ensures that the wearer can trust the subtitle and memory support more reliably. A well-designed confidence object helps in maintaining a balance between providing enough information for reassurance without overwhelming the user with too much detail.

2. **What small change unlocks it**

   Define a concise confidence object format that includes a numeric score, label, and short reason. For example: `score 0.85 + "High" + "Seen recently"`.

3. **Likely payoff**

   By providing clear, understandable confidence indicators, the system can enhance the wearer's trust in the subtitles and memory support. This will lead to a more natural and intuitive experience where the user feels supported without being bombarded with complex information.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   By setting a local memory threshold for face/name recall, we ensure that the system remembers key individuals effectively while respecting battery constraints. This helps maintain trust and usefulness by providing timely support without overwhelming the wearer's device.

2. **What small change unlocks it**

   Define a simple rule: cache up to 10 new faces/names in local memory on the phone for the current session, refreshing the top 5 most recent encounters each time a new face/name is recognized.

3. **Likely payoff**

   This local caching policy will provide just-in-time support for frequently encountered individuals without overloading the device's memory or battery. It ensures that key people are always remembered and helps in building trust through consistent, reliable memory recall.

4. **Immediate next probe**
   - Set a local cache size limit of 10 new faces/names per session.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

By defining a clear boundary for what stays phone-local versus falling back to cloud processing, we can ensure that V1 interactions remain focused on real-time subtitle clarity and memory support without overloading the glasses hardware. This helps maintain the product's lightweight nature while ensuring critical functions are handled efficiently.

2. **What small change unlocks it**

Define a specific task boundary for live subtitle processing: prioritize subtitle rendering and initial placement rules to stay phone-local, with cloud fallback only for advanced face/name recall or memory archive sync tasks that require more computation.

3. **Likely payoff**

This clear delineation will enable V1 to focus on delivering high-quality, real-time subtitles without battery drain from heavy processing. It also ensures that the glasses remain socially acceptable while offloading complex tasks like detailed memory lookup and archival to the phone or cloud when needed.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   Ensuring that subtitles are stable and unobtrusive enhances the wearer's ability to follow conversations in real-time without being distracted by frequent repositioning or movement of subtitle text. This stability is crucial for maintaining trust and ensuring that the assistive feature remains a helpful tool rather than an annoyance.

2. **What small change unlocks it**

   Define two subtitle placement rules: one for high-confidence contexts where subtitles can be placed lower on the screen to avoid obstruction, and another for low-confidence contexts where subtitles need to remain at the top of the screen to ensure they do not move out of sight during rapid conversations.

3. **Likely payoff**

   By setting stable subtitle placement rules based on confidence levels, V1 will maintain a consistent visual experience that minimizes distractions while ensuring critical information is always visible when needed. This will enhance trust and usability in noisy or complex environments.

4. **Immediate next probe**
   - Define one visual priority rule between subtitles and one-line support in V1.
