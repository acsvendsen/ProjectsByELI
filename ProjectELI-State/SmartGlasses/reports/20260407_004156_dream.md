### Idea 1: Subtitle Placement

1. **Why it benefits the core**
   - By defining a fixed subtitle placement rule that is stable across different confidence states, we can ensure consistent and predictable behavior, which helps in building trust with the wearer. This stability allows for faster lookup and more reliable memory support without causing distraction.

2. **What small change unlocks it**
   - Define one fixed subtitle placement mode where subtitles appear at a specific position on the screen (e.g., bottom center) regardless of confidence levels or other factors.

3. **Likely payoff**
   - A consistent subtitle placement will reduce cognitive load by eliminating the need for the wearer to constantly adjust their gaze, which can be particularly important in noisy environments. This predictability also enhances trust as the subtitles are always located in a known position, improving overall user satisfaction and comfort.

4. **Immediate next probe**
   - Define one fixed subtitle placement mode where subtitles appear at the bottom center of the screen.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   By setting a local cache threshold for name recall, we ensure that frequently encountered names are stored on the phone to provide fast lookup and reduce latency. This improves the trustworthiness of memory support by ensuring quick access to recently seen faces and names, which is crucial for maintaining context in real-time interactions.

2. **What small change unlocks it**

   Define a local cache threshold of 10 recent face/name encounters on the phone that are kept in memory with a recency-based eviction policy.

3. **Likely payoff**

   This change will significantly enhance the speed and reliability of name recall, reducing latency and improving the overall trustworthiness of the memory support feature. It ensures that common names seen recently can be quickly accessed without cloud fallback, making interactions smoother and more natural.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.
