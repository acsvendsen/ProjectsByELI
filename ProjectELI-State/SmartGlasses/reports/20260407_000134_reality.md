# Reality Check for SmartGlasses

Based on the provided core field, scorecard, and linked documents, here are the assessments for various aspects of the project:

## Subtitle Placement: Feasible Now
- **Subtitle Placement**: The primary attractor is to maintain clear, fast, and stable subtitles that enhance live conversation. Given current implementation in `TranscriptLab` focusing on real-time transcript behavior, it is feasible to continue refining subtitle placement now. Ensuring subtitles do not become distracting while remaining readable is a practical constraint but should be achievable with ongoing tweaks.
  
## Confidence Display: Feasible Now
- **Confidence Display**: The project emphasizes honesty and trust in confidence display. A label-only format or a brief reason with the label seems feasible based on current implementation constraints. For now, ensuring that confidence indicators are clear and do not overwhelm the wearer is practical.

## Memory/Cache Policy: Feasible Later
- **Memory/Cache Policy**: The project needs to balance memory support for names and faces without creating corrupted recall. Given the current focus on phone-first processing and minimal local storage, this aspect can be addressed later as more data is gathered through usage and testing. Early efforts should prioritize core subtitle clarity and low-friction assistance.

## Phone/Cloud Boundary: Feasible Now
- **Phone/Cloud Boundary**: The initial direction of phone-first processing with cloud support only where clearly justified remains feasible now. Ensuring that the transcript test bed in `TranscriptLab` closely mirrors future glasses behavior is a practical step towards defining this boundary more concretely.

## Visual Hierarchy: Feasible Now
- **Visual Hierarchy**: The goal is to balance clarity and visual hierarchy without becoming too complex or distracting. Given current efforts in `TranscriptLab`, it is feasible to continue refining how subtitles and one-line prompts coexist, ensuring they do not overwhelm the wearer but provide useful assistance.

## Real-time Subtitle Clarity: Feasible Now
- **Real-time Subtitle Clarity**: The core attractor of maintaining clear, fast, and stable subtitles that enhance live conversation is a practical goal. Continuous testing through `TranscriptLab` can help refine this aspect now without requiring new hardware or complex interactions.

- **Latency vs Richness**: The core focus on real-time subtitle clarity and low-friction assistance is feasible now.
