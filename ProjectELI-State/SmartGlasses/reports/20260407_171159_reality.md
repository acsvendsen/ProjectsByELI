**Reasoning:** Confidence behavior should be clear to the wearer but not overloading. The current focus is on ensuring subtitles are reliable and readable, which can be tested and iteratively improved using `TranscriptLab`. This does not require new sensors or complex interaction patterns.

**Reasoning:** The current direction favors a phone-first runtime for heavy processing while keeping glasses hardware simple. **Reasoning:** Defining the visual hierarchy that balances clarity with non-distracting design requires a better understanding of how subtitled information interacts with other UI elements. This can be explored in future iterations once basic subtitle and confidence behaviors are well-established.
