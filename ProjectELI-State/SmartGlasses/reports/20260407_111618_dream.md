### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Improving subtitle placement rules can enhance the wearer's trust in the system by ensuring subtitles remain stable and readable during live conversations. Stable, well-placed subtitles reduce cognitive load and visual distraction, allowing the wearer to focus more on the conversation itself.

2. **What small change unlocks it**

   Define a fixed subtitle placement rule that ensures subtitles appear at the bottom center of the field of view (FOV), with minimal text overlap for clarity. This simple change can prevent subtitles from shifting too much or being obstructed by other UI elements, providing a more consistent and reliable experience.

3. **Likely payoff**

   By fixing the subtitle placement to a stable, central position, users will experience less visual distraction during conversations. This stability will enhance their trust in the system's ability to provide clear, unobstructed subtitles, leading to a better overall user experience.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving confidence display ensures that the wearer can trust the system's output by understanding when the system is certain versus uncertain. This builds a foundation for all other interactions, as the wearer will rely more on the system if they know its reliability level.

2. **What small change unlocks it**

   Define one specific format for confidence labels and short reasons that clearly communicate certainty levels to the wearer. For example, use "High" with "Seen recently," "Medium" with "Name heard once in introduction," and "Low" with "Weak match."

3. **Likely payoff**

   By making the confidence display clear and understandable, users will trust the system more, which can lead to better engagement and adoption of the product. Trust is a critical component for any personal assistant, as it ensures that the wearer feels comfortable relying on the system's output.

4. **Immediate next probe**
   - Define the format for confidence labels to use "High," "Medium," and "Low" levels.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   By optimizing the local cache size for name recall, we can ensure that critical memory objects are available quickly without consuming excessive battery or storage resources. This improves the wearer's trust in the system by providing fast and accurate responses to common queries.

2. **What small change unlocks it**

   Define a fixed-size LRU (Least Recently Used) cache on the phone for name recall, with a threshold of 10 names per session. This cache will store names seen frequently during the current interaction context.

3. **Likely payoff**

   Implementing this cache strategy will reduce latency in recalling common names and faces, enhancing the wearer's trust in the system’s memory capabilities. It also ensures that battery usage remains low by limiting the amount of data stored locally.

4. **Immediate next probe**

   Define one LRU cache eviction rule for name recall with a fixed size limit of 10 names per session to balance memory and performance constraints.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By defining a clear boundary for what stays phone-local versus what falls back to cloud for live subtitle processing, we ensure that subtitles remain fast and reliable in noisy environments. This helps maintain the wearer's trust by keeping the critical real-time function on-device, where latency is minimized.

2. **What small change unlocks it**

   Define one specific task boundary: live subtitle processing. For this task, decide which parts of the subtitle generation pipeline (e.g., initial transcription, confidence calculation) should run entirely phone-local and which can safely offload to cloud for optimization or backup purposes.

3. **Likely payoff**

   By keeping live subtitle processing local, we reduce latency, ensure real-time responsiveness, and maintain a high level of trust in the assistant's accuracy. This will improve the wearer’s understanding in noisy environments without introducing additional network dependencies that could delay or degrade performance.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

2. **What small change unlocks it**

3. **Likely payoff**
