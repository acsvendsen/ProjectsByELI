- **Feasible Now**:

Given that `TranscriptLab` is currently used to test live transcript behavior, it is feasible to continue refining subtitle placement within this app to ensure subtitles are clear, fast, and stable enough for trust in real conversations.
  
## Memory Trust (Confidence Display)
- **Feasible Now**: 
  - The current version of `TranscriptLab` can be used to prototype different confidence display methods. For instance, testing a label-only approach or a combination of labels with short reasons could help determine the best way to represent confidence without overwhelming the wearer.
  
## Low-Friction Assistance (Subtitle and Prompt Coexistence)
- **Feasible Now**: 
  - Since V1 interaction is frame-touch only, experimenting with different ways to coexist subtitles and one-line prompts within this constraint is feasible. This can be done by ensuring that prompts are distinct enough from subtitles but still provide useful assistance without cluttering the display.
  
## Confidence Display (Subtitle and Prompt Coexistence)
- **Feasible Now**: 
  - Using `TranscriptLab` to test different confidence formats, such as labels only or label + short reason, is a practical approach. This will help in understanding which method builds trust best while remaining unobtrusive.

## Memory/Cache Policy (Face/Name Recall)
- **Feasible Now**: 
  - The current `TranscriptLab` setup can be used to prototype and test the caching of face/name memory on the phone. Evaluating how much local storage is needed for fast lookup without compromising battery or overheating will help in refining this aspect.
