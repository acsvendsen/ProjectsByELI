### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   By defining stable subtitle placement rules that prioritize readability over distraction, we ensure the wearer can trust subtitles in live conversation without visual overload. This helps maintain high real-time subtitle clarity and enhances overall user experience.

2. **What small change unlocks it**

   Define two subtitle placement modes: one for low-confidence states (where subtitles are displayed slightly off-center) and another for high-confidence states (where subtitles align more centrally). This simple distinction allows the system to adjust placement based on confidence, improving readability without overwhelming the wearer.

3. **Likely payoff**

   The payoff is a balanced visual experience that enhances trust in live conversations by making subtitles easily readable yet not overly distracting. Stable subtitle placement rules reduce cognitive load and improve overall user satisfaction.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving the confidence display format will enhance the trustworthiness of the system by clearly indicating the reliability of the displayed information. This ensures that the wearer can make informed decisions based on accurate and reliable data, which is crucial for real-time subtitle clarity and memory support.

2. **What small change unlocks it**

   Define a simple yet effective confidence label format that includes both a numeric score and a short reason. For example, using "score 0.84 + 'High' + 'Seen recently'" or "score 0.42 + 'Low' + 'Weak match'". This approach balances clarity with simplicity.

3. **Likely payoff**

   By implementing a clear confidence display format, the system will gain more user trust, leading to better acceptance and usage. This will also help in scenarios where real-time accuracy is crucial, such as during live conversations or complex meetings.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By defining a clear boundary for what stays on the phone versus what falls back to the cloud, we can ensure that V1 remains focused and usable while still leveraging remote processing where it provides real value. This helps in maintaining the balance between privacy, usability, and functionality without overloading the glasses with heavy computations.

2. **What small change unlocks it**

   Define a specific task boundary for live subtitle processing that stays on the phone, such as handling of initial transcript capture and basic confidence scoring, while more complex tasks like transcript cleanup or face/name recall fallback to the cloud only when necessary.

3. **Likely payoff**

   This refinement will help in keeping V1 lightweight and reliable by offloading computationally intensive tasks, thus preserving battery life and ensuring real-time responsiveness. It also aligns with the core mission of providing clear, useful assistance without overcomplicating the system.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

   By clearly defining how subtitles coexist with one-line support in visual hierarchy, we ensure that the product remains useful without overwhelming the wearer. This helps maintain a balance between providing necessary context and keeping the display uncluttered, which is crucial for real-time interaction clarity and trust.
