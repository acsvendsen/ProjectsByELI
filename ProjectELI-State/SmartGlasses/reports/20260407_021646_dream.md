### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   By defining a stable subtitle placement rule that prioritizes readability over distraction, we ensure the subtitles remain clear and usable in noisy environments. This helps maintain the wearer's trust and focus on the conversation.

2. **What small change unlocks it**

   Define a simple subtitle placement rule where subtitles are placed at the bottom center of the frame when the confidence is high (e.g., 0.9+), and move to the side if there is ambiguity or lower confidence (e.g., <0.8).

3. **Likely payoff**

   This change will reduce distraction while ensuring that critical information remains visible, thereby enhancing the wearer's ability to follow conversations without being overwhelmed by visual elements.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving the confidence display format ensures that users can trust the system's memory support, which is crucial for building a reliable personal assistant. A well-designed confidence display will help reinforce user trust by clearly indicating the certainty of remembered names and faces.

2. **What small change unlocks it**

   Define a confidence object format that includes a numeric score, a label, and a short reason. For example: "score 0.85 + 'High' + 'Seen recently in this conversation'. This format provides clarity while remaining simple enough for quick understanding.

3. **Likely payoff**

   By clearly indicating the certainty of name recall, users can better trust the system's memory support during critical interactions. This will reduce cognitive load and social friction, enhancing overall user satisfaction and reliability.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Improving memory cache size thresholds helps ensure that critical face and name memories are retained long enough for effective recall without overloading local storage, thereby maintaining trust in the system's ability to assist with names and conversations.

2. **What small change unlocks it**

   Define a local-memory threshold policy where each new person memory is stored until their confidence score falls below a certain threshold or a reinforcement interval of 30 days, whichever comes first.

3. **Likely payoff**

   By setting a clear retention period for face and name memories, the system can maintain a balance between useful memory recall and efficient local storage use. This improves overall trust and reliability in real-world interactions without excessive data retention.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By defining a clear boundary for what stays phone-local versus what falls back to cloud processing, we ensure that V1 remains focused on delivering real-time subtitle clarity and trustworthiness without overloading the glasses hardware with complex tasks. This will help in maintaining low latency and preserving battery life, which are crucial for the core attractors of real-time subtitle clarity and memory support.

2. **What small change unlocks it**

   Define a single task boundary for live subtitle processing that stays phone-local. For example, decide on rules for when to process subtitles directly on the phone versus sending audio to the cloud for more advanced speech-to-text processing.

3. **Likely payoff**

   By keeping subtitle processing local, we can ensure faster response times and lower power consumption, which are key factors in maintaining high real-time clarity and trustworthiness of subtitles. This will also allow us to continuously improve the local model without impacting battery life or causing delays.

4. **Immediate next probe**

   Define one live subtitle processing rule where audio is sent directly to the phone for on-device speech-to-text conversion, limiting cloud fallbacks only to cases with poor signal quality or complex speech inputs that require more computational power.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   Ensuring a clear visual hierarchy between subtitles and one-line prompts enhances the wearer's ability to focus on key information without overwhelming them. This improves the overall clarity of the user experience, ensuring that critical details are prioritized for attention while non-essential content remains secondary.

2. **What small change unlocks it**

3. **Likely payoff**

This enhances trust in the system's ability to provide relevant assistance while maintaining a natural and unobtrusive appearance.
