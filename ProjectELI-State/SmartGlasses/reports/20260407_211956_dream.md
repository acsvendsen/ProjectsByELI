### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   By defining specific subtitle placement rules for different confidence states, we can ensure that subtitles remain clear and stable while still providing useful information. This approach helps in maintaining a balance between real-time usability and visual distraction, thereby enhancing the wearer's understanding without overwhelming them.

2. **What small change unlocks it**

   Define two to three subtitle placement rules based on the speaker's confidence level: 
   - High-confidence speakers get subtitles centered but slightly dimmed.
   - Medium-confidence speakers get subtitles positioned slightly off-center and more visible.
   - Low-confidence speakers have subtitles placed at the bottom of the field of view, with a higher visibility setting.

3. **Likely payoff**

   This change will help in reducing visual distraction during high-confidence conversations while ensuring that low-confidence or uncertain speech is clearly visible. It also aligns with the core mission of providing real-time and trust-preserving subtitle assistance.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

Improving the confidence display format ensures that the wearer can trust the system's feedback more reliably. By providing clear and concise confidence indicators, we enhance the overall reliability of both subtitle placement and memory support. This clarity fosters a sense of honesty and integrity in the assistant's behavior, which is crucial for building user trust.

2. **What small change unlocks it**

Define one confidence format candidate that includes a numeric score, label, and short reason. For example, a format like "score 0.85 + 'High' + 'Seen recently'".

3. **Likely payoff**

By standardizing the confidence display, we can ensure consistent behavior across all interactions. This will help in reinforcing the trust the wearer has in the system's accuracy and reliability. Clear confidence indicators will reduce ambiguity and provide a more reliable foundation for both subtitle placement and memory support.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Improving the local memory cache policy ensures that frequently encountered faces and names are remembered with high confidence, reducing the need for cloud fallbacks and minimizing latency. This enhances the wearer's trust in the system by providing more reliable and timely recall of important information.

2. **What small change unlocks it**

   Define a local cache threshold for face/name memory objects, ensuring that entities seen within the last 30 days are stored locally with high confidence levels. This threshold can be set to evict less frequently seen entities after 90 days to maintain a reasonable cache size.

3. **Likely payoff**

   By maintaining a consistent and reliable local cache of recently encountered faces and names, the system will reduce the need for cloud fallbacks during live conversations, leading to more stable and faster memory recall. This improves the overall user experience by ensuring that critical information is readily available without latency or privacy concerns.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By defining a clear boundary for what stays phone-local versus what falls back to cloud for transcript cleanup, we ensure that V1 can provide fast and reliable subtitle support without overwhelming the glasses' limited resources. This improves real-time subtitle clarity and reduces battery drain, aligning with the core attractors of subtitle clarity and low-friction assistance.

2. **What small change unlocks it**

   Define a specific task boundary where transcripts are cleaned up on-device versus sent to the cloud for processing. For example, set a rule that any transcript more than 30 seconds old should be processed locally before being sent to the cloud.

3. **Likely payoff**

   By keeping older transcripts local, we can ensure faster response times and lower battery usage, which in turn improves subtitle clarity and user trust. This boundary also helps manage thermal constraints and ensures that the glasses remain socially acceptable for extended use.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   Improving the visual hierarchy between subtitles and one-line support ensures that the wearer can easily focus on critical information while maintaining a low-friction, unobtrusive experience. This helps in reducing cognitive load and social awkwardness, aligning with the core attractors of real-time subtitle clarity and low-friction assistance.

2. **What small change unlocks it**

   Define a clear visual priority rule that shows subtitles above one-line support by default but allows one-line prompts to override subtitles when necessary for critical context or urgency. This can be achieved by adjusting the display precedence in the UI layer without changing core subtitle placement logic.

3. **Likely payoff**

   By establishing a prioritization rule, the system will better manage the wearer's attention during conversations, ensuring that they are more likely to see and process important information quickly. This reduces distraction and enhances overall understanding, which is crucial for both memory support and real-time assistance.

4. **Immediate next probe**

   Define one visual priority rule between subtitles and one-line support: subtitles should display above one-line prompts by default, but critical one-line prompts can override subtitle visibility when necessary.
