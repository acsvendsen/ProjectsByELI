## Project Summary
The project is focused on creating a discreet smart glasses system that assists with real-time subtitles, face/name recall, conversation memory, and one-line prompts. The current V1 will use frame-touch interaction exclusively, avoid voice commands, and leverage the phone for heavy processing while keeping hardware minimal.

- limitation pressure: weight, social acceptability, battery
- progress: The project is keeping hardware minimal with focus on text display and frame-touch interaction. No new sensors or complex hardware are introduced in V1, aligning with the goal.
