### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   By defining a stable subtitle placement rule that prioritizes readability over distraction, we ensure that subtitles remain clear and unobtrusive during live conversations. This helps maintain the wearer's focus on their environment while still providing necessary assistance, thereby upholding the core attractors of real-time clarity and low-friction assistance.

2. **What small change unlocks it**

   Define a subtitle placement rule where subtitles are always displayed below the speaking face, with a fixed height that ensures they remain visible without obscuring important visual cues or becoming distracting. This simple change prevents subtitles from moving erratically based on gaze direction or speaker proximity, ensuring consistent and reliable display.

3. **Likely payoff**

   By implementing a stable subtitle placement rule, we reduce cognitive load for the wearer by providing predictable and unobtrusive information. This improves the overall user experience, aligning with the core attractors of real-time clarity and low-friction assistance. Consistent subtitle positioning also helps in building trust over time as the system becomes more reliable.

4. **Immediate next probe**
   - Define a fixed position rule where subtitles are always displayed 10 pixels below the speaking face.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving the confidence display format directly enhances user trust in the system's memory and recall capabilities. A well-crafted confidence indicator ensures that the wearer understands the reliability of the information provided, which is crucial for maintaining their belief in the assistant's accuracy and helpfulness.

2. **What small change unlocks it**

   Define a clear and concise confidence format that combines a numeric score with a label and a short reason. For example, use "score 0.85 + 'High' + 'Seen multiple times'" to indicate high certainty based on frequent recent encounters.

3. **Likely payoff**

   A well-designed confidence display will help users understand the reliability of names and faces remembered by the system. This increased trust can lead to more effective memory recall during interactions, thereby enhancing the overall assistive value of the smart glasses.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Improving memory cache size and eviction rules will ensure that the glasses can store and retrieve relevant names and faces efficiently without overwhelming local storage, thus maintaining trust in name recall during conversations.

2. **What small change unlocks it**

   Define a simple cache policy where new face/name memories are added to a fixed-size local cache, and old entries are evicted based on recency. For example, limit the cache to 10 entries and evict the least recently seen ones when the limit is reached.

3. **Likely payoff**

   By optimizing memory caching, we can ensure that frequent faces and names remain accessible for quick recall while keeping the local storage footprint manageable. This will enhance trust in name recognition during conversations without compromising on real-time performance or battery life.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By defining a clear boundary for what stays phone-local versus what falls back to cloud, we can ensure that V1 remains focused on delivering real-time, low-latency subtitle assistance and memory support without compromising battery or thermal constraints. This helps maintain the core mission of providing discreet, context-aware personal assistance.

2. **What small change unlocks it**

   Define a specific task boundary for live subtitle processing where all heavy audio processing, speech-to-text conversion, and initial subtitle generation happen on the phone, with only necessary corrections or enhancements falling back to cloud.

3. **Likely payoff**

   By keeping live subtitle processing local, we can ensure that subtitles remain clear, fast, and stable enough to be trusted in real-time conversations. This will reduce latency and conserve battery life, which are critical for V1 success. Additionally, this boundary will allow us to focus on optimizing the phone-side implementation without being constrained by cloud latency.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   By optimizing the visual hierarchy between subtitles and one-line support, we can ensure that the wearer remains focused on the most critical information without being overwhelmed by additional text. This improves the overall user experience, making sure the wearer stays present in conversations and understands key points more effectively.

2. **What small change unlocks it**

   Define a clear precedence rule where subtitles have higher visual prominence than one-line prompts when both are active simultaneously. For example, subtitles should always be displayed prominently on the top half of the field of view, while one-line support appears below them in a smaller, less intrusive manner.

3. **Likely payoff**

   Implementing this rule will reduce cognitive load by ensuring that the wearer’s attention is primarily drawn to the most important information (subtitles). This can significantly enhance understanding and comprehension during live conversations, thereby strengthening the core mission of providing clear real-time assistance.

4. **Immediate next probe**
   - Define one visual priority rule between subtitles and one-line support in V1.
