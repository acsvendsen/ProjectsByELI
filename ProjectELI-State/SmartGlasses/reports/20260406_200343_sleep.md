## Core Field

- **Mission**: Create smart glasses that act as a discreet, context-aware personal assistant focused on live subtitles, face/name recall, conversation memory, and one-line support.
- **Non-negotiables**:
  - Glasses help the wearer.
  - Early hardware remains simple: display text, record audio/visual input; phone/cloud handles heavy processing.
  - V1 interaction is frame-touch only.
  - Context must persist across sessions.
  - New faces and names should be remembered with confidence objects and reinforcement over time.

## Recent Realizations

- **Subtitle Quality**: Subtitles must remain clear, fast, and stable to maintain trust during live conversations. Improving subtitle quality should not compromise memory trust or visual clarity.
- **Memory Support**: Memory support for names, faces, and prior context must be trustworthy without creating false certainty. The system should avoid overloading the wearer with unnecessary information.
- **Low-Friction Interaction**: One-line prompts and visible support should be low-friction to ensure the user experience remains natural and unobtrusive.
