### Idea 1: Subtitle Placement

1. **Why it benefits the core**
   Enhancing subtitle placement rules can significantly improve the wearer's ability to follow live conversations by ensuring subtitles are always visible, stable, and unobtrusive. This will help maintain trust in the system as users rely on clear, consistent information.

2. **What small change unlocks it**
   Define a simple fixed placement rule that keeps subtitles at the bottom of the frame, away from the main visual content, while ensuring they remain within easy view without obstructing peripheral vision or causing distraction.

3. **Likely payoff**
   By maintaining a stable and unobtrusive subtitle position, users will be more likely to rely on the system for real-time information during conversations. This will enhance the overall user experience and trust in the SmartGlasses' capabilities.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Memory caching helps ensure that critical person information is readily available, reducing the risk of lookup latency and improving the reliability of confidence objects over time. By setting a local cache size limit, we can balance memory usage with recall speed and accuracy.

2. **What small change unlocks it**

   Define a policy where new face/name encounters are cached locally for at least 7 days before eviction to ensure recent memories are not lost but old ones make room.

3. **Likely payoff**

   By caching recently encountered faces and names, the system can provide faster and more accurate confidence objects without the need for constant cloud queries. This reduces latency and improves overall memory trustworthiness.

4. **Immediate next probe**

   Define a local cache eviction policy that retains new face/name encounters for at least 7 days before evicting them to balance memory usage with recall speed and accuracy.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   Stabilizing the phone/cloud boundary for live subtitle processing ensures that the wearer gets timely, accurate subtitles without unnecessary latency or data usage. This helps maintain trust by providing near-real-time assistance, which is crucial for the smart glasses' primary mission of helping the wearer understand and respond in real-world interactions.

2. **What small change unlocks it**

   Define a specific task boundary for live subtitle processing that stays phone-local unless explicitly justified otherwise. For example, set a policy where subtitles should be processed locally on the phone until they require more complex or resource-intensive operations, which can then fallback to the cloud.

3. **Likely payoff**

   By keeping subtitle processing local, we reduce latency and ensure consistent performance in noisy environments, which is critical for the glasses' core mission of providing reliable real-time assistance. This also aligns with our V1 focus on phone-first architecture and low-friction assistive behavior.

4. **Immediate next probe**

   Define one phone-cloud fallback boundary for exactly live subtitle processing such that subtitles are processed locally unless they require more complex operations, in which case a cloud fallback is used.
