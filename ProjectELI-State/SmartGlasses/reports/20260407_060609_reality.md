**Subtitle Placement:**
- **Feasible Now:** The `TranscriptLab` test app should focus on subtitle placement that remains readable in motion and noise, aligning with the core mission of enhancing understanding without becoming distracting. - **Visual Hierarchy:** Ensure subtitles have a clear visual hierarchy that distinguishes them from other UI elements, such as using a different color or font size. This helps in maintaining clarity and readability without overwhelming the wearer.

### Confidence Display Feasibility
**Confidence Format:**
- **Feasible Now:** Use a simple label format for confidence to avoid adding complexity early on. For example, "High," "Medium," or "Low" can provide enough context without overloading the UI. This aligns with the core mission of low-friction assistance.

### Memory Trust Feasibility
**Face/Name Memory:**
- **Feasible Now:** Implement a basic face/name memory system that remembers names and faces with clear uncertainty indicators (e.g., "Not sure" or "Uncertain"). This can be achieved through simple reinforcement learning mechanisms, updating the memory cache on the phone. Ensure this does not create a false sense of certainty.

### Low-Friction Assistance Feasibility
**One-Line Prompts:**
- **Feasible Now:** Design one-line prompts that are concise and useful without overwhelming the wearer. For example, "John is here" or "Remember you spoke to Sarah." Ensure these prompts are relevant and non-intrusive.

### Interaction Constraints Feasibility
**Frame-Touch Only V1:**
- **Feasible Now:** Focus on frame-touch interactions for subtitle management and mode switching in the `TranscriptLab` app. This ensures that early versions remain simple and low-friction, aligning with the core mission of assistive behavior without command overhead.

### Phone/Cloud Boundary Feasibility
**Phone-First Runtime:**
- **Feasible Now:** Prioritize heavy processing on the phone where possible. Use cloud services only for clear value additions (e.g., advanced speech recognition) and ensure latency remains acceptable to maintain trust.

### Privacy vs Usefulness Feasibility
