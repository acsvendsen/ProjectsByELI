# Reality Check for SmartGlasses Project

Based on the provided project inputs, here are the assessments for proposed directions against real-world limits:

## Subtitle Placement: Likely Waste of Time
- **Reasoning**: The current focus is on core deepening. While subtitle placement is important, it's currently not a high-priority area without clear evidence that it will significantly impact subtitle clarity and trust in live conversations.

## Confidence Display: Feasible Now
- **Assessments**:
  - **Subtitle Clarity (subtitle_clarity)**: Ensuring subtitles are clear and readable is crucial. A small trial or user test could quickly validate display areas.
  - **User Experience**: The current TranscriptLab app can be used to iterate on confidence displays without heavy lifting.

## Memory/Cache Policy: Feasible Later
- **Assessments**:
  - **Face/Name Memory (memory_trust)**: While the memory policy is important, it's currently being explored through TranscriptLab and live testing. Implementing a basic cache policy can be done as part of core deepening.
  - **Latency**: Ensuring fast lookup and confidence behavior without compromising battery or latency is critical. Early implementations should focus on proof-of-concept rather than full-scale memory caching.

## Phone/Cloud Boundary: Feasible Now
- **Assessments**:
  - **Current Mode (core_deepening)**: The phone-first runtime is already in place, and TranscriptLab validates the transcript path.
  - **Interaction Constraints**: Frame-touch interaction remains the primary control method. Ensuring that phone-cloud boundaries support this can be done incrementally.

## Visual Hierarchy: Feasible Now
- **Assessments**:
  - **Subtitle vs Prompt Visual Clarity (discreet_ux_vs_visual_clarity)**: The TranscriptLab app provides a test bed to iteratively improve visual hierarchy. Initial designs should focus on clarity and readability without overwhelming the user.

## Summary

- **Subtitle Placement**: Likely waste of time until clearer evidence shows it significantly impacts subtitle quality.
- **Confidence Display**: Feasible now using current tools.
- **Memory/Cache Policy**: Feasible later as part of core deepening, pending initial validation through TranscriptLab.
- **Phone/Cloud Boundary**: Feasible now to support frame-touch interaction and early validation.
- **Visual Hierarchy**: Feasible now using TranscriptLab for iterative design.

By focusing on these areas, the project can continue to deepen its core functionality while respecting real-world constraints.
