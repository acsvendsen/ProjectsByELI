### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Ensuring stable subtitle placement enhances the wearer's trust in the system by reducing visual distractions and maintaining readability. A consistent and predictable subtitle display improves focus during conversations, making subtitles more reliable as a primary aid.

2. **What small change unlocks it**

   Define two fixed subtitle placement rules: one for high-confidence matches (e.g., known faces or names) and another for low-confidence matches (e.g., likely new people). This will create a clear distinction in the visual hierarchy, helping to reduce cognitive load while maintaining clarity.

3. **Likely payoff**

   By defining specific subtitle placement rules, we can ensure that high-confidence matches are displayed prominently without causing distractions. Low-confidence matches will be placed less intrusively, allowing the wearer to focus on the conversation while still receiving necessary support. This will improve overall user trust and satisfaction.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   By refining the confidence display format to be more nuanced and clear, we can enhance the wearer's trust in both subtitles and memory support. This clarity ensures that when a subtitle is shown or a name is recalled, the user has an accurate understanding of the system's certainty level, which is crucial for maintaining trust and reliability.

2. **What small change unlocks it**

   Modify the confidence object to include both a numeric score (e.g., 0.84) and a label with a short reason (e.g., "High" + "Seen recently"). This format provides a balanced view of certainty without overloading the user with too much detail.

3. **Likely payoff**

   Implementing this confidence display will allow the wearer to better understand when they can trust the system's output, reducing uncertainty and increasing overall satisfaction. It also helps in reinforcing the system’s reliability through consistent and clear feedback.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.
