## Reality Check

### Subtitle Placement: Feasible Now
- **Subtitle Clarity**: The glasses should display subtitles that are clear, fast, and stable enough to be trusted in live conversation. Current implementation in `TranscriptLab` is focused on real-time transcription and stability, which is essential for subtitle clarity.
- **Constraints**: The glasses must remain lightweight and socially acceptable, with minimal thermal pressure. The placement of subtitles should balance visibility with social acceptability.

### Confidence Display: Feasible Now
- **Memory Trust**: Subtitles need to be accompanied by a confidence display that helps the wearer understand the reliability of the information. This can be implemented using a label + short reason format to build trust.
- **Constraints**: The confidence display should not interfere with subtitle clarity and must remain low-friction.

### Memory/Cache Policy: Feasible Now
- **Memory Trust**: The memory policy for face/name recall should expose uncertainty clearly, ensuring that the wearer is aware of the system's limitations. This can be implemented through periodic reminders to retrain or confirm recognition.
- **Constraints**: Early versions should rely heavily on phone processing and use cloud only where it adds clear value.

### Phone/Cloud Boundary: Feasible Now
- **Core Deepening**: The current implementation in `TranscriptLab` focuses on phone-first runtime, which is appropriate for V1. Cloud support can be added later if necessary.
- **Constraints**: V1 should not depend on heavy on-glasses compute and must remain lightweight.

### Visual Hierarchy: Feasible Now
- **Subtitle Placement**: The subtitle placement needs to ensure readability in motion and noise without becoming distracting. Current implementation is focused on minimizing disruption while providing clear information.
- **Constraints**: The UI should favor clarity over feature density, ensuring that the wearer can easily follow the subtitles.
