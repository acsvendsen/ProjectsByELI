### Idea 1: Subtitle Placement

1. **Why it benefits the core**
   - Improving subtitle placement rules helps ensure that subtitles remain stable, readable, and do not become distracting, which is crucial for maintaining trust in real-time interactions.

2. **What small change unlocks it**
   - Define two subtitle placement rules: one for high-confidence states (e.g., when a person or face has been seen multiple times) and another for low-confidence states (e.g., new faces or names).

3. **Likely payoff**
   - By having distinct placement rules for different confidence levels, the system can provide more reliable and less intrusive subtitles, enhancing the wearer's trust in the assistive technology during critical interactions.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   By refining the confidence display to use a label with a short reason, the system can provide clearer and more reliable signals about the certainty of memory matches and face recognitions. This enhances trust by showing the basis for the assistant's claims, which is crucial for the wearer to feel supported without being misled.

2. **What small change unlocks it**

   Introduce a confidence label format that includes both a numeric score and a short reason. For example, "Medium: Seen once in introduction" or "High: Seen recently." This change will enable more nuanced and transparent communication about the reliability of the memory matches.

3. **Likely payoff**

   The likely payoff is improved trust and accuracy in face/name recall. By providing both a score and a reason for the confidence level, users can better understand the basis for the system's decisions, leading to more reliable interactions and fewer instances where the wearer might doubt the assistant’s reliability.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**
   - Improving the local caching and eviction strategy for face/name memory ensures that relevant information is available quickly, reducing the need for cloud queries and improving trust by providing timely support.

2. **What small change unlocks it**
   - Define a cache eviction rule based on recency of interaction with a person's name or face. For example, if a person's name has been seen recently, keep their memory object in local cache longer to allow fast recall during the next few interactions.

3. **Likely payoff**
   - By keeping frequently encountered names and faces in the local cache for a longer duration, the system will reduce latency during rapid-fire conversations and improve the user's ability to quickly retrieve relevant information without cloud dependency, thus enhancing overall trust and reliability.

4. **Immediate next probe**
   - Define one cache eviction rule for face/name memory based on recency of interaction, with a minimum threshold of [X] interactions in the last [Y] minutes before evicting the memory object from local cache.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By defining a clear boundary for what runs phone-local versus cloud, we can ensure that the system remains responsive and privacy-preserving. This helps in maintaining trust by providing timely assistance without overloading the glasses or compromising user data.

2. **What small change unlocks it**

   Define one task-specific fallback rule that decides when to process face/name recall lookup on-device (phone) versus offloading it to the cloud for heavy processing. For example, V1 can prioritize local processing during live subtitle generation and transition to cloud fallbacks only for transcript cleanup or extensive memory archive sync.

3. **Likely payoff**

   This change will allow the system to remain responsive in critical real-time scenarios like live subtitles while still leveraging cloud capabilities for less urgent tasks. It ensures that privacy-sensitive operations are handled locally, enhancing user trust and reducing battery drain on-device.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

   Ensuring a clear visual hierarchy between subtitles and one-line support helps maintain focus and clarity, reducing cognitive load during live conversations. This balance ensures that critical information (subtitles) remains prominent while auxiliary prompts are concise and unobtrusive.

2. **What small change unlocks it**

3. **Likely payoff**

   By clearly defining subtitle priority, we can reduce visual clutter during critical moments in conversations, enhancing the wearer's ability to follow along with the conversation without being distracted by less essential information.
