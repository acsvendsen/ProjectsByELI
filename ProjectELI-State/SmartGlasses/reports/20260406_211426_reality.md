# Reality Check

## Subtitle Placement: Feasible Now
- **Current Status**: The glasses should display subtitles in a way that is readable and unobtrusive during live conversation.
- **Constraints**: Glasses must remain lightweight, socially acceptable, and avoid drawing too much attention.
- **Feasibility**: V1 interaction through frame touches means the subtitle placement needs to be visible enough for the wearer but subtle enough not to distract others. A small, central display area (e.g., top center) could work well.
- **Implementation Grounding**: The `TranscriptLab` app can test various placements and their readability in real-time scenarios.

## Confidence Display: Feasible Now
- **Current Status**: Confidence needs to be represented clearly to build trust without being intrusive.
- **Constraints**: Must remain low-friction and non-disruptive, as V1 interaction is frame touches only.
- **Feasibility**: Using a simple label or color-coded dot next to subtitles can provide confidence without adding too much complexity. For example, a green dot for high confidence could be used.
- **Implementation Grounding**: The `TranscriptLab` app can test different confidence display methods and their impact on user trust.

## Memory/Cache Policy: Feasible Later
- **Current Status**: Memory support must remember names, faces, and prior context without overloading the system or creating false positives.
- **Constraints**: Early versions rely heavily on phone processing, with cloud optional where useful. V1 interaction is frame touches only.
- **Feasibility**: Implementing basic memory caching on the phone can be done in a future update. Start by storing recently seen faces and names locally and use reinforcement learning to improve recall over time.
- **Implementation Grounding**: The `TranscriptLab` app can simulate memory updates and retrieval, but full integration with glasses hardware will come later.

## Phone/Cloud Boundary: Feasible Now
- **Current Status**: Heavy processing should primarily happen on the phone, with cloud optional where clearly justified.
- **Constraints**: V1 interaction is frame touches only; do not assume voice activation or spoken command control in V1.
- **Feasibility**: Use the `TranscriptLab` app to validate the real-time transcript path and ensure it works reliably before hardware exists. This will inform the phone/cloud boundary for future glasses implementations.
- **Implementation Grounding**: The `TranscriptLab` app can test various scenarios where heavy processing is offloaded to the cloud or kept on-device, ensuring V1 remains simple.

## Visual Hierarchy: Feasible Now
- **Current Status**: Display behavior should remain socially acceptable while still being readable in motion and noise.
- **Constraints**: Glasses must remain lightweight and socially acceptable. Subtitles need to be clear and stable enough for live conversation.
- **Feasibility**: Design a simple, clean visual hierarchy that prioritizes readability over feature density. Test this with the `TranscriptLab` app to ensure it works well in real-time scenarios.
- **Implementation Grounding**: The `TranscriptLab` app can simulate various visual hierarchies and their impact on user experience.

## Assumptions Needing Evidence
- **Subtitle Clarity vs Privacy**: Ensuring subtitles are clear enough for the wearer without being too visible to others remains a balance. More real-world testing is needed.
- **Memory Accuracy vs Usability**: Balancing the need for accurate memory recall with avoiding false positives and maintaining usability will require evidence from user tests.

## Summary
The current focus on subtitle placement, confidence display, and phone/cloud boundary are feasible now given the V1 constraints. Memory/Cache Policy can be addressed in a future update as it requires more complex implementation and testing. The assumptions about privacy vs clarity and memory accuracy vs usability need further evidence through real-world testing.

By grounding these decisions in the `TranscriptLab` app and following the core-deepening approach, we can ensure that the SmartGlasses V1 remains focused on delivering high-value assistive features while respecting real-world constraints.
