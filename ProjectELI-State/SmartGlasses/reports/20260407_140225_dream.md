### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Ensuring stable subtitle placement helps maintain trust in real-time subtitles, which is crucial for the wearer's understanding and confidence during conversations. Stable placement prevents visual distractions that can hinder comprehension and creates a consistent user experience.

2. **What small change unlocks it**

   Define two fixed subtitle placement rules: one for high-confidence situations where accuracy is paramount, and another for lower-confidence scenarios to allow more flexibility in placement while maintaining clarity.

3. **Likely payoff**

   By setting clear placement rules, the system can better manage visual distractions during conversations, enhancing the wearer's trust in the subtitles. This stability will reduce cognitive load and improve overall usability without overwhelming the wearer with constant repositioning of text.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   By refining the confidence display format, we can ensure that the wearer has a clear and trustworthy understanding of the reliability of each piece of information provided by the glasses. This improves overall trust in the system and helps the wearer make better decisions based on the most reliable data.

2. **What small change unlocks it**

   Define a consistent confidence object format that includes a numeric score, label, and short reason for each memory or subtitle. For example: `score 0.84 + "High" + "Seen recently"; score 0.42 + "Low" + "Weak match"; score 0.63 + "Medium" + "Name heard once in introduction"`.

3. **Likely payoff**

   A well-defined confidence display will help the wearer distinguish between high-confidence and low-confidence information, thereby reducing cognitive load and increasing trust in the system's recommendations. This clarity can also lead to more effective use of the glasses during complex interactions, such as multi-party conversations or high-stakes meetings.

4. **Immediate next probe**
   - Define the numeric score format for confidence display in V1.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   By setting a local cache threshold for name recall, we can ensure that frequently seen names are stored and quickly accessible on the phone, reducing latency and improving memory support. This helps in maintaining trust by providing fast and accurate recall without overburdening the cloud.

2. **What small change unlocks it**

   Define a local cache size limit of 50 entries for name-related memories, where each entry includes recent context, confidence score, and label.

3. **Likely payoff**

   Implementing this cache policy will reduce lookup latency by keeping commonly seen names on the phone, thus providing faster and more reliable memory support. This will enhance the core mission by ensuring that frequently encountered individuals are quickly recognized and recalled without the need for cloud queries.

4. **Immediate next probe**
   - Define a local cache size limit of 50 entries for name-related memories.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By refining the phone-cloud boundary for memory archive sync, we can ensure that critical context is stored locally while still leveraging cloud resources when necessary. This balance strengthens trust and reliability by keeping important memories readily accessible without overloading the device or compromising privacy.

2. **What small change unlocks it**

   Define a local cache threshold of 50 face/name entries for memory archive sync, with any additional data falling back to the cloud. This threshold ensures that frequent interactions remain responsive while offloading less commonly accessed information.

3. **Likely payoff**

   Implementing this boundary will improve the speed and reliability of memory recall during live conversations, reducing latency without sacrificing privacy or battery life. It will also provide a clear guideline for future expansions in memory storage and retrieval.

4. **Immediate next probe**
