### Idea 1: Subtitle Placement

1. **Why it benefits the core**
   
   Ensuring stable subtitle placement helps maintain trust in real-time subtitle clarity (subtitle_clarity attractor). Stable placement reduces distractions, making subtitles more readable and less likely to interrupt natural conversation flow.

2. **What small change unlocks it**

   Define a fixed subtitle placement mode that prioritizes clear reading over frequent repositioning or movement.

3. **Likely payoff**

   By locking subtitles to a fixed position, the wearer can focus on the content rather than the display, enhancing overall understanding and trust in the assistive functionality during live conversations.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

Improving the confidence display format enhances user trust in both subtitles and memory recall. A clear and concise confidence label with a short reason will help the wearer understand the reliability of the information, ensuring that they do not act on uncertain data.

2. **What small change unlocks it**

Define a specific confidence object format that includes a numeric score, a confidence label (e.g., High, Medium, Low), and a short reason for the score.

3. **Likely payoff**

By implementing this structured confidence display, users will gain a clearer understanding of the reliability of the subtitles and memory support they receive. This clarity will reduce ambiguity and increase trust in the system's output, leading to more effective use of the product.

4. **Immediate next probe**
   - Define the confidence label style as "High," "Medium," or "Low" for V1.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Improving local memory thresholds for face/name recall ensures that the system can provide fast, reliable support without relying too heavily on cloud resources, thereby reducing latency and improving overall trust. This helps in maintaining a strong daily-use value by ensuring that common interactions do not suffer from connectivity issues.

2. **What small change unlocks it**

   Define a local memory threshold for face/name recall where the system stores recent encounters to reduce the need for frequent cloud lookups. For example, set a rule that names and faces seen in the last 30 minutes are stored locally with high confidence levels.

3. **Likely payoff**

   By caching recently encountered names and faces locally, the system can provide faster, more reliable support during live interactions without constant cloud requests. This reduces latency and enhances the trustworthiness of the memory support feature.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   Improving the phone/cloud boundary for live subtitle processing ensures that critical real-time data remains on-device, reducing latency and maintaining the essential clarity and stability required for subtitles in noisy environments.

2. **What small change unlocks it**

   Define a clear phone-local subtitle caching rule: cache up to 5 recent transcripts locally on the phone for offline playback or near-real-time updates before falling back to cloud processing.

3. **Likely payoff**

   By ensuring that live subtitles can be quickly retrieved from local storage, the system maintains real-time clarity and stability even under high-latency network conditions, enhancing the core subtitle quality and user trust.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   Improving the visual hierarchy between subtitles and one-line support helps maintain the wearer's focus on crucial information without overwhelming them with too much text. This ensures that critical real-time subtitles remain clear and readable, while still providing necessary contextual cues in a less dominant format.

2. **What small change unlocks it**

   Define a single subtitle placement rule where subtitles are centered at the bottom of the display area to maintain their prominence, and one-line support is placed above or below them but with reduced size and opacity to ensure it does not distract from the main content.

3. **Likely payoff**

   By clearly separating critical information (subtitles) from supplementary context (one-line prompts), the system can better manage the wearer's attention span, reducing cognitive load during live interactions while still providing relevant support when needed.

4. **Immediate next probe**
   - Define one visual priority rule between subtitles and one-line support in V1.
