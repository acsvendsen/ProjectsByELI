## Project Summary
The project is focusing on delivering a discreet, context-aware personal assistant with core functionalities like real-time subtitles, face/name recall, and one-line prompts. The V1 will use frame-touch interactions exclusively and rely primarily on the phone for processing while optionally using cloud services. Current priorities include subtitle placement, confidence display, memory caching policy, and visual hierarchy design to ensure a balanced and usable experience.
