### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Improving subtitle placement rules ensures that subtitles are consistently clear, readable, and unobtrusive during live interactions. This helps maintain the wearer's ability to focus on the conversation while still benefiting from real-time captioning.

2. **What small change unlocks it**

   Define a fixed position for subtitles at the bottom center of the frame but slightly off-center to avoid direct gaze interference, ensuring they remain visible yet unobtrusive.

3. **Likely payoff**

   By maintaining a consistent and non-intrusive subtitle placement, users can rely on the captions without distraction during conversations, enhancing their understanding and engagement in social interactions.

4. **Immediate next probe**
   - Define a fixed position rule for subtitles at the bottom center of the frame but slightly off-center to avoid direct gaze interference.

### Idea 2: Confidence Display

1. **Why it benefits the core**
   
   Improving confidence display ensures that the wearer can trust the system's behavior, which is crucial for maintaining their confidence in using the glasses. A clear and understandable confidence format will help users understand when they can rely on the subtitles or memory support.

2. **What small change unlocks it**

   Define a single confidence object format that combines a numeric score with a label and short reason. For example: `score 0.84 + "High" + "Seen recently";` This format provides both certainty and context, enhancing trust and usability.

3. **Likely payoff**

   A well-defined confidence format will reduce user uncertainty about the system's reliability, leading to higher satisfaction and better acceptance of the glasses as a daily-use tool. Clear confidence signals can also help in situations where the wearer might need reassurance quickly during conversations.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Ensuring that memory is stored in a way that supports fast, accurate recall enhances the wearer's trust in the system. By prioritizing recency and confidence-based caching, the glasses can provide more relevant information without overwhelming the user with unnecessary data.

2. **What small change unlocks it**

   Define a local cache eviction policy where older or less confident memory entries are evicted based on recency and certainty scores.

3. **Likely payoff**

   This change will improve the speed and relevance of memory recall, reducing the likelihood of displaying outdated or uncertain information. It will also help in maintaining a streamlined and focused set of memories that are most relevant to the current context.

4. **Immediate next probe**
   - Define the recency-based eviction rule for face/name memory caching.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   Ensuring that live subtitle processing remains local on the phone optimizes battery life, reduces latency, and keeps the system lightweight, all of which are crucial for maintaining real-time clarity and trust in noisy environments.

2. **What small change unlocks it**

   Define a clear boundary where live subtitle processing runs entirely on the phone without falling back to cloud resources unless absolutely necessary.

3. **Likely payoff**

   By keeping subtitle processing local, we can achieve faster, more reliable, and less battery-draining performance, which directly benefits the core mission of providing real-time, high-quality subtitles in noisy environments.

4. **Immediate next probe**
   - Define the boundary for live subtitle processing where it runs entirely on the phone, with fallback to the cloud only for extended periods of high processing load.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

Improving subtitle placement rules can enhance the overall user experience by making subtitles more readable and less distracting, thereby deepening the core mission of helping the wearer understand better in noisy environments.

2. **What small change unlocks it**

Define three distinct subtitle placement modes for different confidence levels: high-confidence (always visible), medium-confidence (appears on demand), and low-confidence (only shown with explicit user input).

3. **Likely payoff**

By providing more flexible subtitle placement options, the system can adapt to varying listening conditions, making subtitles more useful in diverse environments without overwhelming the wearer.

4. **Immediate next probe**
   - Define one visual priority rule between subtitles and one-line support in V1.
