4. **Immediate next probe**

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   By setting a local cache size threshold for name recall, we ensure that the memory system retains enough relevant information to provide fast, accurate lookups without overwhelming the phone's storage or battery resources. This balance helps maintain trust by providing quick access to recent interactions while conserving power and privacy.

2. **What small change unlocks it**

   Define a local cache size limit for name recall memory objects, set at 10 unique names with a recency threshold of the last 30 minutes.

3. **Likely payoff**

   This change will reduce battery usage by minimizing unnecessary data transfers to and from the cloud while ensuring that recent interactions remain accessible. It also helps in maintaining a clean and focused memory system, which enhances the overall user experience without compromising on critical information recall.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.
