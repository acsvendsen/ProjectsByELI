# Consolidated Project Signals

## Strengthening Signals
1. **Subtitle Clarity**: The need for clear, fast, and stable subtitles that the wearer can trust in live conversations remains a primary attractor.
2. **Trustworthy Memory Support**: Enhancing memory support to remember names, faces, and prior context without creating corrupted recall is critical.
3. **Low-Friction Assistance**: Delivering one-line help and visible support while maintaining a low-friction experience is essential.

## Weakening Signals
1. **Privacy vs Usefulness**: The tension between providing useful assistive behavior and respecting privacy concerns remains high but should be managed carefully to avoid invasive practices.
2. **Latency vs Richness**: There is a growing pressure to balance the need for timely assistance with the desire to provide richer, more comprehensive support without overloading the system.

## Contradictions That Must Stay Alive
1. **Always-on Sensing vs Battery and Thermals**: The project must continuously manage the tradeoff between always-on sensing capabilities and battery/thermal constraints.
2. **Discreet UX vs Visual Clarity**: Ensuring a discreet user experience while maintaining readability in motion and noise is an ongoing challenge.

## Dormant Ideas Worth Reactivating
1. **Subtitle Placement**: There are open questions about the best subtitle placement that should be revisited to ensure the subtitles do not become distracting.
2. **Confidence Display**: The format for confidence display, whether a label only, a short reason, or both, is an active tension and worth further exploration.

## Concrete Tensions Around Subtitle Quality, Confidence Trust, Automatic New-Person Memory, Memory Reinforcement, Fast Lookup, Privacy, Latency, Battery, and Visual UX
1. **Subtitle Quality**: Improving subtitle clarity and stability remains a high priority.
2. **Confidence Trust**: Enhancing the trustworthiness of confidence objects is critical to building user confidence.
3. **Automatic New-Person Memory**: Ensuring automatic memory behavior for new faces and names without overloading the system should be prioritized.
4. **Memory Reinforcement**: The method of storing and reinforcing face/name memory for fast lookup must be refined.
5. **Fast Lookup**: Balancing rich context with low-latency response is essential to provide timely assistance.
6. **Privacy**: Ensuring that assistive behavior does not slide into invasive practices remains a key concern.
7. **Battery and Latency**: The system must remain within acceptable battery and latency constraints to avoid breaking trust.
