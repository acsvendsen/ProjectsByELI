### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Improving subtitle placement rules can enhance the clarity and stability of subtitles, ensuring they remain readable and trustworthy during live conversations. This improvement directly supports the primary attractor of real-time subtitle clarity by reducing distractions and maintaining focus on the conversation.

2. **What small change unlocks it**

   Define a fixed subtitle placement rule that keeps subtitles at a consistent position relative to the wearer's gaze but allows for slight adjustments based on the confidence level of the spoken words. For example, if the confidence is high (0.8+), keep the subtitle slightly above the current gaze point; if low (0.6-0.79), place it closer to the center of the field of view.

3. **Likely payoff**

   By implementing a more consistent and adaptive placement rule based on confidence, the system can reduce visual distractions during high-confidence periods while ensuring critical information is easily readable during moments of uncertainty. This will enhance the user's ability to focus on the conversation without constant gaze shifts to follow subtitles, thereby improving overall trust in the system.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving the confidence display format in V1 will enhance trust by clearly communicating the certainty level of the information to the wearer. A well-designed confidence object will help the wearer discern between highly likely and less certain pieces of information, reducing misunderstandings and increasing overall reliability.

2. **What small change unlocks it**

   Define a simple confidence format for V1 that uses a numeric score (0-1) combined with a label and a short reason. For example: "score 0.84 + 'High' + 'Seen recently'; score 0.42 + 'Low' + 'Weak match'. This format allows for clear communication of certainty without overwhelming the user.

3. **Likely payoff**

   By implementing this simple but effective confidence format, users will be able to better trust the system's outputs in real-time interactions. This increased trust can lead to more frequent and reliable use of the glasses, enhancing their daily value as a personal assistant.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   By setting a clear threshold for local memory retention, we ensure that the system stores only relevant and frequently accessed information on the phone, reducing privacy concerns and improving performance.

2. **What small change unlocks it**

   Define a local cache size limit for face/name recall data to ensure that only the most recent and relevant entries are cached, thus balancing memory usage with utility.

3. **Likely payoff**

   This change will help in maintaining a low-friction assistive experience by ensuring that the system does not overwhelm the user's phone storage while still providing useful name and face recognition capabilities.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By defining a clear boundary for what stays phone-local versus what falls back to cloud processing for live subtitle generation, the system ensures that real-time subtitles remain fast and reliable, aligning with the "Real-time subtitle clarity" attractor.

2. **What small change unlocks it**

   Define a single task-specific boundary rule: for live subtitle processing, only critical portions such as initial speech-to-text transcriptions will run on-device; higher-order context analysis and memory recall will be offloaded to the cloud.

3. **Likely payoff**

   By centralizing real-time transcription locally, we ensure that subtitles are delivered with minimal latency, which is crucial for maintaining trust and readability in live conversations. Offloading more complex processing to the cloud allows for richer but potentially slower context analysis without impacting V1's core functionality.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   Ensuring a clear visual hierarchy between subtitles and one-line support helps maintain the wearer's focus on critical information without overwhelming them with too much text. This balance enhances understanding and reduces cognitive load, making the system more useful in noisy environments and complex social interactions.

2. **What small change unlocks it**

   Define a priority rule that places subtitles as the top visual element during live conversations but allows one-line support to coexist seamlessly when necessary, ensuring neither overpowers the other.

3. **Likely payoff**

   By clearly defining subtitle vs one-line line-of-support precedence, the system will maintain a clean and uncluttered interface, improving the wearer's ability to follow conversations in real-time while still receiving essential contextual prompts. This clarity can significantly enhance user trust and satisfaction with the product.

4. **Immediate next probe**
