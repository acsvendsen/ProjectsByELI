# Reality Check for SmartGlasses Project

## Subtitle Clarity (Real-time subtitle clarity)
### Feasible Now: 
- **Subtitle Placement:** Use the `TranscriptLab` app to test various subtitle placements. The goal is to find a placement that remains readable and stable during live conversation without becoming distracting. This can be done through iterative UI tests and feedback from early user testing.
- **Visual Hierarchy:** Define and test different visual hierarchies in `TranscriptLab`, ensuring subtitles are easily readable while not overwhelming the wearer.

### Feasible Later: 
- Introduce more advanced placement algorithms if initial tests do not meet the high standards of clarity and readability. This could involve machine learning techniques to dynamically adjust subtitle positions based on head movements or environmental factors.
  
## Memory Trust (Trustworthy memory support)
### Feasible Now:
- **Face/Name Memory:** Implement a simple face/name recognition system using the phone as the primary processing unit. Use the `TranscriptLab` app to test how quickly and accurately names are recalled, ensuring that the memory support is reliable without overloading the wearer with too much information.
- **Confidence Display:** Experiment with different confidence formats (label only, label + short reason, score + label) in `TranscriptLab`. Choose a format that best balances trust and usability.

### Feasible Later:
- Develop more sophisticated reinforcement learning models for memory recall and correction. This can be done by gradually introducing more complex algorithms to the phone’s processing load as the hardware allows.

## Low-Friction Assistance (Low-friction assistance)
### Feasible Now: 
- **One-Line Prompts:** Design and test one-line prompts in `TranscriptLab` that provide clear, actionable advice without overwhelming the wearer. Ensure these prompts are displayed only when needed and do not interfere with the primary conversation.
- **Subtitle Prompt Coexistence:** Evaluate how subtitles and one-line prompts coexist on the same screen to ensure a low-friction experience.

### Feasible Later:
- Introduce more complex interaction modes, such as voice commands or gesture controls, after the core functionality is well established. This should be done with careful consideration of battery and thermal constraints.

## Privacy vs Usefulness
### Feasible Now: 
- **Memory Object Integrity:** Ensure that face/name memory objects are stored securely on the phone without compromising privacy. Test different encryption methods and data retention policies in `TranscriptLab`.

### Feasible Later:
- Implement additional privacy features such as blur or noise addition to sensitive information, but only if it does not significantly impact usability.

## Latency vs Richness
### Feasible Now: 
- **Subtitle Delivery:** Optimize subtitle delivery using the current hardware and software configurations. Ensure subtitles are delivered in near-real-time without causing delays that would break trust.
  
### Feasible Later:
- Introduce more sophisticated processing techniques, such as batched inference or offloading to cloud services, after initial testing shows that these can be done without significant latency.

## Discreet UX vs Visual Clarity
### Feasible Now: 
- **Subtitle Display:** Ensure subtitles are displayed in a way that minimizes distraction but maximizes clarity. Test different display strategies in `TranscriptLab` to find the best balance.
  
### Feasible Later:
- Introduce more advanced UI features, such as adaptive subtitle sizes or colors based on environmental conditions, after initial testing shows they can be implemented without compromising battery life.

## Core Deepening vs Sprawl
### Feasible Now: 
- Focus on improving core functionality (subtitles, memory support, and confidence display) by continuously iterating on the `TranscriptLab` app. Ensure each iteration brings tangible improvements to the wearer’s experience.
  
### Feasible Later:
- Introduce broader features if initial testing shows they do not significantly impact the core mission or usability. This should be done with careful consideration of constraints such as battery life and thermal pressure.
