# Consolidation for SmartGlasses V1 Direction

## Strengthening Signals
1. **Subtitle Quality and Placement**: 
   - Subtitle placement is increasingly being seen as a critical factor for usability. More prominent subtitle display is preferred over subtlety, ensuring the wearer can quickly read subtitles without distractions.
   
2. **Memory Trust and Reinforcement**:
   - The importance of clear confidence signals is growing. Users want to know when the system is uncertain about faces or names, promoting trust in the memory system.

3. **Interaction Fidelity**:
   - Frame touches are becoming a more central interaction method, with touch interactions expected to handle most user commands and confirmations. This reinforces the need for intuitive, low-friction controls.

## Weakening Signals
1. **Voice Activation**: 
   - There is diminishing interest in voice activation as a primary control method. The focus on frame-touch interactions will remain strong.
   
2. **Complex AR Visuals**:
   - Complexity in augmented reality visuals and multimodal UI is becoming less of a priority, with the core focus remaining on text display and minimal local logic.

3. **Full On-Glasses Inference**:
   - While there is still interest in reducing reliance on cloud processing, fully implementing inference on glasses hardware remains outside the V1 scope for now.
   
## Contradictions That Must Stay Alive
1. **Battery vs Always-On Sensing**: 
   - There is a tension between always-on sensing to enhance real-time assistance and the risk of battery drain. The system must find a balance that keeps it useful without compromising on power efficiency.

2. **Rich Context vs Low-Latency Response**:
   - Providing rich contextual memory for the wearer versus ensuring quick responses remains a critical balance point. The system should avoid overwhelming the user with too much information while maintaining speed.

## Dormant Ideas Worth Reactivating
1. **Subtitle Quality**: 
   - There is an opportunity to revisit subtitle quality, especially in noisy environments. Improving readability and clarity could significantly enhance the core functionality.
   
2. **Memory Cache Policy**:
   - The phone-first architecture requires a clear memory cache policy that balances local storage with cloud support. This will help manage the trade-offs between battery efficiency and real-time responsiveness.

## Concrete Tensions Around Core Domains
1. **Subtitle Reasoning vs Memory Policy**:
   - The system must balance subtitle quality and real-time delivery with memory policies that ensure relevant information is stored and recalled accurately.
   
2. **Privacy vs Usefulness**:
   - There is a need to ensure the system provides useful assistance while respecting user privacy. This tension will guide decisions on how much data to collect and store locally versus in the cloud.

3. **Confidence Objects vs Fast Lookup**:
   - The design must address how to display confidence objects (like uncertainty labels) without overwhelming the wearer, ensuring fast lookup capabilities are not sacrificed for clarity.
   
4. **Visual UX vs Low-Friction Interaction**:
   - The visual hierarchy should support quick and clear interactions while minimizing distractions. This will involve balancing subtitle placement with one-line prompts.

## Open Questions
1. **Subtitle Placement**: 
   - What is the optimal balance between visibility and distraction for subtitles?
   
2. **Confidence Display**: 
   - How should confidence be represented (label only, label + short reason, or score + label) to ensure clarity without overloading the user?

3. **Memory/Cache Policy**:
   - How much face/name memory should be cached locally on the phone versus relying on cloud support?
   
4. **Phone/Cloud Boundary**:
   - When and how should the system use the phone or cloud for processing, given battery constraints?
   
5. **Visual Hierarchy**:
   - What is the best way to visually differentiate subtitles from one-line prompts?

## Real-World Constraints
1. **Battery and Thermals**: 
   - The glasses must remain lightweight and socially acceptable while managing power consumption effectively.
   
2. **Latency**: 
   - Subtitles and memory responses should feel near-real-time to maintain trust.

3. **Privacy**: 
   - Data collection and storage policies must respect user privacy without compromising functionality.

4. **Usability**: 
   - The system should minimize social friction while providing meaningful assistance.

## Evolving Core Mission
- The core mission of the glasses is to act as a discreet, context-aware personal assistant that provides real-time subtitles, face/name recall, conversation memory, and one-line support.
  
By focusing on these areas, the project can continue to deepen its core functionality without veering into unnecessary complexity or feature sprawl.
