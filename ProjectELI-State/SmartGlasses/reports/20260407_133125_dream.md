### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Ensuring stable subtitle placement rules enhances the wearer's trust in the system by making subtitles consistently readable and unobtrusive. This stability helps maintain a low-friction experience, which is crucial for daily use.

2. **What small change unlocks it**

   Define three fixed subtitle placement modes: static bottom-center, dynamic left-corner with scrolling, and dynamic center-with-scrolling. Use the current scorecard inputs to determine the default mode based on known usability constraints.

3. **Likely payoff**

   By defining clear and stable subtitle placement rules, V1 can ensure that subtitles remain consistently readable and unobtrusive. This will enhance user trust and satisfaction, contributing to the core attractor of low-friction assistance.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving confidence display ensures that the wearer can trust the assistant more reliably, which is crucial for maintaining the quality of subtitles and overall user satisfaction. A clear and consistent confidence format helps in signaling when the system is certain about a name or word, thus reducing the risk of misunderstandings.

2. **What small change unlocks it**

   Define a simple yet effective confidence format that uses both a label (e.g., "High," "Medium," "Low") and a short reason (e.g., "Seen recently," "Weak match," "Name heard once in introduction"). This can be applied to memory recall, subtitle placement, and overall context.

3. **Likely payoff**

   By defining a clear confidence format, the system will provide more reliable and trustworthy information to the wearer. This reduces the cognitive load on the user by minimizing uncertainties and fostering trust in the assistant’s ability to help accurately. The improved trust can lead to better engagement and higher satisfaction with the product.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   By setting a local cache threshold for name recall, we ensure that common names are always available locally without overloading the phone's memory. This improves real-time subtitle quality and stability by reducing latency in lookups, which helps maintain trust during live conversations.

2. **What small change unlocks it**

   Define a local cache size limit of 10-20 recent names for quick recall on the phone.

3. **Likely payoff**

   Implementing this cache threshold will reduce the likelihood of name lookup failures due to network latency, ensuring that common names are always available in real-time subtitles and memory support. This enhances user trust and satisfaction by providing reliable assistance without delay.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   Ensuring that live subtitle processing remains phone-local optimizes battery life and reduces latency, thereby maintaining real-time clarity and trustworthiness in noisy environments. This focus on local processing for critical tasks ensures that even under high thermal or battery constraints, essential assistive functions like subtitles remain reliable.

2. **What small change unlocks it**

   Define a clear boundary where live subtitle processing always stays phone-local to avoid cloud latency and thermal issues. Specifically, set a rule that any face or name recall requests directly related to live conversation processing should only trigger local computation on the phone unless explicitly overridden by user interaction through frame touches.

3. **Likely payoff**

   By keeping live subtitle processing strictly phone-local, we ensure that subtitles remain clear, stable, and responsive in real-time. This reduces battery drain from constant cloud queries and minimizes thermal stress on both glasses and phones. The result is a more reliable and trustworthy assistive experience for the wearer.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   Improving the visual hierarchy between subtitles and one-line support ensures that the most critical information is always visible and legible. This enhances the wearer's ability to understand both the ongoing conversation and any contextual prompts, thereby deepening the core mission of providing clear, unambiguous real-time assistance.

2. **What small change unlocks it**

   Define a visual priority rule that shows subtitles with high confidence first, followed by one-line support in a lighter, less intrusive format.

3. **Likely payoff**

   By prioritizing high-confidence subtitles and keeping one-line prompts secondary, the system reduces cognitive load and ensures that the wearer can focus on the most critical information without distraction. This improves overall usability and trust in the assistant’s reliability.

4. **Immediate next probe**
   - Define one visual priority rule between subtitles and one-line support in V1.
