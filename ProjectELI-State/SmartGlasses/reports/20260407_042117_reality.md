# Reality Check for SmartGlasses Project

## Feasibility Assessments

### Subtitle Placement: feasible now
- **Current State**: The `TranscriptLab` app provides a framework to test subtitle placement without requiring glasses hardware.
- **Constraints**: Frame-touch-only V1 interaction limits the need for complex visual hierarchy adjustments in this early stage.

### Confidence Display: feasible later
- **Current State**: Initial confidence display formats can be tested using `TranscriptLab`.
- **Constraints**: The current mode emphasizes core-deepening, and more detailed confidence displays may come as the project evolves to understand user needs better.
- **Reasoning**: Real-time subtitle clarity is a primary attractor. Early iterations should focus on basic functionality before adding complex confidence indicators.

### Memory/Cache Policy: feasible now
- **Current State**: The `TranscriptLab` app can simulate local cache policies using phone-side state management.
- **Constraints**: Core-deepening mode focuses on improving subtitle quality and memory support directly.
- **Reasoning**: Local caching strategies are crucial for real-time performance, and preliminary testing in the `TranscriptLab` is feasible.

### Phone/Cloud Boundary: feasible now
- **Current State**: The `TranscriptLab` app provides a framework to test local vs. cloud processing without glasses hardware.
- **Constraints**: Early versions should rely heavily on phone processing with optional cloud support for non-critical background tasks.
- **Reasoning**: Given the current focus on core-deepening, testing different boundary configurations is practical and aligns with real-world limits.

### Visual Hierarchy: feasible now
- **Current State**: The `TranscriptLab` app can simulate visual hierarchy changes through UI design adjustments.
- **Constraints**: Discreet UX vs. enough visual clarity remains a tension, but initial prototypes in the `TranscriptLab` are viable for testing basic display priority.
- **Reasoning**: Early iterations should focus on user trust and minimalistic design to ensure real-time usability.
