### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   By establishing clear and stable subtitle placement rules, we ensure that subtitles remain easily readable and do not become distracting during live conversations. This improves the wearer's ability to understand spoken content without constant shifting of gaze or focus, which is critical for maintaining trust in the assistive system.

2. **What small change unlocks it**

   Define two subtitle placement modes: one for high-confidence speech (e.g., clear speakers) and another for lower-confidence speech (e.g., background noise or unclear audio). This allows the glasses to adjust subtitle visibility based on the reliability of the input, preventing distraction during critical moments.

3. **Likely payoff**

   By reducing gaze movement and ensuring that subtitles are only displayed when necessary, we can significantly enhance the wearer's comfort and trust in the system. Clear and stable subtitle placement will also reduce cognitive load, allowing the wearer to focus more on the conversation itself rather than constantly checking for subtitles.

4. **Immediate next probe**
   - Define the fixed position of subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Enhancing the confidence display by using a simple numeric score format alongside a clear label and short reason will help build trust through transparent and consistent behavior. This approach ensures that the wearer can easily understand the reliability of the memory and subtitles, fostering a sense of honesty and reliability.

2. **What small change unlocks it**

   Define one confidence format candidate for V1: `score + "Low/Medium/High" + short reason`.

3. **Likely payoff**

   By using this simple yet informative confidence format, the system will provide clear feedback to the wearer about the certainty of information, which can significantly reduce uncertainty and build trust. This clarity will enhance the overall user experience by ensuring that the wearer knows when they can rely on the memory or subtitles.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Improving local memory cache thresholds ensures that the glasses can quickly recall names and faces during conversations, enhancing trust by providing immediate, relevant support without relying on potentially delayed cloud responses.

2. **What small change unlocks it**

   Define a local memory threshold for cached face and name entities, ensuring they are retained in the phone's cache based on recency of interaction. This would allow the glasses to rely on quick, local lookups rather than waiting for cloud responses.

3. **Likely payoff**

   By setting a reasonable local cache size limit, the system can reduce latency during memory recall tasks, thereby increasing trust and improving the real-time responsiveness of name and face recognition, which is critical for effective live conversation support.

4. **Immediate next probe**

   Define one fast-lookup index policy for people and names that limits the cache to 10 recent entities per person or name, prioritizing recency over absolute number of stored items.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By defining a clear boundary between local processing on the phone and cloud fallbacks, we ensure that critical subtitle and memory operations remain fast and reliable while leveraging cloud resources when necessary. This helps in maintaining high subtitle clarity (subtitle_clarity) and trustworthy memory support (memory_trust), which are key to the wearer's trust and daily-use value.

2. **What small change unlocks it**

   Define a specific task for the phone: live subtitle processing, transcript cleanup, face/name recall lookup, or conversation snapshot upload. For example, set the rule that any live subtitle processing should be done on-device (phone) as long as the wearer is in a noisy environment and battery conditions allow.

3. **Likely payoff**

   By keeping live subtitle processing local, we ensure real-time clarity and stability without introducing potential latency from cloud connections. This enhances trust by providing clear and timely subtitles, which are crucial for the core mission of helping the wearer understand conversations better.

4. **Immediate next probe**

   Define one phone-cloud fallback boundary where live subtitle processing runs on-device as long as battery conditions allow.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   Ensuring that subtitles are displayed in a way that coexists harmoniously with one-line prompts enhances the overall usability of the system without overwhelming the wearer. This balance is crucial for maintaining the wearer's focus on the conversation, ensuring they can read both types of content comfortably and efficiently.

2. **What small change unlocks it**

   Define a visual hierarchy rule that prioritizes subtitles over one-line prompts but allows them to coexist in a non-overlapping manner when necessary. Specifically, the subtitle should always be visible if present, while one-line prompts appear only when there is no active subtitle.

3. **Likely payoff**

   By implementing this hierarchy, we reduce cognitive load for the wearer and maintain the clarity of live subtitles. This will help them stay focused on the conversation and understand what is being said more effectively, which aligns with our core attractor of low-friction assistance.

4. **Immediate next probe**

   Define one visual priority rule between subtitles and one-line support where subtitles always have higher precedence but do not block prompts when no subtitle is active.
