### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Improving subtitle placement rules based on confidence levels ensures that subtitles remain stable, readable, and unobtrusive while providing clear support when needed. This balance helps maintain trust in the system's real-time capabilities.

2. **What small change unlocks it**

   Define a fixed subtitle placement rule where subtitles are placed at the bottom of the screen, slightly above the center, with dynamic adjustments only during moments of high confidence to avoid distraction.

3. **Likely payoff**

   By keeping subtitles stable and unobtrusive, users can focus more on the conversation while still receiving essential support. This approach enhances user trust and usability without overwhelming the wearer.

4. **Immediate next probe**
   - Define the fixed position for subtitles at the bottom of the screen, slightly above the center.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving the confidence display format helps build trust by clearly indicating to the wearer how certain the system is about its information. This clarity ensures that subtitles and memory recall are not overtrusted, which is crucial for maintaining the wearer's comfort and ensuring they understand when the system might be uncertain.

2. **What small change unlocks it**

   Define a confidence format using a numeric score, label, and short reason. For example: "score 0.84 + 'High' + 'Seen recently'; score 0.42 + 'Low' + 'Weak match'; score 0.63 + 'Medium' + 'Name heard once in introduction'."

3. **Likely payoff**

   By implementing a clear and concise confidence format, the system can better manage the wearer's trust, ensuring that they are aware of when the system is highly certain versus when it might be making an educated guess. This reduces cognitive load by providing context around the reliability of the information.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   By setting a specific local memory threshold for face/name recall, we ensure that the system efficiently caches relevant memories while maintaining low resource usage. This helps in reducing the load on the cloud and battery life, ensuring that frequently encountered individuals are quickly accessible to the wearer.

2. **What small change unlocks it**

   Define a local cache size limit for person-memory objects based on their recency and frequency of interaction.

3. **Likely payoff**

   Implementing this cache size limit will improve memory lookup efficiency by reducing the number of cloud requests, thereby saving battery life and ensuring faster response times during conversations. It also helps in maintaining privacy by limiting data transmission to necessary interactions.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By defining a clear boundary for what stays local on the phone versus what falls back to the cloud, we can ensure that critical real-time subtitle processing and name recall remain fast and reliable. This helps maintain trust and clarity, which are central to the project's mission.

2. **What small change unlocks it**

   Define one specific task boundary where the glasses must handle live subtitle processing on-device, with no fallbacks to cloud resources under any circumstances.

3. **Likely payoff**

   By keeping live subtitle processing fully local, we ensure that subtitles remain stable and responsive in noisy environments, which is critical for real-time clarity and trust. This reduces battery drain and latency issues while maintaining a high level of assistive value without overloading the phone's resources.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   Ensuring that subtitles are displayed with clear, stable placement reduces cognitive load on the wearer, making real-time understanding more reliable and trust-preserving. This improves the primary attractor of subtitle clarity while also supporting the core mission of helping the wearer stay present and informed during conversations.

2. **What small change unlocks it**

   Define a set of fixed subtitle placement rules that prioritize readability over visual complexity. Specifically, establish two rules: one for when confidence is high (90% or above) and another for when confidence is medium to low (60-89%). These rules should ensure that subtitles remain on the screen long enough for clear reading but do not distract from the conversation.

3. **Likely payoff**

   By standardizing subtitle placement, the glasses will provide a more consistent and reliable experience, reducing the chance of misinterpretation or missed information due to poor visibility. This leads to higher trust in the system's ability to assist during live conversations, reinforcing the primary attractor of real-time subtitle clarity.

4. **Immediate next probe**
   - Define one visual priority rule between subtitles and one-line support in V1.
