# Reality Check

- **Subtitle Clarity**: The current focus is on ensuring subtitles are clear, fast, and stable. This aligns with real-world constraints like low latency and readable text in motion.
- **Feasibility**: Viable now; the `TranscriptLab` app provides a solid foundation for testing subtitle placement without heavy hardware dependencies.

## Confidence Display: Feasible Now
- **Current State**: The confidence display is currently being evaluated within `TranscriptLab`.
- **Real-world Limits**: Battery and thermal constraints are significant, but early V1 interactions can be simple.
- **Feasibility**: Feasible now; focus on numeric scores or labels for clarity without overcomplicating the UI.

## Memory/Cache Policy: Feasible Now
- **Current State**: Face/name memory is being evaluated with a focus on real-time recall and confidence.
- **Real-world Limits**: Battery and data storage constraints are key, but initial implementation can be simple.
- **Feasibility**: Feasible now; start with basic caching on the phone to ensure quick lookup and low battery impact.

## Phone/Cloud Boundary: Feasible Now

- **Real-world Limits**: Battery, latency, and trust are critical factors.
- **Feasibility**: Feasible now; ensure that all core functionality can be implemented on the phone to reduce dependency on the cloud.
