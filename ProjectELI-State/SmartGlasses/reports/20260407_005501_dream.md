### Idea 1: Subtitle Placement

1. **Why it benefits the core**
   - By defining specific subtitle placement rules based on confidence levels, we can ensure that subtitles are always clear and stable enough for the wearer to trust them in live conversations.

2. **What small change unlocks it**
   - Define three subtitle placement modes: 
     1. Fixed position at the bottom of the screen (for high-confidence content).
     2. Dynamic repositioning based on head movement (for medium-confidence content).
     3. Overlay during critical moments (for low-confidence or uncertain content).

3. **Likely payoff**
   - This change will improve subtitle clarity and stability, reducing distractions and enhancing trust in the system's real-time assistance. It will also help balance social acceptability with necessary visual information.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**
   - Improving the confidence display format will enhance trust in memory support by clearly indicating the certainty level of name and face recall. This ensures that the wearer can rely on accurate information without over-relying or under-relying on the system.

2. **What small change unlocks it**
   - Define a clear, concise confidence label format that combines a numeric score with a short reason for the certainty. For example: "High (seen recently)" or "Low (weak match)". This will provide both quantifiable and qualitative feedback to the wearer.

3. **Likely payoff**
   - By implementing a clear and concise confidence display, users will have a better understanding of when they can trust the system’s memory support. This reduces cognitive load by providing immediate reassurance during interactions, leading to a more seamless user experience.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   By optimizing local memory thresholds, we can ensure that the system efficiently manages name recall without overwhelming the user with too much context. This helps maintain a balance between providing useful information and avoiding cognitive overload, which is crucial for keeping the assistant low-friction and discreet.

2. **What small change unlocks it**

   Define a local cache eviction policy that keeps recently seen names within a manageable limit (e.g., 5-10 recent interactions) while still reinforcing long-term memory with more frequent encounters.

3. **Likely payoff**

   This refined memory management will improve the accuracy and relevance of face/name recall, enhancing the wearer's trust in the system without making it feel overly intrusive or memory-heavy. It will also reduce battery usage by limiting the amount of data that needs to be refreshed or stored locally.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   Ensuring that live subtitle processing remains phone-local optimizes battery usage and latency, which are critical for maintaining trust in real-time communication. By keeping this function on the phone, we reduce the risk of dropped or delayed subtitles, thereby enhancing the wearer's understanding and confidence during interactions.

2. **What small change unlocks it**

   Define a specific task boundary where live subtitle processing should remain phone-local: "Define one live subtitle processing rule for real-time transcripts that keeps the glasses light and responsive."

3. **Likely payoff**

   By keeping live subtitle processing on the phone, we ensure that subtitles are crisp and timely, which is crucial for the wearer's trust in the system during conversations. This reduces the risk of dropped or delayed subtitles due to cloud latency, improving overall usability.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   Enhancing the visual hierarchy between subtitles and one-line support ensures that critical information is prioritized for the wearer, reducing cognitive overload and maintaining focus during conversations. This improves overall usability by ensuring that real-time subtitles are more prominent and readable, while one-line prompts remain unobtrusive but still accessible when needed.

2. **What small change unlocks it**

   Define a visual priority rule that routes subtitles to the top of the display hierarchy over one-line support under all circumstances, with the option for one-line support to coexist below or alongside subtitles in a non-distracting manner.

3. **Likely payoff**

   By clearly prioritizing subtitles, the wearer can trust the real-time text more easily, enhancing their understanding and confidence during conversations. This improves daily-use value by making the product more reliable and less distracting, leading to higher satisfaction and better engagement.

4. **Immediate next probe**
   - Define one visual priority rule between subtitles and one-line support in V1.
