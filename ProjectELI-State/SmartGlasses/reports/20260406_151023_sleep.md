# Consolidated Insights for SmartGlasses V1

## Strengthening Signals
1. **Subtitle Quality**: The system should prioritize subtitle quality over complexity, ensuring real-time and accurate text placement without overwhelming the wearer.
2. **Face/Name Memory**: Memory for new faces and names must be reinforced through explicit remember-touch behavior to build trust and confidence in memory accuracy.
3. **Phone-First Processing**: The phone should handle most processing with cloud support only where it adds clear value, ensuring low latency and efficient use of resources.

## Weakening Signals
1. **Complex Interactions**: Simplify interactions to frame touches only; avoid assuming voice activation or complex multimodal UI in V1.
2. **Feature Sprawl**: Focus on deepening the core mission (live subtitles, face/name recall, conversation memory) rather than expanding into new features.

## Contradictions That Must Stay Alive
1. **Privacy vs Usefulness**: The system must balance providing useful assistance with maintaining user privacy and comfort.
2. **Battery Constraints**: Always-on sensing should be minimized to avoid draining the battery excessively, impacting daily use.

## Dormant Ideas Worth Reactivating
- **Confidence Display**: Explore a confidence format (label + short reason) that builds trust without overwhelming the user.
- **Subtitle Placement**: Revisit subtitle placement options to find the best balance between usability and distraction.

## Concrete Tensions Around Core Areas

### Subtitle Quality, Confidence Trust, Automatic New-Person Memory
1. **Subtitle Reasoning vs Visual UX**:
   - Ensure subtitles are clear and unobtrusive while maintaining real-time accuracy.
   - How can confidence indicators (label + short reason) be displayed without distracting the user?

2. **Automatic Memory Behavior vs Explicit Remember-Touch Behavior**:
   - Automatic memory should handle new faces/names with a high degree of confidence but rely on explicit remember-touch to reinforce and correct memories.
   - Explicit remember-touch behavior should provide users with control over when and how new faces/names are stored.

### Fast Lookup, Privacy, Memory Policy
1. **Memory Caching**:
   - Determine the optimal amount of face/name memory to cache locally vs. relying on cloud for faster lookup.
   - Balance between local storage (for quick responses) and privacy concerns (minimizing data exposure).

2. **Privacy Management**:
   - Implement strong privacy policies that allow users to control how their data is used.
   - Ensure the system does not store sensitive information unless necessary.

### Visual Hierarchy, Interaction Constraints
1. **Subtitle Placement and Visual Hierarchy**:
   - Subtitles should be placed prominently but without causing distraction.
   - One-line prompts should visually differ from subtitles in a way that supports quick comprehension.

2. **Interaction Constraints**:
   - Frame touches are the primary interaction method; avoid designing for voice commands or complex UI interactions.

## Open Questions
1. **Subtitle Placement**: What is the best balance between prominence and non-intrusiveness?
2. **Confidence Display**: How should confidence be represented (label, label + short reason, score + label) to build trust without overwhelming users?
3. **Memory/Cache Policy**: How much face/name memory should be cached locally versus relying on cloud for faster lookup?

## Summary
- Focus on real-time subtitle quality and clear confidence indicators.
- Use explicit remember-touch behavior for reinforcing new faces/names.
- Prioritize phone-first processing with minimal local compute to preserve battery life.
- Ensure interactions are simple, respecting frame touches only without voice activation or complex UI.
- Balance memory caching against privacy concerns, ensuring trust in the system.
