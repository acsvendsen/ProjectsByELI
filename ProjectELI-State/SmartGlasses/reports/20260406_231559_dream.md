### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Subtitle placement rules that are fixed and stable, but optimized for readability and trust, ensure that the wearer can always rely on the subtitles. This reduces cognitive load and increases confidence in understanding real-time conversations.

2. **What small change unlocks it**

   Define two subtitle placement modes: one for high-confidence states (e.g., when a name or face is seen frequently) and another for low-confidence states (e.g., when the system is unsure). This allows for more nuanced and context-aware subtitle display without overloading the wearer.

3. **Likely payoff**

   By providing clear and stable subtitle placement based on confidence levels, the system can reduce visual distractions while maintaining high trust in the subtitles during critical moments of conversation. This improves overall user experience and helps the wearer stay focused on the interaction at hand.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Ensuring that confidence displays are clear, concise, and correctly formatted helps maintain the trustworthiness of the system. By using a numeric score combined with a label and short reason, the wearer can quickly assess the reliability of any given piece of information or memory support.

2. **What small change unlocks it**

   Define a consistent format for confidence objects that includes a numeric score (e.g., 0.84), a label (e.g., "High"), and a short reason (e.g., "Seen recently"). This format will help users understand the certainty level of each piece of information.

3. **Likely payoff**

   Implementing this clear confidence display will enhance user trust in the system’s memory support and subtitle accuracy. Clear, concise confidence labels reduce cognitive load by providing immediate context on how reliable the displayed information is, thereby improving overall interaction quality.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Ensuring that new face/name memories are cached locally on the phone with a limited threshold can help maintain privacy and reduce the need for frequent cloud queries, thereby improving the overall trust in the system by minimizing data transmission.

2. **What small change unlocks it**

   Define a local cache size limit for new person memories that automatically evicts older entries to keep the memory storage manageable on the phone.

3. **Likely payoff**

   By limiting the amount of memory stored locally, the system can reduce battery usage and thermal strain while maintaining fast lookup performance for recently seen individuals. This approach also aligns with privacy concerns by reducing data transmission and cloud queries.

4. **Immediate next probe**
   - Define a local cache size limit of 50 entries for new person memories.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By defining a clear boundary between what runs locally on the phone versus what falls back to the cloud for live subtitle processing, we ensure that the real-time subtitles remain as fast and stable as possible. This helps maintain the wearer's trust in the system by keeping critical functionality close to the edge of the network, where it can react quickly without being affected by latency or connectivity issues.

2. **What small change unlocks it**

   Define a specific rule for live subtitle processing that prioritizes phone-local execution for all real-time transcript data except under high-load conditions or when cloud resources are explicitly requested by the user through an explicit touch gesture.

3. **Likely payoff**

   By keeping live subtitle processing phone-local, we can achieve faster and more reliable subtitle delivery, which directly benefits the core attractor of real-time subtitle clarity. This also helps in maintaining a low-friction user experience by avoiding unnecessary cloud interactions that could introduce latency or battery drain.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**
   Improving the visual hierarchy ensures that subtitles remain clear, readable, and unobtrusive while still providing critical information to the wearer. By optimizing how subtitles coexist with one-line support prompts, we can maintain high subtitle clarity without overwhelming the user.

2. **What small change unlocks it**
   Define a clear precedence rule where subtitles have priority over one-line support in the visual hierarchy but do not obscure each other excessively. This rule ensures that the most important information (subtitles) is always visible and readable while still allowing for brief, necessary prompts to coexist without causing distraction.

3. **Likely payoff**
   By defining a well-balanced visual hierarchy, we can ensure that subtitles remain clear and unobtrusive, maintaining the wearer's trust in real-time assistance. This will also help in reducing social awkwardness and confusion caused by overlapping or poorly displayed text.

4. **Immediate next probe**
   Define one subtitle-vs-one-line priority rule for V1 where subtitles have higher precedence but do not obscure each other excessively.
