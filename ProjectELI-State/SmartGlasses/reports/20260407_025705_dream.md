### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   By defining specific subtitle placement rules based on confidence states, we can ensure that subtitles are always visible and readable without becoming distracting. This will improve the wearer's trust in the system by maintaining a clear visual hierarchy that prioritizes important information.

2. **What small change unlocks it**

   Define three subtitle placement rules: one for high-confidence content (always visible), one for medium-confidence content (visible on touch), and one for low-confidence content (only shown on explicit user capture).

3. **Likely payoff**

   This approach will enhance the wearer's trust in the system by ensuring that critical information is always readily available, while less certain information requires more active engagement from the user. This balance reduces distractions and maintains a clear visual hierarchy.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**
   - Improving the confidence display format directly enhances user trust in the system's accuracy, which is crucial for the wearer to rely on the subtitles and memory support provided by the glasses.

2. **What small change unlocks it**
   - Define a simple yet clear confidence label that includes both a score and a short reason for why the recognition was made with that level of certainty. For example: "score 0.85 + 'High' + 'Seen recently'" or "score 0.42 + 'Low' + 'Weak match'".

3. **Likely payoff**
   - A well-designed confidence display can significantly boost the wearer's trust in the system’s ability to accurately recognize faces and names, leading to more confident interactions and a smoother user experience.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Improving memory cache size and eviction policies ensures that the system can reliably recall names and context over longer periods without overwhelming local storage, thus maintaining trust and usefulness in live interactions.

2. **What small change unlocks it**

   Define a local cache threshold for face/name memory objects, setting an upper limit on how much memory is stored locally before evicting older entries based on recency and confidence scores.

3. **Likely payoff**

   By limiting the amount of cached memory, we reduce the risk of storing low-value or outdated information while ensuring that critical and recent interactions are always accessible, enhancing overall system trust and reliability.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   Ensuring that critical subtitle processing remains phone-local helps maintain real-time stability and trust. By keeping live subtitle processing on the phone, we can guarantee near-instant delivery of subtitles without risking latency or battery drain from cloud interactions.

2. **What small change unlocks it**

   Define a specific task boundary for live subtitle processing where no data leaves the phone unless absolutely necessary. This means that all subtitle generation and display logic runs locally, with only minimal state updates pushed to the cloud for storage or fallback in cases of low network quality.

3. **Likely payoff**

   By keeping live subtitle processing local, we ensure real-time responsiveness, which is crucial for maintaining trust and utility. This also helps manage battery consumption more effectively by avoiding constant network communication during active use.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   By optimizing the visual hierarchy to prioritize subtitles over one-line support in fast-moving conversations, the system can ensure that critical information is always clear and prominent. This enhances the wearer's ability to follow the conversation without being overwhelmed by too much text on-screen.

2. **What small change unlocks it**

   Define a subtitle-vs-one-line priority rule where subtitles are displayed with higher precedence than one-line prompts in scenarios with multiple speakers or high speech rate.

3. **Likely payoff**

   This change will reduce visual clutter and help the wearer stay focused on key information during fast-paced conversations, thereby improving overall understanding and engagement without adding complexity.

4. **Immediate next probe**
   - Define one visual priority rule between subtitles and one-line support in V1.
