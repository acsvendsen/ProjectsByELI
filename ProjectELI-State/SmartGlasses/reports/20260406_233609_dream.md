### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   By defining specific subtitle placement rules for different confidence states, we can ensure that subtitles remain stable, clear, and trustworthy in various conversational scenarios. This helps maintain the wearer's trust and ensures that critical information is not lost due to shifting or unstable text.

2. **What small change unlocks it**

   Define a set of fixed subtitle placement modes: one for high-confidence situations (e.g., well-known people), another for medium-confidence situations (e.g., likely familiar faces), and a third for low-confidence situations (e.g., new names or faces).

3. **Likely payoff**

   This approach will provide a consistent and predictable user experience, reducing the chances of subtitle placement issues that could distract the wearer or cause confusion. It will also help in maintaining trust by ensuring that critical information is always visible and stable.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**
   
   Improving the confidence display format will enhance the wearer's trust in the system by providing clear, concise, and reliable indicators of certainty. This improves subtitle clarity and memory support, which are primary attractors.

2. **What small change unlocks it**

   Define a confidence object format that uses a numeric score (e.g., 0-1), a label (e.g., "High", "Medium", "Low"), and a short reason (e.g., "Seen recently", "Weak match").

3. **Likely payoff**

   By clearly indicating the certainty of information, the wearer can better trust the subtitles and memory support provided by the system. This will lead to increased user confidence and satisfaction, which are critical for the core mission.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**
   - Improving local memory caching policies ensures that frequently used names and faces are quickly accessible, enhancing subtitle clarity and trustworthiness by reducing latency in recall. This directly supports the core attractor of real-time subtitle clarity.

2. **What small change unlocks it**
   - Define a recency-based eviction policy for the phone's local cache where entities like names and faces are kept based on recent interaction frequency, with less frequent mentions being automatically purged after a set period to make room for more relevant information.

3. **Likely payoff**
   - This change will ensure that common names and faces remain cached locally, reducing the need for cloud lookups and improving subtitle clarity in live interactions by making recall responses faster and more reliable.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By defining a clear boundary for what runs phone-local versus cloud-fallback, we can ensure that subtitle processing remains fast and reliable while leveraging cloud resources only when necessary. This improves overall system performance and user trust by reducing latency and ensuring real-time responsiveness.

2. **What small change unlocks it**

   Define one task-specific cloud fallback boundary for live subtitle processing where the phone-local runtime is critical for speed and stability.

3. **Likely payoff**

   By keeping subtitle processing entirely on the phone, we can ensure that subtitles are delivered with minimal latency, which is crucial for maintaining trust and usefulness in real-time conversations. This also allows us to focus on optimizing local processing, ensuring a smoother user experience.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   Ensuring a clear visual hierarchy between subtitles and one-line support helps maintain low-friction assistance without overwhelming the wearer. This balance ensures that the subtitles remain primary, providing essential context, while one-line prompts are visible but unobtrusive.

2. **What small change unlocks it**

   Define a priority rule where subtitles always have higher precedence over one-line prompts in visual layout and prominence. This can be achieved by setting a simple subtitle placement mode that ensures subtitles are placed above or to the side of any one-line support text, making them more readable and easier to follow.

3. **Likely payoff**

   By prioritizing subtitles over one-line prompts, the system will maintain clarity in noisy environments and ensure the wearer can trust the subtitles for real-time understanding. This focus on subtitle clarity aligns with the core attractor of "real-time subtitle clarity" and helps reduce cognitive load by keeping necessary information prominent.

4. **Immediate next probe**
   - Define one visual priority rule between subtitles and one-line support in V1.
