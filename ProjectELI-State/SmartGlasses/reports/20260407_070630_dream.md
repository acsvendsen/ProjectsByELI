### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   By establishing stable subtitle placement rules that prioritize readability over distraction, the system can maintain a balance between providing clear, useful information without overwhelming the wearer. This ensures that subtitles remain an aid rather than a hindrance in live conversations.

2. **What small change unlocks it**

   Define and implement three fixed subtitle placement modes: top screen (for high confidence), bottom screen (for low confidence or unknowns), and center screen (as fallback). Each mode should be visually unobtrusive but prominent enough to be read quickly.

3. **Likely payoff**

   This small change will create a consistent, predictable experience for the wearer, reducing cognitive load during conversations and ensuring that critical information is always visible without causing distraction. It also provides a clear visual hierarchy that respects the core tension between real-time clarity and social acceptability.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving the confidence display format helps ensure that the wearer can trust the subtitles and memory support in real-time scenarios. By clearly indicating the certainty level of the information, the system maintains high trustworthiness, which is crucial for daily-use value.

2. **What small change unlocks it**

   Define a simple yet informative confidence label with a short reason next to it. For example, use labels like "High," "Medium," and "Low" along with reasons such as "Seen recently," "Weak match," or "Name heard once." This format provides quick, clear feedback without overwhelming the wearer.

3. **Likely payoff**

   By implementing a clear confidence display, users will have greater trust in the system's output, which is essential for maintaining high engagement and usability in real-world interactions. This clarity can reduce social awkwardness and cognitive load, enhancing the overall user experience.

4. **Immediate next probe**
   - Define the confidence score presentation format for V1 as "High, Seen recently" or "Low, Weak match."

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By defining a clear boundary for what stays phone-local versus what falls back to cloud, we ensure that V1 interactions remain lightweight and fast while maintaining necessary processing capabilities. This helps in preserving battery life and reducing thermal load, ensuring the product remains usable and discreet.

2. **What small change unlocks it**

   Define one task-specific cloud fallback boundary for live subtitle processing. Specifically, determine which parts of subtitle generation and rendering can be handled locally on the phone to ensure real-time performance, while other less critical steps fall back to the cloud.

3. **Likely payoff**

   By optimizing subtitle processing to run primarily on the phone, we can achieve near-real-time subtitle delivery without significant battery drain or thermal issues. This will enhance the wearer's trust in the product's reliability and help maintain a low-friction user experience.

4. **Immediate next probe**
