## Project Summary
The SmartGlasses V1 project is focused on delivering a discreet, context-aware personal assistant with core functionalities including real-time subtitles, face recognition, conversation memory, and one-line prompts. The current V1 architecture prioritizes frame-touch interactions and minimal on-glasses compute to ensure lightweight, socially acceptable hardware while leveraging the phone for heavy processing.
