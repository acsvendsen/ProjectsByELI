# Consolidation of Recent Signals for SmartGlasses V1

## Summary

This consolidation aims to clarify the core signals impacting the development direction of the SmartGlasses project, focusing on subtitle quality, memory trust, low-friction assistance, and other critical areas. The consolidation will preserve distinct boundaries between automatic memory behavior, explicit remember-touch behavior, confidence objects, and fast lookup requirements.

---

### Core Signals

1. **Strengthening Signals:**
   - **Subtitle Clarity (subtitle_clarity):** Ensure subtitles are clear, fast, and stable enough for the wearer to trust them in live conversation.
   - **Memory Trust (memory_trust):** Develop a memory system that accurately remembers names, faces, and prior context without overreliance or corruption.

2. **Weakening Signals:**
   - **Low-Friction Assistance (low_friction_assistance):** Refine the one-line support to provide just enough assistance to avoid creating command overhead or social awkwardness.

3. **Contradictions That Must Stay Alive:**
   - **Privacy vs Usefulness:** Ensure that the system remains privacy-conscious while still providing useful assistive behavior.
   - **Latency vs Richness:** Balance real-time responsiveness with the need for richer, albeit slower, processing capabilities.

4. **Dormant Ideas Worth Reactivating:**
   - **Subtitle Placement (subtitle_placement):** Revisit and optimize subtitle placement to ensure it remains usable without becoming distracting.
   - **Confidence Display (confidence_display):** Explore different confidence formats to find the best way to build trust in the system’s memory and recall.

5. **Concrete Tensions Around:**
   - **Subtitle Quality, Confidence Trust:** Focus on improving the quality of subtitles while maintaining high levels of confidence in memory support.
   - **Automatic Memory Behavior vs Explicit Remember-Touch Behavior:** Ensure that automatic memory behavior is reliable but does not overshadow the explicit remember-touch behavior for critical memories.
   - **Fast Lookup Requirements:** Prioritize fast and accurate lookup requirements to enhance user trust without overwhelming the system with too much data.

6. **No Fluff:**
   - **Core Mission Focus:** Stay focused on the core mission of discreet, context-aware personal assistance through live subtitles, face/name recall, conversation memory, and one-line support.
   - **Low-Complexity Interaction:** Ensure that V1 interactions remain frame-touch only to maintain simplicity and low friction.
