## Core Field Consolidation for SmartGlasses V1

### Strengthening Signals
1. **Subtitle Quality**: Subtitles must be near-real-time to maintain trust, with prominent placement for quick reading.
2. **Face/Name Memory**: Face/name recall should be accurate and quickly reinforced over time to build confidence.
3. **Memory Policy**: Recency-first memory policy ensures that recently interacted faces are prioritized for fast lookup.

### Weakening Signals
1. **Complex Interactions**: Frame-touch interactions are preferred; voice activation is not part of the current V1 design.
2. **Feature Sprawl**: New features like eye-tracking or advanced AR should be avoided until they can be justified by real-world use cases.
3. **Overloading Subtitles**: Avoid overwhelming subtitles with too much text, focusing on one-line prompts for context.

### Contradictions That Must Stay Alive
1. **Always-On Sensing vs Battery Constraints**: The glasses must balance always-on functionality with battery efficiency to ensure usability and longevity.
2. **Local Processing vs Cloud Intelligence**: Optimize for phone-first processing but allow cloud support where it enhances performance without significant latency.

### Dormant Ideas Worth Reactivating
- **Privacy Concerns**: Explore more ways to respect user privacy while providing useful features, such as non-intrusive memory reinforcement methods.

### Concrete Tensions Around Core Domains

1. **Subtitle Quality vs Battery and Thermals**
   - Ensuring subtitles are fast and clear without draining the battery or overheating the glasses.
   
2. **Confidence Display vs Memory Reinforcement**
   - Balancing the need for clear confidence indicators with the memory reinforcement strategy to ensure trust in face/name recall.

3. **Automatic Memory Behavior vs Explicit Remember-Touch Behavior**
   - Automating new-person memory with confidence objects while maintaining explicit remember-touch behavior for verification.
   
4. **Fast Lookup Requirements vs Privacy**
   - Implementing fast lookup features without compromising user privacy or social acceptability.

5. **Visual UX**: Subtitle placement and visual hierarchy should support quick reading and minimal distraction, aligning with the real-world limits of glasses hardware.

### Open Questions
- **Subtitle Placement**: What is the optimal subtitle placement for best readability and least distraction?
- **Confidence Display Format**: How can confidence be displayed effectively to build trust in face/name recall without overwhelming the wearer?
