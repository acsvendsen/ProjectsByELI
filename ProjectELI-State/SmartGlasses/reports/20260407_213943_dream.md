### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   By refining subtitle placement rules based on confidence states, V1 can ensure that subtitles are always in a visible but non-distracting position. This improves real-time subtitle clarity and helps the wearer maintain focus during conversations.

2. **What small change unlocks it**

   Define three fixed subtitle placement modes: high-confidence, medium-confidence, and low-confidence. For each mode, specify an optimal screen position that balances visibility with minimality.

3. **Likely payoff**

   Implementing a fixed subtitle placement rule set will enhance the wearer's trust in the subtitles by ensuring they are always easily readable yet unobtrusive. This will reduce cognitive load and improve overall user experience without adding unnecessary complexity.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   By refining the confidence display format to include a numeric score alongside the label and reason, we can provide users with more nuanced understanding of the reliability of the information provided by the glasses. This enhances trust through transparent and consistent feedback.

2. **What small change unlocks it**

   Define a simple confidence format that includes a numeric score (e.g., 0.85), followed by a label such as "High," and then a short reason (e.g., "Seen recently").

3. **Likely payoff**

   This approach will allow the wearer to quickly assess the reliability of the information, thereby enhancing trust in the system's accuracy. It aligns with the core attractors for memory support and low-friction assistance.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   By defining a clear recency threshold for local memory storage, we can ensure that the system focuses on the most relevant information, reducing clutter and improving trust by only retaining recent and pertinent interactions.

2. **What small change unlocks it**

   Introduce a simple time-based eviction policy where each face or name is stored in local memory with an expiration timestamp. Entries older than 30 minutes are automatically removed to keep the cache size manageable.

3. **Likely payoff**

   This change will help maintain a clean and relevant memory database, reducing the likelihood of outdated or irrelevant information being recalled, thus improving overall trust and utility for the wearer.

4. **Immediate next probe**

   Define one recency-based eviction rule where each face/name entry expires after 30 minutes of inactivity.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By refining the cloud fallback boundary for face/name recall lookup, we can ensure that critical memory support is always available to the wearer without unnecessary data transfers, thus preserving battery and thermal resources while maintaining trust in memory recall.

2. **What small change unlocks it**

   Define a specific task-based cloud fallback boundary: for face/name recall, rely on local cache first and only fall back to the cloud if no recent match is found within a certain time window (e.g., 5 minutes).

3. **Likely payoff**

   This refinement will allow the system to quickly recall recently seen faces and names from the local cache, reducing latency and conserving battery while maintaining the reliability of memory support.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   Improving the visual hierarchy by defining a clear precedence between subtitles and one-line support ensures that the wearer can focus on essential information without feeling overwhelmed. This clarity helps maintain trust in the system, as the wearer knows which content is most important at any given moment.

3. **Likely payoff**

   By ensuring subtitles remain the primary focus, the system maintains its core mission of helping the wearer understand better in noisy environments. Clear visual hierarchy also reduces cognitive load and social friction, making the experience more usable and trustworthy.

4. **Immediate next probe**
