### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   By establishing a fixed subtitle placement rule for different confidence states, we ensure that subtitles remain clear and unobtrusive while still being visible enough to be trusted in live conversation. This approach helps maintain a balance between visual clarity and social acceptability, which is crucial for the core mission of helping the wearer understand better without becoming distracting.

2. **What small change unlocks it**

   Define a fixed subtitle placement rule where subtitles are positioned at the bottom center of the frame by default but move to the side if the confidence level drops below 0.9 to avoid overlapping with complex visuals or text in the conversation.

3. **Likely payoff**

   This fixed rule will help maintain consistent and unobtrusive subtitle visibility, reducing cognitive load on the wearer while ensuring they can trust the subtitles during critical moments of interaction. It also helps in maintaining a discreet UX that aligns with the core attractors of low-friction assistance and real-time clarity.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

This can lead to a more seamless and less stressful user experience, aligning better with the core mission of enhancing understanding without pretending knowledge.

4. **Immediate next probe**

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By defining a clear boundary for what stays phone-local versus what falls back to cloud, we can ensure that subtitle processing happens in real-time on the glasses, maintaining trust and clarity. This local processing also helps manage battery and thermal constraints, ensuring smooth performance during live interactions.

2. **What small change unlocks it**

   Define one task-specific phone/cloud fallback boundary for exactly one task such as live subtitle processing. For example, set a rule that live subtitles are processed on the glasses until they exceed a certain complexity or latency threshold, at which point they fall back to cloud processing.

3. **Likely payoff**

   By keeping live subtitle processing local, we can ensure real-time clarity and stability in noisy environments, enhancing the wearer's trust and understanding during conversations. This approach also helps manage battery usage by offloading heavier tasks only when necessary.

4. **Immediate next probe**
   - Define a rule that live subtitle processing is handled locally on the glasses until it exceeds a complexity threshold of 50 units, at which point it falls back to cloud processing.
