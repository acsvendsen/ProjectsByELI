# Consolidated Signals for SmartGlasses Project

## Strengthening Signals
1. **Subtitle Clarity**: 
   - Core-deepening efforts should focus on improving real-time subtitle clarity to ensure subtitles remain readable, stable, and trust-preserving in live conversations.
   
2. **Memory Trust**:
   - Enhance the memory support system to remember names, faces, and prior contexts accurately without creating false certainty or misleading recall.

3. **Low-Friction Assistance**:
   - Prioritize delivering one-line help and visible support through low-friction interactions that do not introduce command overhead or social awkwardness.

## Weakening Signals
1. **Privacy vs Usefulness**: 
   - The project should prioritize minimizing invasive behavior to maintain user trust while still providing useful assistance.
   
2. **Latency vs Richness**:
   - Focus on delivering timely help without overcomplicating the system with richer but slower processing options.

3. **Discreet UX vs Visual Clarity**:
   - Strive for a balance between maintaining a discreet user experience and ensuring subtitles are visually clear enough to be read in motion and noise environments.

## Contradictions That Must Stay Alive
1. **Core Deepening Over Sprawl**:
   - The project should remain focused on core mission improvements (subtitle quality, memory trust, visual UX) rather than broad feature expansion.
   
2. **Frame-Touch-Only V1 Interaction**:
   - Explicit interaction in the first version should be through frame touches only; voice commands are not a current design assumption.

## Dormant Ideas Worth Reactivating
1. **Subtitle Placement and Visual Hierarchy**:
   - Consider reactivating efforts to define an optimal subtitle placement that balances usability with low distraction, while ensuring it fits within the defined visual hierarchy constraints.

2. **Automatic Memory vs Explicit Remember-Touch Behavior**:
   - Revisit how automatic memory behavior should coexist with explicit remember-touch interactions, especially in contexts where real-time reinforcement is necessary but may not always be available through user interaction.

## Concrete Tensions Around Subtitle Quality, Confidence Trust, Automatic New-Person Memory, Memory Reinforcement, Fast Lookup, Privacy, Latency, Battery, and Visual UX

### Subtitle Quality
- **Subtitle Placement**: Ensure that subtitles are placed in a way that is unobtrusive yet clear enough to be read in noisy environments.
- **Visual Hierarchy**: Define the best visual hierarchy for subtitles so they can be quickly processed by the wearer.

### Confidence Trust
- **Confidence Display**: Decide on the best method to display confidence (label only, label + short reason, or score + label) that builds trust without overwhelming the user.
- **Memory Policy**: Implement a memory policy that reinforces new faces and names over time with appropriate confidence objects.

### Automatic New-Person Memory
- **Automatic New-Person Recognition**: Enhance automatic memory behavior to recognize and reinforce new people in real-time, even when explicit remember-touch interactions are not possible.
  
### Memory Reinforcement
- **Reinforcement Strategies**: Develop strategies for reinforcing remembered names, faces, and contexts over multiple sessions.

### Fast Lookup
- **Local Processing vs Cloud Intelligence**: Balance local processing with cloud intelligence to ensure fast lookup times without excessive battery drain or thermal issues.

### Privacy
- **Data Handling**: Ensure that data handling practices respect user privacy by not recording or storing unnecessary information.

### Latency
- **Real-Time Responses**: Prioritize real-time responses over richer but slower processing options to maintain trust and utility.

### Battery
- **Power Management**: Implement power management strategies to ensure the system remains functional without significantly draining the battery.

### Visual UX
- **Discreet Design**: Maintain a discreet design that does not draw too much attention while still providing necessary information.

## Open Questions Requiring Attention
1. **Subtitle Placement**:
   - Define an optimal placement for subtitles that is unobtrusive yet readable in motion and noise environments.
   
2. **Confidence Display**:
   - Determine the best confidence format (label only, label + short reason, or score + label) to build trust without overwhelming the user.

3. **Memory/Cache Policy**:
   - Decide how much face/name memory should be cached locally on the phone and for how long.
   
4. **Phone/Cloud Boundary**:
   - Establish clear boundaries between what processing happens on the phone versus in the cloud, especially focusing on real-time performance and privacy.

5. **Visual Hierarchy**:
   - Define a visual hierarchy that supports subtitle readability while minimizing distraction.

By addressing these signals and tensions with concrete actions, the project can continue to deepen its core mission without drifting into broader or less impactful directions.
