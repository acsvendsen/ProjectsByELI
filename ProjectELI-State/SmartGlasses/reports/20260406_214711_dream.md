### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   By setting a local cache size threshold for face/name recall, we ensure that the system retains only the most relevant memories while respecting battery constraints. This helps maintain high trust through reinforcement over time without overwhelming the phone's storage or draining the battery.

2. **What small change unlocks it**

   Define a memory cache policy with a fixed local cache size of 10-20 entries for each person or name, limited by both the number of interactions and recent activity.

3. **Likely payoff**

   This approach ensures that frequently encountered individuals are always available quickly, while less relevant memories are purged to keep the system responsive and energy-efficient. It supports fast lookup and trust in memory recall without overburdening the phone’s resources.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By defining a clear boundary for what runs phone-local versus falling back to cloud, we can ensure that the system remains responsive and private while still leveraging cloud resources when needed. This helps in maintaining trust by providing timely assistance without overloading the glasses or compromising privacy.

2. **What small change unlocks it**

   Define a specific task boundary for live subtitle processing where critical real-time decisions are made phone-local to reduce latency, followed by fallbacks to the cloud only for non-critical tasks like transcript cleanup and memory archive sync.

3. **Likely payoff**

   By keeping subtitle processing phone-local, we can ensure that subtitles remain fast and stable enough to be trusted in live conversations. This reduces battery drain and thermal stress on the glasses, maintaining a lighter form factor. Additionally, critical memory and lookup operations are handled locally where privacy concerns are less pronounced.

4. **Immediate next probe**
