# Consolidated Signals for SmartGlasses Project

## Strengthening Signals
1. **Subtitle Clarity**:
   - **Reason**: Subtitles must remain clear, fast, and stable enough to be trusted in live conversations.
   
2. **Memory Trust**:
   - **Reason**: Names, faces, and prior context should be remembered with confidence objects without creating false certainty or recall issues.

3. **Core Deepening Focus**:
   - **Reason**: The project should focus on improving subtitle quality, memory trust, confidence behavior, and architecture improvements that enhance daily-use value.

## Weakening Signals
1. **Low-friction Assistance**:
   - **Reason**: While important, this aspect is currently of medium strength compared to subtitle clarity and memory trust.

2. **Discreet UX vs Visual Clarity Tension**:
   - **Reason**: The tension between a discreet user experience and sufficient visual clarity needs to be managed carefully.

## Contradictions That Must Stay Alive
1. **Privacy vs Usefulness Tension**:
   - **Reason**: Helpful assistive behavior must not quietly slide into invasive capture or retention.
   
2. **Latency vs Richness Tension**:
   - **Reason**: The system should provide timely help without overloading the runtime with richer but slower processing.

3. **Always-on Sensing vs Battery and Thermals Constraint**:
   - **Reason**: Early versions should avoid heavy on-glasses compute to manage battery and thermal risks.

## Dormant Ideas Worth Reactivating
1. **Subtitle Placement and Visual Hierarchy**:
   - **Reason**: These areas need concrete candidates grounded in the current project instance rather than generic ideation.
   
2. **Face/Name Memory Cache Policy**:
   - **Reason**: Deciding how much face/name memory should be cached locally on the phone is a key open question.

## Concrete Tensions Around Core Mission
1. **Subtitle Quality and Memory Richness vs Fast Lookup**:
   - **Reason**: Balancing the need for clear subtitles with fast lookup behavior to avoid overwhelming the wearer.
   
2. **Battery, Latency, Privacy, Usability Limits**:
   - **Reason**: Surface these real-world constraints early so that weak directions can be quickly identified and discarded.

## Current Open Questions
1. **Subtitle Placement**:
   - **Reason**: Determine the best placement for subtitles without becoming distracting.
   
2. **Confidence Display**:
   - **Reason**: Decide on the optimal format for confidence, whether numeric score, label, or short reason.
   
3. **Memory/Cache Policy**:
   - **Reason**: Establish how much face/name memory should be cached locally versus relying on cloud processing.

4. **Phone/Cloud Boundary**:
   - **Reason**: Define when and where to use the phone vs cloud for processing heavy tasks.

5. **Visual Hierarchy**:
   - **Reason**: Ensure subtitles and one-line prompts coexist without overloading the wearer visually.
