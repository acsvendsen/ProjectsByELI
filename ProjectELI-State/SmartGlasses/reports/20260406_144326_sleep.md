# Core Field Consolidation for SmartGlasses V1

## Strengthening Signals
1. **Subtitle Quality**: The system must provide near-real-time subtitles that enhance understanding without overwhelming the wearer. Subtitles should be clear, context-aware, and dynamically adjusted based on environmental noise levels.
2. **Memory Reinforcement**: The memory of new faces and names should be reinforced through frequent interactions to build confidence objects over time. This ensures reliable recall when needed.

## Weakening Signals
1. **Overcomplication**: Avoid adding features or interactions that distract from the core mission of providing real-time assistance through live subtitles, face/name recall, conversation memory, and one-line support.
2. **Unnecessary Hardware**: Stay away from proposing new hardware like eye-tracking sensors unless explicitly justified by project signals.

## Contradictions That Must Stay Alive
1. **Always-on Sensing vs Battery Constraints**: The system must balance the need for always-on sensing with the reality of battery limitations to ensure longevity and usability.
2. **Rich Memory vs Fast Lookup**: Implement a balance between storing rich contextual memory and ensuring fast lookup times to avoid overwhelming the wearer.

## Dormant Ideas Worth Reactivating
1. **Subtitle Placement and Visual Hierarchy**: Explore different subtitle placements (e.g., top, bottom, side) to find the optimal location that minimizes distraction while maximizing readability.
2. **Confidence Display Formats**: Revisit confidence display formats such as numeric scores or labels with short reasons to ensure users trust the system’s reliability.

## Concrete Tensions Around
1. **Subtitle Quality vs Battery and Thermals**:
   - Subtitles must be clear and helpful but should not consume too much battery.
2. **Memory Trust vs Privacy Perception**:
   - The memory of new faces/names should build strong confidence objects, but the system must handle data privacy carefully to maintain trust.

## Open Questions
1. **Subtitle Placement and Visual Hierarchy**: What is the best V1 subtitle placement that minimizes distraction while ensuring clarity?
2. **Confidence Display Formats**: How can we represent confidence in a way that builds trust without being overly complex?
