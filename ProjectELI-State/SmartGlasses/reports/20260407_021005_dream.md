### Idea 1: Subtitle Placement

1. **Why it benefits the core**
   Improving subtitle placement rules can enhance the wearer's trust in the system by ensuring that subtitles remain visible and clear during live conversations, which directly supports the primary attractor of real-time subtitle clarity.

2. **What small change unlocks it**
   Define a fixed subtitle placement rule for V1 that prioritizes stability over reactivity, setting specific coordinates on the display for subtitles to appear consistently without moving unless there is a significant noise or visual disturbance.

3. **Likely payoff**
   By implementing this fixed subtitle placement rule, the system can reduce distractions and ensure that subtitles remain in a consistent field of view, improving the wearer's ability to follow conversations and increasing overall trust in the assistive nature of the glasses.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   By setting a local cache threshold for name recall, we ensure that frequently encountered names are quickly accessible without excessive battery drain or thermal load. This improves trust by providing fast and reliable memory support, which is crucial for the wearer's ability to understand and respond in real-world interactions.

2. **What small change unlocks it**

   Define a local cache size limit of 10 names that are frequently encountered (e.g., based on repeated face encounters or explicit user touch). This limit ensures that common names can be quickly recalled while minimizing memory overhead.

3. **Likely payoff**

   Implementing this cache threshold will reduce latency in name recall, enhance the reliability of memory support, and improve overall trust in the system. The wearer will experience faster and more accurate name recognition during conversations, leading to a better user experience without significant battery or thermal impact.

4. **Immediate next probe**

   Define one local-cache size limit for frequently encountered names as 10 entries based on repeated face encounters or explicit user touch.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By clearly defining what stays phone-local versus what falls back to cloud for live subtitle processing, we can ensure that subtitles remain fast and reliable in real-time, which is critical for maintaining trust and clarity during conversations.

2. **What small change unlocks it**

   Define a clear boundary where confidence scores below a certain threshold are processed locally on the phone, while higher-confidence data falls back to cloud for richer but potentially slower processing.

3. **Likely payoff**

   This approach will ensure that subtitles remain fast and reliable in real-time, reducing latency and maintaining trust with the wearer. It also allows us to leverage cloud resources for more complex processing without impacting critical live subtitle delivery.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   By clearly defining how subtitles coexist with one-line support, we ensure that the wearer receives essential information without visual overload. This balance enhances trust and usability by preventing distractions while maintaining necessary clarity.

2. **What small change unlocks it**

   Define a subtitle-vs-one-line priority rule that prioritizes subtitles for longer, more complex content and one-line support for shorter, context-sensitive prompts. This rule can be implemented as a simple precedence order in the UI design.

3. **Likely payoff**

   A clear coexistence strategy will reduce visual clutter, making it easier for the wearer to focus on the most critical information during conversations. This reduces cognitive load and enhances the overall user experience by maintaining a clean interface that is both functional and unobtrusive.

4. **Immediate next probe**

   Define one subtitle-vs-one-line priority rule where subtitles take precedence over shorter prompts in long, complex sentences or paragraphs.
