### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   By defining clear subtitle placement rules that ensure subtitles remain stable and unobtrusive during live conversations, we can enhance the wearer's trust in the system. This stability helps in creating a predictable and reliable experience, which is crucial for building confidence in the smart glasses as a helpful tool.

2. **What small change unlocks it**

   To achieve this, we need to define two subtitle placement rules: one for when the confidence level is high (e.g., 0.8 or above) where subtitles can remain visible but unobtrusive, and another for lower confidence levels (e.g., below 0.8) where subtitles should fade out slightly more quickly to avoid distraction.

3. **Likely payoff**

   Implementing these subtitle placement rules will ensure that the wearer does not get distracted by constantly moving or appearing subtitles, thereby improving the overall user experience and trust in the system's accuracy. This stability can significantly reduce cognitive load during live conversations, making the smart glasses more useful and reliable.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving confidence display ensures that the wearer can trust the assistant more, which is crucial for maintaining the core attractors like real-time subtitle clarity and memory support. A clear and consistent confidence format helps in building user trust and ensuring that the wearer understands when to rely on the subtitles or memories provided by the system.

2. **What small change unlocks it**

   Define a single, concise confidence format that combines a numeric score with a label and a short reason. For example: "score 0.84 + 'High' + 'Seen recently'". This format provides enough information to convey certainty without overwhelming the wearer.

3. **Likely payoff**

   By standardizing the confidence format, the system can more effectively communicate its level of certainty about names and subtitles. This clarity will reduce user confusion and increase trust in the assistant's abilities, leading to a better overall experience that aligns with the core attractors.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

Improving local memory thresholds will help ensure that the wearer's context is reliably available during live interactions, enhancing the overall trustworthiness of the system without overloading the device with unnecessary data.

2. **What small change unlocks it**

Define a local cache size limit for face and name memories on the phone to avoid storing low-value or redundant information while keeping essential memories fresh and accessible.

3. **Likely payoff**

By setting an appropriate cache size, the system will maintain a balance between providing rich contextual support and conserving resources, ensuring that new faces and names are remembered with confidence objects while older or less relevant entries are pruned to keep memory usage efficient.

4. **Immediate next probe**

Define one local-cache size limit for face and name memories on the phone, balancing memory retention with device constraints.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By defining a clear boundary for what stays phone-local versus what falls back to cloud processing, we ensure that critical real-time subtitle and memory support remains reliable and responsive. This enhances trust by minimizing latency and ensuring that key functionality is not dependent on potentially slower cloud services.

2. **What small change unlocks it**

   Define a single task-specific fallback boundary for live subtitle processing: Keep all local speech-to-text transcription, confidence scoring, and initial subtitle rendering phone-local until the glasses are within a reliable communication range.

3. **Likely payoff**

   This approach will reduce latency and ensure that subtitles remain clear and stable during critical conversations, which is crucial for maintaining trust and usability in real-world scenarios. It also frees up cloud resources for more complex tasks like memory lookup and context refinement, without compromising on the core subtitle quality.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

This alignment supports the core attractors of real-time subtitle clarity and low-friction assistance by making sure the most important information remains prominent, enhancing the overall user experience.

This improvement also reduces cognitive load on the wearer, allowing them to focus more effectively on the conversation at hand without being overwhelmed by additional prompts or notifications.
