# Reality Check for SmartGlasses Core Field

## Subtitle Clarity (Subtitle Placement)

- **Current Status**: Feasible now
- **Reasoning**: The current project setup includes a `TranscriptLab` app that tests real-time subtitle clarity. Given the successful build and tests, we can assume that basic subtitle functionality is feasible with existing hardware. Further optimization and refinement of subtitle placement will be necessary to ensure readability without becoming distracting.

## Memory Trust (Memory/Cache Policy)

- **Current Status**: Feasible now
- **Reasoning**: The project has defined memory policies through the `memory_trust` attractor, which focuses on reliable face/name recall. While the implementation is still in early stages, the core concept of storing and reinforcing confidence objects for fast lookup aligns with current capabilities. Local caching should be limited to what fits within on-device constraints.

## Low-Friction Assistance (Confidence Display)

- **Current Status**: Feasible now
- **Reasoning**: The `TranscriptLab` app already supports basic confidence display, which can evolve into more refined one-line prompts as the project progresses. The current implementation focuses on clarity and trustworthiness, ensuring that any added assistance is low-friction.

## Phone/Cloud Boundary

- **Current Status**: Feasible now
- **Reasoning**: The `TranscriptLab` app demonstrates a phone-first runtime model where heavy processing happens on the phone with cloud support being optional. This aligns well with current constraints, ensuring that early hardware remains simple while preserving a path to stronger capability later.

## Visual Hierarchy

- **Current Status**: Feasible now
- **Reasoning**: The `TranscriptLab` app provides a reusable transcript test bed for UI and control design. Although not fully fleshed out, this setup allows us to iteratively refine the visual hierarchy without overcomplicating early prototypes.

## Core Deepening Over Sprawl

- **Current Status**: Feasible now
- **Reasoning**: The project is currently in a `core_deepening` mode, which emphasizes improvements to subtitle quality, memory trust, and visual UX. This direction is aligned with the core mission and non-negotiables.

## Privacy vs Usefulness

- **Current Status**: Likely waste of time (infeasible now)
- **Reasoning**: The project has explicitly defined that new face/name memory should expose uncertainty clearly to avoid creating corrupted recall or invasive capture. Further work on privacy concerns without clear evidence or user feedback is likely a waste of time at this stage.

## Latency vs Richness

- **Current Status**: Feasible now
- **Reasoning**: The `TranscriptLab` app has demonstrated the ability to provide timely help with real-time subtitles and basic memory support. While there may be room for richer features, the core functionality is currently feasible within current constraints.

## Discreet UX vs Visual Clarity

- **Current Status**: Feasible now
- **Reasoning**: The project is committed to a frame-touch-only V1 interaction mode that respects social acceptability and visual clarity. The `TranscriptLab` app supports this by focusing on clear, readable UI elements.

## Frame-Touch-Only V1 Interaction

- **Current Status**: Feasible now
- **Reasoning**: This constraint is explicitly outlined in the project documentation and will be enforced through the use of the `TranscriptLab` app for early tests. Early interaction design should focus on this mode.

## Phone-First Runtime

- **Current Status**: Feasible now
- **Reasoning**: The setup with `TranscriptLab` already demonstrates a phone-first runtime where heavy processing happens primarily on the phone, making use of cloud support only when clearly justified. This aligns well with current constraints.

## Core Deepening vs Sprawl

- **Current Status**: Feasible now
- **Reasoning**: The project is currently in a `core_deepening` mode that prioritizes improving subtitle quality, memory trust, and visual UX over broad feature expansion. This direction is aligned with the core mission and non-negotiables.
