# Reality Check

## Subtitle Placement: Feasible Now
- **Current Considerations**: The glasses need to display subtitles clearly and quickly in a noisy environment.
- **Constraints**: Social acceptability, readability in motion, and low distraction.
- **Feasibility Analysis**:
  - **Display Size and Location**: Current prototypes using the edge of the lens for subtitle display are feasible. This location is less obstructive while still ensuring the wearer can read subtitles quickly.
  - **Stability and Readability**: The prototype with a clear, non-distracting font that updates in real-time meets the core mission of providing stable, readable subtitles.

**Conclusion**: Subtitle placement on the edge of the lens appears feasible now. However, further testing is required to ensure it remains unobtrusive during active use.

## Confidence Display: Feasible Now
- **Current Considerations**: Representing confidence in memory and real-time responses accurately.
- **Constraints**: Clarity vs. feature density, trustworthiness, and user perception.
- **Feasibility Analysis**:
  - **Label Only**: A simple label (e.g., "High," "Medium," or "Low") could be effective while keeping the interface uncluttered.
  - **Label + Short Reason**: Providing a reason for low confidence (e.g., "Uncertain" with an exclamation mark) could enhance trust but might introduce visual clutter.

**Conclusion**: Using a simple label is feasible now. Adding a short reason would require further testing to ensure it does not detract from the core mission of providing clear and reliable information.

## Memory/Cache Policy: Feasible Now
- **Current Considerations**: Storing and reinforcing face/name memory for fast lookup.
- **Constraints**: Battery, privacy, and real-time responsiveness.
- **Feasibility Analysis**:
  - **Local Storage**: Caching data on the phone is feasible as long as it does not drain the battery excessively or compromise user privacy.
  - **Reinforcement Mechanism**: Using reinforcement learning to update memory with each interaction can be done locally, making use of phone processing.

**Conclusion**: Implementing a local caching and reinforcement mechanism for face/name memory is feasible now. Ensuring this process remains efficient will require ongoing monitoring and optimization.

## Phone/Cloud Boundary: Feasible Now
- **Current Considerations**: Deciding when to rely on the cloud versus the phone for heavy processing.
- **Constraints**: Battery, latency, and always-on sensing.
- **Feasibility Analysis**:
  - **Phone First**: The initial implementation should focus on keeping the glasses lightweight by offloading heavy processing to the phone.
  - **Cloud Optional**: Using the cloud only where it provides clear value (e.g., model updates) without compromising battery or latency.

**Conclusion**: Relying primarily on the phone for early processing while optionally using the cloud for critical tasks is feasible now. This approach balances performance with power efficiency.

## Visual Hierarchy: Feasible Now
- **Current Considerations**: Ensuring subtitles and prompts are visually distinct.
- **Constraints**: Readability, social acceptability, and minimizing distraction.
- **Feasibility Analysis**:
  - **Subtitle vs Prompt Distinction**: Using different colors or styles for subtitles versus prompts can maintain clarity without being distracting.
  - **Simplicity**: Keeping the visual hierarchy simple ensures it remains unobtrusive while still providing necessary information.

**Conclusion**: Distinguishing between subtitles and prompts through color or style differences is feasible now. Further refinement may be needed to ensure optimal readability during use.

## Summary of Feasibility
- **Subtitle Placement, Confidence Display, Memory/Cache Policy, Phone/Cloud Boundary, Visual Hierarchy**: These areas are currently feasible with the given constraints and can proceed as planned.
- **Assumptions Needing Evidence**: Further testing is required for subtitle placement to ensure it remains unobtrusive during use. 

By focusing on these specific areas within the current framework, the project can continue to refine its core mission while addressing real-world limitations early.
