### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Improving subtitle placement rules helps ensure that subtitles remain clear, stable, and unobtrusive during live conversations. This directly supports the primary attractor of real-time subtitle clarity while also reducing social friction, which aligns with low-friction assistance.

2. **What small change unlocks it**

   Define a default fixed subtitle position for V1, placing subtitles at the bottom center of the field of view and ensuring they are slightly offset to avoid overlapping the main focus of the wearer's gaze.

3. **Likely payoff**

   By fixing subtitle placement, we can ensure that subtitles remain consistent and predictable, reducing distraction during conversations. This will help in maintaining clear communication and trust in the system’s ability to provide accurate support without overwhelming the user.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving the confidence display format ensures that the wearer can quickly understand the reliability of information presented by the glasses without being overwhelmed by technical details. This enhances trust in both subtitle and memory support, aligning with the core attractors of real-time subtitle clarity and trustworthy memory support.

2. **What small change unlocks it**

   Define a simple confidence label and short reason format that can be easily read on-the-go. For example, use "High" for high confidence, "Medium" for moderate confidence, and "Low" for low confidence, with reasons like "Seen recently," "Weak match," or "Name heard once."

3. **Likely payoff**

   A clear and concise confidence display will help the wearer trust the system more quickly during interactions, reducing cognitive load and increasing overall usability. This aligns with the goal of low-friction assistance and enhances the core attractor of trustworthy memory support.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Improving the local memory cache size and eviction rule for face/name recall directly addresses the tension between privacy and usefulness by ensuring that critical memory is retained while minimizing storage overhead.

2. **What small change unlocks it**

   Define a local cache threshold of 5-7 recent face/name encounters, with a first-in-first-out (FIFO) eviction policy based on recency.

3. **Likely payoff**

   This change will enhance the wearer's ability to recall names and faces more reliably in noisy environments without overloading the phone's limited memory resources. It also respects privacy by not storing unnecessary information beyond what is immediately relevant.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

   Ensuring that live subtitle processing stays on the phone helps maintain real-time responsiveness, which is crucial for trust in noisy environments. By keeping this task local, we can avoid cloud latency issues and ensure subtitles are delivered with minimal delay, enhancing the wearer's ability to follow spoken content accurately.

2. **What small change unlocks it**

   Define a specific subtitle processing boundary where live transcription and rendering stay on the phone, even for long-wearing sessions or low-bandwidth conditions.

3. **Likely payoff**

   By keeping subtitle processing local, we can ensure real-time responsiveness, reduce battery drain from constant network requests, and maintain a stable user experience that is crucial for trust in noisy environments. This will help deepen the core mission by providing reliable assistance without added latency.

4. **Immediate next probe**
