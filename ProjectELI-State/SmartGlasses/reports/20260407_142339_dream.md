### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   By defining specific subtitle placement rules based on confidence levels, V1 can ensure that subtitles remain clear and unobtrusive while still providing essential support in noisy environments.

2. **What small change unlocks it**

   Define a simple rule that places high-confidence subtitles above the one-line support text and low-confidence subtitles below or to the side of it.

3. **Likely payoff**

   This placement rule will enhance the wearer's ability to focus on the conversation while still receiving critical information when needed, reducing cognitive load and increasing trust in the system.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   By refining how confidence is displayed, we can ensure that the wearer has a clear and honest understanding of the system's certainty about any given piece of information. This helps build trust over time and ensures that the wearer does not rely on false positives or misleading information.

2. **What small change unlocks it**

   Define a consistent format for displaying confidence in subtitles, face/name memory, and other contextual elements. The format should include both a numeric score and a short reason to explain the source of uncertainty.

3. **Likely payoff**

   A well-defined confidence format will help users trust the system more by providing clear indications of reliability. This transparency can reduce social awkwardness and cognitive load, making the glasses more useful in real-world scenarios.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Improving memory cache thresholds ensures that frequently encountered names and faces are quickly accessible, reducing lookup latency and enhancing trust in memory support. By setting a threshold for local memory storage, we can balance between rich context and fast retrieval, ensuring the system remains responsive even under heavy usage.

2. **What small change unlocks it**

   Define a local cache size limit of 50 entries for frequently encountered names and faces, with a recency policy that keeps the most recently seen entities in active memory.

3. **Likely payoff**

   This change will reduce lookup latency by providing quick access to commonly recalled people, thereby improving the overall trustworthiness of the memory support feature. It will also help maintain battery efficiency by limiting the amount of data stored locally, which is crucial for an always-on device like smart glasses.

4. **Immediate next probe**
   - Define a local cache size limit of 50 entries for frequently encountered names and faces.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**
   - By defining a clear boundary for which tasks run locally on the phone versus which fall back to the cloud, we ensure that subtitle processing remains real-time and reliable, enhancing the wearer's trust in the system.

2. **What small change unlocks it**
   - Define one task-specific cloud fallback boundary for live subtitle processing. This involves setting a clear condition under which the glasses will request cloud processing when local resources are insufficient or when there is a high demand on battery life.

3. **Likely payoff**
   - By keeping live subtitle processing phone-local, we ensure that subtitles remain fast and stable, reducing latency issues and maintaining the wearer's trust in the system. This also helps manage battery usage more effectively by avoiding unnecessary cloud requests during critical interactions.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   Ensuring a clear visual hierarchy between subtitles and one-line prompts helps maintain the wearer's focus on critical information without overwhelming them. This balance supports real-time subtitle clarity while allowing essential contextual support to be visible but not distracting.

2. **What small change unlocks it**

   Define a simple coexistence rule that prioritizes subtitles in the center of the display, with one-line prompts appearing either above or below the subtitle text, ensuring they do not overlap and are clearly visible when needed.

3. **Likely payoff**

   By maintaining a clear visual hierarchy, the system can ensure that critical information like real-time subtitles remain the primary focus, while contextual support is easily accessible without causing visual clutter. This will enhance the wearer's understanding during conversations without introducing unnecessary complexity.

4. **Immediate next probe**

   Define one subtitle-vs-one-line priority rule where subtitles take precedence in the center of the display, with one-line prompts appearing either above or below to avoid overlap and maintain clarity.
