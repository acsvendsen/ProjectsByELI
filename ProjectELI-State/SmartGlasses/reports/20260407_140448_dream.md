### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Stabilizing subtitle placement rules ensures that subtitles remain trust-preserving and easily readable, which is crucial for real-time clarity and understanding. By defining specific placement modes based on confidence levels, we can provide more reliable assistance in noisy environments without becoming distracting.

2. **What small change unlocks it**

   Define three subtitle placement rules: 
   - Fixed position at the bottom of the field of view.
   - Adaptive positioning that adjusts slightly downward when the confidence score is low but remains visible.
   - Temporary repositioning to avoid occlusion by hands or objects, with a quick return to fixed position post-reposition.

3. **Likely payoff**

   By establishing clear placement rules, the system can reduce visual distraction and ensure subtitles remain readable and trust-preserving. This will help maintain focus during conversations and improve overall user satisfaction.

4. **Immediate next probe**
   - Define the fixed position rule for subtitles at the bottom of the field of view.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   By refining the confidence display format, we can ensure that the wearer understands the reliability of the information presented in real-time subtitles and memory support. A well-designed confidence format will help build trust and reduce cognitive load by clearly indicating when the system is uncertain or certain about the displayed information.

2. **What small change unlocks it**

   Define a new confidence format that combines a numeric score, label, and a short reason for the confidence level. For example: "score 0.84 + 'High' + 'Seen recently'".

3. **Likely payoff**

   Implementing this confidence format will allow users to quickly understand the reliability of real-time subtitles and memory support. This clarity can significantly enhance trust, reduce cognitive overload, and improve overall user satisfaction by making it clear when the system is highly confident versus less so.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Improving the local cache size threshold for face/name memory helps ensure that frequently encountered individuals are always available quickly, enhancing trust and recall accuracy without overloading the phone's limited resources.

2. **What small change unlocks it**

   Define a local cache eviction policy where infrequently accessed person memories are removed after 7 days of inactivity but retained if they have been seen within the last month.

3. **Likely payoff**

   This policy will ensure that memory is both efficient and useful, allowing for quick recall of frequently encountered individuals while still retaining less common contacts with a moderate level of certainty.

4. **Immediate next probe**

   Set a local cache size limit of 50 entries to balance memory efficiency and recall speed.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By defining a clear phone/cloud boundary for live subtitle processing, we ensure that critical real-time data stays local to minimize latency and thermal load on the glasses hardware. This improves subtitle clarity and trust by keeping the system responsive and low-friction during live conversations.

2. **What small change unlocks it**

   Define one task-specific cloud fallback boundary for exactly one task such as live subtitle processing, ensuring that all other tasks remain phone-local.

3. **Likely payoff**

   A clear, well-defined boundary will reduce latency in real-time subtitle generation, leading to more accurate and faster subtitles. This enhances the wearer's trust in the system during critical moments of conversation.

4. **Immediate next probe**

   Define one task-specific cloud fallback boundary for live subtitle processing, keeping all other tasks phone-local.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   Improving the visual hierarchy between subtitles and one-line prompts enhances the wearer's ability to focus on critical information without becoming overwhelmed by too much text. This balance ensures that real-time subtitles remain clear and stable, while still providing helpful contextual support when needed.

2. **What small change unlocks it**

   Define a subtitle-vs-one-line priority rule that places subtitles first in the visual hierarchy but allows one-line prompts to appear beneath them if necessary, without obscuring the main subtitles.

3. **Likely payoff**

   By prioritizing subtitles while still allowing one-line prompts, the system will remain unobtrusive and focused on providing essential real-time information. This approach ensures that the wearer can trust the subtitles in noisy environments and still receive relevant contextual cues when needed, without the risk of visual overload.

4. **Immediate next probe**
   - Define one visual priority rule between subtitles and one-line support in V1.
