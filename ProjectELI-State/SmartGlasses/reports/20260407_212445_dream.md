### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Ensuring stable subtitle placement rules in V1 helps maintain consistent user trust by reducing distractions and ensuring subtitles remain readable and comprehensible during live conversations. This stability is crucial for the wearer's ability to follow along without being overwhelmed by shifting visual elements.

2. **What small change unlocks it**

   Define a fixed position for subtitles that prioritizes readability over reactivity, such as placing subtitles 10-15 pixels below the bottom of the screen and ensuring they remain visible even when the wearer is moving their head or looking around.

3. **Likely payoff**

   By maintaining consistent subtitle placement, the system can reduce visual distractions and maintain user trust during live conversations. This consistency allows for more reliable reading and comprehension, enhancing the overall assistive value without adding unnecessary complexity.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving the confidence display format helps ensure that the wearer understands the reliability of the subtitles and memory support provided by the glasses. Clear, consistent, and well-designed confidence indicators build trust in the system's accuracy, which is crucial for real-time subtitle clarity (subtitle_clarity attractor) and overall memory trust (memory_trust attractor).

2. **What small change unlocks it**

   Define a simple yet effective format for confidence display that includes both a label and a short reason. For example, use a numeric score followed by a confidence label and a brief reason. This format can be easily implemented and tested in the current V1 architecture.

3. **Likely payoff**

   By clearly indicating the confidence level of subtitles and memory recall, users will better understand when to rely on the system's support. This improved clarity can lead to higher trust in the glasses' performance, reducing cognitive friction and increasing overall user satisfaction.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Improving local memory thresholds helps ensure that the system can quickly recall important names and faces without relying on cloud syncs or frequent interactions, thus maintaining a low-friction experience.

2. **What small change unlocks it**

   Define a local cache size limit for storing face/name memories, ensuring that critical information is retained in phone memory with a defined eviction policy based on recency.

3. **Likely payoff**

   By setting clear limits and an eviction rule, the system can maintain fast recall of key individuals without overloading the device, enhancing both subtitle clarity and overall memory trust while reducing latency concerns.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   Improving the phone-cloud boundary for live subtitle processing ensures that critical real-time data remains on the device, reducing latency and ensuring near-real-time performance. This focus keeps the user's experience smooth and reliable, aligning with the mission of providing clear and stable subtitles in noisy environments.

2. **What small change unlocks it**

   Define a strict local fallback boundary for live subtitle processing where the phone handles all real-time transcription and rendering, only falling back to cloud services if there is an explicit user action or significant network latency issues.

3. **Likely payoff**

   By keeping live subtitle processing entirely on the phone, we can ensure that subtitles remain stable and responsive, even in environments with poor internet connectivity. This improvement will directly benefit real-time clarity and trust, which are core attractors for the project.

4. **Immediate next probe**

   Define one strict local fallback boundary for live subtitle processing where the phone handles all real-time transcription and rendering, only falling back to cloud services if there is an explicit user action or significant network latency issues.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   By defining a clear visual hierarchy between subtitles and one-line support, we ensure that the wearer can focus on critical information without being overwhelmed by auxiliary text. This enhances the overall user experience, aligning with the attractor of low-friction assistance.

2. **What small change unlocks it**

   Define a single rule for subtitle placement precedence: prioritize subtitles over one-line support unless the confidence level is below a certain threshold (e.g., 0.6). This simple rule ensures that critical information remains prominent while keeping the interface clean.

3. **Likely payoff**

   By maintaining a clear visual hierarchy, we can reduce cognitive load and ensure that the wearer's attention is directed to the most important information. This improves overall comprehension and engagement with the system without creating unnecessary distractions.

4. **Immediate next probe**
   - Define one visual priority rule between subtitles and one-line support in V1.
