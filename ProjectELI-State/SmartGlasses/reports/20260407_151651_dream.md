### Idea 1: Subtitle Placement

1. **Why it benefits the core**
   - Stable subtitle placement rules reduce visual distraction and help the wearer focus on the conversation, enhancing trust in the subtitles.

2. **What small change unlocks it**
   - Define two fixed subtitle placement modes: one for higher confidence states (above 0.75) where subtitles are shown at the bottom of the frame, and another for lower confidence states (below 0.65) where they are placed at the top to minimize distraction.

3. **Likely payoff**
   - This change will reduce visual clutter during high-confidence interactions while ensuring critical information is always visible, thereby improving overall user experience without overwhelming the wearer.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

4. **Immediate next probe**

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   By defining a clear local cache size threshold for face/name memory, we ensure that the system retains key person information while managing battery and thermal constraints effectively. This helps in providing reliable one-line support and memory assistance without overwhelming the phone's resources or degrading performance.

2. **What small change unlocks it**

   Define a specific local cache size limit for storing face/name memories, ensuring that the cache does not exceed 100 entries at any time. This threshold balances the need for persistent memory with practical storage limits.

3. **Likely payoff**

   Implementing this threshold will reduce battery usage by minimizing frequent cloud syncs and improve response times for common memory lookups. It also helps in maintaining a clean, reliable memory system that supports the core mission of providing trustworthy assistance without overburdening resources.

4. **Immediate next probe**

   Define one local cache size limit of 100 entries for face/name memories to balance persistent memory and resource constraints.
