### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   By defining specific subtitle placement rules based on confidence levels, we can ensure that subtitles remain stable and unobtrusive while still providing clear and timely assistance to the wearer. This improves real-time subtitle clarity (subtitle_clarity) by ensuring that crucial information is always visible when needed.

2. **What small change unlocks it**

   Define two subtitle placement rules: one for high-confidence content (such as names and faces recognized with a score above 0.8) and another for lower-confidence content (below 0.6).

3. **Likely payoff**

   This approach will result in subtitles that are less likely to distract the wearer during conversations, yet still provide critical information when it matters most. It balances the need for clarity with the desire not to overwhelm the user.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Ensuring that confidence objects are presented clearly and consistently helps build trust in the system's accuracy and reliability. By defining a specific format for confidence labels, short reasons, and numeric scores, we can communicate certainty levels effectively to the wearer without overwhelming them with too much detail.

2. **What small change unlocks it**

   Define a consistent confidence display format using a simple label and a short reason. For example, use "High" + "Seen recently", "Medium" + "Name heard once in introduction", or "Low" + "Weak match". This can be unlocked by setting the default confidence object to include both a numeric score and a concise label with an explanatory reason.

3. **Likely payoff**

   A clear and consistent confidence display will help users trust the system more, as they understand when information is highly probable versus less certain. This clarity will reduce cognitive load and increase overall user satisfaction.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**
   - Improving memory cache policy can enhance the trustworthiness of face/name recall by ensuring that frequently encountered individuals are remembered accurately and consistently, reducing the risk of confusion or false recollection.

2. **What small change unlocks it**
   - Define a local cache eviction rule based on recency: prioritize keeping recently seen faces and names in memory while evicting less frequent encounters to maintain a manageable and accurate set of cached entities.

3. **Likely payoff**
   - By implementing a recency-based cache eviction policy, the system can provide more reliable face/name recall for individuals frequently encountered by the wearer, thereby enhancing overall trust in the device's memory capabilities without overwhelming local storage.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By defining a clear phone-cloud boundary for live subtitle processing, we ensure that subtitles remain fast, reliable, and stable in real-time, which is crucial for maintaining trust during live conversations. This boundary helps us manage battery usage and thermal stress by keeping heavy processing on the phone while still leveraging cloud capabilities where necessary.

2. **What small change unlocks it**

   Define a simple phone-cloud fallback rule: live subtitle processing runs entirely locally unless the connection to the cloud is weak or unavailable for more than 5 seconds, at which point the system switches to a cached local version with minimal degradation in quality and stability.

3. **Likely payoff**

   This approach ensures that subtitles remain clear and fast during critical moments of conversation, reducing the risk of mistranslations or delays that could break trust. It also helps in managing battery usage by avoiding heavy cloud processing when it is not necessary, thereby extending the glasses' operational time.

4. **Immediate next probe**

   Define one phone-cloud fallback boundary for live subtitle processing such that subtitles are generated locally and only fall back to the cloud if connectivity is weak or unavailable for more than 5 seconds.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   Ensuring a clear visual hierarchy between subtitles and one-line support enhances the wearer's ability to focus on crucial information without distraction. This improves overall understanding and trust in real-time assistance, aligning with the core attractor of real-time subtitle clarity.

2. **What small change unlocks it**

   Define a simple coexistence rule that prioritizes subtitles over one-line prompts when both are needed, but ensures one-line support is visible enough to prompt recall without overwhelming the wearer.

3. **Likely payoff**

This will help maintain trust in real-time subtitles during complex conversations, thereby enhancing daily-use value.

4. **Immediate next probe**
