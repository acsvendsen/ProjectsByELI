# Consolidated Project Signals

## Strengthening Signals
1. **Subtitle Clarity**:
   - **Real-time subtitle clarity**: Ensure subtitles remain clear, fast, and stable in live conversation to maintain trust.
2. **Memory Support**:
   - **Trustworthy memory support**: Enhance face/name recall with confidence objects to avoid creating corrupted or uncertain memories.
3. **Low-Friction Assistance**:
   - **Low-friction assistance**: Provide concise one-line prompts for context without adding command overhead.

## Weakening Signals
1. **Feature Sprawl**:
   - Broad feature expansion should be avoided; focus on core deepening to improve subtitle quality, memory trust, and visual UX.
2. **Command Overhead**:
   - Minimize the use of voice commands in V1 interaction; frame touches are the primary user control method.

## Contradictions That Must Stay Alive
1. **Privacy vs Usefulness**:
   - The system must balance the need for useful assistive behavior with privacy concerns to avoid silent invasive capture.
2. **Latency vs Richness**:
   - Prioritize timely assistance over richer but slower processing to maintain a low-latency response.

## Dormant Ideas Worth Reactivating
- **Subtitle Placement**: Revisit subtitle placement strategies that balance readability and distraction, especially in noisy environments.
- **Confidence Display**: Evaluate different confidence formats (label only, label + short reason, score + label) for their impact on trust.

## Concrete Tensions Around Subtitle Quality, Confidence Trust, Automatic New-Person Memory, Memory Reinforcement, Fast Lookup, Privacy, Latency, Battery, and Visual UX
1. **Subtitle Quality**:
   - Ensure subtitles are readable, stable, and fast to maintain live conversation trust.
2. **Confidence Trust**:
   - Clearly display confidence levels for names and prior context to avoid overconfidence or underconfidence.
3. **Automatic New-Person Memory**:
   - Implement automatic memory behavior with explicit remember-touch confirmation to ensure only trusted memories are formed.
4. **Memory Reinforcement**:
   - Develop a strategy for reinforcing face/name memory through repeated interactions to improve recall speed and accuracy.
5. **Fast Lookup**:
   - Optimize the phone processing pipeline to provide fast memory lookups while respecting latency constraints.
6. **Privacy**:
   - Design systems that respect user privacy, ensuring no unnecessary data collection or retention.
7. **Battery Management**:
   - Balance always-on sensing with battery life to ensure the glasses remain usable throughout the day.
8. **Visual UX**:
   - Develop a visual hierarchy that is clear and unobtrusive while providing necessary information quickly.

## No Fluff
- The project should continuously surface real-world limitations early, including hardware, battery, thermal, latency, privacy, and usability constraints.
- Favor additions that deepen the core mission rather than broaden it superficially.
- Keep subtitle placement, confidence display, memory policy, phone/cloud boundaries, and visual hierarchy as distinct domains unless explicitly connected in inputs.

By focusing on these key areas, the project can maintain a clear direction towards improving real-world usefulness while respecting constraints and user privacy.
