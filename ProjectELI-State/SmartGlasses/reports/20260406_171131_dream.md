### Idea 1: Subtitle Placement

1. **Why it benefits the core**
   - By defining more prominent subtitle placement rules, we ensure that subtitles remain clear and stable in various confidence states, enhancing real-time clarity and trust.

2. **What small change unlocks it**
   - Define specific subtitle placement rules for different confidence levels: high (prominent), medium (visible but not obstructive), low (barely visible).

3. **Likely payoff**
   - Improved real-time clarity and trust in noisy or hearing-challenged situations, making the glasses more reliable and useful.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

Improving confidence display by clearly showing certainty levels helps build trust in the system's memory and subtitle accuracy, which is crucial for daily-use value and maintaining a discreet yet effective personal assistant.

2. **What small change unlocks it**

Define a confidence format that combines a numeric score with a label and short reason to provide clear, concise, and actionable feedback about the certainty of the information presented.

3. **Likely payoff**

This enhanced confidence display will reduce cognitive load for the wearer by providing transparent cues on the reliability of the system's memory and subtitles. It will foster trust and make the smart glasses more valuable in real-world interactions.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Improving memory cache size ensures that the system can retain a sufficient amount of relevant information for fast lookup and trust-building, thereby enhancing the wearer's ability to recall names and context accurately during interactions.

2. **What small change unlocks it**

   Define a local cache threshold for face/name memory that balances storage with rapid access needs. This could be set as a number of recent contexts or interactions to keep in memory.

3. **Likely payoff**

   By setting an appropriate local cache size, the system can maintain a reliable and up-to-date memory of recently encountered people and conversations, which will significantly enhance trust through accurate name recall and contextual awareness during live interactions.

4. **Immediate next probe**

   Define one local-cache size limit for face/name memory that balances storage with rapid access needs.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By refining the phone/cloud boundary for live subtitle processing, we ensure that critical real-time operations are handled locally to maintain low latency and high reliability, which is essential for trust in noisy environments. This focus on local processing also helps in maintaining the product's discreet nature and social acceptability.

2. **What small change unlocks it**

   Define a specific rule where live subtitle processing is always done phone-first, with cloud fallback only under exceptional conditions such as heavy load or high confidence uncertainty.

3. **Likely payoff**

   This change will reduce latency, improve reliability, and maintain the product's discreet nature, all of which contribute to higher trust and usability in real-world scenarios.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

Improving the visual hierarchy between subtitles and one-line support ensures that the wearer can focus on critical information without being overwhelmed by less essential content, thereby enhancing their overall understanding and engagement in conversations.

2. **What small change unlocks it**

Define a clear precedence rule where subtitles dominate the primary display area, with one-line support shown only when necessary to avoid distracting the wearer or overloading the visual field.

3. **Likely payoff**

By ensuring that subtitles remain prominent while one-line prompts are secondary, the system can reduce cognitive load and increase trust in the assistant's reliability. This will help maintain the wearer's focus on the conversation without unnecessary interruptions.

4. **Immediate next probe**

Define a subtitle-vs-one-line priority rule where subtitles dominate the primary display area, with one-line support shown only when necessary to avoid distracting the wearer or overloading the visual field.
