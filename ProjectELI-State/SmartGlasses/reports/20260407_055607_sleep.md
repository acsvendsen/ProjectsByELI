# Sleep Cycle Consolidation for SmartGlasses Project

## Strengthening Signals
- **Subtitle Clarity**: Continued focus on real-time subtitle clarity remains high, ensuring subtitles are clear, fast, and stable enough for live conversations.
- **Memory Trust**: Memory support should be trusted but not overconfident. Names, faces, and context recall must remain honest without creating false certainty.

## Weakening Signals
- **Always-on Sensing**: Reducing the emphasis on always-on sensing to prioritize battery and thermal constraints in early hardware versions.

## Contradictions That Must Stay Alive
- **Privacy vs Usefulness**: The balance between providing useful assistance while maintaining privacy remains a critical tension.
- **Latency vs Richness**: Ensuring low latency for timely help without overloading the system with richer but slower processing is essential.

## Dormant Ideas Worth Reactivating
- **Subtitle Placement and Visual Hierarchy**: Early signals suggest revisiting subtitle placement to find the best balance between readability and distraction. Similarly, the visual hierarchy should be optimized to enhance usability without overwhelming the wearer.

## Concrete Tensions Around Core Areas
1. **Subtitle Quality**:
   - Ensure subtitles remain clear, stable, and fast enough.
2. **Confidence Display**:
   - Use a label-only format or label + short reason for confidence, avoiding overly complex solutions that may confuse users.
3. **Automatic Memory Behavior vs Explicit Remember-Touch Behavior**:
   - Prioritize automatic memory support but ensure it remains transparent and reliable, without overloading the wearer with too much data.
4. **Fast Lookup Requirements**:
   - Balance between providing quick access to relevant information while maintaining battery efficiency.

## Core Field Specifics
- The glasses should act as a discreet personal assistant in noisy environments, helping with real-time subtitles, face/name recall, conversation memory, and one-line support.
- V1 interaction is frame-touch only; no voice activation or spoken command control yet.

## Recent Reality Check
- Early versions will focus on phone-first processing to keep hardware simple and reduce thermal and battery pressure.
- Subtitles must feel near-real-time to maintain trust.
- Face/name recall should expose uncertainty clearly, maintaining a balance between helpfulness and privacy.

## Core Deepening Over Sprawl
- Prefer work that improves subtitle quality, memory trust, and visual UX over broad feature expansion. 

## Open Questions
- **Subtitle Placement**: Revisit optimal placement for subtitles to minimize distraction while ensuring readability.
- **Confidence Display**: Determine the best format (label-only or label + short reason) for confidence display.
- **Memory/Cache Policy**: Evaluate how much face/name memory should be cached locally and how it should be reinforced over time.

## Final Consolidation
The project is focused on core deepening, ensuring real-time subtitle clarity, trustworthy memory support, and low-friction assistance. The system must balance privacy vs. usefulness, latency vs. richness, and discreet UX vs. visual clarity while remaining committed to a phone-first V1 interaction model. Early prototypes should focus on these key areas without drifting into speculative feature or hardware complexity.
