# Reality Check for SmartGlasses

## Subtitle Clarity (subtitle_clarity)
### Feasible Now: 
- **Subtitle Placement**: The glasses should prioritize subtitle placement that minimizes distraction while ensuring the subtitles are clearly visible and readable in motion. Given the current focus on real-time clarity, placing subtitles just below or above the wearer's line of sight is feasible now.
- **Visual Hierarchy**: Ensuring subtitles are large enough to read quickly but not so large they distract from the conversation is also achievable with current display technology.

### Likely Waste of Time:
- **High-Frequency Subtitle Adjustments**: Implementing real-time adjustments for subtitle placement based on head movements could be complex and might not provide significant added value. Current efforts should focus on basic stability and readability.

## Memory Trust (memory_trust)
### Feasible Now: 
- **Face/Name Recall**: Implementing a simple memory system that can store new faces and names with confidence indicators is feasible now. Using short, clear labels like "Uncertain" or "Confident" for each face/name recall will help manage privacy while providing useful information.
  
### Likely Waste of Time:
- **Complex Memory Reinforcement Algorithms**: Developing complex algorithms to dynamically adjust memory reinforcement based on user interaction might not be necessary in V1 and could add unnecessary complexity.

## Low-Friction Assistance (low_friction_assistance)
### Feasible Now: 
- **One-Line Prompts**: Delivering one-line prompts for context or correction is feasible with the current frame-touch only interaction model. These should be concise and clear, such as "Did you mean [name]?" or "Remember this person?", to avoid overwhelming the wearer.

### Likely Waste of Time:
- **Multiline Dialogues**: Developing a system for multiline conversations might not be necessary in V1 and could add unnecessary complexity that distracts from core functionality.

## Privacy vs Usefulness (privacy_vs_usefulness)
### Feasible Now: 
- **Confidence Indicators**: Providing clear confidence indicators is essential. Using labels like "Uncertain" or "Highly Confident" will help manage privacy while providing useful information.
  
### Likely Waste of Time:
- **Advanced Privacy Controls**: Implementing more advanced privacy controls might not be necessary in V1 and could add unnecessary complexity.
