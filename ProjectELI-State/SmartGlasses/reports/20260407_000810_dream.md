### Idea 1: Subtitle Placement

1. **Why it benefits the core**

Subtitle placement rules that ensure stable and unobtrusive display can enhance the wearer's trust in the system by making subtitles always readable, even during rapid motion or loud environments. This stability is crucial for maintaining the core mission of helping the wearer understand live conversations without being distracted.

2. **What small change unlocks it**

Define two subtitle placement rules: one that keeps subtitles near the center of the field of view and another that allows them to move slightly towards the top edge when the confidence level is high, reducing the chance of accidental occlusion by moving hands or other objects.

3. **Likely payoff**

This small change will allow the system to maintain a stable subtitle position while still providing flexibility in crowded or noisy environments. By keeping subtitles near the center and allowing movement to the top for higher-confidence scenarios, the system can ensure that critical information remains accessible without causing visual distraction.

4. **Immediate next probe**
   - Define a fixed position rule for subtitles near the center of the field of view.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving the confidence display format will enhance trust in the system's reliability by making the certainty level clearer to the wearer. This clarity helps in aligning the wearer's perception with the actual accuracy of the subtitles and memory support, thereby reinforcing the core mission of helping the wearer understand better without pretending knowledge.

2. **What small change unlocks it**

   Define a simple confidence format that includes a numeric score, a label (e.g., High, Medium, Low), and a short reason (e.g., "Seen recently," "Weak match"). For example: "score 0.84 + 'High' + 'Seen recently'; score 0.42 + 'Low' + 'Weak match'."

3. **Likely payoff**

   This simple yet clear confidence format will help the wearer understand when to trust the system more and when to remain cautious, thereby reducing cognitive load and increasing overall trust in the system's reliability.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Improving the local memory cache threshold for face/name recall ensures that frequently encountered individuals are remembered reliably and quickly, reducing the need for cloud-based lookups and enhancing the system's trustworthiness in real-time interactions.

2. **What small change unlocks it**

   Define a local cache size limit of 50 unique faces/names with a recency threshold of 30 days for face/name recall lookup on the phone before falling back to cloud storage.

3. **Likely payoff**

   By setting a clear and reasonable local memory threshold, the system will maintain a balance between memory utility and processing efficiency, ensuring that common interactions are handled locally while less frequent encounters fall back to more robust but slower cloud services. This improves both the speed of recall and the overall trust in the system's memory capabilities.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 5: Visual Hierarchy

   Ensuring that subtitles are displayed in a clear, unobtrusive manner while still providing enough prominence for quick reading enhances the wearer's ability to follow conversations. This balance helps maintain trust and utility without overwhelming the user.

   Define a visual hierarchy rule that prioritizes subtitle visibility over one-line support when both are present in the field of view simultaneously. Specifically, set subtitles to always appear above or next to one-line prompts but not overlapping them.

3. **Likely payoff**

   By ensuring that subtitles remain readable and unobtrusive while keeping one-line prompts prominent yet separate, this rule will improve the wearer's ability to follow conversations in real-time without visual overload. This can enhance trust and daily-use value significantly.
