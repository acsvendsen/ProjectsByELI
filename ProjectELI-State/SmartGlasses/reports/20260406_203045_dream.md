### Idea 1: Subtitle Placement

1. **Why it benefits the core**
   Improving subtitle placement rules will enhance the clarity and usability of subtitles, ensuring they remain readable and stable during live conversations. This will strengthen the core mission by providing real-time subtitle assistance that is both accurate and unobtrusive.

2. **What small change unlocks it**
   Define two subtitle placement rules: one for high-confidence states where the speaker is known or repeated, and another for low-confidence states where the speaker is new or uncertain. The high-confidence rule will place subtitles near the middle of the frame to avoid distraction, while the low-confidence rule will position them slightly above or below the face to ensure they are visible but do not block important visual information.

3. **Likely payoff**
   By implementing these placement rules, we can reduce subtitle occlusion and improve readability during uncertain interactions. This will enhance trust in the system by ensuring that subtitles remain clear and unobtrusive, even when the context is less certain.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving confidence display helps build trust in the system by providing clear, concise feedback about the reliability of the subtitles and memory support. This clarity ensures that the wearer can easily understand when they should pay extra attention to a particular piece of information.

2. **What small change unlocks it**

   Define a simple, neutral confidence format using a numeric score and short reason for both subtitle and memory entries. For example: "score 0.84 + 'High' + 'Seen recently'; score 0.42 + 'Low' + 'Weak match'".

3. **Likely payoff**

   By providing clear confidence indicators, the system can avoid overloading the wearer with too much detail while still ensuring that critical information is highlighted appropriately. This improves overall trust and usability by making it easier for the user to prioritize which information to pay attention to.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Improving the local cache size for face/name memory allows the system to retain more recent and relevant evidence, thereby enhancing the accuracy and timeliness of name recall and context-based assistance. This directly supports the core attractors by ensuring that the wearer receives accurate and timely support without needing constant cloud interaction.

2. **What small change unlocks it**

   Define a local cache size threshold for face/name memory objects, where only entities with recent interactions or high confidence scores are kept in the local cache. This helps balance storage usage while maintaining critical context.

3. **Likely payoff**

   By setting an appropriate cache size limit, the system can retain enough relevant memories to support fast and accurate name recall during conversations, reducing the need for cloud fallbacks and improving overall trust and usability.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   Staying phone-first with heavy processing on the phone reduces battery drain, thermal stress, and latency, all of which are critical for real-time subtitle clarity and memory support. By keeping complex tasks like face/name recall and conversation memory processing on the phone, we can ensure that subtitles remain clear and stable during live interactions.

2. **What small change unlocks it**

   Define a clear set of phone-local caching rules for face and name recognition data, ensuring that critical memory objects are kept on-device without overwhelming local storage or battery resources.

3. **Likely payoff**

   By limiting cloud fallbacks to only essential tasks like occasional transcript cleanup or rare memory archive syncs, we can significantly reduce power consumption and thermal stress, leading to more reliable subtitle performance and a better user experience. This also ensures that the glasses remain socially acceptable and lightweight, aligning with our core mission of discreet personal assistance.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.
