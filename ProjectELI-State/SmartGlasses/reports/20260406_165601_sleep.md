## Consolidation of Core SmartGlasses V1 Direction

### Strengthening Signals
- **Subtitle Quality**: Focus on real-time subtitles that feel near-real-time to maintain trust.
- **Memory Trust**: Implement robust memory reinforcement mechanisms, such as confidence objects, for faster and more reliable recall.
- **Visual UX**: Ensure subtitle placement is prominent but not distracting, with a clear visual hierarchy.

### Weakening Signals
- **Complex Interaction Patterns**: Avoid adding voice activation or spoken command control in V1. Keep interaction simple with frame-touch only.
- **Heavy AR Features**: Limit initial features to minimal AR capabilities that do not introduce significant complexity or thermal load.

### Contradictions That Must Stay Alive
- **Privacy vs Usefulness**: Maintain a balance between providing useful assistance and respecting privacy, ensuring transparency about data usage.
- **Battery and Thermals**: Prioritize lightweight hardware design in V1, even if it means some processing must happen on the phone.

### Dormant Ideas Worth Reactivating
- **Offline Capabilities**: Explore ways to provide essential functionality offline, such as caching frequently used memory entries for local processing.

### Concrete Tensions Around Core Areas

#### Subtitle Quality vs. Latency
- **Tension**: High-quality subtitles should be real-time to maintain trust but must not drain battery or introduce noticeable latency.
- **Current Focus**: Optimize subtitle rendering algorithms and battery management techniques to achieve near-real-time performance without excessive power consumption.

#### Confidence Trust vs. Memory Reinforcement
- **Tension**: Building trust through clear confidence indicators (e.g., labels + reasons) versus the complexity of implementing robust memory reinforcement mechanisms.
- **Current Approach**: Use a label + short reason format for confidence displays, and prioritize recency-first caching policies to ensure the most relevant information is always accessible.

#### Automatic Memory Behavior vs. Explicit Remember-Touch Behavior
- **Tension**: The system should automatically remember new faces/names but allow users to confirm or adjust memory with explicit touch actions.
- **Current Plan**: Implement automatic memory behaviors for new contacts, supplemented by confidence objects that can be adjusted via frame touches for reinforcement.

#### Fast Lookup vs. Rich Memory
- **Tension**: Prioritize fast and reliable lookup of commonly used information over storing low-value but frequently accessed data.
- **Current Focus**: Use recency-first caching policies to prioritize frequently used items while minimizing storage overhead.
