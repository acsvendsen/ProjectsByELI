### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   By defining specific subtitle placement rules based on confidence states, we can ensure that subtitles remain clear, stable, and trust-preserving in live conversation. This helps maintain the wearer's focus while reducing distractions.

2. **What small change unlocks it**

   Define three subtitle placement rules: one for high-confidence matches (e.g., names and faces seen recently), one for medium-confidence matches (e.g., names and faces heard once or twice), and one for low-confidence matches (e.g., new names and faces not yet reinforced).

3. **Likely payoff**

   This approach will help in creating a more consistent and reliable subtitle experience, reducing the chances of misinterpretation and increasing overall trust in the system's accuracy.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   By refining the confidence display format to use a numeric score with an associated label and short reason, we can enhance the wearer's trust in the system's decisions. This improves both memory support and low-friction assistance by providing clear, transparent, and actionable feedback.

2. **What small change unlocks it**

   Define a specific confidence object format that combines a numeric score (e.g., 0.84) with a label (e.g., "High") and a short reason (e.g., "Seen recently"). This can be represented as `score: 0.84, label: High, reason: Seen recently`.

3. **Likely payoff**

   A clear confidence display will help the wearer understand when they should trust memory or subtitles more confidently. This reduces confusion and enhances overall usability by aligning expectations with the system's certainty.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Improving local memory thresholds ensures that frequently accessed information is readily available to the wearer without relying on cloud latency or battery-draining always-on features. This strengthens trust by providing quick and accurate responses, which are crucial for real-time assistance.

2. **What small change unlocks it**

   Define a policy where recently encountered names and faces have higher local memory thresholds, allowing these entities to remain cached in the phone's memory longer than others. This can be achieved by setting a recency threshold that evicts less recent memories based on last interaction time.

3. **Likely payoff**

   By prioritizing frequently accessed information for local caching, the system will provide faster and more reliable name and face recall, enhancing the wearer’s trust in the glasses’ memory support. This will lead to smoother and more useful interactions without the need for frequent cloud queries or battery-intensive always-on features.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

By refining the phone/cloud boundary for live subtitle processing, we ensure that critical real-time operations remain on-device, minimizing latency and preserving battery while maintaining high subtitle quality. This focus strengthens the core attractor of real-time subtitle clarity by guaranteeing fast, stable subtitle delivery in noisy environments.

2. **What small change unlocks it**

Define a specific task boundary for live subtitle processing to run entirely phone-local. This means that all audio-to-text conversion and initial confidence scoring happens on the phone without offloading any part of this process to the cloud.

3. **Likely payoff**

Implementing this change ensures that subtitles are delivered with minimal latency, enhancing the wearer's trust in the system during live conversations. The reduced reliance on network resources also contributes to better battery management, which is crucial for maintaining the glasses' usability throughout the day.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   Improving subtitle placement rules for different confidence levels will ensure that subtitles are always clear, readable, and not overly intrusive. This enhances the wearer's trust in the system by providing reliable and unambiguous visual assistance during live conversations.

This will enhance the overall trustworthiness of the product and make it more useful in real-world scenarios.
