### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   By defining a fixed subtitle placement rule for different confidence states, we ensure that subtitles remain stable and unobtrusive while providing clear and timely assistance when needed. This approach helps maintain social acceptability and reduces cognitive load on the wearer.

2. **What small change unlocks it**

   Define 2 to 3 subtitle placement rules based on varying levels of confidence: 
   - **High Confidence**: Fixed position in a non-distracting zone, such as slightly above the center.
   - **Medium Confidence**: Slightly dynamic, allowed to move but with limited animation.
   - **Low Confidence**: Avoided during high interaction periods and moved out of the way if necessary.

3. **Likely payoff**

   This small change will enhance user trust by ensuring subtitles remain consistent and unobtrusive while still providing reliable assistance when needed. It will also simplify the UI design, making it more polished and less distracting.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving the confidence display format helps build trust in the wearer by clearly communicating the certainty and source of information. This ensures that the subtitles are reliable, which is crucial for maintaining real-time subtitle clarity and low-friction assistance.

2. **What small change unlocks it**

   Define a new confidence object format: score 0.85 + "High" + "Seen multiple times in recent conversations".

3. **Likely payoff**

   By clearly labeling the certainty of subtitles, the wearer can better trust the displayed text and focus on the conversation without distraction. This improves overall subtitle clarity and trustworthiness.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   By setting a local memory threshold for face and name recall, we can ensure that critical information is always available without overwhelming the wearer's visual field. This helps in maintaining trust by providing quick access to frequently used names and faces, while minimizing distractions.

2. **What small change unlocks it**

   Define a local cache size limit of 10 most recently seen people for face/name recall.

3. **Likely payoff**

   Setting this threshold ensures that the system can quickly lookup and display important names and faces without needing cloud assistance, thus maintaining fast response times and reducing battery drain from constant cloud requests.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

By optimizing which parts of the system run on the phone versus falling back to cloud, we can balance privacy and utility while ensuring low latency and real-time responsiveness for subtitles and memory support.

2. **What small change unlocks it**

Define a clear boundary for live subtitle processing that stays entirely on the phone to maintain fast response times and preserve trust. Only allow fallbacks to the cloud for tasks like face/name recall lookup or memory archive sync when explicitly necessary.

3. **Likely payoff**

This will ensure subtitles remain real-time and highly accurate, while still allowing for useful background memory and face/name processing without sacrificing privacy or battery life in V1.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   By ensuring that subtitles and one-line support coexist in a way that does not overwhelm the wearer, the system can maintain clarity and avoid distraction. This balance helps the wearer stay present and focused during conversations without feeling overloaded with information.

2. **What small change unlocks it**

   Define a visual hierarchy rule that prioritizes subtitles over one-line prompts when confidence is high but allows for coexistence at lower confidence levels to support the wearer in dense environments.

3. **Likely payoff**

   This change will enhance the overall user experience by ensuring that critical information (subtitles) remains prominent while still providing contextual assistance when needed, without overwhelming the wearer. It will reduce cognitive load and maintain trust in the system's reliability.

4. **Immediate next probe**
   - Define one visual priority rule between subtitles and one-line support in V1.
