# Consolidation of SmartGlasses V1 Core Field and Project Signals

## Strengthening Signals
1. **Subtitle Quality**: The focus remains on ensuring subtitles are clear, timely, and placed prominently for optimal reading without being distracting.
2. **Face/Name Memory**: Explicit remember-touch behavior is becoming more important to build trust in the memory system's accuracy over time.
3. **Confidence Display**: Operator guidance has selected a label + reason approach to confidence display.

## Weakening Signals
1. **Implicit Interaction**: Frame touch interaction remains the primary focus, reducing the emphasis on implicit interactions like voice commands or continuous sensing.
2. **Complex AR Features**: The need for complex augmented reality features is weakening as the project narrows its focus on essential functionalities.

## Contradictions That Must Stay Alive
1. **Battery vs Always-On Sensing**: There is a tension between providing always-on functionality and minimizing battery drain, which must be managed carefully.
2. **Privacy vs Useful Memory**: Balancing the need for rich contextual memory with user privacy concerns remains critical.

## Dormant Ideas Worth Reactivating
- The need to explore subtitle placement further in order to find an optimal balance between visibility and distraction.
- Considering how one-line prompts can coexist without overwhelming the wearer, especially during complex conversations.

## Concrete Tensions Around Key Areas

### Subtitle Quality vs. Visual UX
- **Subtitle Placement**: More prominence is needed for subtitles but must be balanced against creating visual clutter.
- **Visual Hierarchy**: Subtitles should dominate visually to ensure they are read quickly, but this needs to be balanced with minimizing distraction.

### Confidence Trust vs. Memory Reinforcement
- **Memory Policy**: The phone-first architecture supports local caching of face/name memory, but the exact balance between caching and cloud updates is still unclear.
- **Fast Lookup**: Ensuring fast lookup for known faces/names without overloading the user interface remains a challenge.

### Fast Lookup vs. Privacy
- **Confidence Display**: A label + reason approach is selected to provide trust while respecting privacy concerns about displaying detailed confidence scores.

## Open Questions and Tensions

1. **Subtitle Placement**:
   - How can we make subtitles more prominent without causing distraction? (Current guidance: More Prominent)

2. **Confidence Display**:
   - What format best builds trust for users? Label only, label + short reason, or score + label?

3. **Memory/Cache Policy**:
   - How much face/name memory should be cached locally on the phone versus updated via cloud?

4. **Phone/Cloud Boundary**:
   - When is it appropriate to use cloud services for memory updates and model upgrades without breaking real-time response times?

5. **Visual Hierarchy**:
   - How can subtitles coexist with one-line prompts in a way that does not overwhelm the wearer? (Current guidance: Subtitles Dominate)

6. **Battery vs Always-On Sensing**:
   - What is the best split between local and cloud processing to minimize battery drain while ensuring real-time response?

7. **Privacy vs Rich Contextual Memory**:
   - How can we balance the need for rich contextual memory with user privacy concerns, especially in social settings?

8. **Interaction Constraints**:
   - The system should remain focused on frame-touch interactions without assuming voice commands until explicitly justified.

## Summary
The project is deepening its focus on subtitle quality and face/name memory while maintaining clear boundaries around interaction methods and real-time processing constraints. Subtitle placement, confidence display, and memory policies are key areas where further refinement will be necessary to ensure the system remains both useful and discreet.
