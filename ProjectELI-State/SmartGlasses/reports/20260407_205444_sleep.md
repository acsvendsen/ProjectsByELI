# Consolidated Signals

## Strengthening Signals
- **Subtitle Clarity**: Ensuring real-time subtitles are clear, fast, and stable to maintain wearer trust in live conversations.
- **Memory Trust**: Enhancing name and face memory support with explicit uncertainty to avoid creating corrupted recall.

## Weakening Signals
- **Low-Friction Assistance**: Reducing the focus on delivering one-line help through low-friction interactions. This is being managed as a medium-priority area, indicating that it may need more attention in future iterations but should not be prioritized over core subtitle and memory quality improvements.

## Contradictions That Must Stay Alive
- **Privacy vs Usefulness**: The system must balance helping the wearer without infringing on privacy. Any enhancement in assistive behavior must avoid covert data capture or retention.
- **Latency vs Richness**: Improving response speed is crucial, but adding richer processing should not come at the cost of timely help.

## Dormant Ideas Worth Reactivating
- **Subtitle Placement and Visual Clarity**: While not currently prioritized, revisiting subtitle placement to ensure they are readable in motion and noise remains a potential area for improvement. This can be explored as part of core-deepening efforts.
- **Confidence Display**: Evaluating different confidence formats (label only, label + short reason, score + label) could provide better trust signals without overloading the wearer.

2. **Memory Reinforcement**:

3. **Visual UX**:
