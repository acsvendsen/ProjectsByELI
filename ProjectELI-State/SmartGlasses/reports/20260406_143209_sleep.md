# Consolidated Insights for SmartGlasses V1 Direction

## Strengthening Signals
- **Subtitle Quality:** The quality of subtitles is becoming increasingly critical as users require near-real-time, accurate, and unobtrusive text display in noisy environments. Improving subtitle accuracy and timing will significantly enhance the user experience.
- **Memory Trust:** User trust in the system's ability to recall names and past conversations is growing more important than ever. Ensuring that memory behavior is reliable and context-aware will build confidence over time.

## Weakening Signals
- **Feature Sprawl:** The tendency to add new features before solidifying core functionality should be minimized. Subtitles, face/name recall, conversation memory, and one-line support remain the primary focus.
- **Complex Interaction Design:** The simplicity of frame-touch interaction is becoming less dominant as the system evolves. More complex interactions may become necessary if they significantly improve user experience without adding unnecessary complexity.

## Contradictions That Must Stay Alive
- **Privacy vs Usefulness:** There is a constant tension between providing useful assistance and respecting privacy concerns. Ensuring that data usage is transparent and minimally invasive will be crucial.
- **Battery Constraints:** Always-on sensing must coexist with the need to minimize battery drain. This contradiction will require careful management of local versus cloud processing.

## Dormant Ideas Worth Reactivating
- **Visual Hierarchy and UX Clarity:** The initial focus on simplicity should not preclude revisiting visual hierarchy and clarity in user experience design. Enhancing how subtitles and prompts are displayed could significantly improve usability.
- **Memory Reinforcement Strategies:** Exploring more effective memory reinforcement strategies, such as periodic reminders or context-aware updates, may be worth reactivating to enhance the system’s reliability.

## Concrete Tensions Around Core Areas
1. **Subtitle Quality vs Battery Drain:**
   - Balancing subtitle accuracy and timing with battery consumption remains a critical tension.
   
2. **Confidence Display vs Memory Privacy:**
   - Determining how to display confidence levels in memory behavior while respecting privacy concerns is essential.

3. **Automatic Memory Behavior vs Explicit Remember-Touch Behavior:**
   - Deciding whether automatic memory updates should be the primary method or if explicit user actions are necessary for reinforcement.
   
4. **Fast Lookup vs Privacy:** 
   - Ensuring that fast lookup requirements do not compromise privacy by over-relying on detailed tracking and storage.

5. **Real-Time Processing vs Cloud Support:**
   - Managing local processing capabilities versus cloud support to provide the best balance of speed, accuracy, and resource efficiency.
   
6. **Social Friction:** 
   - Ensuring that interactions remain discreet enough to avoid social awkwardness while providing sufficient assistance.

## Open Questions
- **Subtitle Placement:** What is the optimal placement for subtitles to be both useful and unobtrusive?
- **Confidence Display Format:** How should confidence levels be represented (label, label + reason, score) to build trust without overwhelming the user?
- **Memory Cache Policy:** How much face/name memory should be cached locally versus relying on cloud storage?
- **Offline vs Cloud Capabilities:** Which interactions should work offline and which require cloud support?

## Reality Check
- The system must continuously surface real-world limitations early, including hardware, battery, thermal, latency, privacy, usability, and social acceptability constraints.
- Ensure that the design remains focused on providing high-value, low-complexity features in V1.

## Operator Guidance
- **Subtitle Placement:** Optimize for clarity without distraction. Consider using dynamic placement based on user context.
- **Confidence Display:** Use a simple label format initially; explore adding reasons if necessary to build trust.
- **Memory Cache Policy:** Start with minimal caching and gradually increase as trust builds.
- **Phone/Cloud Boundary:** Prioritize phone-first processing, but consider cloud support for deeper analysis where it adds clear value.

## Action Inbox
- **Subtitle Placement:** Evaluate current subtitle placement designs against real-world usage scenarios to find the best balance.
- **Confidence Display:** Define a simple confidence format and test its effectiveness in building user trust.
- **Memory Cache Policy:** Set initial caching policies based on minimal data storage, with plans for expansion if needed.
- **Phone/Cloud Boundary:** Ensure that phone processing is optimized for speed and accuracy before considering cloud support.

## Persistent SmartGlasses ELI Inputs
- **Constraints:** Glasses should remain lightweight and socially acceptable; early versions should not depend on heavy on-glasses compute.
- **Architecture Direction:** Focus on glasses as minimal hardware with primary runtime on the phone, keeping battery and thermal concerns in mind.
- **Interaction Constraints:** V1 interaction should be controlled through frame touches only.

By addressing these areas, the project can continue to evolve while maintaining focus on its core mission.
