## Subtitle Clarity: Feasible Now

- **Summary**: Keep subtitles clear, fast, and stable enough that the wearer can trust them in live conversation.
- **Reasoning**: The `TranscriptLab` test app already has mechanisms to handle real-time transcription and display. Given the current implementation in `SpeechTranscriber.swift`, we are capable of producing clear and fast subtitles without significant battery drain or latency issues. Early tests should focus on refining the subtitle rendering to ensure it is readable even during motion, which can be done by tweaking font size, color contrast, and text alignment.
- **Constraints**: Must remain under thermal and power constraints.

## Memory Trust: Feasible Later

- **Summary**: Remember names, faces, and prior context without pretending certainty or creating corrupted recall.
- **Reasoning**: The current implementation in `TranscriptLab` is focused on real-time transcription rather than memory storage. To implement face/name memory, we would need to integrate a confidence-based system for storing and recalling information. This can be achieved by building upon the existing transcript model to include metadata about names and faces. However, this will require more robust backend support and possibly cloud integration to handle persistent storage and reinforcement learning over time.
- **Constraints**: Battery, latency, privacy, and memory constraints must be managed.
