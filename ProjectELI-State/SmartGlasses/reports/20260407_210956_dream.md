### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   By defining fixed subtitle placement rules for different confidence states, we ensure that subtitles remain clear, stable, and unobtrusive in live conversation. This helps maintain trust and improves the wearer's ability to follow the conversation without being distracted by variable or less reliable subtitle positions.

2. **What small change unlocks it**

   Define a fixed subtitle position at the bottom center of the field of view for all confidence states. Adjust only the opacity or color based on confidence, ensuring that lower-confidence subtitles are more subtle but still visible.

3. **Likely payoff**

   A consistent and stable subtitle placement will reduce distraction, enhance trust in the system, and improve overall user experience. This stability will be particularly beneficial in noisy environments where clear, unobtrusive text is crucial for comprehension.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   By defining a clear confidence format that includes both a numeric score and a label with a short reason, the system can provide more accurate and contextually meaningful feedback to the wearer. This improves trust in the assistive behavior by aligning with how humans process uncertainty.

2. **What small change unlocks it**

   Define a simple confidence object format that combines a numeric score (e.g., 0.84), a label (e.g., "High"), and a short reason (e.g., "Seen recently").

3. **Likely payoff**

   This change will enhance the wearer's trust in the system’s memory and recall by providing clear, concise, and relevant information about the confidence of each piece of recalled information. It will help the wearer understand when they can rely on the system with higher certainty.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Improving local memory cache thresholds helps ensure that frequently encountered names and faces are quickly accessible without overwhelming the system with too much data. This reinforces trust by providing fast, accurate recall, which is crucial for real-time interaction support.

2. **What small change unlocks it**

   Define a policy where the phone caches face/name objects in local memory based on recent encounters, but limits the total number of cached entries to avoid thermal and battery strain. For example, cache up to 10 recent faces and names with high confidence scores for quick recall.

3. **Likely payoff**

   By limiting the local cache size while still ensuring critical entities are always available, the system can provide reliable support during frequent interactions, reducing latency and improving overall user trust in real-time memory assistance.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   Improving the phone/cloud boundary for live subtitle processing ensures that subtitles remain real-time and stable. By keeping this critical task local, we can reduce latency and ensure that the subtitles are always available when needed, enhancing trust in the system.

2. **What small change unlocks it**

   Define a clear rule stating that all live subtitle processing must run on the phone first, with fallback to cloud only for rare high-latency conditions or under heavy load.

3. **Likely payoff**

   By ensuring real-time subtitle processing remains local, we can maintain the clarity and stability of subtitles, which is crucial for trust in the system. This will help the wearer understand conversations better without delays, especially in noisy environments where timely information is critical.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   Improving the visual hierarchy between subtitles and one-line support helps ensure that the wearer can focus on the most critical information without being overwhelmed. This distinction supports the core attractor of low-friction assistance by making sure that the wearer's attention is directed where it matters most, enhancing overall understanding and reducing cognitive load.

2. **What small change unlocks it**

   Define a priority rule for subtitle placement that shows subtitles with high confidence first, followed by one-line support, ensuring that important information is given more prominence. This involves creating a visual hierarchy where the most critical data (high-confidence subtitles) are displayed prominently, while less critical but still useful information (one-line support) is shown in a secondary position.

3. **Likely payoff**

   By prioritizing high-confidence subtitles and showing them first, we can ensure that the wearer’s attention is directed towards the most relevant information, leading to better comprehension during live interactions. This improvement will directly contribute to the core attractors of real-time subtitle clarity and low-friction assistance.

4. **Immediate next probe**
   - Define one visual priority rule between subtitles and one-line support in V1.
