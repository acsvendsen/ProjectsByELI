### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Ensuring stable subtitle placement enhances trust in the system, allowing the wearer to rely on the subtitles for real-time understanding during conversations. Stable placement reduces cognitive load and distraction, making the subtitles more useful and less likely to be missed.

2. **What small change unlocks it**

   Define a fixed subtitle position that is slightly above and centered within the field of view (FOV), with minimal movement even when the wearer's head or glasses angle changes. This ensures the subtitles remain consistently visible and readable without sudden jolts or shifts that could distract from the conversation.

3. **Likely payoff**

   By maintaining a stable subtitle placement, users will be more likely to trust the system during conversations, reducing cognitive effort and increasing overall user satisfaction. The consistency in placement also helps in reinforcing the memory support features by ensuring the subtitles are always in a predictable location, making them easier for the wearer to reference.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   By refining the confidence display to use a clear label and short reason, we can enhance trust in the system's memory recall and assistive behavior. This improves overall user confidence without overwhelming them with too much detail.

2. **What small change unlocks it**

   Define one confidence format for V1 that uses a numeric score, a high/medium/low label, and a brief reason (e.g., "Seen recently," "Weak match").

3. **Likely payoff**

   This simple yet effective confidence display will help the wearer understand the reliability of name and face recall without being bombarded with complex details. It ensures that when names or faces are recognized, the user knows why they were remembered, thereby enhancing trust in the system.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   By setting a local cache threshold for name recall, we ensure that common names are stored and quickly accessible on the phone. This improves the system's ability to provide rapid responses in repeated interactions without relying heavily on cloud resources or increasing battery drain.

2. **What small change unlocks it**

   Define a local cache eviction rule that evicts infrequently used names after 7 days of no interaction, ensuring that the cache remains manageable and responsive.

3. **Likely payoff**

   This change will reduce latency for repeated interactions with familiar people, improve overall memory recall efficiency, and help maintain a balance between resource usage and user experience.

4. **Immediate next probe**

   Define one local-cache size limit of 50 names to optimize phone memory while ensuring fast lookup for common interactions.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

By defining a clear boundary for what runs phone-local versus cloud, we ensure that V1 focuses on delivering high-quality, stable subtitle assistance and memory support without overloading the device or creating latency issues. This will enhance trust and real-world usability by keeping critical processing local where battery and thermal constraints are most severe.

2. **What small change unlocks it**

Define a specific task boundary for live subtitle processing that prioritizes phone-local execution to maintain near-real-time performance, while clearly defining when cloud fallbacks occur for transcript cleanup or memory archive sync tasks.

3. **Likely payoff**

This will ensure V1 delivers smooth, reliable subtitles in noisy environments and allows the wearer to trust the system without concern over latency or battery drain. Additionally, it will provide a clear path for later enhancements by setting appropriate boundaries now.

4. **Immediate next probe**

This improves real-time understanding and reduces cognitive load, aligning with the core attractors of real-time subtitle clarity and low-friction assistance.

2. **What small change unlocks it**
