# Reality Check Summary

Based on the provided project inputs and core field, here is a reality-check summary for each decision area:

## Subtitle Placement (feasible now)
- **Subtitle Display**: Use a corner of the glasses display where it minimizes distraction but remains readable. For example, bottom-right or top-left corners are typically good choices.
  - **Reasoning**: This placement balances visual clarity with avoiding center-of-gaze disruptions.

## Confidence Display (feasible later)
- **Confidence Label + Short Reason**: Consider a label like "High" or "Low" combined with a short reason for the confidence level, e.g., "Uncertain name" or "Known face."
  - **Reasoning**: This provides clear signals to the wearer without overwhelming them. It respects privacy by avoiding over-specificity.

## Memory/Cache Policy (feasible now)
- **Local Face/Name Cache Size**: Limit local cache size to a manageable number, say 10 entries, and use reinforcement learning to prioritize recent interactions.
  - **Reasoning**: This keeps memory usage low while ensuring the wearer has immediate recall for recent contacts.

## Phone/Cloud Boundary (feasible now)
- **Phone-first Processing**: Continue focusing on phone-side processing where feasible. Use cloud services only when they clearly enhance the core mission, like background model updates.
  - **Reasoning**: This respects battery and thermal constraints while ensuring V1 remains lightweight and functional.

## Visual Hierarchy (feasible now)
- **Subtitle vs Prompt Display**: Subtitles should be clear and stable with minimal animation. One-line prompts can use a lighter visual style to distinguish them from subtitles, e.g., slightly smaller font or different color.
  - **Reasoning**: This maintains readability while ensuring the wearer can quickly differentiate between regular subtitles and contextual support.

## Tension Surface (constraint pressure)
- **Latency vs Richness**: Optimize for real-time subtitle clarity. Use techniques like speech-to-text acceleration to minimize latency without sacrificing accuracy.
  - **Reasoning**: Real-time responses are critical for trust; any delays must be minimized.

- **Privacy vs Usefulness**: Implement clear privacy policies and avoid storing sensitive information locally unless necessary for context recall.
  - **Reasoning**: This maintains user trust by being transparent about data usage.

## Core Deepening Over Sprawl (current mode)
- **Focus on Subtitle Quality, Memory Trust, Visual UX**: Prioritize improvements in subtitle clarity, memory accuracy, and visual design over broader feature expansion.
  - **Reasoning**: V1 should remain simple to ensure reliability and ease of use.

These decisions are grounded in the current project constraints and inputs. They aim to deepen the core mission while respecting real-world limitations.
