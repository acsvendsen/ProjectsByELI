**Reasoning**: The `TranscriptLab` app is designed to be as close as possible to a future glasses experience, making it suitable for testing memory policies. Local caching can be evaluated here without the need for complex cloud interactions, aligning with the V1 architecture direction.

**Reasoning**: The `TranscriptLab` app is currently focused on phone-first processing and reusable plumbing that could later support glasses hardware. Testing this boundary early helps ensure that future transitions are smooth without unnecessary complexity.

**Reasoning**: The current V1 interaction constraints focus on frame-touch input, not sophisticated visual hierarchy. While this might be important for the final product, it is premature to spend significant effort on it in V1 given the hardware and battery constraints.
