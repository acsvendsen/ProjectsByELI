## Project Summary
The SmartGlasses project is focusing on improving subtitle clarity and memory support while managing persistent tensions such as privacy vs usefulness and latency vs richness. The current phase emphasizes core deepening to strengthen essential features like real-time subtitles, face/name recall, and one-line prompts without broad feature sprawl.
