### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Ensuring stable subtitle placement rules helps maintain consistent readability and trust in real-time subtitles. Stable placement allows the wearer to focus on the conversation without being distracted by constantly moving text, thereby enhancing the core mission of providing clear, reliable assistance.

2. **What small change unlocks it**

   Define 3 to 5 fixed subtitle placement modes for different confidence levels: high-confidence (always visible), medium-confidence (visible with a slight delay), and low-confidence (only shown on explicit user touch).

3. **Likely payoff**

   By implementing stable subtitle placement rules, the system will deliver more consistent and reliable subtitles that do not distract the wearer. This stability will enhance trust in the product's core functionality, making it easier for users to rely on the subtitles in noisy environments.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving the confidence display format will enhance the trustworthiness of the subtitle and memory support provided by the glasses. A well-designed confidence label and short reason will help the wearer understand when to rely on the displayed information, thereby reducing cognitive load and increasing overall user satisfaction.

2. **What small change unlocks it**

   Modify the current confidence object from a single numeric score to include both a label and a short reason. For example, instead of showing just "0.84", display "High: Seen recently". This simple change will provide more context and clarity to the wearer without adding excessive complexity.

3. **Likely payoff**

   By providing clear and concise confidence information, users will have a better understanding of when to trust the displayed subtitles or memory support. This can lead to reduced cognitive strain during interactions and increased user trust in the system, ultimately making the glasses more effective as an assistive device.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   By setting a clear local memory threshold for face/name recall, we ensure that critical memories are retained while minimizing battery usage and thermal load. This balance helps in maintaining trust by ensuring that important information is readily available to the wearer without overwhelming the system.

2. **What small change unlocks it**

   Define a local cache size limit of 10 recent faces/names, with automatic eviction based on recency and confidence scores. This ensures that only the most relevant and recently encountered memories are kept in cache, reducing memory overhead.

3. **Likely payoff**

   Implementing this local cache policy will reduce the burden on the cloud for frequent lookups, improve response times, and enhance overall battery efficiency without compromising on critical memory support. It will also help in maintaining a clean and focused interface by minimizing the number of entities stored locally.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   Ensuring that live subtitle processing remains phone-local for critical tasks like real-time clarity can significantly enhance the wearer's trust in the system during important interactions. By keeping this functionality on-device, we reduce latency and ensure that subtitles remain clear, stable, and responsive, which is crucial for maintaining the core attractor of "Real-time subtitle clarity."

2. **What small change unlocks it**

   Define a specific subtitle placement rule where real-time subtitles are always displayed in a fixed position at the bottom center of the field of view, with no adaptive movement based on confidence or gaze.

3. **Likely payoff**

   This static subtitle placement ensures that critical information is always visible and stable, reducing cognitive load and enhancing trust during important conversations. By keeping this rule phone-local, we ensure consistent performance regardless of cloud connectivity status, which is essential for V1 stability.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   By defining a clear visual hierarchy that prioritizes subtitles over one-line support, we ensure that the wearer's focus remains on critical information while maintaining low social friction and high clarity. This improves overall user experience by preventing distraction from less important prompts.

2. **What small change unlocks it**

   Introduce a subtitle placement rule where subtitles are always shown above the one-line support text when both are active, with the one-line prompt either below or hidden behind a tap-to-reveal overlay.

3. **Likely payoff**

   This simple visual hierarchy will help reduce cognitive load by ensuring that the most important information is prioritized and easily visible, while still allowing for brief, necessary prompts without overwhelming the wearer. It will enhance trust in the system’s ability to assist effectively without creating social awkwardness or distraction.

4. **Immediate next probe**

   Define one subtitle-vs-one-line priority rule where subtitles always appear above the one-line support text when both are active, with the one-line prompt either below or hidden behind a tap-to-reveal overlay.
