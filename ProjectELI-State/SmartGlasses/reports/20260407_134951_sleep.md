# Recent Project Signals Consolidation

## Strengthening Signals
- **Subtitle Clarity**: The real-time subtitle clarity attractor is becoming more true. Subtitles must remain clear, fast, and stable to ensure the wearer can trust them during live conversations.
- **Memory Trust**: Memory support is becoming increasingly important as we aim to remember names, faces, and prior contexts accurately without overcommitting or introducing false certainty.

## Weakening Signals
- **Low-Friction Assistance**: The low-friction assistance attractor is currently less emphasized. This does not mean it's unimportant but that the project is shifting focus temporarily towards subtitle clarity and memory trust.

## Contradictions That Must Stay Alive
- **Privacy vs Usefulness**: There remains a tension between providing useful assistive behavior and ensuring privacy, especially as we consider how much information to store locally versus in the cloud.
- **Latency vs Richness**: The project must continue to balance rich contextual support with timely responses. Delays can undermine trust but so too can overly complex interactions.

## Dormant Ideas Worth Reactivating
- **Subtitle Placement and Visual Hierarchy**: These have been dormant ideas worth reactivating as we face challenges in ensuring subtitles are both clear and unobtrusive, particularly when dealing with motion and noise.
- **Confidence Display**: This remains a key area that needs to be revisited for effective communication of certainty or doubt.

## Concrete Tensions Around Core Areas
1. **Subtitle Quality**:
   - **Automatic Memory Behavior**: Ensuring subtitles are clear, stable, and reliable requires refining automatic memory behavior to prevent distractions.
   - **Explicit Remember-Touch Behavior**: Balancing the need for real-time clarity with the explicit touch-based interaction required by V1.

2. **Memory Reinforcement**:
   - **Confidence Objects**: Implementing confidence objects that help in remembering names and faces accurately while maintaining privacy.
   - **Fast Lookup Requirements**: Ensuring memory can be quickly accessed without compromising battery or thermal constraints.

3. **Visual UX**:
   - **Subtitle Placement**: Positioning subtitles effectively to avoid distraction, yet remain visible and readable during motion.
   - **Confidence Display**: Designing confidence displays that provide enough clarity to help the wearer but do not overwhelm them with too much detail.

4. **Privacy and Usability**:
   - Balancing the need for helpful assistive features with privacy concerns, ensuring no sensitive data is stored or processed without explicit consent.
   - Managing battery and thermal constraints while providing real-time support in noisy environments.

## Open Questions

- What is the best confidence format to ensure trust without overloading the wearer?
- How can we optimize memory behavior for both accuracy and speed, especially as we move from V1 frame-touch interaction?
