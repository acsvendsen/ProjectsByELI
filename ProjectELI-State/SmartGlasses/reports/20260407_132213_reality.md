# Reality Check

## Subtitle Placement: Feasible Now
- **Subtitle Clarity Attractor**: The core mission relies heavily on clear and reliable subtitles. Given the current emphasis on subtitle clarity, it is feasible to start with a basic placement strategy that ensures subtitles are readable and do not distract from live conversation.
- **Current Prototype**: The `TranscriptLab` app can serve as a starting point for testing different subtitle placements. Initial tests could involve placing subtitles at the bottom of the screen or overlaying them in a less intrusive manner, ensuring they remain clear and visible.

## Confidence Display: Feasible Now
- **Memory Trust Attractor**: Confidence display is crucial to building trust in memory support. A simple confidence label (e.g., "Low", "Medium", "High") can be implemented initially.
- **Current Prototype**: The `TranscriptLab` app can include a basic confidence indicator, such as a numeric score or a text label. Early iterations could focus on ensuring the display is unobtrusive and clearly visible to the wearer.

## Memory/Cache Policy: Feasible Now
- **Memory Trust Attractor**: Local caching of face/name memory should be prioritized for initial implementation.
- **Current Prototype**: The `TranscriptLab` app can implement a simple cache policy that stores recently seen faces and names. This can be done using local storage mechanisms available on the phone, ensuring data privacy and minimizing battery drain.

## Phone/Cloud Boundary: Feasible Now
- **Core Deepening Mode**: Biasing towards subtitle quality and memory trust means focusing on the core functionality first.
- **Current Prototype**: The `TranscriptLab` app should continue to leverage local processing for subtitles and memory, with cloud support being optional where clearly justified. Initial tests can focus on ensuring the phone-side runtime is robust and reliable.

## Visual Hierarchy: Feasible Now
- **Low-Friction Assistance Attractor**: A clear visual hierarchy is essential to ensure that one-line prompts are visible without overwhelming the wearer.
- **Current Prototype**: The `TranscriptLab` app can include a simple visual hierarchy for subtitles, confidence indicators, and one-line prompts. This should be designed to minimize distraction while ensuring important information remains easily accessible.
