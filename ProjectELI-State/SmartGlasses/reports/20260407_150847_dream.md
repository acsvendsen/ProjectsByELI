### Idea 1: Subtitle Placement

1. **Why it benefits the core**
   - By defining specific subtitle placement rules based on confidence levels, V1 can ensure that subtitles are always in a clear and unobtrusive position, improving the wearer's ability to read them without distraction while maintaining natural social interactions.

2. **What small change unlocks it**
   - Define three subtitle placement rules: one for high-confidence faces/names, another for medium-confidence entities, and a third for low-confidence or new entities that require user confirmation.

3. **Likely payoff**
   - This change will ensure subtitles are always in a readable position, reducing visual distractions and maintaining the wearer's ability to focus on the conversation. It will also reinforce trust by showing that the system is reliable and not overloading the wearer with unnecessary information.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

Improving the confidence display format helps ensure that the wearer can trust the subtitles and memory support provided by the glasses. Clear and consistent confidence indicators enhance the reliability of the system, making it more useful in critical contexts like noisy environments or complex conversations.

2. **What small change unlocks it**

Define a specific confidence format for V1 that uses a score (e.g., 0-1) combined with a label (e.g., High, Medium, Low) and a short reason (e.g., "Seen recently", "Weak match"). This simple yet informative format can be easily parsed by the wearer to understand the reliability of the displayed information.

3. **Likely payoff**

By using a score-based confidence display, the system can provide immediate feedback on the reliability of the subtitles and memory support. This transparency will help build trust and ensure that the wearer knows when they should rely more heavily on their own judgment, thereby enhancing overall user experience and satisfaction.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   To improve memory support for names and prior context in a way that increases trust without invading privacy, we need to define a local cache threshold for face/name recall. This ensures that new evidence is only attached to existing memory objects after a certain number of interactions, reinforcing confidence over time.

2. **What small change unlocks it**

   Define one entity-linking rule for attaching new evidence (e.g., hearing someone's name multiple times) to an existing person-memory object based on interaction count and recency. This rule can be implemented with a simple counter that resets after a certain period of inactivity, ensuring memory stays relevant but not invasive.

3. **Likely payoff**

   By implementing this entity-linking rule, we reduce the risk of storing unnecessary or outdated information while still reinforcing confidence over time through repeated interactions. This enhances the wearer's trust in the system without compromising privacy.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By defining clear boundaries for what runs phone-local versus what falls back to cloud, we ensure that V1 interactions remain lightweight and battery-conscious while still providing essential assistive behavior. This decision helps maintain the focus on subtitle clarity and memory support without overloading the glasses hardware, ensuring a smooth and reliable user experience.

2. **What small change unlocks it**

   Define a specific task boundary for live subtitle processing: ensure that all real-time subtitle rendering occurs locally on the phone's GPU, while transcript cleanup and face/name recall lookup are offloaded to the cloud when needed.

3. **Likely payoff**

   This approach reduces the battery drain from constant cloud requests during live interactions, ensuring that subtitles remain clear and stable without breaking the wearer’s flow. It also maintains the phone-first constraint, keeping early hardware simple while allowing for richer offline processing capabilities later.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

Improving the visual hierarchy between subtitles and one-line support ensures that the wearer can focus on the most relevant information without feeling overwhelmed. This helps in maintaining a clear and uncluttered view, which is crucial for real-time understanding and engagement.

2. **What small change unlocks it**

Define a simple precedence rule where subtitles have higher priority over one-line prompts when both are visible at the same time. This can be achieved by routing one-line support to a less prominent position or temporarily hiding it when subtitles need more attention.

3. **Likely payoff**

This small change will reduce visual clutter and improve the wearer's ability to follow live conversations without distraction. By prioritizing subtitles, the system ensures that critical information is always visible and easily readable, enhancing overall usability and user trust.

4. **Immediate next probe**
   - Define one visual priority rule between subtitles and one-line support in V1.
