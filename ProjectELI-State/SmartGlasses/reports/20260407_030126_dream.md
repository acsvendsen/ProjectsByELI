### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   By refining subtitle placement rules based on confidence levels, the system can ensure that subtitles are more reliable in critical moments when the wearer needs them most. This will enhance the overall trust and usability of the product, making it a more valuable assistive tool.

2. **What small change unlocks it**

   Define three subtitle placement modes: static top-center, dynamic center-mouse-following, and confidence-aware repositioning. The latter would move subtitles closer to the face when high confidence is detected but revert to a default position otherwise.

3. **Likely payoff**

   Improved subtitle placement can significantly enhance user trust by ensuring that critical information is always visible without unnecessary distractions. This will help in maintaining focus during conversations and reduce cognitive load, making the glasses more effective as an assistive tool.

4. **Immediate next probe**
   - Define the static top-center subtitle placement rule.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving the confidence display format ensures that the wearer can trust the system's memory support and one-line assistance without confusion or over-reliance on uncertain information. A clear, concise, and consistent confidence indicator enhances the reliability of the system, thereby strengthening the core attractors of memory trust and low-friction assistance.

2. **What small change unlocks it**

   Introduce a two-part confidence format: "score + label" with an optional short reason for uncertainty or certainty. For example, "0.85 High - Seen recently", where the score indicates reliability, the label provides a quick assessment of trustworthiness, and the short reason gives context when necessary.

3. **Likely payoff**

   By clearly displaying confidence, the system can avoid creating misleading certainty while still providing useful information. This helps in building trust over time as users learn to interpret the indicators correctly, leading to more reliable interactions and better overall usability.

4. **Immediate next probe**
   - Define the "score + label" confidence format as the V1 candidate.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**
   
   By optimizing local cache thresholds for face/name memory, we can ensure that the system retains enough recent context to support fast lookups and reinforcement over time, while respecting battery and thermal constraints.

2. **What small change unlocks it**

   Define a simple eviction policy that removes old but still relevant memory entries after a set number of days or interactions, ensuring that local cache does not grow indefinitely.

3. **Likely payoff**

   This change will help maintain a balance between rich memory support and low latency, preserving the system's ability to provide timely and accurate assistance without overwhelming the phone’s resources.

4. **Immediate next probe**

   Set a local-cache size limit of 50 entries for face/name memory to optimize for fast lookups and reinforcement over time while managing battery consumption.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By defining a clear boundary between what runs locally on the phone and what falls back to the cloud for memory archive sync, we can ensure that the system remains lightweight and socially acceptable while still providing essential support. This will help in maintaining the trust of the wearer by keeping sensitive data local.

2. **What small change unlocks it**

   Define a specific task boundary where memory archive sync tasks fall back to the cloud only when necessary for backup or retrieval, but stay on-device for frequent use cases.

3. **Likely payoff**

   This approach will enhance privacy while ensuring that critical memory support is available when needed without overburdening the phone's resources. It will also improve user trust by keeping sensitive information local and reducing the risk of data leaks.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**
   - By clearly defining the precedence between subtitles and one-line support, we can ensure that the wearer is not overwhelmed by visual information, which aligns with the low-friction assistance attractor and the core-deepening mode.

2. **What small change unlocks it**
   - Define a clear visual hierarchy rule where subtitles are prioritized over one-line prompts in cases of high confidence or ongoing conversation, but allow one-line support to take precedence for brief, critical information that requires immediate attention.

3. **Likely payoff**
   - This rule will help maintain the wearer's focus on essential information while still providing necessary contextual support. It will reduce cognitive overload and enhance the overall user experience by ensuring that key information is prioritized appropriately.

4. **Immediate next probe**
   - Define one visual priority rule between subtitles and one-line support where subtitles have higher precedence in ongoing conversations but one-line prompts take priority for critical, brief interactions.
