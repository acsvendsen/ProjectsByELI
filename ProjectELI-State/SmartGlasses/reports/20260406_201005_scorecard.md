## Project Summary
The SmartGlasses project is focused on delivering discreet, context-aware personal assistance through live subtitles, face/name recall, conversation memory, and one-line support. The current V1 will use frame-touch interaction exclusively and rely primarily on the phone for processing, with cloud services as optional where clearly justified.

## Hardware Stack

- limitation pressure: weight, social acceptability, battery
- progress: The current focus is on maintaining a simple hardware stack that aligns with the V1 constraints. The phone-first architecture ensures minimal on-glasses processing while providing necessary functionality.
