### Idea 1: Subtitle Placement

1. **Why it benefits the core**
   Improving subtitle placement rules can enhance the overall user experience by ensuring that subtitles are always visible and readable, even in noisy or complex environments. This stability reduces cognitive load and enhances trust in the system.

2. **What small change unlocks it**
   Define three fixed subtitle placement rules: one for high confidence states (e.g., 0.8+), another for medium confidence states (e.g., 0.5-0.79), and a third for low confidence states (e.g., below 0.5). This structured approach ensures that subtitles are consistently placed in the best available position regardless of context.

3. **Likely payoff**
   By defining clear, static subtitle placement rules, the system can maintain consistent and reliable subtitle visibility, reducing visual distractions and enhancing overall user trust. This will contribute to a more seamless and usable experience for the wearer.

4. **Immediate next probe**
   - Define one fixed subtitle position rule for V1: keep subtitles at the bottom center of the display.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Ensuring that confidence objects are clearly displayed helps build trust in the system's reliability and accuracy, which is crucial for the wearer to feel comfortable using the glasses in real-world scenarios. A well-designed confidence display can prevent overreliance on potentially inaccurate information while also providing enough certainty to enhance user confidence.

2. **What small change unlocks it**

   Define a simple format for confidence objects that includes a numeric score, label, and short reason. For example: `score 0.84 + "High" + "Seen recently"` or `score 0.32 + "Low" + "Weak match"`. This clarity will help users understand the reliability of the information provided.

3. **Likely payoff**

   By providing clear and concise confidence indicators, the system can reduce uncertainty for the wearer and enhance overall trust. Users are more likely to engage with the glasses if they feel that the information is reliable, which can lead to higher daily-use value and better user satisfaction.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**

   Ensuring that face/name memory is stored with a recency-first eviction policy helps maintain a balance between keeping useful information readily accessible and not overwhelming the local cache, thus preserving battery and thermal resources.

2. **What small change unlocks it**

   Define a simple yet effective cache size limit for person-memory objects on the phone, using a first-in-first-out (FIFO) eviction rule based on recency of interaction.

3. **Likely payoff**

   By implementing a recency-first eviction policy, we can ensure that the most relevant and recent memories are prioritized while still freeing up space as needed to prevent memory bloat. This improves overall system efficiency and user trust in the memory recall functionality.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By clearly defining what stays phone-local versus what falls back to cloud for a specific task, we can ensure that V1 focuses on delivering real-time subtitle clarity and trustworthiness without overburdening the glasses or compromising battery life. This alignment ensures the system remains discreet, efficient, and effective.

2. **What small change unlocks it**

   Define one clear boundary between what runs locally on the phone for live subtitle processing versus what falls back to cloud for memory archive sync.

3. **Likely payoff**

   By setting a strong V1 phone-first architecture boundary, we can:
   - Ensure real-time subtitle quality remains stable and fast.
   - Reduce battery consumption by offloading heavier tasks like memory syncing.
   - Maintain social acceptability of the glasses without creating command overhead.

4. **Immediate next probe**
   - Choose one phone-local versus cloud fallback boundary for face/name recall lookup in V1.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   Ensuring a clear visual hierarchy between subtitles and one-line prompts helps maintain low-friction assistance while preventing overloading the wearer's cognitive load. By prioritizing subtitle clarity, we can enhance trust in real-time information without overwhelming the user with too much text or visual elements.

2. **What small change unlocks it**

   Define a visual priority rule that ensures subtitles dominate the field of view during live conversation and that one-line prompts are displayed as supplementary, non-overlapping text to avoid distraction but remain accessible when needed.

3. **Likely payoff**

   This change will improve the wearer's trust in the system by ensuring that critical information (subtitles) remains clear and prominent while still providing necessary context or reminders through concise one-line support without causing visual clutter.

4. **Immediate next probe**

   Define a visual priority rule where subtitles dominate the field of view, and one-line prompts are displayed as supplementary text below or to the side of subtitles to avoid overlap.
