# Consolidated Signals for SmartGlasses Project

## Strengthening Signals

### Core Mission Clarity
- **Mission:** Reinforce the core mission to create smart glasses that act as a discreet personal assistant with real-time subtitles and context-aware memory support.
- **Core Attractors:** Ensure real-time subtitle assistance, personal memory recall, one-line prompts for clarity, and low-friction UX.

### Constraints Management
- **Real-world Limits:** Emphasize the need to remain lightweight and socially acceptable, prioritize phone-based processing, and handle battery and thermal constraints carefully.
- **Interaction Constraints:** Keep interactions simple, favoring frame touches over voice commands in V1 to maintain a clear focus on core functionality.

## Weakening Signals

### Feature Sprawl
- **Avoid feature bloat:** Ensure that new features are grounded in the core mission. Avoid adding unnecessary complexity or gimmicky elements.
- **Risks of Drift:** Be cautious against becoming overly complex or focusing on low-value features that distract from the primary goal.

## Contradictions That Must Stay Alive

### Privacy vs Usefulness
- **Balancing Act:** Continuously address the tension between providing useful assistance and maintaining privacy, ensuring that any memory storage is handled with clear confidence indicators.
- **Trust Signals:** Implement mechanisms to clearly signal when information is being used or stored, helping users understand and trust the system.

### Contextual Memory vs Real-time Response
- **Core Tension:** Strive for a balance between rich context (memory) and fast response times. Ensure that real-time subtitles remain primary, with memory support enhancing rather than delaying interactions.

## Dormant Ideas Worth Reactivating

### Offline Functionality
- **Explore offline capabilities:** Consider how much of the system can operate independently without relying heavily on cloud processing. This could help in scenarios where connectivity is limited.
- **Local Processing Capabilities:** Evaluate potential improvements in local processing to reduce dependency on phone or cloud resources.

## No Fluff

### Direct Action Items
- **Subtitle Placement and Style:** Focus on clear, non-distracting subtitle placement that enhances rather than hinders the user experience.
- **Confidence Indicators:** Develop a system for confidence representation (label + short reason) that builds trust without overwhelming users.
- **Memory Caching:** Determine an appropriate amount of face/name memory to cache locally on the phone to balance speed and privacy.

### Real Implementation Constraints
- **Battery Management:** Prioritize low-power consumption in early hardware designs, ensuring that subtitle delivery remains seamless despite limited resources.
- **User Interaction:** Design interactions around frame touches, minimizing voice command dependencies until proven necessary.

## Open Questions

1. **Subtitle Placement & Style:**
   - What subtitle placement is most usable without becoming distracting?

2. **One-Line Prompts vs Subtitles:**
   - How should one-line prompts visually differ from subtitles to maintain clarity and reduce visual clutter?

3. **Confidence Formats:**
   - Which confidence format builds trust best: label only, label + short reason, or score + label?

4. **Local Memory Caching:**
   - How much face/name memory should be cached locally on the phone for fast lookup and trust?

5. **Interactions Offline/Online:**
   - Which interactions should work offline versus requiring cloud support to ensure a robust user experience across various scenarios?
