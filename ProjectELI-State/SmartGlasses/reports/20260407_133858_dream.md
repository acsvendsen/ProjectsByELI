### Idea 1: Subtitle Placement

1. **Why it benefits the core**

   Ensuring stable subtitle placement rules helps maintain a consistent and predictable user experience. This reduces cognitive load by making it easier for users to focus on the content rather than where subtitles appear, which aligns with the mission of reducing social and cognitive friction.

2. **What small change unlocks it**

   Define a fixed position rule that places subtitles in a central but unobtrusive area, ensuring they remain visible without distracting the wearer during conversations or interactions.

3. **Likely payoff**

   By establishing a stable subtitle placement rule, users will experience consistent and predictable subtitle visibility, reducing confusion and cognitive effort. This leads to an overall smoother user experience, which is critical for trust and daily-use value.

4. **Immediate next probe**
   - Define a fixed position rule that places subtitles centrally on the screen for default conditions.

### Idea 2: Confidence Display

1. **Why it benefits the core**

   Improving the confidence display format ensures that the wearer can trust the system's outputs more reliably. A well-designed confidence label with a short reason will help the wearer understand when to rely on the subtitle or memory support and when to pay closer attention to their surroundings.

2. **What small change unlocks it**

   Define a clear, concise confidence label format that includes both a score and a short reason. For example: "score 0.85 + 'High' + 'Seen recently'; score 0.42 + 'Low' + 'Weak match'; score 0.63 + 'Medium' + 'Name heard once in introduction'. This will provide the wearer with immediate context about the reliability of the information.

3. **Likely payoff**

   By providing a clear and concise confidence display, the system can help the wearer make better decisions during interactions. This reduces cognitive load by giving them immediate cues on the quality of the subtitle or memory support, thus enhancing overall trust and utility.

4. **Immediate next probe**
   - Choose one confidence display format for V1: label only or label plus short reason.

### Idea 3: Memory/Cache Policy

1. **Why it benefits the core**
   - Improving the local cache threshold for name recall strengthens the core attractor of memory trust by ensuring that frequently encountered names are readily available, reducing the need to query the cloud and minimizing privacy concerns.

2. **What small change unlocks it**
   - Define a local cache size limit for names where entries older than X days are evicted based on frequency of recent use.

3. **Likely payoff**
   - This will reduce latency in name recall, enhance the trustworthiness of memory support by providing fast and accurate responses, and improve overall user experience without compromising privacy by reducing unnecessary cloud queries.

4. **Immediate next probe**
   - Set one local cache eviction rule for face/name memory in V1.

### Idea 4: Phone/Cloud Boundary

1. **Why it benefits the core**

   By defining a clear boundary for what stays phone-local versus what falls back to cloud processing, we can ensure that V1 interactions remain low-friction and responsive. This will help in maintaining the core mission of providing real-time, stable subtitles and contextually relevant one-line support without overloading the wearer or draining the device's resources.

2. **What small change unlocks it**

   Define a single task boundary for live subtitle processing where the glasses handle all heavy computation locally. For other tasks like transcript cleanup, memory archive sync, or face/name recall lookup, allow fallback to the cloud only when necessary and latency is acceptable.

3. **Likely payoff**

   This decision will streamline V1 interactions by keeping subtitle generation and one-line support real-time and reliable. It will also reduce battery usage and thermal strain on the glasses, ensuring that core functionality remains robust even under heavy use.

4. **Immediate next probe**

   Define one phone/cloud fallback boundary for live subtitle processing where all heavy computation is handled locally.

### Idea 5: Visual Hierarchy

1. **Why it benefits the core**

   Improving subtitle-vs-one-line priority in visual hierarchy ensures that critical information is prioritized while minimizing distraction. This helps maintain focus during live conversations, ensuring that subtitles remain clear and usable without overwhelming the wearer with additional text.

2. **What small change unlocks it**

   Define a single subtitle placement rule where one-line prompts are hidden when confidence in the subtitle is high (e.g., >0.85) but shown for low-confidence situations to provide context when needed.

3. **Likely payoff**

   By strategically managing subtitle and one-line prompt coexistence, V1 can maintain a clean visual interface that enhances rather than hinders the wearer's ability to follow conversations in noisy environments. This balance improves overall user experience without overwhelming the display with too much information.

4. **Immediate next probe**
   - Define one visual priority rule between subtitles and one-line support in V1.
