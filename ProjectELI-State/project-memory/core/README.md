# Project Memory

This repo stores durable reasoning principles, project continuity, review structures, prompts, and status snapshots that should survive tool changes.

It is not tied to a single host surface or a single project.

## Purpose

Keep safe:
- what should shape future reasoning
- what should survive tool changes
- what should not be flattened or forgotten

## Main layers

- `core/` — durable principles
- `frameworks/` — recurring models and progression rules
- `projects/` — project-specific continuity
- `prompts/` — reusable prompt library
- `templates/` — reusable operating templates
- `status/` — current checkpoints and real gaps
