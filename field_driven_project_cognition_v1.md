# Field-Driven Project Cognition v1

A project is not merely tracked. It is maintained as a continuous internal state where purpose, memory, tension, evidence, and direction remain active between explicit work sessions.

## Layers
1. Core field
2. Active field
3. Memory field
4. Dream layer
5. Sleep layer
6. Reality-check layer
7. Wake outputs

## Key principle
A project should not only remember what was decided. It should preserve the living state from which better decisions emerge.

## Practical translation
- weighted memory objects
- background consolidation
- suggestion generation
- contradiction preservation
- grounded feasibility review
- periodic human-readable field snapshots
